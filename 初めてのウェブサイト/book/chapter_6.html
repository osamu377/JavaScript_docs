初めてのウェブサイト

はじめてのウェブサイト公開（こうかい）

世界中（せかいじゅう）の人（ひと）に自分（じぶん）のサイトを見（み）てもらおう

1. はじめに：ウェブサイトを「公開（こうかい）する」とはどういうことか？

ウェブサイトのコードを書（か）き終（お）え、ファイルが整理（せいり）できたら、次（つぎ）のステップは「公開（こうかい）」です。これは、自分（じぶん）のパソコンの中（なか）にあるファイルを、インターネットという広（ひろ）い海（うみ）に出（だ）す作業（さぎょう）です。

なぜ、わざわざ公開（こうかい）する必要（ひつよう）があるのでしょうか？ それには3つの重要（じゅうよう）な理由（りゆう）があります。

  1. アクセス（閲覧：えつらん）： 世界中（せかいじゅう）のどこからでも、あなたのサイトを見（み）てもらえるようになります。
  2. 検索（けんさく）： Googleなどの検索（けんさく）エンジンで見（み）つかるようになり、多（おお）くの人（ひと）に届（とど）きます。
  3. フィードバックと就職（しゅうしょく）： 友人（ゆうじん）からアドバイスをもらったり、就職活動（しゅうしょくかつどう）のときに「ポートフォリオ（作品集：さくひんしゅう）」としてURLを見（み）せたりできるようになります。

自分（じぶん）だけで楽（たの）しむのではなく、他（ほか）の人（ひと）とつながるために「公開（こうかい）」はとても大切（たいせつ）な一歩（いっぽ）なのです。

次（つぎ）に、公開（こうかい）に欠（か）かせない「場所（ばしょ）」と「名前（なまえ）」の考（かんがえ）方（かた）について説明（せつめい）します。

2. ウェブサイトを動（うご）かすために必要（ひつよう）な2つの基本（きほん）

ウェブサイトを公開（こうかい）するには、現実（げんじつ）の世界（せかい）と同（おな）じように「土地（とち）」と「住所（じゅうしょ）」が必要（ひつよう）です。

  • ウェブホスティング（Web Hosting）
    • 何（なに）であるか： ホスティング会社（がいしゃ）から借（か）りる、サーバー上（じょう）の「ファイルを置（お）くスペース（場所：ばしょ）」のことです。
    • なぜ必要（ひつよう）か： 24時間（じかん）動（うご）いているコンピューターにファイルを置（お）くことで、いつでも誰（だれ）かがサイトを見（み）に来（こ）られるようになります。
  • ドメイン名（Domain Name）
    • 何（なに）であるか： mozilla.org のような、インターネット上（じょう）のユニークな「住所（じゅうしょ）」のことです。
    • なぜ必要（ひつよう）か： 訪問者（ほうもんしゃ）が迷（まよ）わずにあなたのサイトにたどり着（つ）くために必要（ひつよう）です。ドメイン登録業者（とうろくぎょうしゃ）から借（か）りて使（つか）います。

【テクニカル・メンターの分析：別（べつ）々の会社（がいしゃ）で契約（けいやく）したら？】 もしホスティングとドメインを別（べつ）の会社（がいしゃ）で用意（ようい）したときは、設定（せってい）が必要（ひつよう）です。ドメインの設定画面（せっていがめん）で「ネームサーバー」という情報（じょうほう）を入（い）れます。 これは**「電話帳（でんわちょう）」**のような役割（やくわり）です。「このドメイン（名前：なまえ）を見（み）たい人（ひと）は、あっちのホスティング（場所：ばしょ）に行（い）ってください」とインターネットに教（おし）える設定（せってい）です。

基本（きほん）がわかったところで、具体的（ぐたいてき）な公開方法（こうかいほうほう）を比較（ひかく）してみましょう。

3. 自分（じぶん）に合（あ）った公開方法（こうかいほうほう）の比較（ひかく）と評価（ひょうか）

公開（こうかい）する方法（ほうほう）はいくつかあります。自分（じぶん）のレベルや目的（もくてき）に合わせて選（えら）びましょう。

公開方法 特徴（とくちょう：メリット・デメリット） おすすめの人 ホスティングとドメインを購入 自由度（じゆうど）が高（たか）いが、設定（せってい）が難（むずか）しくお金（かね）もかかる。 プロを目指（めざ）す人・ビジネス用 GitHub Pages などの無料ツール 戦略的メリット： 無料（むりょう）で使（つか）えて、プロに必須（ひっす）の**「バージョン管理（かんり）」**を学（まな）べる。 初心者（しょしんしゃ）・個人の練習用 その他の無料サービス（Neocitiesなど） WordPress, Google Sites, Neocitiesなど。簡単（かんたん）だが自由（じゆう）なカスタマイズは少（すこ）し難しい。 すぐに試（ため）したい初心者 ウェブIDE（CodePenなど） ブラウザだけで完結（かんけい）するが、画像（がぞう）の保存（ほぞん）などが難（むずか）しい。 短（みじか）いコードの共有（きょうゆう）・学習用

【プロの視点（してん）：なぜ GitHub なのか？】 プロの現場（げんば）では、ただファイルを置（お）くだけでなく「いつ、誰（だれ）が、どこを直（なお）したか」という記録（きろく）を残（のこ）す「バージョン管理（かんり）」が使（つか）われます。GitHub を使（つか）って公開（こうかい）することは、このプロの技術（ぎじゅつ）を自然（しぜん）に身（み）につけることにつながります。また、GitHub はエンジニアの名刺（めいし）代（が）わりのポートフォリオにもなるので、就職（しゅうしょく）にも有利（ゆうり）です。

【プロのヒント：ISPの活用（かつよう）】 家（いえ）や職場（しょくば）で契約（けいやく）している「インターネット・プロバイダー（ISP）」が、おまけで小（ちい）さなホスティングスペースを貸（か）してくれることもあります。一度（いちど）チェックしてみるのも良（よ）いでしょう。

それでは、最もおすすめの方法の一つである「GitHub」を使った手順を見ていきましょう。

4. 【実践】GitHub Pages（ギットハブページズ）でサイトを公開する手順

現代（げんだい）のウェブ開発（かいはつ）において、GitHub を使（つか）いこなすことは成功（せいこう）への近道（ちかみち）です。

  1. アカウント作成とリポジトリの準備（じゅんび）
  • GitHub にサインアップ（登録：とうろく）します。
  • 「Repository（リポジトリ：ファイルを貯（た）める場所）」を新（あたら）しく作（つく）ります。
  • 名前（なまえ）のルール： リポジトリ名（めい）を必ず 自分のユーザー名.github.io にしてください。
  1. ファイルのアップロード
  • ページの中（なか）にある「uploading an existing file（既存のファイルをアップロード）」というリンクをクリックします。
  • 自分のパソコンのフォルダを開（ひら）き、中（なか）にあるファイルをすべて選択（せんたく）します。
  • ブラウザの画面（がめん）に、ファイルを直接（ちょくせつ）ドラッグ＆ドロップします。
  1. 一番上（いちばんうえ）の階層（かいそう）に置（お）くこと
  • 重要（じゅうよう）： フォルダごとアップロードするのではなく、ファイルそのものをアップロードしてください。index.html がリポジトリの**一番上（ルートディレクトリ）**にないと、サイトは表示（ひょうじ）されません。
  1. 保存（ほぞん）と確認（かくにん）
  • 「Commit changes（変更（へんこう）を保存）」ボタンをクリックします。
  • ブラウザで https://自分のユーザー名.github.io にアクセスします。
  • 注意（ちゅうい）： 公開（こうかい）されるまで、数分（すうふん）かかることがあります。すぐに表示（ひょうじ）されなくても、数分待（すうふんま）ってからもう一度（いちど）アクセスしてみてください。

5. 次のステップ：より高度（こうど）なツールと学習（がくしゅう）リソース

GitHub での公開（こうかい）に慣（な）れたら、次（つぎ）のレベルに進（すす）んでみましょう。

  • Netlify（ネットリファイ）： GitHub と連携（れんけい）して、修正（しゅうせい）した内容（ないよう）をすぐに見（み）ることができるプレビュー機能（きのう）などが強力（きょうりょく）です。
  • Fly.io： データベースを使（つか）うような、より複雑（ふくざつ）なアプリケーションを公開（こうかい）するのに適（てき）しています。
  • MDNの関連ガイド： 「ウェブサーバーとは何（なに）か」「ドメイン名（めい）の理解（りかい）」などのリソースを読（よ）むと、技術（ぎじゅつ）の裏側（うらがわ）がもっとよく分（わ）かります。

まとめ ウェブサイトを公開（こうかい）することは、あなたのアイデアや技術（ぎじゅつ）を世界（せかい）に証明（しょうめい）することです。最初は難（むずか）しいかもしれませんが、一度（いちど）覚（おぼ）えてしまえば、あなたは自由（じゆう）に情報（じょうほう）を発信（はっしん）できるクリエイターになります。

留学生（りゅうがくせい）のみなさん、自分（じぶん）の作（つく）ったサイトを自信（じしん）をもって公開（こうかい）してください。あなたの作品（さくひん）を世界（せかい）が待（ま）っています。応援（おうえん）しています！
