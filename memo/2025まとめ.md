# JavaScriptの記述ルール

## 🌐 Webページにおける3つの技術の役割

### 1. HTML（HyperText Markup Language）

*   役割：Webページの「骨組み」を作る。
*   例：見出し、段落、画像、リンクなどの構造を定義。
*   イメージ：家の「柱」や「壁」のようなもの。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <h1>こんにちは！</h1>
    <p>これはHTMLで書かれた段落です。</p>
</body>
</html>
```



### 2. CSS（Cascading Style Sheets）

*   役割：Webページの「見た目」を整える。
*   例：文字の色、サイズ、背景色、レイアウトなどを指定。
*   イメージ：家の「ペンキ」や「インテリア」のようなもの。

```css
h1 {
  color: blue;
  font-size: 36px;
}
```

<div style="page-break-before:always"></div>


### 3. JavaScript

*   役割：Webページに「動き」や「機能」を追加する。
*   例：ボタンをクリックしたらメッセージを表示、フォームの入力チェックなど。
*   イメージ：家の「電気」や「機械装置」のようなもの。

```javascript
alert("こんにちは！");
```



## 📄 HTMLファイルにCSSとJavaScriptを含める方法

### ✅ 基本のフォーマット（例）

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>サンプルページ</title>

  <!-- CSSはここに書く -->
  <style>
    h1 {
      color: green;
    }
  </style>
</head>
<body>

  <h1>ようこそ！</h1>
  <button onclick="sayHello()">クリックしてね</button>

  <!-- JavaScriptはここに書く -->
  <script>
    function sayHello() {
      alert("こんにちは！");
    }
  </script>

</body>
</html>
```



### 🔧補足

*   CSSは`<style> </style>`タグで`<head>`内に書くことが多いです。
*   JavaScriptは`<script> </script>`タグで`<body>`の最後に書くと、ページの読み込みがスムーズになります。
*   外部ファイルとして分けることもできます（例：`style.css`, `script.js`）。

## 🧠 JavaScriptの記述ルール（初心者向けまとめ）

### 1. 文の終わりにはセミコロン（`;`）をつける
- 命令の終わりにセミコロンをつけることで、コードの区切りが明確になります。
```javascript
let name = "Taro";
```

---

### 2. 変数の宣言には `let` や `const` を使う
- `let`：変更可能な変数
- `const`：変更不可の定数
```javascript
let age = 20;
const birthYear = 2005;
```

---

### 3. 文字列は `" "` または `' '` で囲む
- どちらでもOKですが、統一して使うのが良い習慣です。
```javascript
let greeting = "こんにちは";
```

---

### 4. インデント（字下げ）でコードを見やすくする
- 通常はスペース2つまたは4つで揃えます。
```javascript
function sayHello() {
  console.log("こんにちは！");
}
```

---

### 5. コメントを使って説明を書く
- `//` を使ってコードの説明を記述できます。
```javascript
// これは挨拶を表示する関数です
function sayHello() {
  console.log("こんにちは！");
}
```

---

### 6. 命名はわかりやすく、英語で書く
- 変数や関数名は意味のある英語で書くのが一般的です。
```javascript
let userName = "Taro";
function showMessage() {
  console.log("ようこそ！");
}
```

---

### 7. 大文字と小文字は区別される
- `Name` と `name` は別の変数として扱われます。
```javascript
let name = "Taro";
let Name = "Hanako";  // ← 別の変数
```

---

### 8. 文字列やコメント以外は半角文字で記述する
- JavaScriptのコードは基本的にすべて半角英数字で書きます。
- `"こんにちは"` や `// コメント` の中は全角でもOKですが、それ以外は全角文字を使わないように注意しましょう。

❌ ダメな例（全角スペースや全角記号）：
```javascript
ｌｅｔ　name＝"Taro";  // ← 全角が混ざっていてエラーになる可能性あり
```

✅ 正しい例（すべて半角）：
```javascript
let name = "Taro";
```

# イベントハンドラ

## 🎯 イベントハンドラとは？

**イベントハンドラ**とは、ユーザーの操作（クリック、マウス移動、ページ読み込みなど）に応じて、JavaScriptで何かの処理を実行する仕組みです。

*   「イベント」＝ ユーザーの操作やブラウザの動き
*   「ハンドラ」＝ そのイベントが起きたときに実行される関数（処理）

📌 例：ボタンをクリックしたらメッセージを表示する

```html
<button onclick="alert('こんにちは！')">クリックしてね</button>
```

***

## 🖱️ `onclick`（クリックされたとき）

*   要素が**クリックされたとき**に実行されるイベント。
*   よく使われるイベントの1つです。

```html
<button onclick="sayHello()">あいさつ</button>

<script>
  function sayHello() {
    alert("こんにちは！");
  }
</script>
```

***

## 🐭 `onmouseover` / `onmouseout`（マウスが乗ったとき・離れたとき）

*   `onmouseover`：マウスカーソルが要素の上に来たとき
*   `onmouseout`：マウスカーソルが要素から離れたとき

```html
<p onmouseover="this.style.color='red'" onmouseout="this.style.color='black'">
  マウスを乗せてみてください
</p>
```

***

<div style="page-break-before:always"></div>

## 📦 `onload`（ページが読み込まれたとき）

*   ページ全体が読み込まれたときに実行されるイベント。
*   初期化処理などに使います。

```html
<body onload="init()">

<script>
  function init() {
    alert("ページが読み込まれました！");
  }
</script>
```

***

## 🧩 よく使うイベントハンドラ

以下は、JavaScriptでよく使われる**イベントハンドラ**を、3つのカテゴリに整理したものです。

---

### 🖱️ 1. マウス操作に関するイベント

| イベント名 | 説明 | 使用例 |
|------------|------|--------|
| `onclick` | 要素がクリックされたとき | ボタンを押したときに処理を実行 |
| `ondblclick` | ダブルクリックされたとき | 2回クリックで別の動作を実行 |
| `onmouseover` | マウスが要素の上に乗ったとき | テキストの色を変えるなど |
| `onmouseout` | マウスが要素から離れたとき | 元の色に戻すなど |
| `onmousemove` | マウスが動いたとき | マウス位置を表示するなど |
| `oncontextmenu` | 右クリックされたとき | カスタムメニューを表示するなど |

---

### 📦 2. ページの読み込み・移動に関するイベント

| イベント名 | 説明 | 使用例 |
|------------|------|--------|
| `onload` | ページや画像などが読み込まれたとき | 初期化処理を実行 |
| `onunload` | ページが閉じられるとき | 確認メッセージを表示するなど |
| `onresize` | ウィンドウサイズが変更されたとき | レイアウトを調整するなど |
| `onscroll` | ページがスクロールされたとき | スクロール位置に応じた処理 |
| `onerror` | エラーが発生したとき | 画像の読み込み失敗時に代替処理を行うなど |

---

<div style="page-break-before:always"></div>

### 📝 3. フォーム関連のイベント

| イベント名 | 説明 | 使用例 |
|------------|------|--------|
| `onchange` | 入力欄の内容が変更されたとき | ドロップダウンの選択変更など |
| `oninput` | 入力欄に文字が入力されたとき | リアルタイムで文字数をカウント |
| `onsubmit` | フォームが送信されたとき | 入力チェックを行うなど |
| `onreset` | フォームがリセットされたとき | 入力内容を初期化したときの処理 |
| `onfocus` | 入力欄が選択されたとき | 背景色を変えるなど |
| `onblur` | 入力欄の選択が外れたとき | 入力内容の確認など |
| `onkeydown` | キーが押されたとき | 特定のキー操作に反応 |
| `onkeyup` | キーが離されたとき | 入力完了後の処理など |

---

### ✅ 補足
- これらのイベントは、HTMLタグに直接書く方法（例：`<input oninput="..." />`）と、JavaScriptで後から設定する方法（例：`element.addEventListener(...)`）の両方で使えます。
- 初心者には、まずHTML内に直接書く方法が理解しやすいです。

# コンソールの使い方

## 🖥️ Webブラウザのコンソールとは？

**コンソール**とは、Webブラウザに内蔵されている開発者向けのツールの一部で、JavaScriptの動作確認やエラーのチェックができる場所です。

*   JavaScriptのコードを直接入力して試すことができます。
*   `console.log()` などを使って、プログラムの途中経過や値を表示できます。
*   エラーが発生したときには、**エラーメッセージ**が表示されるので、原因を調べるのに役立ちます。

***

## 🧭 コンソールを表示させる方法（Edge・Chrome）

以下の方法で、コンソールを表示できます：

*   **Windowsの場合**：\
    → キーボードの **`F12`キー** を押す\
    → または、右クリック → 「検証」 → 上部の「Console」タブを選択

*   **Macの場合**：\
    → `Command + Option + I` を押す

📌 表示された画面の「Console」タブが、JavaScriptのコンソールです。

***

## 📝 `console.log()` で文字を表示させる具体例

JavaScriptで、コンソールにメッセージを表示するには `console.log()` を使います。

```html
<!DOCTYPE html>
<html>
<head>
  <title>コンソールの例</title>
</head>
<body>
  <button onclick="showMessage()">メッセージ表示</button>

  <script>
    function showMessage() {
      console.log("こんにちは！これはコンソールに表示されるメッセージです。");
    }
  </script>
</body>
</html>
```

✅ このコードを実行してボタンをクリックすると、**コンソールにメッセージが表示されます**。

***

## ⚠️ エラーメッセージを確認する具体例

JavaScriptで間違ったコードを書くと、コンソールにエラーが表示されます。

```html
<!DOCTYPE html>
<html>
<head>
  <title>エラーの例</title>
</head>
<body>
  <script>
    // 間違った関数名（存在しない関数を呼び出している）
    notDefinedFunction();
  </script>
</body>
</html>
```

✅ このコードを実行すると、コンソールに次のようなエラーが表示されます：

    Uncaught ReferenceError: notDefinedFunction is not defined

🔍 このように、**エラーの内容と場所**が表示されるので、修正のヒントになります。

# 関数の基本

## JavaScriptの関数とは

**関数**（かんすう、Function）は、特定の処理をひとまとまりにした「**命令セット**」のようなものです。

例えるなら、**自動販売機**のようなものです。

  * **自動販売機**：
      * ボタン（命令）を押す
      * 飲み物が出てくる（結果）
  * **関数**：
      * 関数を **呼び出す**（命令）
      * 定義した処理を実行する（結果）

何度も同じ処理を書き直す手間がなくなり、コード全体を **整理しやすく**、**わかりやすく** するメリットがあります。

-----

## 関数の作り方

JavaScriptで関数を作るには、主に以下の形式を使います。

### `function` キーワードを使う方法

これが最も基本的な関数の作り方です。

```javascript
// 関数を「定義」する
function sayHello() {
  // ここに実行したい処理を書く
  console.log("こんにちは！JavaScriptの世界へようこそ！");
  alert("関数が実行されました！");
}

// 関数を「呼び出す」
sayHello();
```

  * `function`：これは「今から関数を定義しますよ」という合図です。
  * `sayHello`：**関数名**です。どんな処理をするのかわかる名前にします。
  * `()`：関数の名前の後に必ずつけます。
  * `{}`：**関数本体**（**ブロック**）と呼ばれ、この中に実行したい処理を記述します。
  * `sayHello()`：定義した関数を実際に**実行**（**呼び出し**）するための記述です。

-----

<div style="page-break-after:always"></div>

## 関数名のルール

関数名には、プログラムを読みやすくするために、いくつかの**命名ルール**と**慣習**があります。

### 命名ルール（守るべきこと）

1.  **英数字、アンダースコア (`_`)、ドル記号 (`$`)** のみ使用できます。
2.  **数字から始めることはできません**（例：`1stFunction` は $\times$）。
3.  **予約語**（`function` や `if` など、JavaScriptが特別な意味で使う言葉）は使えません。

### 慣習（推奨されること）

  * **動詞から始める**: 関数は「何かをする」ものなので、`get` (取得する)、`show` (表示する)、`calculate` (計算する)、`handle` (処理する) などの**動詞**から始めるのが一般的です。
  * **キャメルケース (camelCase)** を使う:
      * 最初の単語は小文字で始め、2つ目以降の単語の先頭だけを大文字にする方法です。
      * 例：`showUserData`、`showMessage`

-----

## イベントハンドラから関数を呼び出す

HTMLの要素がクリックされたり、マウスが乗ったりといった「**イベント**」が発生したときに、特定の関数を自動的に実行させる方法です。

ここでは、HTMLのボタンが**クリックされた**ときに、定義したJavaScriptの関数を実行する例を見てみましょう。

### HTMLファイル内の記述例

この例では、`<script>`タグ内にJavaScriptの関数を書き、HTMLのボタン要素の`onclick`属性からその関数を呼び出しています。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>関数とイベント</title>
</head>
<body>
    <button onclick="sayThankYou()">ありがとうボタン</button>
    <script>
        // JavaScriptの関数を定義
        function sayThankYou() {
            alert("ボタンをクリックしてくれてありがとう！");
            console.log("クリックイベントが発生し、関数が実行されました。");
        }
    </script>
</body>
</html>
```

  * **`onclick` 属性**: これはHTMLの**イベントハンドラ**の一つで、「クリックされたときに実行する処理」を指定できます。
  * **`"sayThankYou()"`**: `onclick`属性の値として、定義した**関数名と丸括弧**を記述することで、ボタンがクリックされた瞬間にこの関数が呼び出され、`alert()`の処理が実行されます。

このように、関数を使うと、**HTMLの操作**と**JavaScriptの動作**をきれいに連携させることができます。


# 変数の利用

JavaScriptを学ぶ初心者向けに、**変数**について説明します。変数は、データを一時的に保存しておくための「**名前のついた箱**」のようなものだと考えてください。📦

-----

## 💡 変数とは (What is a Variable?)

**変数**とは、プログラムの中で扱うデータ（数値や文字列など）を**保存しておくための入れ物**に付ける**名前**です。

例えば、テストの点数や、ユーザーの名前など、プログラムの実行中に変わる可能性のあるデータを記憶するために使われます。

### 例え

変数は、引き出しや箱に「名前（ラベル）」を貼って、その中に「データ」を入れるようなイメージです。

  * **名前（ラベル）** $\rightarrow$ 変数名 (`age`, `myName` など)
  * **箱の中身** $\rightarrow$ データ (数値の `20`, 文字列の `"山田"` など)

-----

## 1\. 変数宣言 (Variable Declaration)

**変数宣言**とは、JavaScriptで新しく「箱」（変数）を使うことをシステムに知らせる行為です。宣言することで、その変数名を使えるようになります。

JavaScriptでは、主に以下のキーワードを使います。

1.  **`let`**:
      * **最も一般的で推奨される方法**です。
      * 宣言後に**値を変更**（再代入）することができます。
      * 例: `let score;`
2.  **`const`**:
      * 一度値を代入したら、**後から値を変更できない**（定数）変数を宣言するときに使います。
      * **値が変わらない**もの（円周率、設定値など）に使います。
      * 例: `const MAX_LEVEL = 99;`

### 📝 宣言の例

```javascript
// 'myName'という名前の変数を宣言
let myName;

// 'PI'という名前の変数を宣言し、同時に初期値も代入（constは基本的に初期値が必要です）
const PI = 3.14;
```

-----

## 2\. 変数に数値を代入 (Assigning a Number to a Variable)

変数に**数値**のデータを入れる場合、数字をそのまま書きます。整数でも小数でも構いません。

代入には **代入演算子** の `=` (イコール) を使います。これは数学の「等しい」という意味ではなく、「**右側の値を、左側の変数に入れる**」という意味です。

### 📝 代入の例

```javascript
// 変数 'age' を宣言
let age;

// 変数 'age' に数値 20 を代入
age = 20;
console.log(age); // 出力: 20

// 変数 'temperature' を宣言と同時に、小数 25.5 を代入
let temperature = 25.5;
console.log(temperature); // 出力: 25.5
```

-----

## 3\. 変数に文字列を代入 (Assigning a String to a Variable)

**文字列**（テキストのデータ）を変数に入れる場合、その文字列を**シングルクォーテーション (`'`)** または **ダブルクォーテーション (`"`)** で**必ず囲みます**。

クォーテーションで囲むことで、JavaScriptはそのデータが文字として扱われることを認識します。

### 📝 代入の例

```javascript
// 変数 'name' に文字列を代入 (ダブルクォーテーションを使用)
let name = "山田太郎";
console.log(name); // 出力: 山田太郎

// 変数 'greeting' に文字列を代入 (シングルクォーテーションを使用)
const greeting = 'こんにちは！';
console.log(greeting); // 出力: こんにちは！

// 宣言と代入を同時に行うのが一般的です
let message = "勉強頑張ろう！";
```

<div style="page-break-after:always"></div>

### 💡 ポイント

`let`で宣言した変数は、後から中身を別の種類のデータに変更することもできます。

```javascript
let data = 100; // 最初は数値
data = "完了";   // 後から文字列に変更 (再代入)
console.log(data); // 出力: 完了
```

# 変数の演算

## JavaScriptの演算子（Operator）とは

**演算子**とは、**値（データ）を操作したり、計算したり、比較したりするための記号**のことです。

例えば、数学で使う「+」や「=」なども演算子の一種です。JavaScriptでは、これらの演算子を使ってさまざまな処理を行います。

-----

## 1\. 算術演算子 🧮

算術演算子は、主に**数値の計算**に使われます。学校で習う算数とほぼ同じです。

| 演算子 | 意味 | 例 | 結果 |
| :---: | :--- | :--- | :--- |
| **`+`** | **足し算** (加算) | `5 + 3` | `8` |
| **`-`** | **引き算** (減算) | `10 - 4` | `6` |
| **`*`** | **掛け算** (乗算) | `6 * 2` | `12` |
| **`/`** | **割り算** (除算) | `10 / 2` | `5` |
| **`%`** | **余り** (剰余) | `10 % 3` | `1` (10を3で割った余り) |

```javascript
let x = 15;
let y = 4;

console.log(x + y); // 19
console.log(x * y); // 60
console.log(x % y); // 3 (15 ÷ 4 = 3 余り 3)
```

-----

## 2\. 代入演算子 ⬅️

代入演算子は、**右側の値を左側の変数に格納**するために使われます。

### 基本の代入

| 演算子 | 意味 | 例 |
| :---: | :--- | :--- |
| **`=`** | **代入** | `let score = 100;` (変数 `score` に `100` を格納) |

<div style="page-break-after:always"></div>

### 複合代入演算子

これは、**計算と代入を一度に行う**ための便利な演算子です。

| 演算子 | 意味 | 動作 (簡略化前) | 例 |
| :---: | :--- | :--- | :--- |
| **`+=`** | 足して代入 | `a = a + b` | `a += 5;` |
| **`-=`** | 引いて代入 | `a = a - b` | `a -= 2;` |
| **`*=`** | 掛けて代入 | `a = a * b` | `a *= 3;` |
| **`/=`** | 割って代入 | `a = a / b` | `a /= 2;` |

**例:**

```javascript
let num = 10;
num += 5;  // これは num = num + 5; と同じ意味です。
console.log(num); // 15

num *= 2;  // これは num = num * 2; と同じ意味です。
console.log(num); // 30
```

-----

## 3\. インクリメントとデクリメント 📈📉

これは、変数の値を\*\*「1」だけ増やす\*\*、または\*\*「1」だけ減らす\*\*ための専用の演算子です。ループ処理などで頻繁に使われます。

| 演算子 | 意味 | 動作 (簡略化前) |
| :---: | :--- | :--- |
| **`++`** | **インクリメント** | `a = a + 1;` または `a += 1;` |
| **`--`** | **デクリメント** | `a = a - 1;` または `a -= 1;` |

**例:**

```javascript
let count = 5;

count++; // count を 1 増やす
console.log(count); // 6

count--; // count を 1 減らす
console.log(count); // 5
```

> 💡 **少し発展：** `++count`（前置）と `count++`（後置）は、どちらも結果的に `count` を1増やしますが、その行での**値が評価されるタイミング**が異なります。最初はあまり気にせず、**変数名の直後に `++` をつける**という使い方から覚えましょう。

-----

<div style="page-break-after:always"></div>

## 4\. 文字列に対する `+` 演算子 🔗

算術演算子の「+」は通常、足し算に使われますが、JavaScriptでは**文字列**に対しても特別な役割があります。

### 結合（連結）

文字列と文字列の間で `+` 演算子を使うと、それらの文字列が\*\*結合（連結）\*\*されて一つの大きな文字列になります。

```javascript
let firstName = "太郎";
let lastName = "山田";

// 文字列の結合
let fullName = lastName + firstName;
console.log(fullName); // "山田太郎"

// スペースを挟んで結合
let greeting = "こんにちは、" + fullName + "さん！";
console.log(greeting); // "こんにちは、山田太郎さん！"
```

### 文字列と数値の結合

文字列と数値を `+` 演算子で組み合わせようとすると、JavaScriptは数値を**自動的に文字列に変換**してから結合します。

```javascript
let age = 18;
let message = "私の年齢は" + age + "歳です。";

// 18 が文字列に変換され、結合される
console.log(message); // "私の年齢は18歳です。"
```

> **注意点:** `+` 演算子では、少しでも文字列が関わると「足し算」ではなく「結合」が優先されます。

```javascript
console.log("2" + 3);  // "23" になる（文字列結合）
console.log(2 + 3);    // 5 になる（足し算）
```

# 配列の利用

## 配列とは

**配列（Array）** は、**複数のデータをひとつの変数にまとめて格納する**ための「リスト」のようなものです。

例えば、テストの点数や、好きな果物の名前など、関連する複数のデータをまとめて扱いたいときに便利です。

  * 配列内のひとつひとつのデータは「**要素**」と呼ばれます。
  * 要素は、左から順番に「**インデックス（添字）**」と呼ばれる番号で管理されています。
  * JavaScriptでは、このインデックスは必ず**0から**始まります。

<hr>

## 配列の宣言とデータの代入

JavaScriptで配列を新しく作るには、主に **角括弧（`[]`）** を使います。

### 1\. 宣言と同時にデータを代入する

最も一般的な方法です。

```javascript
// 変数`fruits`に3つの文字列（要素）を持つ配列を代入
const fruits = ["りんご", "バナナ", "みかん"];
```

  * `const`：配列を格納する変数を宣言します（const キーワードを使っても、配列の内容は自由に変更できます）。
  * `[]`：この中に、カンマ（`,`）で区切って要素を記述します。


### 2\. 空の配列を宣言してから、後でデータを代入する

```javascript
// まず空の配列を宣言
const scores = [];

// 後から要素を代入
scores[0] = 85; // インデックス 0 に '85' を代入
scores[1] = 92; // インデックス 1 に '92' を代入

console.log(scores); // 出力: [85, 92]
```

【参考】

const キーワードを使って配列を定義した場合、たとえ話でいうと、

1. ファイルを参照するためのパス（例えば、`C:\Users\student1\Documents\テキスト ドキュメント.txt`）を変更できないようにする
2. それでも、`テキスト ドキュメント.txt`の中身を書き換えることはできる
3. ただし、`テキスト ドキュメント.txt`のファイル名を変えようとしたり、 `C:\Users\student1\Downloads\` に移動しようとすると、エラーになる

ような状態と考えてください。

-----

## 配列の読み込み

配列に格納されている特定の要素を取り出して利用するときは、**配列名の後に角括弧でインデックスを指定**します。

**【重要ポイント】** インデックスは**0から始まる**ことを忘れないでください。

### 例

先ほどの配列 `fruits` を使って説明します。

```javascript
const fruits = ["りんご", "バナナ", "みかん"];
// インデックス:  0       1         2

console.log(fruits[0]); // インデックス 0 の要素を出力 -> "りんご"
console.log(fruits[1]); // インデックス 1 の要素を出力 -> "バナナ"
console.log(fruits[2]); // インデックス 2 の要素を出力 -> "みかん"
```

<hr>

## 配列の長さ

配列にいくつの要素が格納されているか、**配列の要素の数**を知りたいときに使います。

配列の直後に「**`.length`**」を付けて取得します。

### 例

```javascript
const fruits = ["りんご", "バナナ", "みかん"];
const length = fruits.length;

console.log(length); // 出力: 3
```

この `.length` は、配列のすべての要素を順番に処理する「**繰り返し処理（ループ）**」を行うときによく使われます。

例えば、配列の最後の要素の**インデックス**は、`配列の長さ - 1` で求めることができます。

```javascript
const lastIndex = fruits.length - 1; // 3 - 1 = 2
console.log(fruits[lastIndex]); // インデックス 2 の要素を出力 -> "みかん"
```

# C言語とJavaScriptの配列の違い

C言語の配列とJavaScriptの配列は、どちらも複数のデータを扱うための機能ですが、その**性質、柔軟性、そしてメモリ上での動作**に大きな違いがあります。

| 特徴 | C言語の配列 (例: `int arr[5];`) | JavaScriptの配列 (例: `const arr = [];`) |
| :--- | :--- | :--- |
| **データ型** | **単一の型**（全て`int`、`char`など） | **混合可能**（数値、文字列、関数、オブジェクトなど） |
| **配列の長さ** | **固定**。宣言時に長さを指定し、後から変更できない。 | **可変**。要素の追加や削除で、長さは自動的に変化する。 |
| **メモリ** | メモリ上で要素が**連続**して配置される。 | 要素は連続しているとは限らない（実体は**オブジェクト**）。 |
| **インデックス** | 0から始まる。境界外にアクセスすると未定義の動作（危険）。 | 0から始まる。境界外にアクセスすると`undefined`が返る（安全）。 |

-----

## 1\. データ型と柔軟性の違い

### C言語の配列（静的・厳格）

C言語の配列は**静的**で**厳格**です。

1.  **単一のデータ型**: 配列の全ての要素は、宣言時に指定した**同じデータ型**でなければなりません。例えば、`int arr[5];` なら、すべての要素は整数型でなければなりません。
2.  **固定長**: 配列の長さは、**コンパイル時または実行前に固定**されます。宣言後に要素を追加して長さを変えることはできません。

### JavaScriptの配列（動的・柔軟）

JavaScriptの配列は**動的**で**柔軟**です。

1.  **型の混合**: 異なるデータ型の要素を**一つの配列に混在**させることができます（例：`[10, "Hello", true, {key: 'value'}]`）。
2.  **可変長**: 配列の長さは決まっておらず、実行中に要素を追加したり削除したりすることで、**自動的に長さが変わります**。

-----

## 2\. 実体とメモリ上の動作の違い

### C言語の配列

C言語の配列は、**メモリの連続した領域**を確保します。

  * 配列名（`arr`）は、**配列の最初の要素のメモリのアドレス**（ポインタ）とみなされます。
  * この構造により、高速な要素へのアクセス（`arr[i]`）が可能です。

### JavaScriptの配列

JavaScriptの配列は、C言語のような連続したメモリ領域ではありません。

  * 実体は特殊な**オブジェクト**です。インデックス（`0`, `1`, `2` など）がプロパティ名として機能し、要素がその値として格納されます。
  * 要素は、メモリ上で**連続している保証はありません**。これにより、型の混合や可変長が実現されています。

-----

## 3\. 境界外アクセス時の違い

### C言語

宣言した配列の範囲外のインデックスにアクセスすると、**予期しないメモリ領域を読み書き**することになります。これは**バッファオーバーフロー**などの深刻なバグやセキュリティ問題を引き起こす可能性があり、未定義の動作として扱われます。

### JavaScript

宣言した配列の範囲外のインデックスにアクセスした場合、エラーになるのではなく、**`undefined`** という値が返されます。新しいインデックスに値を代入すれば、配列の長さが自動的に伸びます。

```javascript
const jsArr = [10, 20];
console.log(jsArr[10]); // undefined が返る (安全)

jsArr[10] = 100; // 配列の長さが 11 に伸びる (自動で拡張)
```

# 関数の引数

関数の引数についての説明です。

-----

## 📝 関数の引数とは

関数の**引数（ひきすう）とは、関数が処理を実行するために外部から受け取る値**のことです。

関数は、特定の処理を行うための一連の命令をまとめたものです。引数を使うことで、**関数が処理する対象のデータ**を渡したり、**処理の内容を柔軟に変えたり**することができます。

たとえば、「2つの数を足し算する関数」を作る場合、足し算する「2つの数」が引数になります。

-----

## 💻 引数の定義方法（仮引数）

関数を**定義**する際に、関数が受け取る値を入れるための「箱」として名前をつけるのが **仮引数（かりひきすう）** です。

これは、関数が処理の中で使用する**ローカルな変数**のようなものです。

### 定義の書式

関数の名前の後の**丸かっこ `()` の中**に、受け取りたい引数の名前を記述します。

```javascript
// 関数宣言の場合
function 関数名(仮引数1, 仮引数2, ...) {
  // 関数の処理で仮引数1や仮引数2を使う
}

// 関数式（アロー関数）の場合
const 関数名 = (仮引数1, 仮引数2, ...) => {
  // 関数の処理
};
```

### 例

「挨拶をする関数」で、**誰に**挨拶をするかという名前を引数として受け取る場合。

```javascript
function greet(name) { // 'name' が仮引数
  console.log("こんにちは、" + name + "さん！");
}
```

この例では、`name` が仮引数です。

-----

## 🛠️ 引数の指定方法（実引数）

定義した関数を **実行（呼び出し）** する際に、実際に渡す値のことを **実引数（じつひきすう）** と呼びます。

### 指定の書式

関数を呼び出す際に、関数の名前の後の**丸かっこ `()` の中**に、渡したい**値や変数**を記述します。

```javascript
関数名(実引数1, 実引数2, ...);
```

### 例

先ほどの `greet` 関数を呼び出す場合。

```javascript
greet("太郎"); // "太郎" が実引数
// 出力: こんにちは、太郎さん！

let person = "花子";
greet(person); // 変数も実引数として渡せる
// 出力: こんにちは、花子さん！
```

関数が実行されるとき、実引数として渡された値（例: `"太郎"`）が、関数の定義で指定された対応する仮引数（例: `name`）に代入されて、関数の処理が実行されます。

-----

## 🔢 複数の引数

関数は、必要に応じて**複数の引数**を受け取ることができます。

複数の引数を定義・指定する場合は、それぞれを**コンマ `,` で区切ります**。

### 定義と指定の例

「2つの数を足して表示する関数」の例。

```javascript
// 複数の仮引数をコンマで区切って定義
function add(num1, num2) { // num1 と num2 が仮引数
  let result = num1 + num2;
  console.log("合計は " + result + " です。");
}

// 複数の実引数をコンマで区切って指定
add(5, 10); // 5 が num1 に、10 が num2 に渡される
// 出力: 合計は 15 です。

add(100, 50);
// 出力: 合計は 150 です。
```

複数の引数を使うことで、関数に**複数のデータ**を与えたり、**複数の設定**を渡したりすることが可能になり、より汎用的な関数を作ることができます。

# .textContentプロパティと.innerHTMLプロパティ

取得したHTML要素の**内容**を操作する `.textContent` と `.innerHTML` プロパティについて説明します。これらは、ウェブページ上のテキストや構造をJavaScriptから動的に変更するためによく使われます。

-----

## 1\. `.textContent` プロパティ

`.textContent` は、要素の**内部にあるすべてのテキストデータ**を操作するために使われます。

| 操作 | 説明 |
| :--- | :--- |
| **取得** | 要素内の**すべてのテキスト**（HTMLタグは無視されます）を文字列として取得します。 |
| **書き換え** | 新しい文字列を代入すると、要素の**既存のコンテンツ全体**が、その新しい**プレーンテキスト**（装飾のない文字）に置き換えられます。 |

### ✏️ テキストを書き換える方法

新しく設定したいテキストを代入するだけです。HTMLタグを文字列として含めても、それは単なる**文字**として表示され、HTML要素としては解釈されません。

**【コード例】**

```javascript
// HTML: <p id="message">こんにちは、世界！</p>
let element = document.querySelector("#message");

// テキストを書き換え
element.textContent = "新しいメッセージです！";
// 結果HTML: <p id="message">新しいメッセージです！</p>

// HTMLタグを含む文字列を代入しても、タグは無視されそのまま表示されます
element.textContent = "これは <strong>強調</strong> されません。";
// 結果HTML: <p id="message">これは <strong>強調</strong> されません。</p>
// ユーザーの画面には、<strong>という文字も含めて表示されます。
```

-----

## 2\. `.innerHTML` プロパティ

`.innerHTML` は、要素の**内部にあるHTMLコンテンツ（構造）全体**を操作するために使われます。

| 操作 | 説明 |
| :--- | :--- |
| **取得** | 要素内の**HTMLタグを含む**コンテンツ全体を文字列として取得します。 |
| **書き換え** | 新しい文字列を代入すると、要素の既存のコンテンツ全体が、その新しい**HTML構造**に置き換えられます。 |

### 🖼️ HTMLを書き換える方法

新しく設定したいHTML構造を文字列として代入します。代入された文字列に含まれるHTMLタグは、ブラウザによって**HTML要素として解釈・描画**されます。

**【コード例】**

```javascript
// HTML: <div id="content">元々のテキスト</div>
let element = document.querySelector("#content");

// HTML構造を含む文字列を書き換え
element.innerHTML = "<h2>新しい見出し</h2><p>そして段落。</p>";
/* 結果HTML: 
<div id="content">
  <h2>新しい見出し</h2>
  <p>そして段落。</p>
</div> 
*/

// 強調タグ（<strong>）も正しくHTMLとして解釈されます
element.innerHTML = "これは <strong>強調</strong> されます。";
// ユーザーの画面では、「強調」の部分が太字になります。
```

### ⚠️ セキュリティに関する注意点

`.innerHTML` は強力で便利ですが、ユーザーが入力したデータをそのまま代入すると、悪意のあるスクリプトを実行されてしまう（**クロスサイトスクリプティング、XSS**）セキュリティ上のリスクがあります。

  * **安全な使い方**: 自分で用意した、信頼できる固定のHTML構造を設定する場合。
  * **危険な使い方**: ユーザーのコメントなど、**外部から入力された内容**をHTMLとして解釈させてしまう場合。

**プレーンテキスト**を代入するだけであれば、`.textContent`を使う方が**安全**です。もしHTML構造の変更が必要な場合は、セキュリティに注意を払うか、より安全なDOM操作メソッド（`createElement`など）の使用を検討してください。

# セレクタ

JavaScriptでHTMLの要素を取得する際の**キーとなるもの**（セレクタ）について、初心者の方にも分かりやすいようにまとめます。💻

JavaScriptがHTMLを操作するためには、まず「どのHTML要素を操作したいか」を正確に特定する必要があります。その「特定するための目印」となるのが、ここで説明するIDやClassなどのセレクタです。

-----

## JavaScriptでHTML要素を取得するための主なキー（セレクタ）

HTML要素を取得する際によく使われる、主な目印（属性やタグ名）は以下の通りです。

| キー | HTMLでの目印 | JavaScriptでの主な取得方法 | 特徴 |
| :--- | :--- | :--- | :--- |
| **ID** | `id="idname"` | `document.getElementById('idname')` | **固有の識別子**。一つのHTMLページで**一意**である必要があります。特定の一つの要素を確実に取得するのに最適です。 |
| **Class** | `class="classname"` | `document.getElementsByClassName('classname')` | **グループ化**のための目印。複数の要素に同じクラス名をつけられます。特定の**グループ**の要素をまとめて取得したい場合に便利です。 |
| **タグ名** | 例: `<div>`, `<p>`, `<a>` | `document.getElementsByTagName('div')` | HTMLの**要素の種類**そのもの。ページ内の特定のタグ名の要素（例：すべての`<div>`）をまとめて取得します。 |
| **CSSセレクタ** | 例: `.classname`, `#idname`, `div > p` | `document.querySelector('セレクタ')`<br>`document.querySelectorAll('セレクタ')` | **CSSのセレクタ**の記法（ID, Class, 属性、親子関係など）をそのまま使えます。最も**柔軟**で**強力**な方法です。 |

-----

## 各キーの詳細と使い方

### 1\. ID (`getElementById`)

IDは、HTML要素に**唯一無二**の名前を付けるための属性です。

  * **HTMLの例:** `<button id="submitButton">送信</button>`
  * **JavaScriptでの取得:**
    ```javascript
    const button = document.getElementById('submitButton');
    // 'submitButton'というIDを持つ要素を一つだけ取得
    ```
  * **ポイント:** IDはページ内で重複させてはいけません。必ず**単一の要素**を取得したいときに使います。

### 2\. Class (`getElementsByClassName`)

Classは、複数のHTML要素を**グループ化**するための属性です。

  * **HTMLの例:**
    ```html
    <li class="menuItem">ホーム</li>
    <li class="menuItem">サービス</li>
    <li class="menuItem">お問い合わせ</li>
    ```
  * **JavaScriptでの取得:**
    ```javascript
    const menuItems = document.getElementsByClassName('menuItem');
    // 'menuItem'というクラスを持つ要素のリスト（配列のようなもの）を取得
    ```
  * **ポイント:** 複数の要素に同じクラス名を付けることができ、まとめて操作したいときに便利です。取得されるのは\*\*要素のリスト（HTMLCollection）\*\*になります。

### 3\. タグ名 (`getElementsByTagName`)

タグ名そのままを使って要素を取得します。

  * **HTMLの例:** `<p>段落1</p><p>段落2</p>`
  * **JavaScriptでの取得:**
    ```javascript
    const paragraphs = document.getElementsByTagName('p');
    // ページ内の全ての <p> 要素のリストを取得
    ```
  * **ポイント:** 特定の種類の要素全体を対象としたいときに使います。これも\*\*要素のリスト（HTMLCollection）\*\*を取得します。

### 4\. CSSセレクタ (`querySelector` / `querySelectorAll`)

これは最もモダンで柔軟な方法で、**CSSを書くときに使うセレクタの記法**をそのまま使えます。

  * **`querySelector()`**: セレクタに一致する**最初の一つ**の要素を取得します。
  * **`querySelectorAll()`**: セレクタに一致する**全ての要素**をリスト（NodeList）として取得します。

| セレクタの例 | 意味 | JavaScriptでの取得（例） |
| :--- | :--- | :--- |
| `#mainHeader` | IDが `mainHeader` の要素 | `document.querySelector('#mainHeader')` |
| `.card` | Classが `card` の要素 | `document.querySelectorAll('.card')` |
| `div p` | `div` 要素の子孫にある `p` 要素 | `document.querySelectorAll('div p')` |

  * **ポイント:**
      * IDは`#`を、Classは`.`をセレクタの前に付けます。
      * この方法を覚えれば、ID、Class、タグ名、さらに複雑な親子関係や属性などもすべて**一つの方法**で扱えるため、非常に便利です。

初心者のうちは、**ID**を使って**単一の要素**を確実に操作することから始め、慣れてきたら**Class**や**CSSセレクタ**を使った**複数の要素**の操作に進むのがおすすめです。

# 複数の要素の取得

## 1\. `querySelector()`と`querySelectorAll()`の使い方

これらのメソッドは、HTMLドキュメント（ウェブページ）の中から特定の要素を見つけ出すために使われます。

### `querySelector()`

これは、指定した**CSSセレクタ** に一致する**最初（一つだけ）** の要素を返します。

| 特徴 | 説明 |
| :--- | :--- |
| **返り値** | **最初に見つかった**`Element`オブジェクト。見つからなかった場合は`null`。 |
| **用途** | ページ内で**特定の一つ**の要素を取得したい場合。 |

**【使い方】**

```javascript
// IDが "main-title" の要素を一つ取得
let title = document.querySelector("#main-title");

// クラスが "item" の要素の中で最初に見つかったものを一つ取得
let firstItem = document.querySelector(".item");

// <button>タグの要素の中で最初に見つかったものを一つ取得
let button = document.querySelector("button");
```

### `querySelectorAll()`

これは、指定したCSSセレクタに一致する**すべて**の要素を、**リスト（配列のようなもの）** として返します。

| 特徴 | 説明 |
| :--- | :--- |
| **返り値** | 一致する**すべて**の要素を含む`NodeList`（リスト形式）。一つも見つからなかった場合は**空の`NodeList`**。 |
| **用途** | ページ内で**複数の**要素をまとめて取得したい場合。 |

**【使い方】**

```javascript
// クラスが "item" の要素をすべて取得
let allItems = document.querySelectorAll(".item");
// allItems は [要素1, 要素2, 要素3, ...] のようなリストになります

// <li>タグの要素をすべて取得
let listItems = document.querySelectorAll("li");

// 取得したリストから特定の要素にアクセスするには、配列のようにインデックス（番号）を使います
console.log(allItems[0]); // 最初の "item" クラスの要素
```

-----

## 2\. `querySelectorAll()`に複数条件を渡す

`querySelectorAll()`を使う場合、CSSセレクタのルールに従って、**「複数の条件を満たす要素」** や **「いくつかの異なる種類の要素」** を取得することができます。

### A. **複数の条件を**「同時に」**満たす要素**を取得する（AND条件）

一つの要素が**複数の条件をすべて**満たすように指定するには、セレクタを**つなげて**記述します。間に**スペースは入れません**。

| 条件の例 | セレクタ | 意味 |
| :--- | :--- | :--- |
| `<div>`タグで、かつクラスが `"active"` | `div.active` | `<div class="active">` の要素 |
| クラスが `"item"`で、かつIDが `"special"` | `  #special.item ` | `<p id="special" class="item">` のような要素 |

**【例】**

```html
<button class="btn primary">送信</button>
<button class="btn secondary">キャンセル</button>
```

```javascript
// クラスが "btn" かつ "primary" の両方を持つ要素を取得
let primaryButton = document.querySelectorAll(".btn.primary"); 
// 結果: [送信ボタン] のみが含まれる NodeList
```

### B. **複数の**「異なる種類の」**要素**をまとめて取得する（OR条件）

複数の異なるセレクタの**どれか一つでも**一致する要素をまとめて取得するには、セレクタを**カンマ (`,`)** で区切ります。

| 条件の例 | セレクタ | 意味 |
| :--- | :--- | :--- |
| クラスが `"error"` または `<span>`タグ | `.error, span` | `.error`を持つ要素 **と** `<span>`タグの要素 **をすべて** |

**【例】**

```javascript
// クラスが "warning" の要素 または <p>タグの要素 をすべて取得
let importantElements = document.querySelectorAll(".warning, p"); 
// 結果: .warning の要素と <p>タグ の要素がすべて含まれる NodeList
```

### C. **半角スペース** で区切って、**親子関係（子孫）** で絞り込む

セレクタを**半角スペース**で区切ると、「左側の要素の**中にある**右側の要素」という関係で要素を絞り込めます。これは**子孫セレクタ**と呼ばれ、間にどれだけ階層が離れていても適用されます。

| セレクタ | 意味 | 取得される要素 |
| :--- | :--- | :--- |
| `.parent .child` | クラスが `"parent"` の**要素の中にある**、クラスが `"child"` の要素 | `<div class="parent">... <p class="child">取得</p> ...</div>` |
| `ul li` | `<ul>` タグの**中にある**、`<li>` タグの要素 | `<ul><li>取得</li></ul>` |

**【例】**

```html
<div id="main-content">
  <p class="text">メインの段落</p>
  <ul>
    <li class="item">リスト1</li>
    <li class="item">リスト2</li>
  </ul>
</div>

<div id="sidebar">
  <p class="text">サイドバーの段落</p>
</div>
```

```javascript
// IDが "main-content" の中にある、クラスが "text" の要素を取得
// 半角スペースで区切ることで、「main-content の子孫」に限定される
let mainText = document.querySelectorAll("#main-content .text"); 
// 結果: [メインの段落] の <p> 要素のみが含まれる NodeList
// サイドバーの段落は含まれない

// IDが "main-content" の中にある、すべての <li> 要素を取得
let mainListItems = document.querySelectorAll("#main-content li");
// 結果: [リスト1, リスト2] の <li> 要素が含まれる NodeList
```

#### 💡 **他の親子関係のセレクタ**

半角スペース以外の記号を使って、さらに厳密な親子関係で絞り込むこともできます。

| セレクタ | 意味 | 関係性 |
| :--- | :--- | :--- |
| `>` (大なり記号) | **直下の**子要素のみ | `.parent > .child` は、`.parent` の**直後**にある `.child` のみ |
| `+` (プラス記号) | **直後**に続く兄弟要素 | `.prev + .next` は、`.prev` の**すぐ隣**にある `.next` のみ |

初心者のうちは、まずは**半角スペース（子孫セレクタ）** を使って「〇〇の中の△△」という絞り込みを理解しておくと、様々な要素を効率的に取得できるようになります。



# 要素の追加と削除

## 🚀 要素の追加: `.insertAdjacentHTML()`

`.insertAdjacentHTML()`メソッドは、既存の要素の**すぐ近く**に新しいHTMLの要素を文字列として追加するのに非常に便利です。

これは、「**どの要素**の」「**どこ**に」「**どんなHTML**を」追加するか、という3つの情報で動作します。

### 1\. 使い方

```javascript
// ターゲット要素を取得
const targetElement = document.querySelector('#target');

// 新しいHTMLを追加
targetElement.insertAdjacentHTML(position, htmlString);
```

### 2\. 重要な引数（`position` の指定）

このメソッドの最大の特徴は、**4つのキーワード**を使って、追加する場所を細かく指定できることです。

| キーワード | 意味 | 追加される場所 |
| :--- | :--- | :--- |
| **`'beforebegin'`** | ターゲット要素の**直前** | ターゲット要素の外側に追加されます。 |
| **`'afterbegin'`** | ターゲット要素の**最初の子要素**として | ターゲット要素の内側、既存コンテンツの**前**に追加されます。 |
| **`'beforeend'`** | ターゲット要素の**最後の子要素**として | ターゲット要素の内側、既存コンテンツの**後**に追加されます。 |
| **`'afterend'`** | ターゲット要素の**直後** | ターゲット要素の外側に追加されます。 |

### 3\. コード例

例えば、以下のようなHTMLがあったとします。

```html
<div id="container">
  <p>既存のコンテンツ</p>
  </div>
```

新しいボタンを追加する場合：

```javascript
const container = document.querySelector('#container');
const newButton = '<button>新ボタン</button>';

// ターゲット要素の内側、コンテンツの最後にボタンを追加
container.insertAdjacentHTML('beforeend', newButton); 
```

## 🗑️ 要素の削除: `.remove()`

`.remove()`メソッドは、JavaScriptで取得した**その要素自身を、HTMLドキュメントから完全に削除**するために使います。

これは非常にシンプルで、削除したい要素に対してメソッドを呼び出すだけで済みます。

### 1\. 使い方

```javascript
// 削除したい要素を取得
const elementToRemove = document.querySelector('#delete-me');

// 削除を実行
elementToRemove.remove();
```

### 2\. コード例

例えば、不要になったアラートメッセージを消したい場合：

```html
<div id="alert-message">
  エラーが発生しました。
  <button id="close-btn">閉じる</button>
</div>
```

```javascript
// 削除したい要素を取得
const alert = document.querySelector('#alert-message');

// 要素を削除
alert.remove();

// ページから <div id="alert-message">...</div> が完全に消えます。
```


# 繰り返し処理1.1 for文

## 🔑 for文の基本的な考え方

for文は、プログラムの中で**同じ処理を繰り返し実行**したいときに使う、非常に重要な構文です。

for文は、**「初期設定」「継続条件」「増減処理」** の3つの要素を定義し、継続条件が満たされている間、コードブロック内の処理を繰り返し実行します。

### 📌 構文

基本的な書き方は以下の通りです。

```javascript
for (初期設定; 継続条件; 増減処理) {
  // 継続条件がtrueの間、繰り返し実行される処理
}
```

### 📝 各要素の役割

| 要素名 | 役割 | 説明 |
| :--- | :--- | :--- |
| **初期設定** | カウンター変数の初期化 | 繰り返しを数えるための変数（例: `i`）を最初に設定します。通常、`let i = 0` のように0から始めます。 |
| **継続条件** | 繰り返しの実行を判断 | 繰り返しを続けるかどうかの**真偽**を判断する式です。これが`true`の間は処理が実行されます。`false`になった時点で繰り返しは終了します。|
| **増減処理** | カウンター変数の更新 | 1回の繰り返し処理が終わるたびに、カウンター変数をどう変化させるかを指定します。通常は `i++` (1増やす) を使います。|

-----

## 💡 実行の流れ（具体例）

以下のコードを例に、`for`文の実行される順序を説明します。

```javascript
for (let i = 0; i < 3; i++) {
  console.log("現在の i の値: " + i);
}
console.log("ループ終了");
```

| ステップ | 処理 | 結果 |
| :--- | :--- | :--- |
| 1 | **初期設定** (`let i = 0`) | 変数 `i` が $\mathbf{0}$ で作られる。（**1度だけ実行**） |
| 2 | **継続条件** (`i < 3`) | $\mathbf{0 < 3}$ なので **`true`**。 |
| 3 | **ブロック実行** | `console.log("現在の i の値: 0")` が実行される。 |
| 4 | **増減処理** (`i++`) | `i` が $\mathbf{1}$ になる。 |
| --- | --- | --- |
| 5 | **継続条件** (`i < 3`) | $\mathbf{1 < 3}$ なので **`true`**。 |
| 6 | **ブロック実行** | `console.log("現在の i の値: 1")` が実行される。 |
| 7 | **増減処理** (`i++`) | `i` が $\mathbf{2}$ になる。 |
| --- | --- | --- |
| 8 | **継続条件** (`i < 3`) | $\mathbf{2 < 3}$ なので **`true`**。 |
| 9 | **ブロック実行** | `console.log("現在の i の値: 2")` が実行される。 |
| 10 | **増減処理** (`i++`) | `i` が $\mathbf{3}$ になる。 |
| --- | --- | --- |
| 11 | **継続条件** (`i < 3`) | $\mathbf{3 < 3}$ なので **`false`**。 |
| 12 | **ループ終了** | `for`文を抜け、`console.log("ループ終了")`が実行される。|

### 🖥️ コンソール出力

```
現在の i の値: 0
現在の i の値: 1
現在の i の値: 2
ループ終了
```

-----

## 🚀 for文の一般的な使用例

### 1\. 決まった回数だけ処理を繰り返す

「5回だけ」「100回だけ」といった、回数が決まっている繰り返しに最適です。

```javascript
for (let j = 0; j < 5; j++) {
  console.log(j + "回目"); // 0回目から4回目まで実行
}
```

### 2\. 配列の要素を順番に処理する

JavaScriptでは、配列の要素に`0`から順番にアクセスするために`for`文をよく使います。

```javascript
const fruits = ["りんご", "バナナ", "みかん"];

// 配列の長さ (fruits.length) を継続条件に使う
for (let k = 0; k < fruits.length; k++) {
  console.log(fruits[k] + "を食べます");
}
```

#### 🖥️ コンソール出力

```
りんごを食べます
バナナを食べます
みかんを食べます
```

# 繰り返し処理1.2 比較演算子

比較演算子は、主に**for文の継続条件**や**if文の条件分岐**など、プログラムの「条件式」を作るために使われます。

これらの演算子は、左辺と右辺の値を比較し、その結果が\*\*真（`true`）**か**偽（`false`）\*\*のブール値として返されます。

## 🔑 主要な比較演算子一覧

| 演算子 | 名称 | 意味 | 使用例 | 結果（`true` or `false`）|
| :--- | :--- | :--- | :--- | :--- |
| **`>`** | より大きい | 左辺が右辺より大きい | `5 > 3` | `true` |
| **`<`** | より小さい | 左辺が右辺より小さい | `5 < 3` | `false` |
| **`>=`** | 以上 | 左辺が右辺と等しいか、または大きい | `5 >= 5` | `true` |
| **`<=`** | 以下 | 左辺が右辺と等しいか、または小さい | `5 <= 4` | `false` |
| **`==`** | 等しい（値の比較）| 左辺と右辺の**値**が等しい | `'5' == 5` | `true` |
| **`!=`** | 等しくない（値の比較）| 左辺と右辺の**値**が等しくない | `10 != 'ten'` | `true` |
| **`===`** | 厳密に等しい | 左辺と右辺の**値と型**が両方等しい | `'5' === 5` | `false` |
| **`!==`** | 厳密に等しくない| 左辺と右辺の**値または型**のどちらか、あるいは両方が等しくない | `'5' !== 5` | `true` |

-----

## 💡 特に重要なポイント：`==` と `===` の違い

初心者が最も混乱しやすいのが、等価をチェックする\*\*「`==`」**と**「`===`」\*\*の違いです。

### 1\. `==` (等しい - **緩やかな比較**)

  * **値**だけを比較します。
  * JavaScriptが\*\*自動的にデータ型を変換（型変換）\*\*して比較しようとします。

<!-- end list -->

```javascript
// '5' (文字列) と 5 (数値) は、型を無視すれば値は同じと見なされる
console.log('5' == 5);  // true
```

### 2\. `===` (厳密に等しい - **厳密な比較**)

  * **値とデータ型**の両方を比較します。
  * 型変換は行いません。

<!-- end list -->

```javascript
// '5' (文字列) と 5 (数値) は、値は同じだが「型」が違うため false
console.log('5' === 5); // false
```

### ✅ 初心者へのアドバイス

**特殊な理由がない限り、常に**`===`（厳密に等しい）**を使う**ことを強くお勧めします。予期せぬ型変換によるバグを防ぎ、コードの動作を明確にすることができます。

-----

## 🚀 for文と条件式の組み合わせ例

`for`文の継続条件として比較演算子がどのように使われるかの例です。

```javascript
// 変数 i が 5 より小さい間（0, 1, 2, 3, 4）繰り返す
for (let i = 0; i < 5; i++) {
  // if文の条件分岐にも比較演算子を使う
  if (i === 3) {
    console.log("3に到達しました！");
  } else {
    console.log(i);
  }
}
```

### 🖥️ コンソール出力

```
0
1
2
3に到達しました！
4
```

```javascript
// '5' (文字列) と 5 (数値) は、型を無視すれば値は同じと見なされる
console.log('5' == 5);  // true
```

### 2\. `===` (厳密に等しい - **厳密な比較**)

  * **値とデータ型**の両方を比較します。
  * 型変換は行いません。

<!-- end list -->

```javascript
// '5' (文字列) と 5 (数値) は、値は同じだが「型」が違うため false
console.log('5' === 5); // false
```

### ✅ 初心者へのアドバイス

**特殊な理由がない限り、常に**`===`（厳密に等しい）**を使う**ことを強くお勧めします。予期せぬ型変換によるバグを防ぎ、コードの動作を明確にすることができます。

# 条件分岐-1
JavaScriptの**if文**は、プログラムの流れを柔軟に変えるための最も基本的な構文です。初心者の方にも分かりやすいように、身近な例を使って説明しますね。

## 🚦 条件分岐とは

**条件分岐**とは、ある**条件**が正しいか（**真** / `true`）どうかによって、実行するプログラムの**処理を切り替える**ことです。

これは、日常生活で「もし雨が降っていたら傘を持っていく。そうでなければ傘は持っていかない」と判断するのと同じ仕組みです。

| 条件が true (真) のとき | 条件が false (偽) のとき |
| :--- | :--- |
| **実行される** | **スキップされる** |

-----

## 💻 if文の記述方法

最もシンプルな `if` 文は、条件が `true` の場合にのみ実行される処理を定義します。

### 構文

```javascript
if (条件式) {
  // 条件式が true の場合のみ実行される処理
}
```

### 例

特定の変数がある値より大きいかどうかをチェックする例です。

```javascript
let score = 85;

if (score > 80) {
  console.log("おめでとう！高得点です。"); // scoreが80より大きいので実行される
}
```

-----

## ✂️ if〜elseで処理を２つに分岐

条件が true の場合と、そうではない場合 (false の場合) の**両方に**、別の処理を用意したいときに `else` を使います。

### 構文

```javascript
if (条件式) {
  // 条件式が true の場合（Aの処理）
} else {
  // 条件式が false の場合（Bの処理）
}
```

### 例

変数 `isRaining` が `true` か `false` かによって処理を分けます。

```javascript
let isRaining = false;

if (isRaining) {
  console.log("傘を持っていきましょう。"); // isRainingがtrueのときの処理
} else {
  console.log("傘はいりません。"); // isRainingがfalseなので、こちらが実行される
}
```

-----

# else ifで処理を３つ以上に分岐

処理の分岐が 3 つ以上ある場合は、**`else if`** を使って 2 つ目以降の条件を順番に設定します。

プログラムは上から順に条件をチェックし、**最初に** `true` になったブロックの処理を実行したら、残りの `else if` や `else` は**すべて無視**して終了します。

## 構文

```javascript
if (1つ目の条件) {
  // 1つ目の条件が true の場合
} else if (2つ目の条件) {
  // 1つ目が false で、2つ目の条件が true の場合
} else if (3つ目の条件) {
  // 1つ目と2つ目が false で、3つ目の条件が true の場合
} else {
  // どの条件も true でなかった場合
}
```

## 例：成績の判定

点数によって「優」「良」「可」「不可」を判定する例です。

```javascript
let finalScore = 75;

if (finalScore >= 90) {
  console.log("成績は 優 です。");
} else if (finalScore >= 80) {
  console.log("成績は 良 です。");
} else if (finalScore >= 70) {
  console.log("成績は 可 です。"); // finalScoreが75なので、ここで実行される
} else {
  console.log("成績は 不可 です。");
}
```

### 💡 ポイント

もし `finalScore` が 95 だった場合、

1.  `finalScore >= 90` が true になる。
2.  「成績は 優 です。」が実行される。
3.  残りの `else if` と `else` は**チェックすらされず**にスキップされます。

# 論理演算子

論理演算子は、主に**条件式**（`if`文や`for`文の継続条件など）の中で使われ、複数の条件を組み合わせたり、条件を反転させたりするために使用されます。

この3つの演算子を使うと、より複雑で賢い判断をプログラムにさせることができます。

-----

## 🔑 1. 論理積 (AND) : `&&` (かつ)

「〜も、〜も、**両方**とも true でなければならない」という条件を作るときに使います。

### 意味

  - **すべての条件が true** のときだけ、全体が true になります。
  - 1 つでも false があれば、全体は false になります。

| 条件 A | 条件 B | 結果 (A && B) |
| :---: | :---: | :---: |
| true | true | **true** |
| true | false | false |
| false | true | false |
| false | false | false |

### 例

「**年齢が 18 歳以上** **かつ** **会員登録が完了している**」場合のみ、お酒を販売する。

```javascript
let age = 20;
let isRegistered = true;

if (age >= 18 && isRegistered) {
  console.log("お酒の購入が可能です。"); // 両方 true なので実行される
}
```

-----

## 🔑 2. 論理和 (OR) : `||` (または)

「〜か、〜か、**どちらか 1 つ**でも true であればよい」という条件を作るときに使います。

### 意味

- **1 つでも条件が true** であれば、全体が true になります。
- すべての条件が false のときだけ、全体は false になります。


| 条件 A | 条件 B | 結果 (A \|\| B) |
| :---: | :---: | :---: |
| true | true | **true** |
| true | false | **true** |
| false | true | **true** |
| false | false | false |

### 例

「**天気予報が雨** **または** **気温が 10 度以下**」のとき、長袖を着ていく。

```javascript
let weather = "晴れ";
let temperature = 8; // 8度

if (weather === "雨" || temperature <= 10) {
  console.log("長袖を着て出かけましょう。"); // 2つ目の条件が true なので実行される
}
```

-----

## 🔑 3. 論理否定 (NOT) : `!` (ではない)

条件の結果を**反転**させるときに使います。

### 意味

  - true を false に、false を true に変えます。

| 条件 A | 結果 (\!A) |
| :---: | :---: |
| true | false |
| false | true |

### 例

「**まだログインしていない状態**」のときに、ログイン画面を表示する。

```javascript
let isLoggedIn = false; // ログインしていない

if (!isLoggedIn) { // 「isLoggedIn が true ではない」という意味になる
  console.log("ログインが必要です。"); // isLoggedIn が false なので、!isLoggedIn は true になり実行される
}
```

### 💡 まとめ

| 演算子 | 読み方 | 意味 | 覚えるポイント |
| :--- | :--- | :--- | :--- |
| **`&&`** | 論理積（AND） | **かつ** | **すべて true** でないと true にならない |
| **`\|\|`** | 論理和（OR） | **または** | **1 つでも true** なら true になる |
| **`!`** | 論理否定（NOT） | **ではない** | 結果を true と false で**反転**させる |

# switch文

JavaScriptの **`switch`文** は、**一つの変数の値** に応じて、実行する処理をいくつもの選択肢から選びたいときに使う便利な構文です。

これは、多くの `else if` を連続して書くよりも、コードを **より読みやすく、簡潔に** するための方法だと考えると理解しやすいでしょう。

-----

## 🚦 switch文とは？

`switch`文は、ある変数の値が **「これと一致するか？」** という比較を複数回行うための構造です。

たくさんの選択肢がある信号機のようなものだとイメージしてください。

| `if`/`else if`文 | `switch`文 |
| :--- | :--- |
| **複数の条件式**（`score > 90` や `name == 'Alice'` など）を上から順番にチェックする。 | **一つの変数の値**が、用意された複数の**定数**（`1` や `'Monday'` など）のどれと一致するかをチェックする。 |

-----

## 💻 switch文の記述方法

### 構文

```javascript
switch (検査したい値や変数) {
  case 値1:
    // 検査したい値が「値1」と一致した場合の処理
    break; // ★ 処理を終了し、switch文から抜け出す
    
  case 値2:
    // 検査したい値が「値2」と一致した場合の処理
    break;
    
  // ... さらに case を追加可能 ...
    
  default:
    // どの case にも一致しなかった場合の処理 (else に相当)
}
```

### 各キーワードの役割

| キーワード | 役割 |
| :--- | :--- |
| **`switch ( )`** | 検査したい変数や値を指定します。 |
| **`case 値:`** | `switch`に指定した値が、この `値` と**一致** (`==`) したときの処理を指定します。 |
| **`break;`** | **必須**。現在の `case` の処理が終わったら、`switch`文全体から抜け出すために使います。これがないと、次の `case` の処理まで実行されてしまいます（これを**フォールスルー**と呼び、意図しないバグの原因になることがあります）。 |
| **`default:`** | どの `case` の値にも一致しなかった場合に実行される処理を指定します。（`if-else if` 構造における `else` に相当します。） |

### 例：曜日の判定

数字（1 \sim 7）から曜日名を出力するプログラムを考えます。

```javascript
let dayNum = 3; // 水曜日を意味する

switch (dayNum) {
  case 1:
    console.log("今日は月曜日です。");
    break;
  case 2:
    console.log("今日は火曜日です。");
    break;
  case 3:
    console.log("今日は水曜日です。"); // dayNumが3なので、ここが実行される
    break;
  case 4:
  case 5:
    console.log("今日は木曜日か金曜日です。");
    break;
  default:
    console.log("今日は週末です。"); // どの case にも当てはまらない場合
}
```

#### 💡 **フォールスルーの利用 (caseの連続)**

上記の例で `case 4:` の後に `break;` がありません。これは、`dayNum` が 4 の場合も 5 の場合も、同じ処理を実行したいときに利用されます。

1.  `dayNum` が 4 の場合、`case 4:` に一致しますが、`break;` がないので次の `case 5:` の処理もそのまま実行されます。
2.  `dayNum` が 5 の場合、`case 5:` に一致し、その後の処理が実行されます。

このように、`break` をあえて省略することで、複数の条件で同じ処理をさせることができます。

# break, continue and while

JavaScriptの **`while`文**は、`for`文と同じく処理を繰り返すための構文ですが、**繰り返し回数が決まっていない**場合に特に役立ちます。

また、ループの途中で強制的に抜け出したり、一部の処理をスキップしたりするために、**`break`** と **`continue`** という特別なキーワードが使われます。

-----

## 🔁 1. while文（条件が $\text{true}$ の間、繰り返す）

`while`文は、「指定された**継続条件**が $\text{true}$ である限り、ブロック内の処理を繰り返し実行し続ける」というシンプルな仕組みです。

### 構文

```javascript
while (継続条件) {
  // 継続条件が true の間、繰り返し実行される処理
  
  // ★重要: ループを終了させるための処理を必ず記述する！
}
```

### 動作の流れ

1.  まず、括弧内の**継続条件**をチェックします。
2.  条件が $\text{true}$ であれば、ブロック内の処理を実行します。
3.  ブロック内の処理が終わったら、再び **継続条件** に戻ってチェックします。
4.  条件が $\text{false}$ になるまで、2と3を繰り返します。

### 例

カウンター変数を使って $1$ から $3$ まで数える例です。

```javascript
let count = 1; // ① 初期設定

while (count <= 3) { // ② 継続条件
  console.log(count + "回目の処理");
  count++; // ③ 増減処理 (★これがないと無限ループになる！)
}
// 出力:
// 1回目の処理
// 2回目の処理
// 3回目の処理
```

### ⚠️ 注意：無限ループ

`while`文のブロック内で、継続条件をいつか $\text{false}$ にする処理（上記の例では `count++`）を書き忘れると、**条件が永遠に $\text{true}$ のまま**になり、プログラムが停止しなくなる**無限ループ**が発生します。

-----

## 🛑 2. break（ループを強制終了する）

**`break`** は、`for`文や `while`文といったループ処理を、**継続条件が $\text{false}$ になる前でも**、その場で**強制的に終了**させるために使われます。

### 例

$10$ まで数える予定だったが、$5$ になったらすぐに止めたい場合。

```javascript
let i = 1;

while (i <= 10) {
  if (i === 6) {
    break; // iが6になったら、ここで while文全体を終了！
  }
  console.log(i);
  i++;
}
// 出力:
// 1, 2, 3, 4, 5
```

-----

## ↪️ 3. continue（今回の処理をスキップする）

**`continue`** は、ループ内の処理のうち、`continue`が実行された**その時点から後の処理だけをスキップ**し、すぐに次の繰り返し（次の継続条件のチェック）に移るために使われます。

### 例

$1$ から $5$ まで数えるが、 $3$ のときだけ処理をスキップしたい場合。

```javascript
let j = 0;

while (j < 5) {
  j++; // ★ continue の前に j++ を置いて、無限ループを防ぐ
  
  if (j === 3) {
    continue; // jが3のとき、この後の console.log はスキップされ、次のループへ
  }
  
  console.log(j);
}
// 出力:
// 1, 2, 4, 5
// ※ 3 のときだけスキップされている
```

### 💡 `continue`使用時の注意

`while`文で `continue` を使う場合、**カウンター変数の増減処理（`j++` など）を `continue` の前に**記述しないと、増減処理がスキップされ、無限ループに陥る可能性があるので特に注意が必要です。

# 関数の戻り値

## 🎁 return文とは？（自動販売機の例）

関数は、何かを**インプット（引数）として受け取り、その内部で処理**を行い、最終的に**アウトプット（戻り値）**を出す、「処理の箱」のようなものです。

`return`文は、この **「アウトプット」** の役割を果たします。

| 関数の要素 | 自動販売機の例 | 説明 |
| :--- | :--- | :--- |
| **関数** | 自動販売機全体 | 処理を行う機械。 |
| **引数 (Input)** | 入れるお金、押すボタン | 処理に必要な情報（データ）。 |
| **`return`文** | **商品を取り出し口から出す** | **関数の処理結果**を呼び出し元に渡す役割。 |
| **戻り値 (Output)** | 出てきたジュース | 関数が返した処理結果の値。 |

### 💻 構文

`return`文は、関数ブロックの実行を終了し、指定された値を返します。

```javascript
function 関数名(引数) {
  // 関数の処理...
  
  return 返したい値; // ★ この行で関数は終了し、値が返される
}
```

## 💡 return文の重要な $2$ つの役割

`return`文には、主に $2$ つの重要な役割があります。

### 1\. 処理結果を呼び出し元へ渡す

関数が計算などの処理を行った結果を、それを実行した場所に渡します。

**例：消費税を計算して返す**

```javascript
function calculateTax(price) {
  const taxRate = 0.10; // 10%
  const taxAmount = price * taxRate;
  
  return taxAmount; // 税額を計算し、関数の外へ返す
}

// 関数を呼び出す
let itemPrice = 500;
let tax = calculateTax(itemPrice); // 戻り値(50)が変数 tax に代入される

console.log("税額は " + tax + "円です。"); // 出力: 税額は 50円です。
```

この例では、`return taxAmount;` によって計算結果の $50$ が呼び出し元に返され、`tax`という変数に格納されています。

-----

### 2\. 関数の実行をそこで終了させる

`return`文が実行された時点で、その関数内の残りのコードは**一切実行されません**。

**例：エラー時に処理を途中で止める**

```javascript
function checkAge(age) {
  if (age < 0) {
    return "エラー：無効な年齢です"; // ageがマイナスなら、ここで関数を強制終了し、メッセージを返す
  }
  
  // return文が実行された場合、以下のコードはスキップされる
  console.log("年齢チェックを完了しました。");
  
  if (age >= 20) {
    return "成人です。";
  } else {
    return "未成年です。";
  }
}

console.log(checkAge(-5)); // 出力: エラー：無効な年齢です
console.log(checkAge(25)); // 出力: 年齢チェックを完了しました。 / 成人です。
```

最初の呼び出し `checkAge(-5)` では、`age < 0` が $\text{true}$ になり、**`return` が実行されたため、その後の `console.log("年齢チェックを完了しました。");` は実行されずに終了しています。**

### ⚠️ まとめ

  * `return` は、関数が計算などの**結果を外に渡す**ための出口です。
  * `return` が実行された瞬間、その関数の**実行はそこで終わり**ます。
  * 値を返さない `return;` も可能ですが、その場合の戻り値は `undefined` になります。

  # 文字入力

JavaScriptでユーザーからデータを入力してもらうための方法と、そのデータが数値として適切かを確認する方法について説明します。

-----

## 💻 1. ユーザーの入力を受け取る: `prompt()`

`prompt()`は、ブラウザに小さなダイアログボックスを表示し、ユーザーにテキストの入力を求めるための関数です。

### 📌 記述方法

```javascript
let userInput = prompt("ここにユーザーに尋ねたいメッセージを書きます");
// ユーザーが入力した文字列が変数 userInput に格納される
```

### 💡 動作のポイント

1.  **ダイアログの表示:** ブラウザの画面中央に入力欄と「OK」「キャンセル」ボタンを持つダイアログが表示されます。
2.  **戻り値:**
      * ユーザーが何かを入力して「OK」を押すと、その**入力された内容が** **文字列 (string)** として返されます。
      * ユーザーが何も入力せずに「OK」を押した場合、空の文字列 `""` が返されます。
      * ユーザーが「キャンセル」を押した場合、特殊な値である `null` が返されます。

**注意:** `prompt()`で受け取るデータは、ユーザーが数字を入力しても、必ず**文字列**として扱われます。計算に使うためには、次に説明する変換が必要です。

-----

## 🔢 2. 文字列を数値に変換する: `parseInt()`と`parseFloat()`

`prompt()`で受け取った文字列を、計算に使える**数値**に変換するために使います。

### `parseInt()` (整数に変換)

文字列を**整数 (小数点以下のない数値)** に変換します。

```javascript
let strAge = "25";
let numAge = parseInt(strAge); // => 25 (数値)

let strValue = "10.5リットル";
let numValue = parseInt(strValue); // => 10 (小数点以下は切り捨てられる)
```

### `parseFloat()` (浮動小数点数/実数に変換)

文字列を**浮動小数点数 (小数点以下を含む数値)** に変換します。

```javascript
let strWeight = "65.7";
let numWeight = parseFloat(strWeight); // => 65.7 (数値)

let strPi = "3.14159...";
let numPi = parseFloat(strPi); // => 3.14159 (数値)
```

-----

## 🛑 3. 「数値ではない」を表す特別な値: `NaN`

数値への変換処理が失敗した場合、その結果は特別な値である **`NaN`** (Not a Number) になります。

### 📌 `NaN` が返される例

`parseInt()`や`parseFloat()`が、**数値として解釈できない文字**から始まる文字列を処理しようとすると `NaN` が返されます。

```javascript
let result1 = parseInt("こんにちは"); // => NaN
let result2 = parseFloat("abc123");   // => NaN
let result3 = parseInt("50%OFF");     // => 50 (※先頭が数値なら途中まで変換される)
```

**`NaN` は、それ自体が「無効な計算結果」** を表す特別な数値型データです。

-----

## ❓ 4. `NaN`を判定する: `isNaN()`

通常の比較演算子 (`===`) を使って `NaN` をチェックすることはできません。そのため、**「この値は `NaN` ですか？」** を判定するために専用の関数 **`isNaN()`** を使います。

```javascript
let data = parseInt(prompt("数値を入力してください")); // 例: ユーザーが「あいうえお」と入力

if (isNaN(data)) {
  console.log("入力された値は数値として認識できませんでした。");
} else {
  console.log("正しい数値が入力されました。");
}
```

### 💡 なぜ `isNaN()` が必要か？

`NaN` は非常に特殊な値で、**自分自身と比べても $\text{false}$ になります**。

```javascript
let x = NaN;
console.log(x === NaN); // => false (!!!)

// したがって、NaNのチェックには isNaN() を使う必要がある
console.log(isNaN(x));  // => true
```

### まとめ：安全な数値入力の受け取り方

1.  `prompt()`で**文字列**として入力を受け取る。
2.  `parseInt()`や`parseFloat()`で**数値に変換**する。
3.  `isNaN()`で**無効な入力でないかチェック**してから、計算に使う。

-----

## parseInt() と parseFloat()に関する注記

`parseInt()` も `parseFloat()` も、**文字列の先頭から見て、整数として解釈できる部分だけを抽出する**というルールに従って動作します。

### 💡 `parseInt()` の動作ルール

1.  **文字列の先頭から**読み込みを始めます。
2.  **数字**（`0`〜`9`）と**符号**（`+`、`-`）を検出する限り、それを数値の一部として取り込みます。
3.  **数値として解釈できない文字**（この場合は `k`）に遭遇した時点で、読み込みを**そこで停止**します。
4.  停止するまでに読み込んだ部分（`55`）を**整数**として返します。

### 📝 具体的な動作の例

| 関数 | 入力文字列 | 戻り値 | 理由 |
| :--- | :--- | :--- | :--- |
| `parseInt("55kg")` | `"55"` まで読み込み | **55** | `k` で停止。 |
| `parseInt("12.99ドル")` | `"12"` まで読み込み | **12** | `.` (小数点) を整数の一部と見なさないため、`.` で停止し、小数点以下は切り捨てられる。 |
| `parseInt("123A45")` | `"123"` まで読み込み | **123** | `A` で停止。 |
| `parseInt("A123")` | `"A"` で停止 | **NaN** | 先頭が数値ではないため、何も読み込めずに失敗。 |

### 💡 `parseFloat()` の動作ルール

1.  **文字列の先頭から**読み込みを始めます。
2.  **数字**（`0`〜`9`）と、**符号**（`+`、`-`）、そして**小数点**（`.`）を検出する限り、それを数値の一部として取り込みます。
3.  **数値として解釈できない文字**（この場合は `k`）に遭遇した時点で、読み込みを**そこで停止**します。
4.  停止するまでに読み込んだ部分（`55.5`）を数値として返します。

### 📝 具体的な動作

| 文字 | 動作 | 結果 |
| :---: | :--- | :--- |
| `5` | 数値として取り込み開始 | `5` |
| `5` | 数値として取り込み | `55` |
| `.` | 小数点として取り込み | `55.` |
| `5` | 数値として取り込み | `55.5` |
| **`k`** | **数値ではない文字に遭遇** | **ここで読み込みを停止** |
| `g` | 読み込まれない | |

したがって、`parseFloat("55.5kg")` の戻り値は `55.5` となります。

### ⚠️ エラーになるケース (`NaN`が返るケース)

文字列の**先頭**に数値として解釈できない文字がある場合は、何も抽出できないため、エラー値である `NaN`（Not a Number）が返されます。

```javascript
parseFloat("kg55.5");   // => NaN
parseInt("こんにちは"); // => NaN
```

# オブジェクト、メソッド、プロパティ

## DOMツリー

JavaScriptにおけるオブジェクトツリーにおいて、**`window`オブジェクト**は、ブラウザ環境（ウェブブラウザ）における**グローバルオブジェクト**であり、この環境におけるオブジェクト階層の**最上位（ルート）** に位置します。

これは、JavaScriptがブラウザで実行される際に利用可能なすべてのオブジェクト、関数、変数のスコープを提供する基盤となります。

### 1. Windowオブジェクトの概要

`window`オブジェクトは、以下の**2つ**の重要な役割を持っています。

#### a. グローバルスコープ
* ブラウザで実行されるJavaScriptにおいて、`var`や関数宣言で定義された変数や関数は、特に指定がない限り **`window`オブジェクトのプロパティ** として作成されます。
* 例えば、`function foo() {}`は`window.foo()`としてアクセス可能です（厳密には実行コンテキストによる違いはありますが、概ねこの理解で問題ありません）。
* `window`オブジェクト自体は、グローバル変数として常に利用可能です。

#### b. ブラウザウィンドウの表現
* `window`オブジェクトは、**ブラウザのウィンドウやタブそのもの**を表します。
* ウィンドウのサイズ変更、開閉、ナビゲーション（`location`プロパティ）、履歴（`history`プロパティ）といった、ブラウザ機能へのインターフェース（**BOM: Browser Object Model**）を提供します。

---

### 2. Windowをルートとするオブジェクトツリー

`window`をルートとするオブジェクトツリーは、主に**BOM（Browser Object Model）**と**DOM（Document Object Model）** の二つの主要な構造から構成されます。

####a. BOM (Browser Object Model)
ブラウザ固有の機能にアクセスするためのオブジェクト群で、`window`の直下にぶら下がります。

| オブジェクト | 説明 |
| :--- | :--- |
| **`window.document`** | **DOMのルートオブジェクト**。ロードされたHTMLドキュメント自体を表します。（後述） |
| `window.navigator` | ブラウザの種類、バージョン、OSなど、ユーザーエージェントに関する情報を提供します。 |
| `window.location` | 現在のページのURLに関する情報や、ページ遷移のためのメソッド（`assign()`, `reload()`など）を提供します。 |
| `window.history` | ブラウザの閲覧履歴へのアクセスを提供します。 |
| `window.screen` | ユーザーの画面（ディスプレイ）に関する情報（幅、高さ、色深度など）を提供します。 |
| `window.frames` | ウィンドウ内の`<iframe>`要素に対応するウィンドウオブジェクトのコレクションです。 |
| `window.setTimeout()` | 指定時間後にコードを実行するためのメソッド（タイマー機能）です。 |

#### b. DOM (Document Object Model)
`window`オブジェクトのプロパティである **`document`** オブジェクトをルートとする、HTML/XML文書の構造化された表現です。

* **`window.document`**：
    * DOMツリーの**最上位ノード**（ルート）です。
    * HTML文書全体を表し、文書内のすべての要素、テキスト、コメントなどは`document`の子孫として階層構造（**ノードツリー**）を形成します。
    * 
* **要素ノード（Element Node）**：
    * `document`の子ノードとして、HTML要素（例: `<html>`, `<body>`, `<div>`, `<p>`など）がツリー状に配置されます。
* **テキストノード（Text Node）**：
    * 要素内のテキストコンテンツを表します。
* **属性ノード（Attribute Node）**：
    * 要素の属性（例: `id`, `class`, `href`など）を表します。

JavaScriptは、この`document`オブジェクトを通して、HTML要素の追加・削除・変更、イベントリスナーの設定など、動的なウェブページの操作を行います。

---

### 3. まとめ
ウェブブラウザ環境におけるJavaScriptの**オブジェクトツリー**は、

1.  **ルート**は **`window`** オブジェクト。
2.  `window`は**ブラウザウィンドウ**と**グローバルスコープ**を兼ねる。
3.  `window`のプロパティとして**BOM**（`navigator`, `location`など）のオブジェクトがぶら下がる。
4.  BOMの一部である **`document`** オブジェクトをルートとして **DOMツリー**（HTML文書の構造）が形成される。

という構造で成り立っており、`window`はブラウザ環境におけるすべての起点となっています。

## メソッドとプロパティ

オブジェクトの**メソッド（Method）**と**プロパティ（Property）** は、JavaScript（および多くのオブジェクト指向プログラミング言語）におけるオブジェクトを構成する基本的な要素です。

-----

### 1\. プロパティ (Property)

**プロパティ**とは、オブジェクトが持つ**データ（値）**のことです。オブジェクトの状態や特徴を定義する変数のようなものです。

| 特徴 | 説明 |
| :--- | :--- |
| **役割** | オブジェクトの**データ**を格納する。 |
| **形式** | キーと値のペア（`key: value`）で構成される。 |
| **アクセス** | ドット記法（`object.property`）またはブラケット記法（`object['property']`）でアクセスできる。 |
| **例** | ユーザーオブジェクトの`name`（名前）、`age`（年齢）など。 |

**例:**

```javascript
const user = {
  name: "Taro", // nameがプロパティ
  age: 30      // ageがプロパティ
};

console.log(user.name); // プロパティへのアクセス
```

-----

### 2\. メソッド (Method)

**メソッド**とは、オブジェクトが実行できる**アクション（操作）** のことです。オブジェクトに紐付けられた関数と考えると分かりやすいです。

| 特徴 | 説明 | |
| :--- | :--- | :--- |
| **役割** | オブジェクトの**操作や振る舞い**を定義する。 |
| **形式** | オブジェクトのプロパティとして格納された**関数**。 |
| **アクセス** | ドット記法でアクセスした後、関数として実行（`object.method()`）。 |
| **例** | ユーザーオブジェクトの`greet()`（挨拶する）、配列オブジェクトの`push()`（要素を追加する）など。 |

**例:**

```javascript
const user = {
  name: "Taro",
  // greetがメソッド（関数を値として持つプロパティ）
  greet: function() {
    console.log(`Hello, my name is ${this.name}`);
  }
};

user.greet(); // メソッドの実行
```

この例では、`greet`という名前のプロパティに「関数」が格納されており、これがメソッドとして機能します。

-----

### 3\. まとめ：違いと関係性

| 項目 | プロパティ (Property) | メソッド (Method) |
| :--- | :--- | :--- |
| **本質** | データ（値） | 振る舞い（関数） |
| **用途** | オブジェクトの**状態**を記述 | オブジェクトに**作用**する |
| **呼び出し方** | `object.prop` | `object.method()` |

メソッドとプロパティは、どちらもオブジェクトのキーと値のペアですが、その**値が関数であるか、そうでないか**という点で区別されます。これら二つが組み合わさることで、オブジェクトはデータとそのデータを操作する能力を持つことができます。

(end)

「ルートを `window` とするブラウザのオブジェクトツリー」について説明しますね。

---

### 🌐 ブラウザのオブジェクトツリー（DOMとBOM）

Webブラウザでは、JavaScriptを使ってページやブラウザ自体を操作できます。これを可能にしているのが、**オブジェクトツリー**です。大きく分けて以下の2つがあります：

1. **BOM（Browser Object Model）**  
   - ブラウザそのものを操作するためのオブジェクト群
   - ルートは `window` オブジェクト

2. **DOM（Document Object Model）**  
   - HTMLドキュメントをツリー構造で表現したもの
   - `window.document` からアクセス

# オブジェクトとは

オブジェクトをロールプレイングゲーム（RPG）のキャラクターに例えた説明を以下にまとめます。

-----

## 🎮 オブジェクトとは？（RPGキャラクターに例えて）

JavaScriptにおける**オブジェクト (Object)** という概念は、RPGに登場する**キャラクター全体**に例えることができます。

キャラクターは、「持っている情報（ステータス）」と「できること（行動）」をひとまとめにした存在です。この「ひとまとめ」にしたものが、プログラミングにおける「オブジェクト」です。

### 1\. プロパティ（持っている情報：データ）

オブジェクトが「持っている情報」や「状態」を表すのが**プロパティ (Property)** です。

| プログラミング | RPGの例 | 説明 |
| :--- | :--- | :--- |
| **プロパティ** | **ヒットポイント (HP)**, **防御力**, **攻撃力**, **名前**, **職業** | キャラクターが持つ、**変動する可能性のあるデータ**です。これらの値が変わることで、キャラクターの状態が変わります。 |

**イメージ:**
あなたのキャラクター（オブジェクト）の名前プロパティは「アレン・ストームブレイド」、HPプロパティは「1450」という値を保持しています。

### 2\. メソッド（できること：機能）

オブジェクトが「実行できる行動」や「機能」を表すのが**メソッド (Method)** です。

| プログラミング | RPGの例 | 説明 |
| :--- | :--- | :--- |
| **メソッド** | **移動する**, **攻撃する**, **回復魔法を使う**, **アイテムを拾う** | キャラクターが**実行できるアクション**です。メソッドが呼び出されると、キャラクターの状態（プロパティ）が変わったり、他のオブジェクトに影響を与えたりします。 |

**イメージ:**

## 1\. JavaScriptでCSSを変更する方法

JavaScriptを使って、HTMLタグに設定されているCSSのプロパティ（設定項目）を変更することができます。

### 変更の基本的な書き方

HTML要素のCSSプロパティを変更するには、次の形を使います。

```javascript
document.getElementById("要素のID").style.CSSプロパティ名 = "新しい値";
```

例えば、IDが `"main"` という要素の文字色を**赤**（`#FF0000`）に変えたい場合は、以下のようになります。

```javascript
document.getElementById("main").style.color = "#FF0000";
```

  * `document.getElementById("main")`: **ID**が `"main"` のHTML要素を**指定**しています。
  * `.style`: その要素の**CSSの見た目**を変更し始めますよ、という宣言です。
  * `.color`: **文字の色**というCSSのプロパティを指定しています。

\<hr\>

### ⚠️ プロパティ名（キャメルケース）の注意点

CSSで使っていたプロパティ名の中には、JavaScriptで扱うときに**書き方を変える**必要があるものがあります。

CSSのプロパティ名にハイフン（`-`）が含まれている場合、JavaScriptではそのハイフンを取り除き、**次の文字を大文字**にするルールがあります。これを**キャメルケース**（Camel Case）と呼びます。

| CSSでの書き方 | JavaScriptでの書き方（キャメルケース） | 意味 |
| :--- | :--- | :--- |
| `font-size` | **`fontSize`** | 文字の大きさ |
| `background-color` | **`backgroundColor`** | 背景色 |
| `border-radius` | **`borderRadius`** | 角の丸み |

**例:** `font-size`を`20px`に変更したい場合

```javascript
// CSS: font-size
document.getElementById("main").style.fontSize = "20px";
```

このように、ラクダのコブのように文字の途中に大文字（`S`）がくるのが、キャメルケースの名前の由来です。

\<hr\>

## 2\. `this`オブジェクトとは？

HTMLのイベント（マウスを乗せた、クリックしたなど）が発生したときに、「**今、操作されている**」HTML要素自身を指すのが特別なキーワード **`this`** です。

「**私自身**」や「**この要素**」という意味合いで使われます。

### `this`を使って関数を呼び出す例

例えば、画像にマウスを乗せたとき、**その画像**の見た目だけを変えたいとします。

**HTML側** (`<img>`タグ内):

```html
<img src="sample.jpg" onmouseover="mOver(this)">
```

1.  ユーザーがこの画像の上にマウスを乗せます（`onmouseover`）。
2.  `mOver()`という関数を呼び出します。
3.  このとき、引数に `this` が指定されているので、**今マウスが乗っている**この`<img>`タグ自身を関数に渡します。

**JavaScript側** (関数):

```javascript
function mOver(obj){
    // obj は、HTML側から渡された「<img>要素自身」を表す
    obj.style.opacity = 1.0;
}
```

1.  関数 `mOver` は、引数として渡された要素を `obj` という名前で受け取ります。
2.  この `obj` は、**マウスが乗った元の `<img>` 要素そのもの**なので、`obj.style.opacity = 1.0;` と書くことで、**その要素だけ**の透明度を変更できます。

このように、`this`を使うことで、一つの関数（`mOver`）を用意するだけで、ページ上の**どの要素**に対してイベントが発生しても、その要素だけを操作できるようになり、非常に便利です。

## 💡 HTML要素のAttribute（属性）とは

HTML要素の**属性（Attribute）とは、その要素に関する追加情報や設定**を定義するために、開始タグ内に記述される「`属性名="属性値"`」のペアのことです。

例えば、リンク要素（`<a>`）の`href`属性や、画像要素（`<img>`）の`src`属性などが代表的です。

| HTMLでの記述例 | 属性名 | 属性値 | 役割 |
| :--- | :--- | :--- | :--- |
| `<a href ="index.html">リンク</a>` | `href` | `"index.html"` | リンク先URLを指定 |
| `<img src="image.jpg"alt="説明">` | `src` | `"image.jpg"` | 画像ファイルのパスを指定 |
| | `alt` | `"説明"` | 代替テキストを指定 |

-----

## 💻 JavaScriptから属性を操作する方法

JavaScriptは、HTML要素のDOM（Document Object Model）を介して、これらの属性を**取得、変更、追加、削除**することができます。主に以下のメソッドが使われます。

| メソッド | 役割 |
| :--- | :--- |
| `element.getAttribute(name)` | 指定した属性の**値を取得**します。 |
| `element.setAttribute(name, value)` | 指定した属性の**値を設定（変更・追加）します。 |
| `element.removeAttribute(name)` | 指定した属性を削除**します。 |
| `element.hasAttribute(name)` | 指定した属性が**存在するかどうか**をチェックします（`true`または`false`を返します）。 |

### 具体的な使用例

HTML: `<button id="myButton" data-count="0">クリック</button>`

```javascript
const button = document.getElementById('myButton');

// 1. 属性の値を取得
const initialCount = button.getAttribute('data-count');
console.log(initialCount); // "0" が出力されます

// 2. 属性の値を変更
button.setAttribute('data-count', '1');

// 3. 新しい属性を追加
button.setAttribute('disabled', ''); // 論理属性（値はあってもなくても要素に存在すれば有効）

// 4. 属性の有無を確認
console.log(button.hasAttribute('disabled')); // true が出力されます
```

### 🧐 属性（Attribute）とプロパティ（Property）の違い

JavaScriptでHTML要素を操作する際、**属性（Attribute）** と **プロパティ（Property）** という2つの概念を理解しておくことが重要です。

  * **属性（Attribute）**:
      * HTMLの**開始タグ**に記述されるものです。（例：`<input type="text" value="初期値">`）
      * 常に**文字列**です。
      * 主に`getAttribute()` / `setAttribute()` で操作されます。
  * **プロパティ（Property）**:
      * DOMオブジェクト（JavaScriptのオブジェクト）が持つ**特性**です。
      * 型は文字列以外（ブール値、数値など）もあります。（例：`button.disabled` は `true` / `false` のブール値）
      * ドット記法（`.`）でアクセスします。（例：`element.id` や `element.value`）

標準的な属性（`id`, `class`, `value`など）の多くは、DOMオブジェクトの対応する**プロパティ**として自動的にマッピングされ、通常はプロパティとしてアクセスする方が便利です。

| 属性 (Attribute) | プロパティ (Property) |
| :--- | :--- |
| `element.getAttribute('id')` | `element.id` |
| `element.setAttribute('value', '新値')` | `element.value = '新値'` |

非標準の属性（例：`data-count`などの`data-`属性）や、特定の操作を行いたい場合は、`getAttribute()` / `setAttribute()` メソッドを使用します。

## 🔗 `<a>`タグの`href`属性の例

`href`属性は、アンカー（`<a>`）要素がリンクする**目的地のURL**を指定します。

### HTMLの例

```html
<a id="myLink" href="https://www.google.com/" target="_blank">Googleで検索</a>
```

### JavaScriptによる操作例

JavaScriptを使って、リンク先URLやその他の関連属性を取得・変更できます。

| 操作内容 | JavaScriptコード | 結果（コンソール出力） |
| :--- | :--- | :--- |
| **属性の取得** | `const url = link.getAttribute('href');` | `"https://www.google.com/"` |
| **属性の変更** | `link.setAttribute('href', 'https://www.yahoo.co.jp/');` | リンク先をYahoo\!に変更 |
| **プロパティによる変更** | `link.target = '_self';` | リンクを現在のタブで開くように変更 |
| **属性の削除** | `link.removeAttribute('target');` | `target="_blank"`を削除 |

```javascript
const link = document.getElementById('myLink');

// 1. 属性の値を取得
console.log(`現在のリンク先: ${link.getAttribute('href')}`);

// 2. 属性の値を変更
link.setAttribute('href', 'https://www.yahoo.co.jp/');
console.log(`変更後のリンク先: ${link.getAttribute('href')}`);

// 3. プロパティで target を変更（_blankから_selfへ）
link.target = '_self';
console.log(`target属性: ${link.getAttribute('target')}`); 
```

`src`属性は、画像（`<img>`）要素が表示する\*\*画像ファイルのパス（URL）\*\*を指定します。

### HTMLの例

### JavaScriptによる操作例

JavaScriptで`src`属性を変更することで、動的に表示する画像を切り替えることができます。

## 【参考】テンプレートリテラル（Template Literals）の説明

コード例で、コンソール出力に`${}`（ドル記号と波括弧）が使われているのは、JavaScriptの**テンプレートリテラル（Template Literals）**という機能を使用しているためです。

これは、文字列内に変数や式の結果を埋め込むための、非常に便利な構文です。


### 1. テンプレートリテラルの構文

テンプレートリテラルは、通常の引用符（`""`や`''`）ではなく、**バッククォート（ `` ）** で囲まれた文字列です。

* **通常の文字列:** ` "現在のリンク先: " + url`
* **テンプレートリテラル:** `` `現在のリンク先: ${url}` ``

### 2. `${}`が使われる理由（式の埋め込み）

このバッククォートで囲まれた文字列の中で、`${}`という構文を使用すると、その中に入れた**変数や式の結果**を文字列の中に直接埋め込むことができます。

#### 比較例

| 構文 | コード例 | 出力結果 (url = "[https://example.com/](https://example.com/)") |
| :--- | :--- | :--- |
| **文字列の結合（従来の書き方）** | `console.log("現在のリンク先: " + url);` | `現在のリンク先: https://example.com/` |
| **テンプレートリテラル** | `console.log(\`現在のリンク先: ${url}\`);` | `現在のリンク先: https://example.com/` |

このように、テンプレートリテラルを使うことで、文字列の結合（`+`演算子）を何度も使う必要がなくなり、コードが**より簡潔で読みやすく**なります。

### 3. その他のメリット

テンプレートリテラルは、`${}`による式の埋め込み以外にも、以下のようなメリットがあります。

* **改行の記述が簡単**：文字列内に直接改行を記述できます。
* **より複雑な式も埋め込める**：変数だけでなく、関数呼び出しや計算式なども埋め込めます。（例：`${a + b}`）

---

つまり、このコード例で`${}`が使われているのは、文字列の途中に変数`link.getAttribute('href')`や`link.src`の値を、**分かりやすく簡単に組み込む**ためです。

# イベントリスナー

JavaScriptのイベントリスナーは、Webページ上でユーザーが行う操作（クリック、キー入力など）や、ブラウザの状態変化といった「イベント」を監視し、イベントが発生した際に特定の処理（関数）を実行するための仕組みです。

## 👂 JavaScript イベントリスナーの使い方

### 1\. イベントリスナーを使用する際の流れ

イベントリスナー（主に `addEventListener()` メソッド）を使って処理を実行するまでの流れは、以下の2つのステップで構成されます。

#### ステップ 1: 要素の特定

まず、イベントを監視したいHTML要素をJavaScriptから操作できるように特定（取得）します。

  * **主な要素の特定方法:**
      * `document.getElementById('ID名')`：`id`属性で要素を特定する（最も一般的）
      * `document.querySelector('セレクター')`：CSSセレクターに一致する最初の要素を特定する
      * `document.querySelectorAll('セレクター')`：CSSセレクターに一致するすべての要素を特定する

**【コード例】**

```javascript
// IDが "myButton" の要素を特定
const button = document.getElementById('myButton');
```

#### ステップ 2: `addEventListener`を使った関数の呼び出し設定

特定した要素に対して `addEventListener()` メソッドを使い、「**どのイベント**が起きたら、**どの関数**を実行するか」を設定します。

```javascript
要素.addEventListener( 'イベントの種類', 実行する関数 );
```

| 引数 | 説明 | 例 |
| :--- | :--- | :--- |
| **イベントの種類** | 監視したいイベントを文字列で指定します。 | `'click'`, `'mouseover'`, `'keydown'`, `'submit'`など |
| **実行する関数** | イベント発生時に実行したい処理（関数）を指定します。 | `handleClick` (定義済みの関数名), `function() { ... }` (無名関数) |

**【コード例】**

```javascript
// クリックイベントが発生したら、sayHello関数を実行するように設定
button.addEventListener('click', sayHello);

function sayHello() {
  console.log('ボタンがクリックされました！');
}
```

-----

## 2\. 無名関数を使った、引数のある関数の呼び出し方

`addEventListener`に渡す「実行する関数」は、引数を直接渡すことができません。例えば、以下のように書くと、イベント発生前に関数が即時実行されてしまい、イベントリスナーとして機能しません。

❌ **誤った例（即時実行されてしまう）**

```javascript
button.addEventListener('click', sayName('田中')); // sayNameがすぐに実行される
```

### ✅ 無名関数（アロー関数）を使った正しい方法

この問題を解決するには、引数を持つ関数を\*\*無名関数（またはアロー関数）\*\*でラップ（包む）します。

無名関数自体は引数をとりませんが、その**内部**で、引数を指定した目的の関数を呼び出すことができます。

```javascript
要素.addEventListener('イベントの種類', () => {
  // ここが無名関数
  目的の関数(引数); 
});
```

**【コード例】**

```javascript
const button = document.getElementById('sendData');

function sendName(name) {
  console.log(`${name} さんのデータを送信しました。`);
}

// 無名関数でラップし、その中で引数 '佐藤' を指定して sendName を呼び出す
button.addEventListener('click', () => {
  sendName('佐藤'); 
});
```

この方法で設定すると、

1.  ユーザーがボタンを**クリック**する。
2.  `addEventListener`に登録された**無名関数**が実行される。
3.  無名関数の内部にある `sendName('佐藤')` が実行される。
4.  コンソールに「佐藤 さんのデータを送信しました。」が出力される。

-----

## 🛠️ イベントリスナーを使ったデモコード

このデモでは、「**ボタンをクリックすると、見出しのテキスト内容が変わる**」という処理を実装します。

### HTML (`index.html`)

```html

</head>
<body>

    <h2 id="targetText">初期のメッセージです。</h2>
    
    <button id="changeButton">メッセージを変更</button>

    <script>
        // ここにJavaScriptコードを記述します
        // 以下のコードを参照してください
    </script>
</body>
</html>
```

### JavaScript（`<script>`タグ内に記述）

```javascript
// 1. 操作したい要素（見出しとボタン）を特定する
const targetElement = document.getElementById('targetText');
const buttonElement = document.getElementById('changeButton');

// 変更後のメッセージを保持する関数
function updateMessage(newMessage) {
    // 取得した要素のtextContentプロパティを変更し、テキストを書き換える
    // ※ 属性 (attribute) ではありませんが、要素の内容（プロパティ）を操作する代表的な例です。
    targetElement.textContent = newMessage;
    
    // （おまけ）変更後にボタンの属性を操作する例
    buttonElement.setAttribute('disabled', '');
    buttonElement.textContent = '変更済み';
}

// 2. addEventListenerを使って、ボタンにイベントリスナーを設定する
// 無名関数（アロー関数）を使って、引数付きの関数を呼び出す
buttonElement.addEventListener('click', () => {
    
    // 無名関数内で、引数として新しいメッセージを指定して関数を呼び出す
    updateMessage('🎉 イベントが発生し、メッセージが書き換わりました！');
});

console.log('スクリプトが読み込まれました。ボタンをクリックしてください。');
```

### 動作の解説

1.  **要素の特定**: `getElementById`を使い、見出し（`targetText`）とボタン（`changeButton`）を取得します。
2.  **イベントの設定**: `buttonElement.addEventListener('click', ...)` で、ボタンのクリックを監視します。
3.  **無名関数（ラッパー）**: `() => { ... }` という無名関数が、クリック時に実行されます。
4.  **引数付き関数の呼び出し**: 無名関数内から `updateMessage('新しいメッセージ')` を呼び出すことで、引数（新しいテキスト）を渡して処理を実行します。
5.  **コンテンツの書き換え**: `updateMessage`関数内で、`targetElement.textContent` プロパティに新しい文字列を代入し、画面上の表示を更新します。
6.  **属性の操作（おまけ）**: `setAttribute('disabled', '')`により、ボタンに`disabled`属性が追加され、ボタンが押せなくなります。

# フォームについて

フォーム要素は、ウェブサイトからユーザーの入力（名前、メールアドレス、選択肢など）を受け取り、それをサーバーに送信するために不可欠なHTMLの機能です。

ご要望に応じ、フォーム（`form`要素）の基本的な仕組みと、主要な入力要素について説明します。

-----

## 📝 HTMLのフォーム（`<form>`）の基本

HTMLのフォームは、ユーザーからの情報を収集するためのコンテナ（入れ物）として機能します。

### 主な役割と属性

| 要素 | 役割 |
| :--- | :--- |
| **`<form>`** | フォーム全体を定義する要素です。 |
| `action` 属性 | ユーザーが入力したデータを送信する先のURL（サーバー側のプログラムなど）を指定します。 |
| `method` 属性 | データの送信方法を指定します。通常は `GET`（URLにデータを含める）か `POST`（データを見えない形で送信する）を指定します。 |

**【記述例】**

```html
<form action="/submit-data" method="POST">
    </form>
```

-----

## 🔠 主要な入力要素

ユーザーが直接情報を入力したり、選択したりするための要素群です。これらは通常、`<form>`タグの中に配置されます。

### 1\. `<input>` 要素

`<input>`要素は、フォーム入力の**最も基本的な要素**です。その種類は、`type`属性の値を変更することで切り替わります。

| `type` 属性値 | 役割 | 備考 |
| :--- | :--- | :--- |
| `text` | **一行のテキスト入力**欄 | 名前や自由記述などに使用されます。 |
| `email` | **メールアドレス入力**欄 | 入力内容がメールアドレス形式かブラウザがチェックします。 |
| `password` | **パスワード入力**欄 | 入力内容が `*` や `•` で隠されます。 |
| `submit` | **送信ボタン** | フォームデータを `action`で指定されたURLへ送信します。 |
| `reset` | **リセットボタン** | フォーム内のすべての入力を初期状態に戻します。 |

**【記述例】**

```html
<input type="text" name="username" placeholder="名前を入力">

<input type="password" name="userpass">

<input type="submit" value="送信">
```

### 2\. チェックボックス (`type="checkbox"`)

複数の選択肢の中から、**いくつでも**選択肢を選べるようにする場合に使用します。

  * **特徴**: 各チェックボックスは**独立**しています。
  * **重要な属性**:
      * `type="checkbox"`: チェックボックスであることを指定します。
      * `name` 属性: **すべて同じ値**を指定し、サーバーに複数の値をまとめて送れるようにします。
      * `value` 属性: チェックされたときに、サーバーに送信される具体的な値を指定します。

**【記述例】**

```html
<label>
    <input type="checkbox" name="hobbies" value="reading"> 読書
</label>
<label>
    <input type="checkbox" name="hobbies" value="sports"> スポーツ
</label>
```

### 3\. ラジオボタン (`type="radio"`)

複数の選択肢の中から、**一つだけ**を選ばせたい場合に使用します。

  * **特徴**: **同じ `name` 属性を持つもの**は、一つのグループと見なされ、その中から一つしか選択できません。
  * **重要な属性**:
      * `type="radio"`: ラジオボタンであることを指定します。
      * `name` 属性: **グループ内で同じ値**を指定します。
      * `value` 属性: 選択されたときに送信される具体的な値を指定します。

**【記述例】**

```html
<label>
    <input type="radio" name="gender" value="male"> 男性
</label>
<label>
    <input type="radio" name="gender" value="female"> 女性
</label>
```

### 4\. セレクトボックス（`<select>`と`<option>`）

ドロップダウンリストとして選択肢を表示し、その中から**一つ（または複数）の項目**を選ばせたい場合に使用します。

  * **`<select>`**: ドロップダウンリスト全体を定義します。`name`属性をここで指定します。
  * **`<option>`**: 選択肢の項目を一つ一つ定義します。`value`属性に送信する値を指定します。

**【記述例】**

```html
<select name="prefecture">
    <option value="">都道府県を選択してください</option>
    <option value="tokyo">東京都</option>
    <option value="osaka">大阪府</option>
</select>
```

-----

これらの要素を組み合わせることで、ユーザーから多様な情報を効率的に収集するフォームを作成できます。

フォームについて、例えば**データの送信方法（GETとPOSTの違い）やJavaScriptでのフォーム入力値の取得方法**など、さらに詳しく知りたい点はありますか？

JavaScriptでフォームの入力値を取得する方法は、Webアプリケーション開発において非常に重要です。主に、フォームの**各入力要素（`<input>`、`<select>`、`<textarea>`など）が持つDOMプロパティ**を利用します。

特に重要なのは、ほとんどの入力要素が持つ **`value`プロパティ** です。

ご要望に応じ、入力値を取得する際の手順と、要素ごとの具体的な取得方法を解説します。

-----

## 💻 JavaScriptでのフォーム入力値の取得手順

フォームの入力値を取得する基本的な流れは、**イベントリスナー**を活用し、ユーザーが「送信」などの操作をしたタイミングで値を取り出すことです。

### 1\. 要素の特定

まず、値を取得したい**入力要素自体**と、処理を開始する **トリガー（通常は送信ボタン）** を特定します。

```javascript
// 値を取得したいテキスト入力欄を特定
const usernameInput = document.getElementById('username');

// 送信ボタン（クリックのトリガー）を特定
const submitButton = document.getElementById('submitBtn');
```

### 2\. イベントリスナーの設定

フォーム送信時（またはボタンクリック時）に、値を取得する処理を実行するように設定します。

```javascript
submitButton.addEventListener('click', (event) => {
    // 💡 フォームの送信処理を一時停止（ページ遷移を防ぐため）
    // event.preventDefault(); 
    
    // 3. 値の取得と利用
    const username = usernameInput.value;
    console.log(`ユーザー名: ${username}`);
    
    // ここでサーバーへ送信する処理などを実行
});
```

### 3\. 値の取得と利用

特定した要素の **`.value`プロパティ** にアクセスすることで、現在入力されている値（文字列）を取得できます。

-----

## 📋 要素ごとの具体的な値の取得方法

入力要素の種類によって、`value`プロパティの動作や、値の取得に必要な追加のチェックが異なります。

### 1\. テキスト入力 (`<input type="text">`, `<input type="password">` など)

これらの要素の値は、シンプルに`.value`プロパティから取得できます。

| 要素の特定 | 値の取得 |
| :--- | :--- |
| `const input = document.getElementById('myText');` | `const value = input.value;` |

### 2\. セレクトボックス (`<select>`)

選択肢（`<option>`）のうち、現在選択されている項目の`value`属性値を取得できます。

| 要素の特定 | 値の取得 |
| :--- | :--- |
| `const select = document.getElementById('mySelect');` | `const selectedValue = select.value;` |

### 3\. チェックボックス (`<input type="checkbox">`)

チェックボックスは、値と同時に**チェックされているか否か**を確認する必要があります。

| 要素の特定 | 状態の確認 | 値の取得 |
| :--- | :--- | :--- |
| `const checkbox = document.getElementById('myCheckbox');` | `const isChecked = checkbox.checked;` | `const value = checkbox.value;` |

  * 💡 `checkbox.checked` は、チェックされていれば `true`、されていなければ `false` を返します。通常は、`true`の場合にのみ`value`を利用します。

### 4\. ラジオボタン (`<input type="radio">`)

ラジオボタンはグループで管理されているため、**グループ全体**から**チェックされている要素**を探し出す必要があります。

1.  まず、すべてのラジオボタン要素を`name`属性や親要素で特定します。
2.  その中から、`.checked`プロパティが`true`になっている要素を見つけます。

**【コード例】**

```javascript
// 1. name="gender"を持つすべてのラジオボタンを取得
const genderRadios = document.getElementsByName('gender'); 
let selectedGender = '';

// 2. ループ処理でチェックされているものを探す
genderRadios.forEach(radio => {
    if (radio.checked) {
        selectedGender = radio.value;
    }
});

console.log(`選択された性別: ${selectedGender}`);
```

このコードは、前のステップで学んだ「要素の特定」「イベントリスナーの設定」「`.value`プロパティによる値の取得」の流れを明確に示すものとなります。

```javascript
// ===================================
// 1. 必要な要素を特定する

const inputElement = document.getElementById('usernameInput');
```

## 📻 ラジオボタンの値の取得方法

ラジオボタンは、**複数の選択肢の中から「一つだけ」を選ばせる**ためのものです。そのため、特定のグループ内で**どれがチェックされているか**を判別する必要があります。

### 取得のロジック

1.  **グループの特定**: `name`属性が同じ要素（グループ）をすべて取得します。
2.  **チェックの確認**: 取得した要素を一つずつチェックし、`.checked` プロパティが `true` になっている要素を見つけます。
3.  **値の取得**: チェックされている要素の `.value` を取得します。

### 🛠️ デモコード（ラジオボタン）

```html
<form id="radioForm">
    <label><input type="radio" name="color" value="red" id="radioRed"> 赤</label>
    <label><input type="radio" name="color" value="blue"> 青</label>
    <label><input type="radio" name="color" value="green"> 緑</label>
    
    <button type="button" id="radioSubmit">ラジオボタンの値を取得</button>
</form>

<script>
    const radioSubmitButton = document.getElementById('radioSubmit');

    radioSubmitButton.addEventListener('click', () => {
        // 1. name="color"を持つすべての要素を取得 (getElementByIdではない点に注意)
        const colorRadios = document.getElementsByName('color'); 
        let selectedColor = '';

        // 2. ループ処理でチェックされているものを探す
        colorRadios.forEach(radio => {
            // .checked プロパティが true の要素を見つける
            if (radio.checked) {
                // 3. その要素の .value を取得
                selectedColor = radio.value;
            }
        });

        console.log(`選択された色: ${selectedColor}`);
    });
</script>
```

## ✅ チェックボックスの値の取得方法

チェックボックスは、**複数の選択肢の中から「いくつでも」選択できる**ものです。そのため、チェックされた**すべての値**を取得し、配列などにまとめる必要があります。

### 取得のロジック

1.  **要素の特定**: `name`属性が同じ要素（グループ）をすべて取得します。
2.  **チェックの確認**: 取得した要素を一つずつチェックし、`.checked` プロパティが `true` になっている要素だけを抽出します。
3.  **値の収集**: 抽出されたすべての要素の `.value` を配列として収集します。

### 🛠️ デモコード（チェックボックス）

```html
<form id="checkboxForm">
    <label><input type="checkbox" name="fruits" value="apple"> リンゴ</label>
    <label><input type="checkbox" name="fruits" value="banana"> バナナ</label>
    <label><input type="checkbox" name="fruits" value="orange"> オレンジ</label>
    
    <button type="button" id="checkboxSubmit">チェックボックスの値を取得</button>
</form>

<script>
    const checkboxSubmitButton = document.getElementById('checkboxSubmit');

    checkboxSubmitButton.addEventListener('click', () => {
        // 1. name="fruits"を持つすべての要素を取得
        const fruitCheckboxes = document.getElementsByName('fruits');
        // 選択された値を格納する空の配列を用意
        const selectedFruits = [];

        // 2. ループ処理でチェックされているものだけを収集
        fruitCheckboxes.forEach(checkbox => {
            // .checked プロパティが true の場合
            if (checkbox.checked) {
                // 3. その要素の .value を配列に追加
                selectedFruits.push(checkbox.value);
            }
        });

        console.log(`選択された果物（配列）: ${selectedFruits}`); 
        console.log(`選択された果物（文字列）: ${selectedFruits.join(', ')}`);
    });
</script>
```

# forEach と コールバック関数

JavaScriptの`forEach`は、**配列**の要素を一つずつ順番に取り出して処理を行うための、とても便利で現代的な方法です。従来の`for`ループよりも簡潔に書けるため、よく使われます。

-----

## 💡 `forEach`とは？

`forEach`は、JavaScriptの**配列**（Array）に用意されているメソッド（機能）です。

  * **役割:** 配列のすべての要素に対して、同じ処理を順番に実行します。
  * **特徴:** 繰り返し処理を**短く、読みやすく**書くことができます。

### 📝 基本構文

`forEach`は、引数に「**コールバック関数**」というものを一つ取ります。コールバック関数とは、「後で呼び出してもらうための関数」のことです。

#### 1\. 基本の形

```javascript
配列名.forEach(function(要素) {
    // 👈 ここに、要素ごとに実行したい処理を書きます
});
```

#### 2\. アロー関数を使ったより一般的な形（推奨）

最近のJavaScriptでは、より短く書ける**アロー関数**を使うことが一般的です。

```javascript
配列名.forEach((要素) => {
    // 👈 ここに、要素ごとに実行したい処理を書きます
});
```

-----

### 🛠️ 実際の使用例

数字の配列の全ての要素をコンソールに出力する例を見てみましょう。

#### 例: 配列の要素をすべて表示する

```javascript
const numbers = [10, 20, 30, 40];

// forEachで各要素を順番に処理
numbers.forEach((num) => {
    console.log(num); // 順番に 10, 20, 30, 40 と出力される
});

// forEachを使って「要素を2倍にする」処理も簡単に書けます
numbers.forEach((num) => {
    const doubled = num * 2;
    console.log(doubled); // 順番に 20, 40, 60, 80 と出力される
});
```

-----

### 🔧 コールバック関数が受け取る引数（おまけ）

`forEach`に渡す関数は、実は最大で**3つ**の引数を受け取ることができます。

1.  `要素` (必須): 現在処理している**配列の要素の値**。
2.  `インデックス` (省略可): その要素が配列の**何番目**にあるかを示す番号（0から始まります）。
3.  `元の配列` (省略可): 処理を実行している**元の配列全体**。

#### 3つの引数を使った例

```javascript
const fruits = ['Apple', 'Banana', 'Cherry'];

fruits.forEach((fruit, index, array) => {
    console.log(`${index}番目の要素: ${fruit}`);
    // array を使えば、元の配列全体を参照することもできます
});

/*
// 出力結果
0番目の要素: Apple
1番目の要素: Banana
2番目の要素: Cherry
*/
```

-----

### ⚠️ 注意点（`for`ループとの違い）

`forEach`を使う上で、一つだけ重要な注意点があります。

  * **途中で処理を中断できない**：従来の`for`ループで使える`break`文や、次の要素に進む`continue`文は、`forEach`では使えません。`return`文を使うと、現在の要素の処理は終わりますが、次の要素の処理は続行されます。
  * もし**特定の条件でループ全体を中断したい場合**は、`for...of`ループや従来の`for`ループの使用を検討する必要があります。

-----

## 👂 コールバック関数とは？

次に、上の説明に出てきた「コールバック関数」が「普通の関数」とどう違うのかについて、説明します。

簡単に言うと、コールバック関数は「**人にお願いされた仕事（関数）**」のようなものです。

### 1\. 🤝 「普通の関数」：自分で呼び出す関数

「普通の関数」は、私たちがコードを書いたときに、**自分でその名前を呼んで**（実行して）使います。

| 項目 | 説明 | 例（普通の関数） |
| :--- | :--- | :--- |
| **役割** | 自分で必要なときに、その場で処理を実行させる。 | 挨拶をする関数を、自分で「`greet()`」と呼び出す。 |
| **呼び出し** | **自分自身**（プログラマー）が呼び出す。 | `myFunction();` |

### 2\. 🎁 「コールバック関数」：渡して、後で実行してもらう関数

コールバック関数は、**他の関数に「引数」として渡され**、その「他の関数」が**適切なタイミングで**実行してくれる関数です。

| 項目 | 説明 | 例（コールバック関数） |
| :--- | :--- | :--- |
| **役割** | 特定の処理の**途中**や、**処理が終わった後**などに実行される。 | `forEach`メソッドに渡し、「配列の要素を取り出すたび」に実行してもらう。 |
| **呼び出し** | **他の関数**（呼び出し元の関数）が呼び出す。 | `forEach` メソッドが、配列の要素ごとに呼び出す。 |
| **渡し方** | 関数名や関数そのものを**引数**として渡す。 | `array.forEach( <--- ここに渡す` function(item){...} ) |

-----

## 🍎 具体的なイメージの比較

先ほどの`forEach`を例に、具体的な役割の違いを見てみましょう。

### シナリオ：スーパーのリンゴをチェックする

| 関数 | JavaScriptでの役割 | イメージ |
| :--- | :--- | :--- |
| **親関数**<br>（`forEach`） | 配列の要素を**一つずつ順番に取り出す**役割。 | スーパーの店員さん。リンゴを一つずつ棚から取る。 |
| **コールバック関数**<br>（渡された関数） | 取り出された要素に**どんな処理をするか**を決める役割。 | 店員さんに頼まれた **「リンゴのチェック方法」**（例: 大きさを測る、傷がないか見る）。 |

**コードでの流れ:**

1.  あなたは店員さん（`forEach`）に、「**リンゴを一つ取ったら、この方法でチェックしてね**」というメモ（コールバック関数）を渡します。
2.  店員さん（`forEach`）は、リンゴを1個取り出すたびに、そのメモ（コールバック関数）を**自分で読んで実行**してくれます。

<!-- end list -->

```javascript
const fruits = ['Apple', 'Banana', 'Cherry'];

// forEach（店員さん）に、チェック方法（コールバック関数）を渡している
fruits.forEach((fruit) => { 
    // コールバック関数の処理（チェック方法）
    console.log(`現在のフルーツは ${fruit} です。`);
}); 
```

### まとめ

コールバック関数は、**「処理の本体」を定義する**役割を持っています。あなたは処理の枠組み（`forEach`で配列を回す、など）を誰かに任せて、**「何をやるか」だけ**を教えてあげている、というイメージです。

-----

この説明で、コールバック関数のイメージが掴めたでしょうか？

# オブジェクト変数

## 💡 オブジェクト変数とは？

オブジェクト変数は、**プロパティ**（情報）を格納するための「**入れ物**」のようなものです。

  * 普通の変数（例: `let name = "田中";`）は一つの値しか保存できません。
  * オブジェクト変数（例: `let person = {...};`）は、名前、年齢、趣味など、関連する**複数の値**にそれぞれ**名前**をつけて（これがプロパティ）、まとめて保存できます。

### 🏠 オブジェクトの例え

「**人物ファイル**」をイメージするとわかりやすいです。

| 変数名 | ファイル名 | プロパティ名 | 値 |
| :--- | :--- | :--- | :--- |
| `person` | 人物ファイル | `name` | "山田 太郎" |
| | | `age` | 30 |
| | | `city` | "東京" |

-----

## 🛠️ オブジェクト変数の作り方

オブジェクト変数は、**波括弧 `{}`** を使って作成します。

### 1\. 基本の形

`{` と `}` の中に、`プロパティ名: 値` のペアを**カンマ `,`** で区切って記述します。

```javascript
let car = {
  // プロパティ名: 値
  brand: "Toyota",
  model: "Corolla",
  year: 2024,
  isElectric: false
};

// この car がオブジェクト変数です
```

  * **プロパティ名**（`brand`, `model`, `year`, `isElectric` など）は、基本的に**文字列**（引用符で囲まなくてもOK）として扱われます。
  * **値**には、文字列、数値、真偽値（`true`/`false`）など、どんなデータ型でも入れることができます。

### 2\. 空のオブジェクトを作って後から追加

まず空のオブジェクトを作り、後から情報を追加していくこともできます。

```javascript
// 1. まず空のオブジェクトを作る
let dog = {};

// 2. 後からプロパティを追加する
dog.name = "Pochi";
dog.breed = "Shiba Inu";
dog.age = 5;
```

-----

## 🚀 オブジェクト変数の使い方（値の取り出し）

オブジェクト変数に保存された値を取り出すには、主に2つの方法があります。

### 1\. ドット記法 (Dot Notation) 👉 最も一般的

オブジェクト変数名の**直後にドット `.`** をつけ、続けてプロパティ名を記述します。

```javascript
let person = {
  name: "花子",
  age: 25
};

// nameプロパティの値を取り出す
console.log(person.name);   // 出力: 花子

// ageプロパティの値を取り出す
console.log(person.age);    // 出力: 25
```

### 2\. ブラケット記法 (Bracket Notation)

オブジェクト変数名の**直後に角括弧 `[]`** をつけ、その中にプロパティ名を**文字列として**記述します。

```javascript
let person = {
  name: "花子",
  age: 25
};

// nameプロパティの値を取り出す
console.log(person["name"]); // 出力: 花子
```

> ⚠️ **ブラケット記法**は、プロパティ名が数字やハイフンを含む特殊な文字列の場合や、**変数を使ってプロパティ名にアクセスしたい場合**などに役立ちます。

-----

## ✏️ プロパティの値の変更・削除

オブジェクトに格納されている情報は、後から簡単に**変更**したり**削除**したりできます。

### 1\. 値の変更 (Update)

ドット記法またはブラケット記法でアクセスし、新しい値を代入します。

```javascript
let item = {
  name: "ペン",
  price: 100
};

// priceプロパティの値を変更する
item.price = 120;

console.log(item.price); // 出力: 120
```

### 2\. 削除 (Delete)

`delete` キーワードを使います。

```javascript
let item = {
  name: "ペン",
  price: 120,
  color: "青"
};

// colorプロパティを削除する
delete item.color;

console.log(item.color);    // 出力: undefined (プロパティが存在しない)
console.log(item);          // 出力: { name: 'ペン', price: 120 }
```

-----

これで、オブジェクト変数の基本的な作り方、情報の取り出し方、そして更新・削除の方法がわかりましたね。オブジェクトはJavaScriptで最も重要な概念の一つなので、ぜひ実際にコードを書いて試してみてください！

お待たせしました！JavaScriptの**オブジェクトの配列**は、実際の開発で最もよく使われるデータ構造の一つです。初心者の方にも伝わるよう、作り方と使い方を説明しますね。

## 📚 オブジェクトの配列（Array of Objects）とは？

**オブジェクトの配列**とは、その名の通り、**複数のオブジェクトを一つの配列にまとめたもの**です。

これは、同じ「**種類**」の情報（例：複数のユーザー、複数の商品、複数のブログ記事など）をリスト形式で扱うために使われます。

### 🏢 例えるなら「顧客リスト」

前回ご説明した「人物ファイル（オブジェクト）」が個々のデータだとすると、オブジェクトの配列は「**顧客名簿**」や「**商品カタログ**」のようなものです。

| 配列の位置（インデックス） | 個別のデータ（オブジェクト） |
| :---: | :--- |
| `[0]` | `{ name: "山田", age: 30, city: "東京" }` |
| `[1]` | `{ name: "佐藤", age: 25, city: "大阪" }` |
| `[2]` | `{ name: "田中", age: 40, city: "福岡" }` |

-----

## 🛠️ オブジェクトの配列の作り方

配列を作成する**角括弧 `[]`** の中に、複数の**オブジェクト `{}`** を**カンマ `,`** で区切って記述します。

### 1\. 複数の商品データを格納する例

```javascript
let products = [
  // 1番目のオブジェクト (インデックス0)
  {
    id: 101,
    name: "ワイヤレスマウス",
    price: 3500,
    inStock: true
  },

  // 2番目のオブジェクト (インデックス1)
  {
    id: 102,
    name: "メカニカルキーボード",
    price: 12800,
    inStock: false
  },

  // 3番目のオブジェクト (インデックス2)
  {
    id: 103,
    name: "Webカメラ",
    price: 6000,
    inStock: true
  }
];
```

この `products` 変数が**オブジェクトの配列**です。

-----

## 🚀 オブジェクトの配列の使い方

値を取り出すには、「**配列のアクセス**」と「**オブジェクトのアクセス**」という2つのステップが必要です。

### 1\. 個々のオブジェクトを取り出す（配列のアクセス）

通常の配列と同じように、**インデックス（位置）** を使って、まず目的のオブジェクトを取り出します。インデックスは `0` から始まります。

```javascript
// 配列の2番目の要素（インデックス1）を取り出す
let secondProduct = products[1];

// secondProduct は一つのオブジェクトになる
console.log(secondProduct);
// 出力: { id: 102, name: "メカニカルキーボード", price: 12800, inStock: false }
```

### 2\. オブジェクト内のプロパティを取り出す

取り出したオブジェクトに対して、前回学んだ**ドット記法 `.`** を使って、プロパティの値にアクセスします。

```javascript
// 1行で記述する場合：
// 配列の2番目の要素(products[1])の name プロパティにアクセス
console.log(products[1].name);  // 出力: メカニカルキーボード

// 配列の3番目の要素(products[2])の price プロパティにアクセス
console.log(products[2].price); // 出力: 6000
```

### 3\. ループ処理で全てを表示する

オブジェクトの配列はデータの一覧表示によく使われるため、`for` ループや `forEach` メソッドを使って、すべての要素を順番に処理します。

```javascript
// forEach を使った例
products.forEach(function(product) {
  // product は、配列から順番に取り出された個々のオブジェクト
  console.log(`商品名: ${product.name} / 価格: ${product.price}円`);
});

// 出力:
// 商品名: ワイヤレスマウス / 価格: 3500円
// 商品名: メカニカルキーボード / 価格: 12800円
// 商品名: Webカメラ / 価格: 6000円
```

-----

## ✏️ オブジェクトの配列への操作

### 1\. 要素の追加

配列の末尾に新しいオブジェクトを追加するには、`push()` メソッドを使います。

```javascript
// 新しい商品オブジェクト
let newProduct = {
  id: 104,
  name: "充電器",
  price: 4000,
  inStock: true
};

// 配列に追加
products.push(newProduct);

// products の最後に "充電器" が追加される
```

### 2\. 特定のプロパティの変更

インデックスでオブジェクトにアクセスし、ドット記法でプロパティを更新します。

```javascript
// 1番目の商品（ワイヤレスマウス）の価格を変更する
products[0].price = 3000;

console.log(products[0].price); // 出力: 3000
```

オブジェクトの配列は、Webサイトから取得したデータ（JSON形式）や、アプリケーションで管理するリストなど、あらゆる場所で使われます。この構造を理解することが、JavaScriptでのデータ処理の第一歩となります。

## ⏰ `setInterval()` の使い方

`setInterval()` は、JavaScriptで**一定の時間間隔**で**関数を繰り返し実行**させたいときに使用する機能です。デジタル時計の表示更新や、スライドショーの自動切り替えなどによく使われます。

-----

### 1\. 基本構文

`setInterval()` は、主に2つの引数（ひきすう）を取ります。

```javascript
const intervalID = setInterval(実行したい関数, 実行間隔);
```

| 引数名 | 意味 | 単位 |
| :--- | :--- | :--- |
| **実行したい関数** | 繰り返し実行させたい処理（関数名、または無名関数）を指定します。 | N/A |
| **実行間隔** | 関数を呼び出す間隔を**ミリ秒（1/1000秒）** 単位で指定します。 | ミリ秒 (ms) |

`setInterval()` を呼び出すと、実行を停止するための識別子（ID）が返されます。このIDを保持しておくことで、後から実行を止めることができます。

-----

### 2\. サンプルコード

1秒（1000ミリ秒）ごとにコンソールにメッセージを表示する例です。

```javascript
function sayHello() {
  console.log("Hello! 1秒ごとに実行中...");
}

// sayHello 関数を1000ミリ秒（1秒）ごとに実行する
const timerId = setInterval(sayHello, 1000); 
```

**無名関数（アロー関数）を使う方法**も一般的です。

```javascript
let count = 0;
const timerId = setInterval(() => {
  count++;
  console.log(`${count}秒経過しました。`);
}, 1000); 
```

-----

### 3\. 実行の停止: `clearInterval()`

`setInterval()` は、一度実行されると、ブラウザを閉じるか、明示的に停止するまで**永遠に**実行され続けます。繰り返し処理を停止するには、**`clearInterval()`** 関数を使用します。

`clearInterval()` には、`setInterval()` を実行したときに取得した**タイマーID**を引数として渡します。

```javascript
let count = 0;

const timerId = setInterval(() => {
  count++;
  console.log(`${count}秒経過しました。`);

  // 5秒経過したら停止する
  if (count >= 5) {
    clearInterval(timerId); // タイマーを停止
    console.log("タイマーを停止しました。");
  }
}, 1000);
```

### 4\. 引数を渡す（補足）

実行する関数に引数を渡したい場合、`setInterval()` の第3引数以降に指定します。

```javascript
function greet(name) {
  console.log(`こんにちは、${name}さん！`);
}

// greet 関数を2秒ごとに実行し、「太郎」を引数として渡す
setInterval(greet, 2000, "太郎"); 
```

-----

## ⚠️ `setTimeout()` との違い

`setInterval()` と似た関数に **`setTimeout()`** があります。

  * **`setInterval()`**: 指定した時間間隔で**繰り返し**関数を実行する。
  * **`setTimeout()`**: 指定した時間経過後に**一度だけ**関数を実行する。

用途に合わせて使い分けてください。

はい、JavaScriptのコードをHTMLから**別のファイルに分離**する方法は、初心者にとって非常に重要なステップです。これにより、コードの管理がずっと楽になります。

## 📝 外部JavaScriptファイル（.js）の作成

まず、HTMLファイルに直接書いていたJavaScriptのコードだけを抜き出して、新しいファイルに保存します。

  * **拡張子:** ファイルの拡張子は必ず **`.js`** にします（例：`script.js`、`main.js`）。
  * **内容:** この `.js` ファイルには、純粋なJavaScriptコードだけを記述します。HTMLファイルに書くときのように `<script>` タグは**不要**です。

## 🔗 HTMLファイルでの読み込み方

次に、作成した外部JavaScriptファイルをHTMLファイルから読み込む必要があります。これには、HTMLの `<script>` タグの **`src`** 属性を使用します。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>外部ファイル読み込みの例</title>
</head>
<body>
    <h1>JavaScriptの分離</h1>
    <button id="myButton">クリック</button>

    <script src="script.js"></script> 
</body>
</html>
```

  * **`<script>` タグ:** JavaScriptを読み込みたい場所に `<script>` タグを記述します。
  * **`src` 属性:** **`src`** (Sourceの略) 属性に、作成した `.js` ファイルの**パス**を指定します。上記の例では、HTMLファイルと同じフォルダに `script.js` がある場合の指定方法です。

-----

## ✨ 分離するメリット

JavaScriptを外部ファイルに分離することで、主に以下のメリットがあります。

1.  **管理のしやすさ:** HTMLとJavaScriptがごちゃ混ぜにならず、それぞれのコードの修正が**独立**して行えるようになります。
2.  **再利用性:** 作成した `.js` ファイルを**複数のHTMLページ**で使い回すことができます。
3.  **読み込みの高速化:** ブラウザが一度ファイルをキャッシュすると、**2回目以降**のページ表示時にJavaScriptファイルを**再ダウンロード**する必要がなくなり、ページの読み込みが速くなります。
4.  **メンテナンス性:** コード量が増えても、HTMLとJavaScriptの役割が明確に分かれているため、**バグの発見や修正**が容易になります。

-----

この方法は、モダンなウェブ開発の**基本中の基本**です。最初のうちは少し手間かもしれませんが、コードが大きくなるほどその重要性が分かってくるでしょう。

他に、外部ファイルに関する疑問（例えば、どこに `<script>` タグを書くべきかなど）はありますか？

はい、JavaScriptを読み込むための `<script>` タグをHTML内の**どこに配置するか**は、パフォーマンスと動作に影響を与えるため、非常に重要です。

基本的には、以下の2つの主要な配置場所があります。

## 1\. \<body\>タグの閉じタグ（`</body>`）の直前 🚀

これが**最も推奨される配置方法**です。

```html
<!DOCTYPE html>
<html>
<head>
    </head>
<body>
    <h1>ページの内容</h1>
    <script src="script.js"></script>
</body>
</html>
```

-----

### なぜここが推奨されるのか？

ブラウザはHTMLファイルを**上から順番**に読み込み、表示していきます。

1.  ブラウザが `<script>` タグを見つけると、HTMLの解析を**一時停止**し、JavaScriptファイル（`script.js`）の**ダウンロード、解析、実行**を先に行います。
2.  JavaScriptの処理が終わってから、残りのHTMLの解析を再開します。

もし `<script>` タグを `<head>` 内に置いてしまうと、JavaScriptの読み込み・実行が完了するまで、**ページの内容（`<body>` 内の要素）の表示が止まって**しまいます。

`</body>` の直前に置けば、HTMLの**すべての要素が表示され終わってから**JavaScriptが実行されるため、ユーザーはすぐにページの内容を見ることができ、**体感的な読み込み速度が向上**します。

-----

## 2\. \<head\>タグの中

ページの**最初**にJavaScriptを実行する必要がある場合や、小さなスクリプトでのみ使われる配置です。

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>タイトル</title>

    <script src="script.js"></script>
</head>
<body>
    </body>
</html>
```

### パフォーマンスへの注意点

前述の通り、ここに置くとHTMLの描画がブロックされるため、大規模なスクリプトではページの表示が遅くなります。

ただし、この場所で読み込む場合でも、HTMLの描画をブロックするのを避けるために、**`defer`** または **`async`** 属性を使用することが一般的です。

  * **`defer` 属性:**

      * `<script src="script.js" defer></script>`
      * JavaScriptの**ダウンロード**をHTMLの解析と**並行**して行い、HTMLの解析が**完了した後**に、JavaScriptを**実行**します。動作としては `</body>` の直前に置くのと同じような効果が得られ、推奨されます。

  * **`async` 属性:**

      * `<script src="script.js" async></script>`
      * JavaScriptの**ダウンロード**と**実行**の両方を、HTMLの解析と**並行**して行います。実行のタイミングが予測できないため、他のスクリプトとの依存関係がない**独立したスクリプト**（例：アクセス解析タグなど）に使用されます。

| 配置場所 | 実行のタイミング | 主なメリット |
| :--- | :--- | :--- |
| **`</body>` の直前** | ページのHTML要素がすべて読み込まれた後。 | **体感速度が速い**。HTML要素を参照しやすい。 |
| **`<head>` 内 + `defer`** | ページのHTML要素がすべて読み込まれた後。 | パフォーマンスを維持しつつ、`<head>` 内にコードをまとめられる。 |
| **`<head>` 内 + `async`** | ダウンロード完了後、すぐに実行（HTML解析を中断する可能性あり）。 | 他のスクリプトに依存しない独立したスクリプト向き。 |

**初心者の方には、まず「`</body>` の直前」に配置する方法を基本として覚えることを強くおすすめします。**

-----

# プリミティブ型とオブジェクト型

```JavaScript
let theDay = new Date(2030, 5, 1);
let msg = "Hello";
```

`Date`オブジェクトに`new`が必要な理由と、文字列（String）に`new`が不要な理由の背後には、JavaScriptが持つ「**プリミティブ型**」と「**オブジェクト型**」の明確な違いがあります。

-----

## 🧐 プリミティブ型とオブジェクト型

JavaScriptのデータには、大きく分けて「プリミティブ型（基本型）」と「オブジェクト型（参照型）」の2種類があり、この違いが生成方法に影響しています。

### 1\. プリミティブ型（例: 文字列 / String）

文字列（String）、数値（Number）、真偽値（Boolean）などはプリミティブ型に分類されます。

| 項目 | 文字列 (`'hello'`) |
| :--- | :--- |
| **データ** | **単純な値**（それ自体がデータ） |
| **メモリ** | メモリ上の**決まった場所**に、値が直接格納される。 |
| **生成方法** | **代入（リテラル）** でシンプルに生成。 |

#### `new`が不要な理由

文字列は「`hello`」という単純な値だけで完結しており、特別な初期化処理や、複雑な内部状態を持つ必要がないため、最もシンプルな代入構文で生成されます。

```javascript
// シンプルな値なので、newは不要
let str = 'apple';
```

#### なぜメソッドが使えるのか？ (補足)

文字列はプリミティブ型ですが、`.toUpperCase()`などのメソッドを使えます。これは、メソッドを呼び出す瞬間だけ、JavaScriptが内部的にそのプリミティブ値を**一時的なオブジェクト**に変換（ラッパーオブジェクト化）し、メソッドの実行が終わると**すぐに破棄**しているためです。

### 2\. オブジェクト型（例: `Date`）

オブジェクト型には、`Date`、`Array`、`Object`、そして自作する`class`のインスタンスなどが含まれます。

| 項目 | `Date` オブジェクト |
| :--- | :--- |
| **データ** | **複雑な構造**と**複数の内部データ**を持つ。 |
| **メモリ** | 値そのものではなく、データが格納されている**場所（参照）** が格納される。 |
| **生成方法** | **コンストラクタ（`new`）** を呼び出して生成する。 |

#### `new`が必要な理由

`Date`オブジェクトは、以下の**複雑な初期設定**を伴うため、専用の工場である**コンストラクタ（`Date()`）** を通して生成する必要があります。

1.  **新しい実体の作成:** `new`演算子が新しい空のオブジェクト（インスタンス）を準備します。
2.  **初期化処理の実行:** `Date()`コンストラクタが実行され、その瞬間の「年」「月」「日」「時」「分」「秒」といった複数のデータを計算し、新しく作ったオブジェクトに設定（初期化）します。
3.  **実体の返却:** 初期化が完了したオブジェクトが変数に格納されます。

-----

## 🔑 まとめ

| 種類 | `Date`（オブジェクト型） | 文字列（プリミティブ型） |
| :--- | :--- | :--- |
| **生成** | `new Date()` | `let str = '...'` |
| **理由** | **複雑な内部状態**を持ち、**初期化処理**（コンストラクタ）が不可欠だから。 | **単純な値**であり、初期化処理が不要で、シンプルに扱えるから。 |

この違いが、JavaScriptにおけるメモリ管理やコードの振る舞いの基本となっています。

-----

## 🔍 値渡し（プリミティブ型）と参照渡し（オブジェクト型）

この2つの型の最も大きな違いは、「**値をコピーして渡すのか**」「**データの場所を指し示す情報（参照）を渡すのか**」という点にあります。

### 1\. プリミティブ型の場合：値渡し (Pass by Value)

プリミティブ型（文字列、数値など）の変数を別の変数に代入するときは、**値そのものがコピーされます**。

#### 💻 コード例

```javascript
let strA = 'Hello'; // ① strAに 'Hello' という値が入る
let strB = strA;   // ② strBに 'Hello' の「コピー」が入る

strB = 'World';    // ③ strBの値を変更

console.log(strA); // 結果: 'Hello'
console.log(strB); // 結果: 'World'
```

#### 💡 解説

1.  `strB = strA` のとき、`strA`が持っている値 `'Hello'` がメモリ上の**別の場所**にコピーされます。
2.  そのため、その後に`strB`だけを変更しても、`strA`の値には**全く影響がありません**。
3.  これは、2つの変数が**完全に独立した値**を持っているからです。

-----

### 2\. オブジェクト型の場合：参照渡し (Pass by Reference)

オブジェクト型（`Date`、`Array`、`Object`、`class`インスタンスなど）の変数を別の変数に代入するときは、オブジェクトのデータそのものではなく、データが格納されている**メモリ上の「場所」（参照）がコピーされます**。

#### 💻 コード例

```javascript
// 配列（オブジェクト型）を例にします
let arrA = [10, 20]; // ① arrAは、配列データがある「場所A」を指し示す
let arrB = arrA;     // ② arrBに「場所A」という情報（参照）がコピーされる

arrB.push(30);       // ③ arrBを使って、場所Aにある配列に要素を追加

console.log(arrA); // 結果: [10, 20, 30]
console.log(arrB); // 結果: [10, 20, 30]
```

#### 💡 解説

1.  `arrB = arrA` のとき、`arrA`と`arrB`は**同じ一つの配列データ（場所A）** を指し示しています。
2.  そのため、`arrB`を使ってデータを変更すると、**arrAから見ても**同じデータが変更されていることになります。
3.  これは、2つの変数が**同じ実体**を共有しているからです。

-----

## 🔑 まとめ

この「値渡し」と「参照渡し」の挙動は、JavaScriptで意図しないバグを防ぐために非常に重要です。

| 特徴 | プリミティブ型 (値渡し) | オブジェクト型 (参照渡し) |
| :--- | :--- | :--- |
| **代入時** | 値が**コピー**される。 | データの場所（参照）がコピーされる。 |
| 変更の影響 | 片方を変更しても、もう片方に影響しない。 | 片方を変更すると、もう片方にも**影響する**。 |

この「参照渡し」の概念は、`forEach`などを使って配列の要素を処理するとき（要素がオブジェクトの場合）にも関わってくる、重要な知識です。

# 🔎 JavaScriptの変数のスコープ（Scope）

JavaScriptにおける**スコープ**とは、**変数がどこからアクセス（利用）できるか**を決める「**変数の見える範囲**」のことです。変数を宣言する方法（`var`, `let`, `const`）によって、この見える範囲が大きく異なります。

-----

## 1\. グローバルスコープ (Global Scope) 🌎

**グローバルスコープ**で宣言された変数は、コードの**どこからでも**アクセスできます。

  * **定義:** 関数の外側やブロック（`{}`）の外側で宣言された変数です。
  * **特徴:** プログラム全体で共有されるため、どこかで値を変更すると、それが全体に影響します。安易な利用は、コードの予期せぬ動作（バグ）につながりやすいため、**非推奨**とされることが多いです。

<!-- end list -->

```javascript
// グローバルスコープ
const globalMessage = "世界中に見えるメッセージ";

function showGlobal() {
  console.log(globalMessage); // どこからでもアクセスできる
}

showGlobal();
```

-----

## 2\. 関数スコープ (Function Scope) ⚙️

**関数スコープ**は、主に古いバージョンのJavaScriptで使われていた `var` キーワードの変数が持つスコープです。

  * **定義:** 変数が宣言された**関数の中**でのみアクセス可能です。
  * **特徴:** 関数を抜けると、変数は消滅し、外側からはアクセスできません。

<!-- end list -->

```javascript
function myFunction() {
  // 関数スコープ
  var functionVar = "私は関数の中でのみ生きる";
  console.log(functionVar); // 関数内OK
}

myFunction();

// console.log(functionVar); // エラー: functionVar は定義されていません
```

-----

## 3\. ブロックスコープ (Block Scope) 🧱

**ブロックスコープ**は、`let` や `const` キーワードで宣言された変数が持つスコープです。最新のJavaScript（ES6以降）では、このブロックスコープが主流です。

  * **定義:** 変数が宣言された**ブロック `{}`（if文、for文、while文などの波括弧）の中**でのみアクセス可能です。
  * **特徴:** 変数の有効範囲が狭くなり、意図しない場所での変数の上書きを防げるため、より安全で管理しやすいコードになります。

<!-- end list -->

```javascript
if (true) {
  // ブロックスコープ
  let blockLet = "私はブロックの中だけ";
  const blockConst = 100;
  console.log(blockLet); // ブロック内OK
}

// console.log(blockLet); // エラー: blockLet は定義されていません
// console.log(blockConst); // エラー
```

-----

## 🔑 宣言キーワードによる違いのまとめ

| キーワード | スコープの種類 | 特徴 | 推奨度 |
| :---: | :---: | :--- | :---: |
| `var` | **関数スコープ** | 古い。意図せず関数の外側からアクセスできてしまうなど、混乱を招きやすい。 | 低い |
| `let` | **ブロックスコープ** | 変数。再代入（値の変更）が可能。 | 高い |
| `const` | **ブロックスコープ** | 定数。再代入（値の変更）は不可。 | **最高** |

> 💡 **ポイント:** 現代のJavaScriptでは、デフォルトで **`const` ** を使い、値を変える必要がある場合にのみ ** `let`** を使うのがベストプラクティスとされています。`var` の使用は避けることが推奨されます。

-----

## 🧊 `const` の不変性（Immutability）の理解

。`const` が防ぐのは「**再代入**」だけであり、「**中身の変更**」は防がない、というこの違いは、初心者にとって最も混乱しやすいポイントの一つです。

これを理解するために、変数を「**名札**」、データ（オブジェクトや配列）を「**箱**」に例えて説明します。

-----

### 1\. プリミティブ値の場合 (`const` = 完全に固定)

数値や文字列などのプリミティブな値は、名札が直接その値（情報）を指しています。

```javascript
const favoriteNumber = 10;
// favoriteNumber (名札)  ->  10 (値)
```

この場合、`const` は以下の操作を防ぎます。

| 操作 | 結果 | 理由 |
| :--- | :--- | :--- |
| `favoriteNumber = 20;` | ❌ **エラー** | `const` のルールにより、名札を別の新しい値に**付け替える（再代入する）** ことを禁止しているからです。 |

プリミティブ値は箱を持たないため、名札が固定されれば、値は完全に不変になります。

-----

### 2\. オブジェクトや配列の場合 (`const` = 名札の固定)

オブジェクトや配列は「**参照型**」データと呼ばれます。この場合、名札が指しているのは、データが格納されている**メモリ上の「箱」（アドレス）** です。

```javascript
const person = { name: "Alice", age: 25 };
// person (名札)  ->  [メモリのアドレス]  ->  { name: "Alice", age: 25 } (箱の中身)
```

このとき、`const` は以下の操作を許可し、禁止します。

#### ❌ 禁止される操作：名札の付け替え（再代入）

`const` が防ぐのは、`person` という名札を**別の新しい箱に付け替える**操作です。

```javascript
// 新しい別のオブジェクト
const newPerson = { name: "Bob", age: 30 }; 

// 再代入を試みる
// person = newPerson; 
// 👆 ❌ TypeError! (名札を新しい箱に付け替えることはできません)
```

#### ✅ 許可される操作：箱の中身の変更

`const` は、**名札が指している箱の「中身」（プロパティ）をいじる**操作は制限しません。

```javascript
// 箱の中身のプロパティを更新する
person.age = 26; // 👈 ✅ OK!

// 箱の中に新しいプロパティを追加する
person.city = "Tokyo"; // 👈 ✅ OK!

console.log(person); 
// 出力: { name: "Alice", age: 26, city: "Tokyo" }
```

名札 (`person`) は常に同じ箱を指し続けているため、`const` のルールは破られていない、とJavaScriptは判断します。

### まとめ

| キーワード | 許可される操作 | 禁止される操作 |
| :---: | :--- | :--- |
| `const` | オブジェクトや配列の**中身の変更** | 変数への**再代入（名札の付け替え）** |
| `let` | 中身の変更も、変数への再代入も可能 | なし |

この動作は、`const` は「値の不変性」ではなく「**参照の不変性**」を保証している、と理解すると、より正確です。
