## ⏰ `setInterval()` の使い方

`setInterval()` は、JavaScriptで**一定の時間間隔**で**関数を繰り返し実行**させたいときに使用する機能です。デジタル時計の表示更新や、スライドショーの自動切り替えなどによく使われます。

-----

### 1\. 基本構文

`setInterval()` は、主に2つの引数（ひきすう）を取ります。

```javascript
const intervalID = setInterval(実行したい関数, 実行間隔);
```

| 引数名 | 意味 | 単位 |
| :--- | :--- | :--- |
| **実行したい関数** | 繰り返し実行させたい処理（関数名、または無名関数）を指定します。 | N/A |
| **実行間隔** | 関数を呼び出す間隔を**ミリ秒（1/1000秒）** 単位で指定します。 | ミリ秒 (ms) |

`setInterval()` を呼び出すと、実行を停止するための識別子（ID）が返されます。このIDを保持しておくことで、後から実行を止めることができます。

-----

### 2\. サンプルコード

1秒（1000ミリ秒）ごとにコンソールにメッセージを表示する例です。

```javascript
function sayHello() {
  console.log("Hello! 1秒ごとに実行中...");
}

// sayHello 関数を1000ミリ秒（1秒）ごとに実行する
const timerId = setInterval(sayHello, 1000); 
```

**無名関数（アロー関数）を使う方法**も一般的です。

```javascript
let count = 0;
const timerId = setInterval(() => {
  count++;
  console.log(`${count}秒経過しました。`);
}, 1000); 
```

-----

### 3\. 実行の停止: `clearInterval()`

`setInterval()` は、一度実行されると、ブラウザを閉じるか、明示的に停止するまで**永遠に**実行され続けます。繰り返し処理を停止するには、**`clearInterval()`** 関数を使用します。

`clearInterval()` には、`setInterval()` を実行したときに取得した**タイマーID**を引数として渡します。

```javascript
let count = 0;

const timerId = setInterval(() => {
  count++;
  console.log(`${count}秒経過しました。`);

  // 5秒経過したら停止する
  if (count >= 5) {
    clearInterval(timerId); // タイマーを停止
    console.log("タイマーを停止しました。");
  }
}, 1000);
```

### 4\. 引数を渡す（補足）

実行する関数に引数を渡したい場合、`setInterval()` の第3引数以降に指定します。

```javascript
function greet(name) {
  console.log(`こんにちは、${name}さん！`);
}

// greet 関数を2秒ごとに実行し、「太郎」を引数として渡す
setInterval(greet, 2000, "太郎"); 
```

-----

## ⚠️ `setTimeout()` との違い

`setInterval()` と似た関数に **`setTimeout()`** があります。

  * **`setInterval()`**: 指定した時間間隔で**繰り返し**関数を実行する。
  * **`setTimeout()`**: 指定した時間経過後に**一度だけ**関数を実行する。

用途に合わせて使い分けてください。
