# 変数（キーワード）

1. **変数（へんすう）**
   データを保存（ほぞん）しておくための「**名前のついた箱**」のようなものです。変数に名前（ラベル）を付けることで、必要なときにそのデータを何度も取り出して使うことができます。

2. **代入（だいにゅう）**
   変数という**箱の中にデータを入れる**ことを言います。記号の **`=`（イコール）** を使い、「**右側にあるデータを、左側の変数に入れる**」というプログラミング特有のルールがあります。

3. **const と let（コンスト と レット）**
   変数を作るとき（宣言するとき）に使うキーワードです。**const** は一度決めたら中身を変えられない「**定数**」の箱、**let** は後から中身を入れ替えられる「**変数**」の箱です。ミスを減らすために、基本は const を使い、値を変える必要があるときだけ let を使うのが良い方法です。

4. **データ型（がた）**
   変数に入れる**データの種類**のことです。代表的なものに、テキストを表す「**文字列型**」、計算に使う「**数値型**」、正しい（true）か間違い（false）かを表す「**論理型**（Boolean）」などがあります。

5. **型の変換（かたのへんかん）**
   あるデータ型を別の型に変えることです。例えば、入力フォームから受け取った「文字列」の数字を計算に使うために、`parseInt()` や `Number()` を使って「数値型」に変える操作などがこれにあたります。
