JavaScriptを学《まな》ぶとき、画面《がめん》に文字《もじ》を表示《ひょうじ》したり、文章《ぶんしょう》を作《つく》ったりする機会《きかい》がたくさんありますよね。

**テンプレートリテラル（Template Literals）** は、JavaScriptで「文章《ぶんしょう》と変数《へんすう》（データ）を、かんたんに美《うつく》しく組み合わせるための道具《どうぐ》」です。

留学生《りゅうがくせい》の方《かた》に教《おそ》えるための、やさしい例《たと》えと使い方《つかいかた》をまとめました。

---

## 1. テンプレートリテラルって何《なに》？（比喩《ひゆ》で伝える）

昔《むかし》のJavaScriptでは、文字《もじ》と変数《へんすう》を組み合わせるときに `+`（プラス）をたくさん使《つか》う必要《ひつよう》があり、まるで「パズル」のようで大変《たいへん》でした。

テンプレートリテラルは、「穴《あな》あきカード」のようなものです。あらかじめ文章《ぶんしょう》の形《かたち》を作《つく》っておき、空《あ》いた穴《あ》の中に、あとから変数《へんすう》をポンと入れることができます。

---

## 2. ２つの大切《たいせつ》なルール

テンプレートリテラルを使《つか》うときは、キーボードの打ち方《かた》にルールがあります。

* **バッククォート（ ` ` ）で囲《かこ》む：** シングルクォート（ `'` ）やダブルクォート（ `"` ）ではなく、キーボードの「Shift + @」などで打つ **` `** を使《つか》います。
* **変数は `${ }` に入れる：** 穴《あ》あきの部分《ぶぶん》です。このカッコの中に入れた変数《へんすう》の中身《なかみ》が、自動的《じどうてき》に文字《もじ》になります。

---

## 3. 昔《むかし》の書き方と、今の書き方の比較《ひかく》

留学生《りゅうがくせい》の「アリさん（20歳）」の自己紹介《じこしょうかい》を作《つく》ってみましょう。

### ✕ 昔《むかし》の書き方（プラスでつなぐ）

```javascript
const name = "アリ";
const age = 20;

// プラスが多くて、スペースの間違いが起きやすいです
console.log("こんにちは、" + name + "です。私は" + age + "歳です。");

```

### ◯ テンプレートリテラル（今の書き方）

```javascript
const name = "アリ";
const age = 20;

// 文章をそのまま書いて、入れたい場所に ${ } を置くだけ！
console.log(`こんにちは、${name}です。私は${age}歳です。`);

```

---

## 4. テンプレートリテラルのすごいところ

### ① 改行《かいぎょう》（エンター）がそのままできる！

昔《むかし》は途中《とちゅう》で改行《かいぎょう》するとき、`\n` という特殊《とくしゅ》な記号《きごう》を書《か》く必要《ひつよう》がありました。テンプレートリテラルなら、コードの中でエンターキーを押《お》して改行《かいぎょう》すると、画面《がめん》でもそのまま改行《かいぎょう》されます。

```javascript
// HTMLのタグを作るときに、ものすごく便利です！
const htmlCard = `
  <div>
    <h2>${name}</h2>
    <p>${age}歳</p>
  </div>
`;

```

## 5. 留学生《りゅうがくせい》向けのまとめ（青空文庫形式《あおぞらぶんこけいしき》）

> **テンプレートリテラルを覚《おぼ》えよう！**
> JavaScriptで文字《もじ》を書《か》くとき、今《いま》までは `+`（プラス）をたくさん使《つか》って大変《たいへん》でした。
> でも、**バッククォート（ ` ` ）**を使《つか》えば、とても簡単《かんたん》になります。
> 1. **バッククォート（ ` ` ）**で、文章《ぶんしょう》全体《ぜんたい》を優《やさ》しく包《つつ》みます。
> 2. 変数《へんすう》を入《い》れたい場所《ばしょ》に、**`${変数名}`** という穴《あ》を作《つく》ります。
> 
> 
> これを使《つか》うと、コードがすっきりして、読《よ》みやすくなります。間《ま》違《ちが》いも少《すく》なくなるので、これからはこの形《かたち》で書《か》く練習《れんしゅう》をしましょう！
