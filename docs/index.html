留学生のためのJavaScript学習ガイド

JavaScriptジャバスクリプトを始はじめる前まえに

留学生りゅうがくせいのためのJavaScript学習がくしゅうガイド：Webを動うごかす魔法まほうを学まなぼう

留学生りゅうがくせいのみなさん、こんにちは！ プログラミングの世界せかいへようこそ。

みなさんが毎日まいにち使つかっているスマートフォンやパソコンの画面がめん。ボタンを押おすとメニューが出でてきたり、地図ちずが動うごいたりしますね。これはすべて「JavaScript（ジャバスクリプト）」という言葉ことばが命令めいれいを出だして動うごかしています。

このガイドでは、自分じぶんでウェブページを動うごかせるようになるための基礎きそをやさしく解説かいせつします。それがJavaScriptの基本きほんだからです。

(参考さんこう) 現在げんざいのJavaScriptは、ウェブページの操作そうさだけでなく、いろいろな用途ようとに使えるプログラム言語げんごになっています。しかし、今いまでも、ブラウザ上じょうで活躍かつやくしています。

I. 私わたしたちの舞台ぶたい：WWW（ワールド・ワイド・ウェブ）

まず、javaScriptの活躍かつやくの舞台ぶたい、WWW（ワールド・ワイド・ウェブ）とは何なにかについて、説明せつめいしましょう。

WWW（ワールド・ワイド・ウェブ） は、世界中せかいじゅうのコンピュータが「クモの巣す（Web）」のようにつながって、情報じょうほうを共有きょうゆうする仕組しくみのことです。

これを、「図書館としょかん」 に例たとえて、やさしく説明せつめいしますね。

1. 3つの大切たいせつな「道具どうぐ」

WWWを動うごかすために、3つの主役しゅやくがいます。

  • Webブラウザ（お客きゃくさん）
    ChromeやSafariなど、私わたしたちがサイトを見みるためのソフトです。「本ほんを読よみたい人ひと」です。
  • Webサーバ（図書館としょかんのスタッフ） 世界中せかいじゅうのどこかにある、24時間じかん動うごいているコンピュータです。「本ほんを管理かんりしている人ひと」です。
  • HTML（本ほんの内容ないよう）
    ウェブサイトに書かいてある文章ぶんしょうや写真しゃしんのデータです。これが「本ほん」そのものです。

2. ウェブサイトが表示ひょうじされるまでの「4つのステップ」

あなたがブラウザでURLを入力にゅうりょくしてから、画面がめんが出でるまでの流ながれを見みてみましょう。

  1. リクエスト（注文ちゅうもん）：
    あなたが「このページを見みたい！」とURLをクリックします。これは図書館としょかんのスタッフに「あの本ほんを貸かしてください」と頼たのむのと同おなじです。

  2. 住所じゅうしょの確認かくにん（DNS）：
    インターネットの世界せかいでは、google.comのような名前なまえではなく、数字すうじの住所じゅうしょ（IPアドレス 例えば、“142.251.223.46” みたいな）で場所ばしょを探さがします。

  3. レスポンス（返事へんじ）：
    サーバがあなたのリクエストを受うけて、HTMLなどのデータをあなたのブラウザに送おくり返かえします。「はい、どうぞ！」と本ほんを渡わたしてくれるイメージです。

  4. レンダリング（組くみ立たて）：
    ブラウザが、届とどいたHTMLデータを読よみ取とって、きれいなデザインに組くみ立たてて表示ひょうじします。

3. WWWで使つかわれる「魔法まほうの言葉ことば」

ウェブの世界せかいには、共通きょうつうのルール（プロトコル）があります。

  • HTTP / HTTPS： 情報じょうほうをやり取とりするときの「言葉ことばのルール」です。
  • URL：
    ウェブサイトの「住所じゅうしょ」です。世界せかいに一ひとつしかありません。

まとめテーブル

ITの言葉ことば図書館としょかんでの例たとえ役割やくわり
クライアント本ほんを読よみたい人ひとブラウザでリクエストを送おくる
サーバ図書館としょかんのスタッフデータを保管ほかんして、送おくり返かえす
HTML本ほんのページ文字もじや写真しゃしんのデータ
URL本ほんの整理番号せいりばんごうサイトがどこにあるか教おしえる

いかがでしょうか？「注文ちゅうもんして、送おくってもらって、組くみ立たてる」。このシンプルな流ながれがWWWの正体しょうたいです。

「WWWは、世界中せかいじゅうの情報じょうほうをだれでも、どこでも見みられるようにしたすごい発明はつめいなんです。

II. ウェブページを作つくる「3つの力ちから」：HTML・CSS・JavaScriptの役割やくわり

ウェブページは、3つの技術ぎじゅつがチームワークを発揮はっきしてできています。これを「家いえづくり」に例たとえてみましょう。

技術名役割（やくわり）家づくりに例えると？
HTML骨組ほねぐみ・構造こうぞう柱はしら、壁かべ、床ゆか
CSS見みた目め・デザインペンキの色いろ、インテリア、壁かべに貼はる紙かみ
JavaScript動うごき・機能きのう電気でんき、機械装置きかいそうち

JavaScriptの役割やくわり：電気でんきを通とおすこと

HTMLとCSSだけでは、家いえは完成かんせいしても「電気でんきが通とおっていない」状態じょうたいです。HTMLとCSSだけのウェブページは、ただ情報じょうほうを表示ひょうじするだけの、動うごきのない「紙かみのポスター」のようなものです。

JavaScriptという電気でんきが通とおることで、スイッチを押おせばライトがつき、ドアの前まえに立たてば自動じどうドアが開ひらき、ボタンを押おせばエレベーターが動うごくようになります。ウェブページはユーザーと「対話たいわ」ができる便利べんりな道具どうぐに変かわるのです。

III. イベントとは

1. 「きっかけ」を待まっているコンピューター

普段ふだん、ウェブページはただじっとしているだけに見みえますが、実じつはあなたの操作そうさを 「今いまか今いまかと待まっている」 状態じょうたいです。

例えば、あなたがこんな動うごきをしたとき、それがすべて「イベント」になります。

  • ボタンを カチッ（クリック） としたとき。
  • キーボードで 文字もじを入力にゅうりょく したとき。
  • 画面がめんを 上下じょうげに動うごかした（スクロール） とき。

このように、「ユーザーが何なにかをした！」 という出来事できごとのことを、JavaScriptでは「イベント」と呼よびます。

2. 「もし〜したら、〜する」という約束やくそく

イベントの考かんがえ方かたは、皆みなさんの日常にちじょうにある 「センサー」 と同おなじです。

  • 自動じどうドア： 「人ひとが前まえに来きたら（イベント）、ドアを開あける」
  • 目覚めざまし時計どけい： 「朝あさの7時じになったら（イベント）、音おとを鳴ならす」
  • ウェブサイト： 「ボタンが押おされたら（イベント）、メッセージを出だす」

JavaScriptを学まなぶと、この 「もし〜が起おきたら、この仕事しごとをやってね！」 というマニュアルを書かけるようになります。

3. 留学生りゅうがくせいへの導入どうにゅうメッセージ

「今いまはまだ、難むずかしい魔法まほうの言葉ことばを覚おぼえる必要ひつようはありません。 画面がめんの中なかで起おきる 『クリック』や『入力にゅうりょく』などの変化へんかの一ひとつひとつに、名前なまえ（イベント）がついているんだな 、ということだけ覚おぼえておいてください。 皆みなさんが『何なにか』をしたときに、サイトが『反応はんのう』するのは、このイベントのおかげなんですよ！」

まとめ

言葉ことばイメージ
イベント「何なにかが起おきた！」という合図あいず
きっかけユーザーがマウスやキーボードを動うごかすこと
反応はんのう画面がめんの色いろが変かわったり、窓まどが開あいたりすること

「ウェブページを生いきているように動うごかすための『スイッチ』」。それがイベントです。

IV. オブジェクトとは

皆みなさんがこれから学まなぶのは、ウェブページを動うごかす方法ほうほう です。ウェブページを動うごかすためには、ウェブページを表示ひょうじしているブラウザに「これこれこういうことをしなさい」と命令めいれいする ことが必要ひつようです。

1. オブジェクトとはどんなもの？

HTMLやCSSという設計図せっけいずに従したがって、ブラウザはそれをウェブページとして作つくり上あげてくれます。JavaScriptは出来上できあがったウェブページの部品ぶひんを 「オブジェクト」 としてとらえ、それに対たいして『これこれこういうことをしなさい』と命令めいれいします。

さまざまな人ひとが集あつまって会社かいしゃができているのと同おなじように、ウェブページももさまざまなオブジェクトから構成こうせいされています。そして、「会社かいしゃに何なにかをしてもらう」というのは、実際じっさいには「その会社かいしゃの人ひとに何なにかをしてもらう」ことです。同おなじように、「ウェブページを動うごかす」というのは「ウェブページのオブジェクトに何なにかをしてもらう」 ということです。

2. あいまいさのない命令めいれい：「誰だれが」「何なにをする」

JavaScripはマニュアルですから、「みんなで協力きょうりょくして、こういうことをやりなさい」とぼんやりした命令めいれいをするのではなく、「Aさんはこれをして」「Bさんはあれをして」と一人ひとりひとりの作業さぎょうを正確せいかくに伝つたえなければなりません。 「誰だれが」「何なにをする」のかを、だれが読よんでもわかるように書かく ことが大事だいじです。

この「Aさん」「Bさん」がJavaScriptでは 「オブジェクト」 にあたります。

「オブジェクト」という言葉ことばは、皆みなさんには聞ききなれないものかもしれませんが、とりあえず、次つぎのようなイメージを頭あたまに思おもい描えがいてください。

  • ウェブページの中なかには、たくさんのオブジェクトと呼よばれるものがいて、JavaScriptを使つかって、彼かれらに命令めいれいすれば、仕事しごとをしてくれるらしい

今いまは、それだけで十分じゅうぶんです。「オブジェクトの中身なかみがどうなっているのか？」や「それに仕事しごとをしてもらうためのマニュアルをどう書かけばよいのか？」については、これから少すこしずつ、何度なんどかに分わけて説明せつめいします。

3. HTMLとCSS

では、JavaScriptで扱あつかうオブジェクトとは具体的ぐたいてきには、どんなものでしょうか？

ブラウザはサーバーからのレスポンスを受うけ取とります。そのレスポンスのうち「HTML」と「CSS」がウェブページという「家いえ」の柱はしら、壁かべ、床ゆか、あるいはペンキ、インテリア、壁紙かべがみ、といった部品ぶひんになるのは、前まえに説明せつめいした通とおりです。

実じつは、この「ウェブページの部品ぶひん」こそが、JavaScriptの オブジェクト です。

したがって、JavaScriptでウェブページを操あやつるためには、まずウェブページの部品ぶひんそのものについて、理解りかいしなければなりません。

次つぎのステップでは、ウェブページの設計図せっけいずである HTML と CSS について説明せつめいします。

このセクションのまとめ

JavaScriptが動うごく順番じゅんばんをイラストで描えがくとこんな風ふうになります。

つまり、JavaScriptでウェブページを動うごかすために

  • 「何なにが起おきたら」（どのイベントに反応はんのうさせるか？）
  • 「誰だれに」（どのオブジェクトに仕事しごとをさせるか？）
