留学生のためのJavaScript学習ガイド

ブラウザのオブジェクト

初心者しょしんしゃのためのJavaScript：ブラウザを動うごかす「オブジェクト」の仕組しくみ

みなさん、こんにちは！ これからJavaScriptを使つかってウェブサイトに「動うごき」をつける方法ほうほうを学まなんでいきましょう。

プログラミングは難むずかしく見みえますが、実じつは 「ブラウザという家いえ」の中なかにある「道具どうぐ」の使つかい方かた を覚おぼえるだけなんです。今日きょうは、その道具どうぐである「オブジェクト」について、プロの視点してんからやさしく解説かいせつします。

JavaScriptは「誰だれが」「何なにをするか」を指示しじするマニュアル

ここでもう一度いちど、最初さいしょに説明せつめいしたイメージを思おもい出だしてください。

  • ウェブページの中なかには、たくさんのオブジェクトと呼よばれるものがいて、JavaScriptを使つかって、彼かれらに命令めいれいすれば、仕事しごとをしてくれるらしい

    JavaScriptは「誰だれが」「何なにをするか」を指示しじするマニュアルです。

    マニュアルですから、「みんなで協力きょうりょくして、これをやりなさい」とぼんやりした命令めいれいをするのではなく、「Aさんはこれをして」「Bさんはあれをして」と一人ひとりひとりの作業さぎょうを正確せいかくに、細こまかく書かく必要ひつようがあります。そうしないと、みんなが同おなじ仕事しごとをしようとしたり、大事だいじな仕事しごとを誰だれもしなかったり、ということが起おこります。

    ここでは、 「誰だれが」（つまり、どのオブジェクトが）その作業さぎょうをするのか を、間違まちがいなく伝つたえるために、 JavaScriptがどのようにそのオブジェクトを見みつけるのか 、その方法ほうほうを説明せつめいします。

BOM/DOMツリーは「ブラウザが作つくった地図ちず」

われわれが「これをしなさい」と命令めいれいする相手あいては、オブジェクトと呼よばれる、ウェブページのいろいろな部品ぶひんです。その部品ぶひんとは、たとえば、ひとまとまりの文ぶんである『段落だんらく<p>』であり、『見出みだし<h1>』であり、あなたが文字もじを入力にゅうりょくする『入力にゅうりょくボックス<input>』であり、あなたがクリックする『ボタン<button>』です。これらは 「ツリー構造こうぞう（木きの枝えだのような形かたち）」 で整理せいりされています。

document（HTMLのページ全体）
  └── html（<html>タグ）
        ├── head（<head>タグ）
        |     └── title（タイトルなど）
        └── body（<body>タグ）
              ├── h1（見出し）
              └── p（文章や画像など）

ブラウザは、HTMLファイルを受うけ取とると、中身なかみを読よみ取とって、その指示しじに従したがって オブジェクト たちを作つくり、それらをコンピュータが扱あつかいやすい 「木き（Tree）」 の形かたちに並ならべ替かえます。これを DOM（Document Object Model）ツリー と呼よびます。

またブラウザ自身じしんも自分じぶんの持もっている機能きのうをツリーの形かたちで整理せいりしています。これを BOM（Browser Object Model） と呼よびます。 ブラウザ世界せかいの構造こうぞう 一番上いちばんうえのボスは window オブジェクト です。上うえで説明せつめいした DOM は BOMの一部いちぶ です。

window（ブラウザのウィンドウ全体）
 ├── document（HTMLのページ全体:この部分がDOM）
 ├── navigator（ブラウザの情報）
 ├── screen（画面の情報）
 ├── location（URLの情報）
 └── history（履歴）

ツリーの「家族かぞく（かぞく）」関係かんけい

DOMツリーの中なかでは、それぞれの要素ようそ（Element）を 「ノード（Node）」 と呼よび、家族かぞくのような名前なまえで関係かんけいを表あらわします。

  • Document（ルート）： 木きの「一番下いちばんしたの根ねっこ」または「一番上いちばんうえの先祖せんぞ」。すべての始はじまりです。
  • Parent（親おや）： ある要素ようそを包つつんでいる外側そとがわのタグ。
  • Child（子こ）： タグの中なかに入はいっている内側うちがわのタグ。
  • Sibling（兄弟きょうだい）： 同おなじ親おやの中なかに並ならんでいるタグ同士どうし。

JavaScriptの仕事しごと：地図ちずをたどって操作そうさする

JavaScriptはこの「地図ちず」を使つかって、オブジェクトの場所ばしょを探さがし出だし、命令めいれいを出だします。

  1. 見みつける（Select） 「IDが ‘btn’ のボタン（子こ）を探さがして！」
  2. 変かえる（Change） 「そのボタンの色いろを赤あかくして！」
  3. 作つくる・消けす（Create / Delete） 「新あたらしいリストを1つ増ふやして、古ふるいのは消けして！」

学生がくせいへのアドバイス：なぜ「ツリー」と呼よぶの？

> 「HTMLのコードはただのテキストだけど、ブラウザの中なかでは 『生いきている木き』 のように枝分えだわかれしているんだ。 > 枝えだの先さきにある葉はっぱ（文字もじや画像がぞう）を動うごかしたいときは、幹みきから順番じゅんばんにたどっていくイメージを持もつと、プログラミングがすごく分わかりやすくなるよ！」

まとめテーブル

言葉ことば意味いみ役割やくわり
Document木きの全体ぜんたいJavaScriptが操作そうさする入いり口ぐち
Node（ノード）木きの節ふしタグやテキストのひとつひとつ
Element（要素ようそ）タグそのもの具体的ぐたいてきなパーツ（<div>, <h1>など）

まずは、この家いえの「家主やぬし」であり、すべてを管理かんりしている「Windowオブジェクト」から見みていきましょう。

すべての基点きてん：Windowオブジェクト

ブラウザのタブを開ひらいたとき、その画面全体がめんぜんたいを管理かんりしているのがWindow（ウィンドウ）オブジェクトです。これはJavaScriptの世界せかいの「王様おうさま」です。

  • 階層かいそう（重かさなりの順番じゅんばん）のイメージ： Windowオブジェクトはすべての「ルート（根ねっこ）」です。Windowという大おおきな箱はこの中なかに、この後あと説明せつめいするDocument（書類しょるい）やLocation（場所ばしょ）など、すべての道具どうぐが入はいっています。
  • 王様おうさまのインパクト： もし王様おうさま（Window）がいなくなると、その国くに（タブ）にあるすべてのデータや書類しょるい（Document）も消きえてしまいます。タブを閉とじるとページの情報じょうほうが消きえるのはそのためです。
  • Windowの便利べんりな機能きのう： alert() や prompt() などがあります。
    • alert(“こんにちは！”)：画面がめんにメッセージを出だす「拡声器かくせいき（大おおきな声こえを出だす機械きかい）」のようなものです。
    • prompt(“お名前なまえは？”)：ユーザーに文字もじを入力にゅうりょくしてもらう「アンケート用紙ようし」のような役割やくわりです。 次つぎは、王様おうさまが持もっている大切たいせつな「書類しょるい」、つまりページの中身なかみを指さす「Document」についてお話はなしします。

ウェブページを操あやつる：DOMとDocumentオブジェクト

ウェブページに表示ひょうじされている文字もじや画像がぞうそのものを操作そうさするのがDocument（ドキュメント）オブジェクトです。

ここで大切たいせつなのが DOM（Document Object Model）です。HTMLの構造こうぞうは、枝分えだわかれした「木き（ツリー）」 のような親子関係おやこかんけいになっています。これを「DOMツリー」と呼よびます。

DOMツリーの中なかから、操作そうさしたい「特定とくていのパーツ」を見みつけることを、プログラミングでは 「要素ようその取得しゅとく」 や 「セレクタ」 と呼よびます。 学生がくせいの方かたには、「たくさんの家いえが並ならんでいる街まちの中なかから、特定とくていの家いえを探さがし出だす方法ほうほう」 だと教おしえてあげてください。住所じゅうしょ（ID）で探さがす方法ほうほうもあれば、家いえの色いろ（クラス）で探さがす方法ほうほうもあります。

1. よく使つかう4つの「探さがし方かた」

JavaScriptには、目的もくてきのオブジェクトを見みつけるための代表的だいひょうてきな命令めいれいが4つあります。

① getElementById（一番確実いちばんかくじつな「住所じゅうしょ」）

世界せかいにひとつしかない「ID（アイディー）」を使つかって探さがします。

  • イメージ： 「東京都とうきょうと○○区く…」という**絶対的ぜったいてきな住所じゅうしょ**で家いえを特定とくていする。
  • 特徴とくちょう： 一番いちばんスピードが速はやくて正確せいかくです。

② getElementsByClassName（同おなじ「グループ」）

同おなじ「クラス名めい」がついているものを、まとめて全部ぜんぶ探さがします。

  • イメージ： 「赤あかい屋根やねの家いえを全部集ぜんぶあつめて！」とお願ねがいする。
  • 特徴とくちょう： 複数ふくすうの要素ようそが「リスト（配列はいれつのような形かたち）」で返かえってきます。

③ getElementsByTagName（「種類しゅるい」で探さがす）

<div> や <li> など、タグの種類しゅるいで探さがします。

  • イメージ： 「この街まちにある『コンビニ』を全部探ぜんぶさがして！」

④ querySelector / querySelectorAll（最強さいきょうの「万能ばんのうメガネ」）

CSSのセレクタ（.class や #id）を使つかって探さがします。最近さいきんのプログラミングで最もっともよく使つかわれます。

  • イメージ： 「2番目ばんめの角かどにある、青あおいドアの家いえを探さがして」という複雑ふくざつな指定していができます。

2. 実際じっさいのコード

学生がくせいに、コードの書かき方かたの違ちがいを見みせてあげましょう。

// 1. IDで探す（1つだけ見つかる）
const title = document.getElementById("main-title");
title.style.color = "red";

// 2. クラスで探す（たくさん見つかるので、[0]のように番号を指定する）
const items = document.getElementsByClassName("menu-item");
items[0].textContent = "最初のメニュー";

// 3. 万能（ばんのう）な探し方（CSSと同じ書（か）き方（かた））
const firstLink = document.querySelector("nav a"); // navの中の最初のaタグ

3. 学生がくせいへのアドバイス：HTMLCollection に注意ちゅうい！

初心者しょしんしゃがよくハマるポイントです。

「getElementsByClassName や querySelectorAll を使つかったときは、『1人り』ではなく『グループ（リスト）』 が返かえってくるんだ。
だから、1人りだけに命令めいれいしたいときは、items[0] のように 『0番目ばんめの人ひと！』 と番号ばんごうで呼よんであげてね。これを忘わすれると、命令めいれいが届とどかないから気きをつけて！」

IV. まとめ：オブジェクトを自由じゆうに操あやつるために

お疲つかれさまでした！今回こんかい学まなんだオブジェクトたちは、バラバラではなく、みんなで協力きょうりょくしてひとつのページを動うごかしています。

いかがでしょうか？「どうやって特定とくていのパーツを指名しめいするか」が分わかれば、DOM操作そうさの半分はんぶんはマスターしたも同然どうぜんです！

ターゲットが見みつかったら、次つぎは具体的ぐたいてきにその「部品ぶひん」をどう動うごかすかを見みていきましょう。

学習がくしゅうのアドバイス：

  1. まずは「Window」の alert で遊あそぶ。
  2. 次つぎに「Document」で文字もじを書かき換かえる。
  3. そして「Event」でユーザーの動うごきに反応はんのうさせる。

このステップで進すすめば、きっと上達じょうたつします。エラーが出でても大丈夫だいじょうぶ、それは成長せいちょうのチャンスです。
