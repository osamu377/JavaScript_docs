留学生のためのJavaScript学習ガイド

日付ひづけ（Date）

プログラミングで「日付ひづけ」や「時間じかん」をあつかうときは、Dateオブジェクト を使つかいます。

学生がくせいの方かたには、Dateオブジェクトは 「世界中せかいじゅうどこでも使つかえる、魔法まほうの時計とけい（とけい）」 だと教おしえてあげてください。

I. Dateオブジェクト

1. Dateオブジェクトの作つくり方かた

JavaScriptで時計とけいを動うごかすには、まず new Date() と書かきます。

new を使つかうことで、メモリの中なかに新あたらしい「日付ひづけというデータの箱はこ」を作つくり、その場所ばしょを指さし示しめすようになります。

// 今（現在）の日付と時間を手に入れる
const now = new Date();
console.log(now); 
// 結果例（れい）：Fri Feb 20 2026 16:40:00 ...（実行した時の時間が出ます）

また、「特定とくていの日ひ（過去かこや未来みらい）」 の時計とけいを作つくることもできます。

// 2026年1月1日の時計を作る
const newYear = new Date("2026-01-01");

// 2026年4月1日0時0分0秒の時計を作る(年, 月, 日, 時, 分, 秒)
const aprilFool = new Date(2026, 3, 1, 0, 0, 0);

「プリミティブ型がた」と「オブジェクト型がた」の違ちがい

ここで「プリミティブ型がた」と「オブジェクト型がた」の違ちがいを理解りかいしましょう。

  • プリミティブ型がた（数値すうちや文字列もじれつ）: データそのものが変数へんすうに入はいっています。
  • オブジェクト型がた（Dateなど）: データそのものではなく、データが保存ほぞんされているメモリ上じょうの「場所ばしょ（参照さんしょう）」が変数へんすうに入はいっています。

So What?（なぜ大切たいせつなの？） これらの組くみ込こみオブジェクトを使つかいこなすことは、プログラミングの世界せかいで「車輪しゃりんの再発明さいはつめい（すでにあるものを一いちから作つくる無駄むだなこと）」を防ふせぐことになります。用意よういされた道具どうぐを使つかうことで、開発かいはつスピードを劇的げきてきに速はやめることができます。

2. よく使つかうメソッド（情報じょうほうの取とり出だし方かた）

作つくった時計とけいから、「年ねん」「月つき」「日ひ」をバラバラに取とり出だすことができます。

知しりたいことメソッド名注意点ちゅういてん（ここが難むずかしい！）
年getFullYear()getYear ではなく Full をつけます。
月getMonth()0から始まります（0=1月, 1=2月…） ⚠️
日getDate()getDay ではないので注意！
曜日getDay()0(日) 〜 6(土) の数字で返ってきます。
時間getHours()0 〜 23時。

3. 初心者しょしんしゃが絶対ぜったいに間違まちがえるポイント

Dateオブジェクトには、初心者しょしんしゃ泣なかせの「ひっかけ問題もんだい」が2つあります。ここを優やさしく教おしえてあげましょう。

① 月つき（Month）は 0 から数かぞえる

配列はいれつと同おなじで、1月は 0 です。

  • 1月 → 0
  • 12月 → 11

Tip

解決策かいけつさく：
画面がめんに表示ひょうじするときは、いつも getMonth() + 1 と書かこうね！と教おしえてあげてください。

② 「日ひ」と「曜日ようび」の名前なまえ

  • getDate() ： 1日、2日…という 「日付ひづけ」
  • getDay() ： 月、火…という 「曜日ようび」

4. かっこいい日付ひづけの表示ひょうじかた（日本にほんでのマナー）

日本にほんでよく使つかう「2026年ねん2月がつ20日にち」という形式けいしきにするコード例れいです。

const today = new Date();

const year = today.getFullYear();
const month = today.getMonth() + 1; // 1を足すのを忘れないで！
const date = today.getDate();

console.log(`${year}年${month}月${date}日`); 
// 結果：2026年2月20日

まとめ

学生がくせいへのアドバイス：

  1. new Date() は「今いまの時計とけい」を作つくる合言葉あいことば！
  2. 月つき（Month） を使つかうときは、いつも心こころに 「＋1」 を！
  3. 曜日ようび（Day） は数字すうじで返かえってくるから、日本語にほんご（月火水げつかすい…）に直なおすときは配列はいれつを使つかうと便利べんりだよ！

いかがでしょうか？「月つきが0から始はじまる」というルールさえクリアすれば、Dateオブジェクトはとても頼たよりになる道具どうぐになります。

II. 日付ひづけの計算けいさん

日付ひづけの計算けいさんは、プログラミングでとてもよく使つかいます。 例たとえば、「今日きょうから3日後にちごはいつ？」「テストまであと何日なんにち？」という計算けいさんです。

「Dateオブジェクトは、数字すうじを書かきかえるだけで自動じどうでカレンダーをめくってくれる、かしこい時計とけい（とけい）」 です。

1. 基本きほんのやりかた：set メソッドを使つかう

日付ひづけを計算けいさんするときは、まず今いまの情報じょうほうを「ゲット（get）」して、計算けいさんしたあとに「セット（set）」しなおします。

例れい：今日きょうから「5日後にちご」を計算けいさんする

const today = new Date(); // ① 今日の時計を作る

// ② 今の「日（Date）」をゲットして、5を足す
const futureDate = today.getDate() + 5;

// ③ 新しい数字をセットする
today.setDate(futureDate);

console.log(today.toLocaleDateString()); // 5日後の日付が出ます

2. ここがすごい！「繰くり上あがり」の自動計算じどうけいさん

一番いちばん感動かんどうするのは、JavaScriptが 「月末げつまつ」を勝手かってに計算けいさんしてくれる ところです。

例たとえば、「1月31日がつさんじゅういちにちの1日後にちご」 を計算けいさんするとします。 普通ふつうなら「次つぎは2月1日がつついたちだ」と自分じぶんで考かんがえる必要ひつようがありますが、JavaScriptはこうなります：

const endOfMonth = new Date("2026-01-31");

endOfMonth.setDate(endOfMonth.getDate() + 1);

console.log(endOfMonth.toLocaleDateString()); // 自動で「2026/2/1」になる！
  • 32日にちになっても大丈夫だいじょうぶ： setDate(32) とすると、次つぎの月つきの1日にちに自動じどうで進すすみます。
  • 13月がつになっても大丈夫だいじょうぶ： setMonth(12)（13番目ばんめの月つき）とすると、次つぎの年としの1月がつに進すすみます。

4. かっこいい日付ひづけの表示ひょうじかた（日本にほんでのマナー）

日本にほんでよく使つかう「2026年ねん2月がつ20日にち」という形式けいしきにするコード例れいです。

const month = today.getMonth() + 1; // 1を足すのを忘れないで！

// 結果：2026年2月20日

  2. 月つき（Month） を使つかうときは、いつも心こころに 「＋1」 を！
  3. 曜日ようび（Day） は数字すうじで返かえってくるから、日本語にほんご（月火水げつかすい…）に直なおすときは配列はいれつを使つかうと便利べんりだよ！

3. 「あと何日なんにち？」の計算けいさん（ミリ秒びょうのひき算ざん）

「今日きょうからイベントまであと何日なんにち？」を計算けいさんするときは、少すこし特殊とくしゅな方法ほうほうを使つかいます。 日付ひづけを 「ミリ秒びょう（とても小ちいさな数字すうじ）」 に直なおしてひき算ざんをします。

const today = new Date();
const eventDay = new Date("2026-03-01");

// ① 引（ひ）き算（ざん）をして「ミリ秒」の差（さ）をだす
const diffMs = eventDay - today;

// ② ミリ秒を「日」に変換（へんかん）（へんかん）する
// 1日 = 24時間 × 60分 × 60秒 × 1000ミリ秒
const diffDays = Math.ceil(diffMs / (24 * 60 * 60 * 1000));

console.log(`イベントまであと ${diffDays} 日です！`);

Note

Math.ceil（マスシール）とは？
小数点しょうすうてん（しょうすうてん）を切きり上あげる魔法まほうです。残のこり時間じかんが「1.2日にち」だったら「あと2日にち」と表示ひょうじするために使つかいます。Mathオブジェクト（数学すうがくの道具どうぐ）についてはあとの章しょうで説明せつめいします。

まとめ：学生がくせいへのアドバイス

日付ひづけの計算けいさんを教おしえるときの合言葉あいことばはこれです！

  1. 「今いまの数字すうじをゲットして、足たして、セットする！」
  2. 「カレンダーの終おわり（2月がつが28日にちか29日にちか、など）は、JavaScriptが全部ぜんぶやってくれるから任まかせてOK！」
やりたいこと使つかうメソッド
日 を進すすめるgetDate() + setDate()
月 を進すすめるgetMonth() + setMonth()
年 を進すすめるgetFullYear() + setFullYear()

いかがでしょうか？「自分じぶんでカレンダーをめくらなくていい」というメリットが伝つたわれば、日付ひづけの計算けいさんが楽たのしくなりますよ。
