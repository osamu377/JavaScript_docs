Screen（スクリーン）オブジェクト

Screen（スクリーン）オブジェクト は、ユーザーが今使いまつかっている「パソコンの画面がめん」や「スマホのディスプレイ」そのものの情報じょうほうを教おしえてくれるオブジェクトです。

留学生りゅうがくせいの方かたには、Screenオブジェクトは「パソコンやスマホの画面がめんの測量士そくりょうし（そくりょうし）」だと教おしえてあげてください。画面がめんがどれくらい大おおきいのか、今いまどれくらいの広ひろさを使つかえるのか、といったサイズに関かんする情報じょうほうをすべて持もっています。

1. Screenオブジェクトとは？

window.screen を通とおじてアクセスします。このオブジェクトを見みれば、ユーザーがどんな大おおきさのディスプレイ（モニター）でサイトを見みているかが分わかります。

2. よく使つかうプロパティ（画面がめんの情報じょうほう）

「画面がめんの大おおきさはどれくらい？」を知しるためのプロパティです。

  • width（ウィズ） / height（ハイト）
    ディスプレイ全体ぜんたいの 横幅よこはば と 高たかさ のピクセル数すうです。
  • 例れい： フルHDのモニターなら width は 1920、height は 1080 が返かえってきます。スマホやパソコンの「画面がめんそのものの物理的ぶつりてきな限界げんかいサイズ」です。
  • availWidth（アベラブル・ウィズ） / availHeight（アベラブル・ハイト） 実際じっさいにブラウザが自由じゆうに使つかえる 「有効ゆうこう（ゆうこう）な横幅よこはばと高たかさ」 です。
  • 例れい： パソコンの画面下がめんしたにある「タスクバー」や、Macの「メニューバー」など、システムが使つかっている場所ばしょを引ひき算ざんした、本当ほんとうにアプリが動うごける広ひろさを教おしえてくれます。
  • colorDepth（カラー・デプス） 画面がめんが何色なにいろの種類しゅるいを表現ひょうげんできるかという 「色深度いろしんど（いろしんど）」 です。
  • orientation（オリエンテーション）
    スマホなどの画面がめんが今いま、「縦向たてむき（縦長たてなが）」 か 「横向よこむき（横長よこなが）」 かという向むきの情報じょうほうを教おしえてくれます。

3. よく使つかうメソッド（便利べんりな機能きのう）

Screenオブジェクト自体じたいには、直接動ちょくせつうごかすような一般的いっぱんてきなメソッド（関数かんすう）はほとんどありません。なぜなら、Screenは「画面がめんの状態じょうたいを調しらべるための観察日記かんさつにっき」のようなものだからです。

しかし、先さきほど登場とうじょうした orientation（向むき）プロパティと組くみ合あわせることで、最近さいきんのスマホブラウザでは画面がめんの向むきをコントロールすることができます。

orientation.lock()

スマホの画面がめんを 「縦向たてむき、または横向よこむきに固定こてい（ロック）」 します。

  • screen.orientation.lock("landscape");（画面がめんを横向よこむきに固定こていします）

orientation.unlock()

画面がめんの 「固定こていを解除かいじょ（かいじょ）」 して、スマホを傾かたむけたら自由じゆうに回まわるように戻もどします。

  • イメージ： スマホ用ようのブラウザゲームなどを作つくる時ときに、勝手かってに画面がめんが回まわらないようにするために使つかいます。
