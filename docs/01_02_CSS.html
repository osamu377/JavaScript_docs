留学生のためのJavaScript学習ガイド

JavaScriptジャバスクリプト学習者がくしゅうしゃのためのCSS基本きほんガイド：ウェブページのデザインを学まなぼう

なぜJavaScriptの前まえにCSSを学まなぶ必要ひつようがあるのか？

JavaScriptでデザインを変かえるためには、CSSの知識ちしきがどうしても必要ひつようです。留学生りゅうがくせいの皆みなさんにもわかりやすい「やさしい日本語にほんご」で、大切たいせつなポイントを解説かいせつします。

JavaScriptはCSSを操作そうさして、デザインを動的どうてきに変かえる役割やくわりを持もっています。CSSを知しっておくことには、次つぎのような戦略的せんりゃくてきなメリットがあります。

  1. CSSを知しらないとJavaScriptが書かけない： JavaScriptで「背景色はいけいしょくを変かえる」という命令めいれいを出だすとき、CSSのプロパティ名めい（backgroundColorなど）を知しらないと、プログラムが書かけません。
  2. 無駄むだなコードが減へる： 簡単かんたんなデザインの変化へんか（マウスを乗のせたときに色いろを変かえるなど）は、CSSだけで作つくれます。CSSでできることを知しっていれば、JavaScriptのコードを短みじかく、シンプルに保たもつことができます。
  3. エラーを減へらせる： CSSの仕組しくみを理解りかいしていれば、JavaScriptでデザインを操作そうさしたときに「なぜか動うごかない」というミスを防ふせぐことができます。

まず、デザインの基本きほんである「文字もじのスタイル」について学まなびましょう。

I. 文字もじのスタイル（文字もじのデザインを変かえる）

Webサイトにおいて、文字もじは情報じょうほうを伝つたえるための最もっとも大切たいせつな要素ようそです。文字もじの「読よみやすさ」は、ユーザーの体験たいけん（UX “User eXperience“のこと）に大おおきな影響えいきょうを与あたえます。

基本きほんの3つのプロパティ

まずは、よく使つかわれる以下いかの3つの命令めいれい（プロパティ）を覚おぼえましょう。

  1. font-size： 文字もじの大おおきさ。
  2. color： 文字もじの色いろ。
  3. text-align： 文字もじの並ならべ方かた。左ひだり（left）、真まん中なか（center）、右みぎ（right）のどこに揃そろえるかを決きめます。

CSSの書かき方かたの基本きほん

CSSは、「どの場所ばしょに（セレクタ）」「何なにの項目こうもくを（プロパティ）」「どう変かえるか（値あたい）」というルールで書かきます。

/* h1タグ（見出し）のデザインを変える例（れい） */
h1 {
  font-size: 24px;      /* 大きさを24ピクセルにする */
  color: blue;          /* 色を青にする */
  text-align: center;   /* 真ん中（まんなか）に並べる */
}

先さきほどのHTMLに、このCSSを適用てきようすると、下したのように変かわります。

セレクタ

セレクタ はウェブページを分解ぶんかいして、その一部いちぶを取とり出だすときに、必要ひつような部分ぶぶんを探さがすヒントとして使つかう、名前なまえや特徴とくちょうです。「タグ セレクタ」「クラス セレクタ」などがあります。

> [!important]
> セレクタ はJavaScriptでも、とても大事だいじです。JavaScriptを書かくときは、仕事しごとをしてもらうオブジェクトを指定していしなければなりません。そのとき、この セレクタ を利用りようするのです。

II. タグのスタイル（HTML要素ようそに直接ちょくせつ命令めいれいする）

「タグ セレクタ」とは、<h1>や<p>、<table>といったHTMLのタグ名めいに対たいして、スタイルを適用てきようする方法ほうほうです。ページ全体ぜんたいのデザインを一度いちどに整ととのえるのにとても便利べんりです。

テーブル（表ひょう）のスタイル例れい

「テーブル（表ひょう）」をきれいに見みせるためのプロパティを比較ひかく（ひかく）してみましょう。

プロパティ名意味（いみ）具体的な例と効果
border枠線わくせん（わくせん）1px solid black（1pxの太ふとさの黒くろい実線じっせん）
padding内側うちがわの余白よはくセルの中なかの文字もじと枠線わくせんの間あいだのスペースを広ひろげます。
background-color背景はいけいの色いろ表ひょうの背景はいけいに色いろを塗ぬります。

実線じっせん：途中とちゅうで切きれず、ずっと続つづいている線せん

先さきほどのHTMLに、このCSSを適用てきようすると、下したのように変かわります。

border-collapse: collapse; は「魔法まほうの言葉ことば」

テーブルのデザインで最もっとも重要じゅうようなのが border-collapse: collapse; です。 通常つうじょう、テーブルの枠線わくせんはセルごとに分わかれていて、そのままでは「二重線にじゅうせん」のように見みえてしまいます。このプロパティを <table>タグ に適用てきようすると、隣となりり合あう2本ほんの線せんを1本ぽんにまとめることができます。まさに 「2本ほんの線せんを1本ぽんにする魔法まほうの言葉ことば」 です。これを使つかうだけで、見みた目めがスッキリとプロらしくなります。

/* テーブルのデザインを変える例（れい） */
table {
    width: 100%;
    border-collapse: collapse;
    font-family: sans-serif;
}
th, td {
    border: 1px solid #333;
}
th, td {
    padding: 12px 15px;
}
th {
    background-color: #4CAF50; /* ヘッダーは緑 */
    color: white;
}
tr:nth-child(even) {
    background-color: #f2f2f2;
}

Note

注意ちゅうい：border（枠線わくせん）は各かくセル（<th>や<td>）に設定せっていし、border-collapseは全体ぜんたいの親おやである<table>に設定せっていするのが正ただしいルールです。

例れいのHTMLに適用てきようするCSSを、上うえのものに変更へんこうすると、見みた目めは下したのように変かわります。

III. 特定とくていの要素ようそ（クラス）のスタイル

「クラス（Class）」を使つかうと、特定とくていのグループに名前なまえをつけて、その名前なまえを呼よぶことでスタイルを適用てきようできます。同おなじデザインを何度なんども書かかなくて済すむため、コードの管理かんりがとても楽らくになります。

タグの名前なまえはあらかじめHTMLのルールで決きまっていますが、クラスの名前なまえはプログラマが自分じぶんで付つけるもの です。

クラスを使つかうステップ

  1. HTMLで名前なまえをつける： <p class="highlight"> のように書かきます。
  2. CSSでデザインを決きめる： .highlight { color: red; } のように、先頭せんとうにドットをつけて書かきます。

クラス名めいのルール

  • 名前なまえの始はじまりには必かならず .（ドット） をつけます（例れい：.main-title）。
  • 名前なまえは、そのグループが何なにであるかわかる 意味いみのある英語えいご を使つかいます。
  • 複数ふくすうの単語たんごを繋つなげる場合ばあいは、JavaScriptと同おなじ camelCase（キャメルケース） （例れい：.submitButton）を使つかうのがおすすめです。JSとCSSで名前なまえの付つけ方かたを統一とういつ（とういつ）すると、ケアレスミス（不注意ふちゅういな間違まちがい）を減へらすことができます。

JavaScriptへの繋つながり

JavaScriptには、getElementsByClassName() という「クラス名めいを使つかって要素ようそを見みつける」命令めいれいがあります。CSSでクラスを使つかってグループ化かしておけば、後あとでJavaScriptからそのグループだけを一度いちどに動うごかすことが非常ひじょうに簡単かんたんになります。

/* highlightクラスのデザインを変える例（れい） */
.highlight { color: red; }

例れいのHTMLに適用てきようするCSSを、上うえのものに変更へんこうすると、見みた目めは下したのように変かわります。

IV. 特定とくていの状態じょうたいのスタイル

ウェブページには「普段ふだんの状態じょうたい」だけでなく、「マウスが乗のったとき」のような「特別とくべつな状態じょうたい」があります。この特別とくべつな状態じょうたいを 疑似ぎじ（ぎじ）クラス と呼よびます。

代表的だいひょうてきな疑似ぎじクラス：:hover

最もっともよく使つかわれるのが :hover（ホバー）です。これは「要素ようその上うえにマウスカーソルが乗のったとき」の状態じょうたいを指さします。

  • CSSの :hover： マウスが乗のったときに、色いろをサッと変かえることができます。
  • JavaScriptの onmouseover / onmouseout： マウスが乗のったとき（over）と離はなれたとき（out）に、より複雑ふくざつ（ふくざつ）な動うごき（計算けいさんや画面がめんの切きり替かえ）をさせるときに使つかいます。

使つかい分わけの指針ししん（ししん）： 「ボタンの色いろを少すこし明あかるくする」といった見みた目めの変更へんこうだけなら CSS を使つかい、「ボタンに乗のったらデータを保存ほぞん（ほぞん）する」といった機能きのうの追加ついかは JavaScript を使つかいましょう。

a:link,
a:visited {
  color: rebeccapurple;
  font-weight: bold;
}
a:hover {
  color: hotpink;
}

例れいのHTMLに適用てきようするCSSを、上うえのものに変更へんこうし、マウスカーソルをリンクテキスト上じょうに置おくと、見みた目めは下したのように変かわります。

V. JavaScriptからCSSを操作そうさする重要じゅうようルール

JavaScriptを使つかってデザインを書かき換かえるとき、CSSのプロパティ名めいの書かき方かたが少すこし変かわるという「重要じゅうようなルール」があります。

キャメルケースへの変換へんかん（へんかん）

CSSでハイフン（-）を使つかっていた名前なまえは、JavaScriptではハイフンを消けして、次つぎの文字もじを大文字おおもじにする 「キャメルケース」 に書かき換かえます。

CSSの書き方JavaScriptでの書き方意味
font-sizefontSize文字もじの大おおきさ
background-colorbackgroundColor背景はいけいの色いろ
border-radiusborderRadius角かどの丸まるみ（かどのまるみ）

JavaScriptでの書かき換かえ構造こうぞう：「道みちのり」で考かんがえる

JavaScriptからCSSを操作そうさするときは、次つぎのような構造こうぞうで命令めいれいを出だします。

// ID名が "title" の要素の色を赤に変える
document.getElementById("title").style.color = "red";

これを、目的地もくてきち（もくてきち）までの 「道みちのり（みちのり）」 として分解ぶんかいしてみましょう。

  1. document：このウェブページという「大おおきな書類しょるい」の中なかから、
  2. .getElementById(“title”)：IDが “title” の「場所ばしょ」を見みつけて、
  3. .style：「デザイン（スタイル）」の担当者たんとうしゃに、
  4. .color = “red”：「文字もじの色いろ」を「赤あか」に変かえるように命令めいれいする。

このように、ドット（.）で繋つなぐことで、操作そうさしたい場所ばしょへ順番じゅんばんにたどり着つくことができます。

【参考さんこう】この「道みちのり」を英語えいごを使つかって「パス(path)」と呼よぶことがあります。

VI. CSS基礎きそのまとめ

  • 文字もじスタイル： font-size や color で読よみやすくする。
  • タグスタイル： タグに直接ちょくせつ命令めいれいし、border（1px solid black）などで整ととのえる。
  • クラス： 名前なまえをつけてグループ化かし、JavaScriptからも操作そうさしやすくする。
  • 疑似ぎじ（ぎじ）クラス： :hover でユーザーの動うごきに反応はんのうさせる。

HTMLをしっかり覚おぼ（おぼ）えることが、JavaScriptをマスターするための近道ちかみち（ちかみち）です。また、CSSで自分じぶんの思おもい通どおりのデザインが作つくれるようになると、JavaScriptの学習がくしゅうはもっと楽たのしくなります。まずは 「自分じぶんの書かいたコードで画面がめんが変かわる楽たのしさ」 を大切たいせつにしてください。
