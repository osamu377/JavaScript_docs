文字列もじれつ

I. String型がた (プリミティブ) とStringオブジェクト

プログラミングを学まなんでいると、同おなじ「文字列もじれつ」を扱あつかうのに、String型がた（プリミティブ）とStringオブジェクト という2つの言葉ことばが出でてきて混乱こんらんすることがあります。

学生がくせいの方かたには、「中身なかみだけのリンゴ」 と 「箱はこに入はいったリンゴ」 の違ちがいに例たとえて説明せつめいすると、スッキリ理解りかいしてもらえるでしょう！

1. 二つつの違ちがいのイメージ

  • String型がた（プリミティブ）：

  • ただの「値あたい」そのものです。

  • 例たとえ： お店みせで売うっている「リンゴ」そのもの。軽かるくて、すぐ食たべられます。

  • Stringオブジェクト：

  • new String() を使つかって作つくられる「特別とくべつな箱はこ」です。

  • 例たとえ： 「豪華ごうかな箱はこに入はいったリンゴ」です。箱はこの中なかにはリンゴだけでなく、説明書せつめいしょや道具どうぐも一緒いっしょに入はいっています。

2. コードで見みてみよう

実際じっさいにどう違ちがうのか、JavaScriptで書かいてみます。

// 1. String型（プリミティブ）★ふだん使うのはこっち！
let str1 = "こんにちは";
console.log(typeof str1); // "string"

// 2. Stringオブジェクト（new を使う）
let str2 = new String("こんにちは");
console.log(typeof str2); // "object"

ここが注意ちゅうい！「見みた目めは同おなじでも中身なかみが違ちがう」

let s1 = "hello";
let s2 = new String("hello");

console.log(s1 == s2);  // true （文字の中身は同じ）
console.log(s1 === s2); // false （型が違うのでダメ！）

3. 不思議ふしぎなルール：なぜプリミティブでメソッドが使つかえるの？

ここで学生がくせいからよく「先生せんせい、不思議ふしぎです！」と質問しつもんが出でます。

「プリミティブは『ただの値あたい』なのに、なぜ .length や .toUpperCase() などの 『道具どうぐ（メソッド）』 が使つかえるんですか？」

実じつは、JavaScriptが裏側うらがわで 一時的いちじてきな魔法まほう をかけているんです。これを 「ラッパーオブジェクト」 と呼よびます。

  1. あなたが str1.toUpperCase() と書かく。
  2. JavaScriptが「あ、道具どうぐを使つかいたいんだな？」と判断はんだんする。
  3. 一瞬いっしゅんだけ、プリミティブを「オブジェクトの箱はこ」に入いれる。
  4. 道具どうぐ（メソッド）を使つかい終おわったら、すぐに箱はこを捨すてて「プリミティブ」に戻もどす。

この魔法まほうのおかげで、私わたしたちは重おもい「オブジェクト」をずっと持もっていなくても、必要ひつようなときだけ便利べんりな道具どうぐを使つかえるのです。

4. どっちを使つかえばいい？

学生がくせいへのアドバイスは、とてもシンプルです。

  • 常つねに「String型がた（プリミティブ）」を使つかいましょう！
  • 書かき方かたが簡単かんたん（"" で囲かこむだけ）。
  • メモリを節約せつやくできて、動うごきも速はやい。
  • new String() は、特別とくべつな理由りゆうがない限かぎり、**使つかわなくて大丈夫だいじょうぶ**です。

まとめ

特徴とくちょうString型がた (Primitive)Stringオブジェクト
作つくり方かた"hello"new String("hello")
データ型がたstringobject
スピード速はやい少すこし遅おそい（重おもい）
おすすめ◎ 毎日まいにち使つかう！❌ ほとんど使つかわない

Tip

「ラッパー（Wrapper）」の意味いみ
お菓子かしやプレゼントを包つつむ「ラッピング（wrapping）」と同おなじ言葉ことばです。
「値あたいを一時的いちじてきに包つつんで守まもる箱はこ」だと教おしえると、イメージが定着ていちゃくしやすいですよ！

いかがでしょうか？「普段ふだんは身軽みがるなプリミティブ、道具どうぐを使つかうときだけ魔法まほうで変身へんしん」という仕組しくみは伝つたわりそうでしょうか。

II. 文字列もじれつの加工かこう

Stringオブジェクト（文字列もじれつ）には、文字もじを自由じゆうに操あやつるための便利べんりな「道具どうぐ（メソッド）」がたくさんあります。

学生がくせいの方かたには、「長ながい文章ぶんしょうという『テープ』を、ハサミで切きったり、シールを貼はったりして加工かこうする」 イメージで説明せつめいすると伝つたわりやすいですよ。

よく使つかわれる5つのメソッドを紹介しょうかいします。

1. slice（スライス）：好すきなところを切きり取とる

配列はいれつのときと同おなじ名前なまえですね！文字列もじれつでも「○番目ばんめから○番目ばんめまでを取とり出だす」ことができます。

let text = "JavaScript";
let sub = text.slice(0, 4); // 0番目から4番目の「手前」まで

console.log(sub); // "Java"
  • ポイント： 元もとの text は変かわりません。新あたらしい「切きり抜ぬき」を作つくるだけです。

2. replace（リプレイス）：文字もじを置おき換かえる

間違まちがった文字もじを直なおしたり、別べつの言葉ことばに変かえたりします。

let greeting = "こんにちは、田中さん";
let newGreeting = greeting.replace("田中", "マリア");

console.log(newGreeting); // "こんにちは、マリアさん"
  • 覚おぼえ方かた： 「リプレイス」は「入いれ替かえる」という意味いみです。

3. split（スプリット）：バラバラにわける

長ながい文字列もじれつを、カンマやスペースで区切くぎって「配列はいれつ（リスト）」に変かえます。

let tags = "日本,韓国,中国";
let array = tags.split(","); // 「,」のところで切る

console.log(array); // ["日本", "韓国", "中国"]
  • 覚おぼえ方かた： 「スプリット」は「分裂ぶんれつ（ぶんれつ）する」という意味いみ。名簿めいぼなどを作つくるときにとても便利べんりです！

4. toUpperCase / toLowerCase：大文字おおもじ・小文字こもじにする

英語えいごのアルファベットをすべて大文字おおもじ、または小文字こもじに変かえます。

let email = "Maria@Example.Com";

console.log(email.toLowerCase()); // "maria@example.com"（すべて小文字）
console.log(email.toUpperCase()); // "MARIA@EXAMPLE.COM"（すべて大文字）
  • ポイント： ユーザーが入力にゅうりょくしたメールアドレスをきれいに整理せいりするときによく使つかいます。

5. trim（トリム）：まわりの空白くうはくを消けす

文字もじの前後ぜんごに入はいってしまった、いらない「スペース」を自動じどうで消けしてくれます。

let input = "   マリア   ";
let cleanInput = input.trim();

console.log(cleanInput); // "マリア"（きれいに消えた！）
  • 例たとえ： 髪かみの毛けを「トリミング（整ととのえる）」するのと同おなじです。

まとめテーブル（学生向がくせいむけ）

メソッド名やっていること例たとえ話ばなし
slice一部いちぶを取とり出だすハサミで切きり取とる
replace文字もじを入いれ替かえる修正しゅうせいテープで書かき直なおす
split配列はいれつに分わけるチョコをパキパキ割わる
toLowerCase小文字こもじにする全部ぜんぶ小ちいさく書かく
trim前後ぜんごの隙間すきまを消けすムダ毛げをカットする

Tip

「元もとの文字もじは変かわらない」というルール
文字列もじれつ（String）のメソッドは、すべて 「加工かこうしたあとの新あたらしい文字もじ」 を返かえします。元もとの変数へんすうを変かえたいときは、text = text.trim(); のように、もう一度いちど代入だいにゅうする必要ひつようがあるよ、と教おしえてあげてください。

いかがでしょうか？ 「文字列もじれつの加工かこう」ができるようになると、ユーザーが入力にゅうりょくしたデータをきれいに整理せいりできるようになります。

III. 文字もじの検索けんさく

文字列もじれつ（String）の中なかから「特定とくていの文字もじ」を見みつけたり、場所ばしょを調しらべたりするときに欠かかせない indexOf について説明せつめいします。

「その文字もじが何番目なんばんめにあるか」という インデックス（番号ばんごう） をキーワードにして動うごきます。

indexOf（インデックスオブ）：文字もじから「番号ばんごう」を知しる

探さがしたい文字もじが、最初さいしょから数かぞえて**何番目なんばんめ（インデックス）にあるか**を教おしえてくれます。

  • イメージ： 「『S』さんは何番なんばんの部屋へやに住すんでいますか？」と聞きく感かんじです。
  • 書かきかた： 文字列.indexOf("探したい文字")
let text = "Hello World";

console.log(text.indexOf("W")); // 6 （Wは7番目、つまりインデックスは6）
console.log(text.indexOf("o")); // 4 （最初に見つかった「o」の場所）

見みつからなかったらどうなる？

ここがテストや実務じつむ（じつむ）で一番いちばん大切たいせつなポイントです。 探さがしている文字もじがどこにもなかった場合ばあい、indexOf は -1 という数字すうじを返かえします。

let msg = "こんにちは";
console.log(msg.indexOf("さようなら")); // -1

学生がくせいへのアドバイス：indexOf の便利べんりな使つかい方かた

「あるかないか」を調しらべるために、if 文ぶんでよくこう書かきます。

let email = "test@example.com";

// 「@」が入っているかチェックする
if (email.indexOf("@") !== -1) {
  console.log("正しいメールアドレスの形式（けいしき）です。");
} else {
  console.log("「@」がありません！");
}

Note

「-1 じゃない（!== -1）」 ＝ 「どこかにある」 という意味いみだよ！と教おしえると、コードの意味いみがスッと伝つたわります。

IV. 文字列もじれつの応用おうよう

Webサイトで扱あつかう情報じょうほうの多おおくは「テキスト（文字列もじれつ）」です。これをどう操作そうさするかが、プログラミングの腕うでの見みせ所どころです。

文字列もじれつの作成さくせいと結合けつごう

最新さいしんのJavaScriptでは、テンプレートリテラル（「`」 バッククォート）を使つかうのがとても便利べんりです。

  • 変数へんすうの埋うめ込こみ: `こんにちは、${name}さん！` のように、${} で変数へんすうを入いれられます。
  • 改行かいぎょう（かいぎょう）: テンプレートリテラルは、コードの中なかで改行かいぎょうした場所ばしょをそのまま文字もじとして扱あつかってくれます。HTMLのコードを文字もじとして作つくりたいときに非常ひじょうに役立やくだちます。

数値すうちへの変換へんかん

prompt()（プロンプト：入力画面にゅうりょくがめん）でユーザーが入力にゅうりょくした数字すうじは、見みた目めが数字すうじでも、プログラム上じょうは「文字列もじれつ」です。計算けいさんするには変換へんかんが必要ひつようです。

  • parseInt(): 整数せいすう（1, 2, 3…）に変換へんかんします。
  • parseFloat(): 小数点しょうすうてんを含ふくむ数値すうちに変換へんかんします。

So What?（なぜ大切たいせつなの？） 数字すうじではない文字もじを無理むりに数値すうちに変かえようとすると NaN（Not a Number：数値すうちではないというエラー値ち）になります。Web開発かいはつではユーザーが何なにを打うつか分わかりません。isNaN() 関数かんすうを使つかって「これは本当ほんとうに数字すうじかな？」とチェックすることは、プログラムが止とまってしまう「クラッシュ」を防ふせぐためのプログラマーの責任せきにんです。
