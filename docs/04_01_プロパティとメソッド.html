留学生のためのJavaScript学習ガイド

オブジェクトの中なかを見みてみてみよう

I. オブジェクトとは？

オブジェクトについて、もう少すこし詳くわしく説明せつめいしましょう。

ここまでは「オブジェクトを使つかう」という目的もくてきのために必要ひつようなことを、できるだけ簡単かんたんに説明せつめいしてきました。いわば、自動販売機じどうはんばいきを外側そとがわから見みていたようなものです。

自動販売機じどうはんばいきを使つかうには

  1. お金かねを入いれて
  2. ボタンを押おせば
  3. ジュースが出でてくる

という点てんだけ理解りかいしていれば、ふつうは大丈夫だいじょうぶでしょう。機械きかいの蓋ふたを開あけて、中なかに何なにが入はいっているか見みる必要ひつようはありません。しかし、それでは、中身なかみをまったく知しらない小ちいさな子供こどものように、お菓子かしの自動販売機じどうはんばいきからジュースを出だそうして、困こまってしまうことになるかもしれません。

なので、ここではちょっとだけ、オブジェクトの中身なかみを見みてみましょう。自動販売機じどうはんばいきだって、「この中なかにジュースの缶かんやボトルがたくさん入はいっているんだ」「入いれたコインが何円なんえんかを計算けいさんする装置そうちが入はいっているんだ」ということを知しっていると、安心あんしんして使つかえるでしょう。

心配しんぱいしなくても、難むずかしいことはありません。

オブジェクトを内側うちがわから見みると、「関係かんけいがある情報じょうほうをまとめたもの」 であることがわかります。

ここでは、「プロフィールのカード」 や 「キャラクター」 に例たとえて説明せつめいします。

II. イメージは「自己紹介じこしょうかいカード」

例たとえば、ある学生がくせいのことを変数へんすうで表あらわしてみます。すると、こんなふうになります。

  • let name = "マリア";
  • let age = 20;
  • let country = "ブラジル";

しかし、これだと、情報じょうほうがバラバラで管理かんりが大変たいへんです。そこで、これらを1枚まいのカードにまとめてみます。

III. オブジェクトの書かき方かた

JavaScriptでは { } を使つかって、このように書かきます。

const student = {
  name: "マリア",  // 名前
  age: 20,         // 年齢
  country: "ブラジル" // 出身
};

このように、いくつかの情報じょうほうを1枚まいのカードにまとめたもの 、それが「オブジェクト」です。

IV. プロパティ

カードの中なかのひとつひとつの情報じょうほうを 「プロパティ」 と言いいます。カードの中なかから情報じょうほうを取とり出だすときは、「.（ドット）」 を使つかいます。

  • student.name → 「マリア」を取とり出だせる！
  • student.age → 「20」を取とり出だせる！

ブラウザ・オブジェクトでの例れい：

document.body.style.backgroundColor = "red";

このコードは、documentオブジェクトの中なかのbodyオブジェクトの、backgroundColor（プロパティ）を“red“に変かえるという命令めいれいです。

V. メソッド: 「特徴とくちょう」と「動うごき」をセットにできる

オブジェクトのすごいところは、データ（特徴とくちょう） だけでなく、関数かんすう（動うごき） も一緒いっしょにまとめられることです。オブジェクトに含ふくまれる関数かんすうを メソッド と言いいます。

  • プロパティ（特徴とくちょう）： 名前なまえ、身長しんちょう、色いろ、値段ねだんなど
  • メソッド（動うごき）： 走はしる、話はなす、計算けいさんするなど

VI. ゲームのキャラクターで例たとえると：

「オブジェクト」の考かんがえ方かたは、ゲームのキャラクターに例たとえると非常ひじょうに分わかりやすくなります。

  • オブジェクト： キャラクター自身じしん（例れい：勇者ゆうしゃアレン）
  • プロパティ： ステータス（例れい：hp や name）
  • メソッド： 行動こうどう（例れい：attack() や heal()）

コードでの例れい:

const hero = {
  name: "Allen"      // 特徴（プロパティ）
  hp: 100,           // 特徴（プロパティ）
  level: 5,          // 特徴（プロパティ）
  
  attack: function() { 
    alert("エイッ！と攻撃しました"); // 動（うご）き（メソッド）
  }
};

VII. なぜ「オブジェクト」を使つかうの？

世界せかいにあるものは、すべて「名前なまえ」や「状態じょうたい」や「動うごき」を持もっていますよね。

  • 車くるま： 名前なまえ、色いろ、スピード、ブレーキをかける動うごき
  • スマホ： モデル名めい、電池でんちの残のこり、アプリを開ひらく動うごき

オブジェクトを使つかうと、現実げんじつの世界せかいと同おなじようにプログラムが書かける ので、複雑ふくざつなアプリも作つくりやすくなるんです。

Tip

「オブジェクト ＝ 便利べんりな情報じょうほうのセット」 だと考かんがえてください。 “Object“という英語えいごを辞書じしょで見みると、難むずかしい漢字かんじの「対象物たいしょうぶつ（たいしょうぶつ）」と出でてきます。プログラムでは、そう考かんがえるより、「データとアクションをひとまとまりにしたもの」 と覚おぼえるのが近道ちかみちです！

オブジェクトのイメージはつかめたでしょうか？

上うえで見みたstudentやhereのように、自分じぶんでオブジェクトを作つくることもできます（その方法ほうほうについては、もっとあとで説明せつめいします）。でも、そのまえに、ブラウザに用意よういされているオブジェクトを利用りようしてみましょう。
