Historyオブジェクト

Historyオブジェクトは、ブラウザの「戻もどる」ボタンや「進すすむ」ボタンと同おなじ役割やくわりをするオブジェクトです。

学生がくせいの方かたには、Historyオブジェクトは**「ブラウザの中なかにある『タイムマシン』」**だと教おしえてあげてください。ユーザーが今いままでに見みてきたページの履歴りれき（ひれき）を管理かんりしています。

1. Historyオブジェクトとは？

window.history を通とおじてアクセスします。ユーザーがそのタブでこれまでに訪おとずれたページのリストを持もっていて、JavaScriptから「1つ前まえのページに戻もどる」といった操作そうさができます。

2. よく使つかうプロパティ（履歴りれきの情報じょうほう）

  • length 現在げんざいのタブの履歴りれきリストに、全部ぜんぶでいくつページがあるかを教おしえてくれます。
  • console.log(history.length);
  • 初はじめて開ひらいたタブなら 1 になります。

3. よく使つかうメソッド（タイムマシンを動うごかす）

直感的ちょっかんてきに使つかえるメソッドが揃そろっています。

back()

ブラウザの「戻もどる（←）」ボタンを押おすのと同おなじです。1つ前まえのページに戻もどります。

  • history.back();

forward()

ブラウザの「進すすむ（→）」ボタンを押おすのと同おなじです。

  • history.forward();

go(数字)

指定していした数かずだけ、履歴りれきを移動いどうします。

  • history.go(-1); （1つ戻もどる。back() と同おなじ）
  • history.go(-2); （2つ戻もどる）
  • history.go(1); （1つ進すすむ。forward() と同おなじ）

4. 高度こうどなメソッド：URLを書かき換かえる（履歴りれきを作つくる）

最近さいきんのモダンなウェブサイト（SPAなど）でよく使つかわれる、少すこし魔法まほうのようなメソッドです。

pushState(データ, タイトル, URL)

ページを読よみ直なおさずに、URLだけを新あたらしく書かき換かえて履歴りれきに追加ついかします。

  • 例れい： 検索結果けんさくけっかをフィルタリングしたときに、ページはそのままでURLだけを変かえたいときに使つかいます。

replaceState(データ, タイトル, URL)

今いまの履歴りれきを、新あたらしいURLで 上書うわがき（書かき換かえ） します。

5. 実際じっさいに動うごかしてみよう！

学生がくせいに「戻もどるボタン」を自作じさくする方法ほうほうを教おしえてあげましょう。

// 「戻る」ボタンを作るとき
function goBack() {
  // 履歴が1つ以上あれば戻る
  if (history.length > 1) {
    history.back();
  } else {
    alert("戻るページがありません！");
  }
}

6. 学生がくせいへのアドバイス：プライバシーに注意ちゅうい！

学生がくせいが「ユーザーがどのサイトから来きたか（URLの中身なかみ）」を知しりたがることがありますが、それはできません。

「Historyオブジェクトは『何個戻なんこもどれるか』や『戻もどれ！』という命令めいれいはできるけど、プライバシーを守まもるために『戻もどる先さきの具体的ぐたいてきなURL』を覗のぞくことはできないんだよ」
