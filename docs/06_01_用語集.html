はじめに

こんにちは！このドキュメントは、JavaScriptを勉強（べんきょう）しているけれど、まだ日本語に慣（な）れていない皆（みな）さんのための用語集（ようごしゅう）です。プログラミングの言葉（ことば）はむずかしいものも多（おお）いですが、ここでは、やさしい日本語と簡単（かんたん）な例（れい）を使（つか）って、一（ひと）つずつていねいに説明（せつめい）します。あなたの学習（がくしゅう）の助（たす）けになればうれしいです。

I. Webページの基本 (Webページの きほん)

Webページを作（つく）るためには、3つの大切（たいせつ）な技術（ぎじゅつ）があります。それはHTML、CSS、JavaScriptです。これを「家」に例たとえてみましょう。HTMLは家の「柱や壁」、CSSは家の「ペンキ（ぺんき）やインテリア（いんてりあ）」のような飾（かざ）りつけ、そしてJavaScriptは電気（でんき）をつけたり機械（きかい）を動（うご）かしたりする「機能（きのう）」のようなものです。この3つが協力（きょうりょく）して、私（わたし）たちがいつも見（み）ているWebページができています。

  • HTML
    • Webページの骨組ほねぐみや構造（こうぞう）を作（つく）るための言葉（ことば）です。
  • CSS
    • Webページの見みた目め（みため）をきれいにするための言葉（ことば）です。
  • JavaScript
    • Webページに動（うご）きをつけたり、機能（きのう）を追加（ついか）するための言葉（ことば）です。

それでは、JavaScriptを書（か）くときの、基本的（きほんてき）なルールについて見（み）ていきましょう。

II. JavaScriptの基本ルール (JavaScriptの きほん ルール)

日本語（にほんご）に文法（ぶんぽう）があるように、JavaScriptにもコードを正（ただ）しく書（か）くためのルールがあります。このルールを守（まも）ることで、コンピューターがあなたの命令（めいれい）をきちんと理解（りかい）できるようになり、エラーを防（ふせ）ぐことができます。

  • 変数へんすう (へんすう)
    • 数字（すうじ）や文字（もじ）などのデータを入（い）れておくための、名前（なまえ）がついた「箱（はこ）」のようなものです。
  • let
    • 中身（なかみ）を後（あと）から変（か）えることができる変数へんすうを作（つく）るときに使（つか）います。
  • const
    • 一度（いちど）データを入（い）れたら、後（あと）から変（か）えることができない変数へんすう（「定数（ていすう）」といいます）を作（つく）るときに使（つか）います。
  • 命名規則 (めいめい きそく)
    • 変数へんすうや関数かんすう関数かんすうの名前（なまえ）のルールです。意味（いみ）のわかる英語（えいご）で、2つ目（め）の単語（たんご）から最初（さいしょ）の文字（もじ）を大文字（おおもじ）にする「キャメルケース」（例れい: myScore）で書（か）くのが一般的（いっぱんてき）です。
  • 大文字と小文字の区別 (おおもじと こもじの くべつ)
    • JavaScriptでは、大文字（おおもじ）と小文字（こもじ）は別（べつ）のものとして扱（あつか）われます。たとえば、Nameとnameは、違（ちが）う変数へんすうになります。
  • 半角はんかく文字の使用 (はんかくもじの しよう)
    • 文字列（もじれつ）やコメントの中（なか）以外（いがい）のコードは、すべて半角はんかくの英数字えいすうじ（えいすうじ）や記号（きごう）で書（か）く必要（ひつよう）があります。全角ぜんかくスペースなどを使（つか）うとエラーになります。
  • データ型 (データがた)
    • 変数へんすうが扱（あつか）うデータの種類（しゅるい）のことです。主（おも）に次（つぎ）のようなものがあります。
  • 文字列 (もじれつ)
    • 「こんにちは」のような、テキストのデータのことです。“か’で囲（かこ）みます。
  • 数値すうち (すうち)
    • 100や3.14のような、数字（すうじ）のデータのことです。
  • 論理ろんり型 (ろんりがた)
    • true（はい）かfalse（いいえ）のどちらかを表（あらわ）すデータのことです。
  • セミコロン (;)
    • 文（ぶん）の終（お）わりにつける記号（きごう）です。命令（めいれい）の区切（くぎ）りをわかりやすくします。
  • コメント (//)
    • コードの中（なか）に書（か）くことができるメモです。//の後（あと）に書（か）いた文字（もじ）は、プログラムとしては無視（むし）されます。

ルールがわかったら、次（つぎ）はJavaScriptがどうやって計算（けいさん）や比較（ひかく）をするのかを見（み）てみましょう。

III. 計算と比較 (けいさんと ひかく)

プログラムの中（なか）では、足（た）し算（ざん）をしたり、2つの値（あたい）を比（くら）べたりすることがよくあります。そのために使（つか）うのが「演算えんざん子（えんざんし）」という特別（とくべつ）な記号（きごう）です。演算えんざん子（えんざんし）を使（つか）うことで、プログラムにいろいろな判断（はんだん）をさせることができます。

  • 演算えんざん子 (えんざんし)
    • 計算（けいさん）や比較（ひかく）など、データに対（たい）して何（なに）かをするための記号（きごう）のことです。
    • 例（れい）: +, =, >
  • 算術さんじゅつ演算えんざん子 (さんじゅつ えんざんし)
    • 足（た）し算（ざん）や引（ひ）き算（ざん）など、数学（すうがく）の計算（けいさん）をするときに使（つか）います。++（1増やす）や–（1減らす）もよく使われます。
    • 例（れい）: 5 + 3 や count++
  • 代入だいにゅう演算えんざん子 (だいにゅう えんざんし)
    • 変数へんすうにデータを入（い）れる（代入だいにゅうする）ときに使（つか）います。
    • 例（れい）: let score = 100;
  • 比較演算えんざん子 (ひかく えんざんし)
    • 2つの値（あたい）を比（くら）べて、trueかfalseかを判断（はんだん）するときに使（つか）います。
    • 例（れい）: score > 80 （scoreは80より大（おお）きいですか？）
  • 論理ろんり演算えんざん子 (ろんり えんざんし)
    • 「AかつB」や「AまたはB」のように、複数（ふくすう）の条件（じょうけん）を組（く）み合（あ）わせるときに使（つか）います。
    • 例（れい）: age >= 20 && hasTicket （20才以上で、チケットも持っていますか？）

これらの演算えんざん子（えんざんし）は、プログラムの流（なが）れをコントロールするためによく使（つか）われます。

IV. プログラムの流れをコントロールする (プログラムの ながれを コントロールする)

プログラムは、いつも上（うえ）から下（した）へ順番（じゅんばん）に進（すす）むだけではありません。まるで私（わたし）たちが毎日（まいにち）、「もし雨（あめ）が降（ふ）ったら、傘（かさ）を持（も）っていこう」と考（かんが）えるように、条件（じょうけん）によってやることが変（か）わったり、同（おな）じことを繰（く）り返（かえ）したりします。これを「制御せいぎょフロー（せいぎょふろー）」と呼（よ）びます。

  • if文 (いふ ぶん)
    • 「もし〜だったら、この処理（しょり）をする」というように、条件（じょうけん）がtrueのときだけコードを実行（じっこう）します。
  • else
    • if文（ぶん）の条件（じょうけん）がfalseだった場合（ばあい）に、「そうでなければ、こちらを実行（じっこう）する」という処理（しょり）を書（か）くときに使（つか）います。
  • switch文 (すいっち ぶん)
    • if…else if…がたくさん続（つづ）く代（か）わりに使（つか）える文（ぶん）です。ひとつの変数へんすうの値（あたい）によって、たくさんの選択肢せんたくし（せんたくし）から処理（しょり）を選（えら）びたいときに便利（べんり）です。
  • for文 (ふぉー ぶん)
    • 「10回（かい）繰（く）り返（かえ）す」のように、決（き）まった回数（かいすう）だけ同（おな）じ処理（しょり）をしたいときに使（つか）います。for (初期しょき設定せってい; 継続条件; 増減処理)という形（かたち）で書（か）きます。
  • while文 (わいる ぶん)
    • 「条件（じょうけん）がtrueの間（あいだ）はずっと繰（く）り返（かえ）す」というように、回数（かいすう）が決（き）まっていないときに使（つか）います。
  • break
    • for文（ぶん）やwhile文（ぶん）の繰（く）り返（かえ）しを、途中（とちゅう）でやめたいときに使（つか）います。
  • continue
    • 繰（く）り返（かえ）しの中（なか）で、今回（こんかい）の処理（しょり）だけをスキップして、次（つぎ）の回（かい）に進（すす）みたいときに使（つか）います。

こうしていくつかの処理（しょり）を作（つく）っていくと、同（おな）じようなコードをまとめたくなります。そんな時（とき）に便利（べんり）なのが次（つぎ）の機能（きのう）です。

V. 処理をまとめる (しょりを まとめる)

プログラムを書（か）いていると、同（おな）じことを何回（なんかい）もすることがあります。そんなとき、処理（しょり）をひとつのグループにまとめて、いつでも呼（よ）び出（だ）せるようにすると便利（べんり）です。これを「関数かんすう関数かんすう」と呼（よ）びます。関数かんすう関数かんすうは、自動販売機（じどうはんばいき）のようなものです。お金（かね）を入（い）れてボタンを押（お）す（関数かんすうを呼び出す）と、いつでも決（き）まった飲（の）み物（もの）が出（で）てくる（処理が実行される）ように、コードを整理（せいり）して再利用（さいりよう）しやすくします。

  • 関数かんすう (かんすう)
    • 特定（とくてい）の処理（しょり）をひとつのグループにまとめたものです。名前（なまえ）を呼（よ）ぶだけで、いつでもその処理（しょり）を実行（じっこう）できます。
  • 引数ひきすう (ひきすう)
    • 関数かんすう関数かんすうに処理（しょり）をしてもらうために、外（そと）から渡（わた）すデータのことです。自動販売機（じどうはんばいき）で言（い）うと、お金（かね）や、どの飲（の）み物（もの）かを選（えら）ぶボタンのようなものです。
  • 戻もどり値ち (もどりち) / return
    • 関数かんすう関数かんすうが処理（しょり）を終（お）わった後（あと）、その結果（けっか）を呼（よ）び出（だ）した場所（ばしょ）に返（かえ）すことです。自動販売機（じどうはんばいき）から出（で）てくるジュースのようなものです。
  • コールバック関数かんすう (コールバック かんすう)
    • 他（ほか）の関数かんすう関数かんすうに引数ひきすう（ひきすう）として渡（わた）される、「後（あと）でこの処理（しょり）を実行（じっこう）してください」とお願いするための関数かんすうです。誰（だれ）かにお願（ねが）いする仕事（しごと）の「指示メモ」のようなものです。

これまでプログラムのロジックについて学（まな）んできましたが、次（つぎ）はJavaScriptが実際（じっさい）にWebページをどうやって動（うご）かすのかを見（み）ていきましょう。

VI Webページを操作する (Webページを そうさする) - DOM

JavaScriptは、Webページの見みた目め（みため）や内容（ないよう）を自由（じゆう）に変（か）えることができます。そのために使（つか）うのが「DOM（ドム）」です。DOMは、HTMLページを木（き）のような構造（こうぞう）で表（あらわ）した「地図（ちず）」のようなものです。JavaScriptはこの地図（ちず）を見（み）て、特定（とくてい）のHTML要素（ようそ）を探（さが）したり、文字（もじ）を変（かえ）たり、新（あたら）しい要素（ようそ）を追加（ついか）したりします。

  • DOM (Document Object Model)
    • HTML文書（ぶんしょ）の構造（こうぞう）を、JavaScriptが操作（そうさ）できるようにしたものです。
  • window
    • ブラウザのウィンドウやタブそのものを表（あらわ）す、すべてのオブジェクトの親（おや）となる一番（いちばん）上（うえ）にあるオブジェクトです。
  • document
    • 表示ひょうじされているHTMLページ全体（ぜんたい）を表（あらわ）すオブジェクトで、windowオブジェクトの一部（いちぶ）です。DOM操作（そうさ）はここから始（はじ）まります。
  • セレクタ (selector)
    • 操作（そうさ）したいHTML要素（ようそ）を見（み）つけるための「目印（めじるし）」のことです。CSSを書くときと同じように、IDは’#id-name’、クラスは’.class-name’のように書きます。
  • getElementById()
    • IDを使（つか）って、特定（とくてい）のHTML要素（ようそ）をひとつだけ探（さが）します。
  • querySelector()
    • CSSセレクタを使（つか）って、条件（じょうけん）に合（あ）う最初（さいしょ）のHTML要素（ようso）をひとつ探（さが）します。
  • querySelectorAll()
    • CSSセレクタを使（つか）って、条件（じょうけん）に合（あ）うHTML要素（ようそ）をすべて探（さが）して、リストとして受（う）け取（と）ります。
  • .textContent
    • 要素（ようそ）の中（なか）にあるテキスト（文字（もじ）だけ）を取得しゅとく（しゅとく）したり、書（か）き換（か）えたりします。安全（あんぜん）な方法（ほうほう）です。
  • .innerHTML
    • 要素（ようそ）の中（なか）にあるHTMLタグも含（ふく）めた内容（ないよう）全体（ぜんたい）を取得しゅとく（しゅとく）したり、書（か）き換（か）えたりします。ユーザーからの入力にゅうりょくをそのまま使うと危険（きけん）な場合（ばあい）があります。
  • .style
    • 要素（ようそ）のCSS（色（いろ）や大（おお）きさなど）を変更（へんこう）します。
  • 属性ぞくせい (ぞくせい)
    • <a>タグのhrefや<img>タグのsrcなど、HTMLタグに追加（ついか）される情報（じょうほう）のことです。JavaScriptで変更（へんこう）できます。

ページの内容（ないよう）を変（か）えるのは、多（おお）くの場合（ばあい）、ユーザーが何かをしたときです。次（つぎ）に、そのユーザーの操作（そうさ）にどう対応たいおう（たいおう）するかを学（まな）びましょう。

VII. ユーザーの操作に対応たいおうする (ユーザーの そうさに たいおうする) - イベント

Webページをインタラクティブにするためには、ユーザーの動（うご）きに反応はんのうする必要（ひつよう）があります。JavaScriptでは、ユーザーがボタンをクリックしたり、マウスを動（うご）かしたりすることを「イベント」と呼（よ）びます。JavaScriptはこれらのイベントを「聞（き）いて」（監視（かんし）して）、イベントが起（お）きたときに決（き）められた処理（しょり）を実行（じっこう）することができます。

  • イベント (event)
    • ユーザーがボタンをクリックするなど、Webページ上（じょう）で起（お）こる出来事（できごと）のことです。
  • イベントハンドラ (event handler)
    • イベントが起（お）きたときに実行（じっこう）される関数かんすう関数かんすうや処理（しょり）のことです。
  • イベントリスナー (addEventListener)
    • HTML要素（ようそ）に対（たい）して、「このイベントが起（お）きたら、この処理（しょり）をしてください」と設定せっていするための機能（きのう）です。
  • this
    • イベントが起（お）きたとき、「今（いま）、操作（そうさ）されているHTML要素（ようそ）そのもの」を指（さ）す特別（とくべつ）な言葉（ことば）です。

ユーザーの操作（そうさ）に対応たいおう（たいおう）するとき、たくさんのデータを扱（あつか）うことがあります。次（つぎ）は、そのデータを便利（べんり）に管理（かんり）する方法（ほうほう）を見（み）ていきましょう。

VIII. データを便利に扱う (データを べんりに あつかう)

プログラムは、たくさんの関連（かんれん）するデータをまとめて扱（あつか）う必要（ひつよう）がよくあります。たとえば、たくさんの学生（がくせい）の名前（なまえ）や、ショッピングサイトの商品（しょうひん）リストなどです。JavaScriptには、このようなデータの集（あつ）まりを整理（せいり）して管理（かんり）するための強力（きょうりょく）な方法（ほうほう）として、「配列はいれつ（はいれつ）」と「オブジェクト」があります。

  • 配列はいれつ (はいれつ)
    • 複数（ふくすう）のデータを順番（じゅんばん）に並（なら）べた「リスト」のようなものです。
  • インデックス (index)
    • 配列はいれつ（はいれつ）の中（なか）のデータが、何番目（なんばんめ）にあるかを示（しめ）す番号（ばんごう）です。JavaScriptでは必（かなら）ず0から始（はじ）まります。最後（さいご）の要素（ようそ）のインデックスは「配列はいれつの長さ - 1」でわかります。
  • .length
    • 配列はいれつ（はいれつ）にいくつのデータが入（はい）っているか、その数（かず）を知（し）ることができます。
  • forEach
    • 配列はいれつ（はいれつ）の各要素（かくようそ）に、5章で学んだコールバック関数かんすうを使って同（おな）じ処理（しょり）をするためのメソッドです。
  • オブジェクト (object)
    • 名前（なまえ）と値（あたい）をセットにして、関連（かんれん）するデータをまとめたものです。RPGのキャラクターのように、「名前」や「HP」といった情報（じょうほう）と、「攻撃する」といった機能（きのう）を一緒（いっしょ）に管理（かんり）できます。
  • プロパティ (property)
    • オブジェクトが持（も）っているキャラクターの「名前（なまえ）」や「HP」のような「情報（じょうほう）」のことです。
  • メソッド (method)
    • オブジェクトが実行（じっこう）できる「攻撃（こうげき）する」や「回復（かいふく）する」のような「機能（きのう）やアクション」のことです。オブジェクトに属（ぞく）している5章で学んだ関数かんすうのことです。
  • オブジェクトの配列はいれつ (オブジェクトの はいれつ)
    • 複数のオブジェクトをひとつの配列はいれつ（はいれつ）にまとめたものです。「顧客（こきゃく）リスト」のように、同（おな）じ種類（しゅるい）のデータをたくさん扱（あつか）うときに非常（ひじょう）に便利（べんり）です。

JavaScriptは、これらのデータを使（つか）って、ブラウザが持（も）っている他（ほか）の便利（べんり）な機能（きのう）も操作（そうさ）できます。

VIII. ブラウザの機能を使う (ブラウザの きのうを つかう)

Webブラウザには、JavaScriptから使（つか）えるたくさんの便利（べんり）な道具（どうぐ）や機能（きのう）が最初（さいしょ）から入（はい）っています。これらの機能（きのう）を使（つか）うと、コードが正（ただ）しく動（うご）いているかを確認（かくにん）したり、ユーザーとやりとりしたり、時間（じかん）に関（かか）わる処理（しょり）をコントロールしたりすることができます。

  • コンソール (console.log)
    • ブラウザの開発かいはつ者（かいはつしゃ）ツールにある、コードの途中（とちゅう）経過（けいか）や変数へんすうの中身（なかみ）を表示ひょうじして、エラーを確認（かくにん）できる場所（ばしょ）です。
  • prompt()
    • ユーザーに文字（もじ）を入力にゅうりょくしてもらうための、小（ちい）さなウィンドウを表示ひょうじします。
  • parseInt()
    • 「“100”」のような文字列（もじれつ）のデータを、計算（けいさん）で使える整数（せいすう）のデータに変（か）えます。“55kg“のような文字列（もじれつ）は55になります。
  • parseFloat()
    • 文字列（もじれつ）のデータを、3.14のような小数点（しょうすうてん）を含（ふく）む数値すうちに変（か）えます。
  • NaN
    • “Not a Number” の略りゃく（りゃく）で、数値すうちへの変換へんかん（へんかん）に失敗（しっぱい）したときなどに表示ひょうじされる「数値すうちではない」ことを示（しめ）す特別（とくべつ）な値（あたい）です。
  • isNaN()
    • ある値（あたい）がNaNかどうかをチェックするための関数かんすう関数かんすうです。
  • setTimeout()
    • 指定（してい）した時間（じかん）が過（す）ぎた後（あと）に、処理（しょり）を一度（いちど）だけ実行（じっこう）します。
  • setInterval()
    • 指定（してい）した時間（じかん）ごとに、処理（しょり）を繰（く）り返（かえ）し実行（じっこう）します。
  • スコープ (scope)
    • 変数へんすうが、プログラムのどの範囲（はんい）から使（つか）えるかを決（き）めるルールです。主（おも）に3種類（しゅるい）あります。
      • グローバルスコープ: プログラムのどこからでも使える変数へんすうですが、バグの原因（げんいん）になりやすいので注意（ちゅうい）が必要（ひつよう）です。
      • 関数かんすうスコープ: 関数かんすう関数かんすうの中（なか）だけで使える変数へんすうで、昔（むかし）のvarがこれにあたります。
      • ブロックスコープ: {}で囲（かこ）まれた範囲（はんい）だけで使える変数へんすうです。letやconstがこれにあたり、安全（あんぜん）で管理（かんり）しやすいため、現在（げんざい）はこちらを使（つか）うのが一般的（いっぱんてき）です。
