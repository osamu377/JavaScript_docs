留学生のためのJavaScript学習ガイド

やさしい日本語にほんごで学まなぶJavaScript用語集ようごしゅう

はじめに

こんにちは！このドキュメントは、JavaScriptを勉強べんきょうしているけれど、まだ日本語にほんごに慣なれていない皆みなさんのための用語集ようごしゅうです。プログラミングの言葉ことばはむずかしいものも多おおいですが、ここでは、やさしい日本語にほんごと簡単かんたんな例れいを使つかって、一ひとつずつていねいに説明せつめいします。あなたの学習がくしゅうの助たすけになればうれしいです。

I. ウェブページの基本きほん

ウェブページを作つくるためには、3つの大切たいせつな技術ぎじゅつがあります。それはHTML、CSS、JavaScriptです。これを「家いえ」に例たとえてみましょう。HTMLは家いえの「柱はしらや壁かべ」、CSSは家いえの「ペンキやインテリア」のような飾かざりつけ、そしてJavaScriptは電気でんきをつけたり機械きかいを動うごかしたりする「機能きのう」のようなものです。この3つが協力きょうりょくして、私わたしたちがいつも見みているウェブページができています。

  • HTML
    • ウェブページの骨組ほねぐみや構造こうぞうを作つくるための言葉ことばです。
  • CSS
    • ウェブページの見みた目めをきれいにするための言葉ことばです。
  • JavaScript
    • ウェブページに動うごきをつけたり、機能きのうを追加ついかするための言葉ことばです。

それでは、JavaScriptを書かくときの、基本的きほんてきなルールについて見みていきましょう。

II. JavaScriptの基本きほんルール

日本語にほんごに文法ぶんぽうがあるように、JavaScriptにもコードを正ただしく書かくためのルールがあります。このルールを守まもることで、コンピューターがあなたの命令めいれいをきちんと理解りかいできるようになり、エラーを防ふせぐことができます。

  • 変数へんすう
    • 数字すうじや文字もじなどのデータを入いれておくための、名前なまえがついた「箱はこ」のようなものです。
  • let
    • 中身なかみを後あとから変かえることができる変数へんすうを作つくるときに使つかいます。
  • const
    • 一度いちどデータを入いれたら、後あとから変かえることができない変数へんすう（「定数ていすう」といいます）を作つくるときに使つかいます。
  • 命名規則めいめいきそく
    • 変数へんすうや関数かんすうの名前なまえのルールです。意味いみのわかる英語えいごで、2つ目めの単語たんごから最初さいしょの文字もじを大文字おおもじにする「キャメルケース」（例: myScore）で書かくのが一般的いっぱんてきです。
  • 大文字おおもじと小文字こもじの区別くべつ
    • JavaScriptでは、大文字おおもじと小文字こもじは別べつのものとして扱あつかわれます。たとえば、Nameとnameは、違ちがう変数へんすうになります。
  • 半角文字はんかくもじの使用しよう
    • 文字列もじれつやコメントの中なか以外のコードは、すべて半角はんかくの英数字えいすうじや記号きごうで書かく必要ひつようがあります。全角ぜんかくスペースなどを使つかうとエラーになります。
  • データ型がた
    • 変数へんすうが扱あつかうデータの種類しゅるいのことです。主おもに次つぎのようなものがあります。
  • 文字列もじれつ
    • 「こんにちは」のような、テキストのデータのことです。“か’で囲かこみます。
  • 数値すうち
    • 100や3.14のような、数字すうじのデータのことです。
  • 論理型ろんりがた
    • true（はい）かfalse（いいえ）のどちらかを表あらわすデータのことです。
  • セミコロン (;)
    • 文ぶんの終おわりにつける記号きごうです。命令めいれいの区切くぎりをわかりやすくします。
  • コメント (//)
    • コードの中なかに書かくことができるメモです。//の後あとに書かいた文字もじは、プログラムとしては無視むしされます。

ルールがわかったら、次つぎはJavaScriptがどうやって計算けいさんや比較ひかくをするのかを見みてみましょう。

III. 計算けいさんと比較ひかく

プログラムの中なかでは、足たし算ざんをしたり、2つの値あたいを比くらべたりすることがよくあります。そのために使つかうのが「演算子えんざんし」という特別とくべつな記号きごうです。演算子えんざんしを使つかうことで、プログラムにいろいろな判断はんだんをさせることができます。

  • 演算子えんざんし
    • 計算けいさんや比較ひかくなど、データに対たいして何なにかをするための記号きごうのことです。
    • 例れい: +, =, >
  • 算術演算子さんじゅつえんざんし
    • 足たし算ざんや引ひき算ざんなど、数学すうがくの計算けいさんをするときに使つかいます。++（1増ふやす）や–（1減へらす）もよく使つかわれます。
    • 例れい: 5 + 3 や count++
  • 代入演算子だいにゅうえんざんし
    • 変数へんすうにデータを入いれる（代入だいにゅうする）ときに使つかいます。
    • 例れい: let score = 100;
  • 比較演算子ひかくえんざんし
    • 2つの値あたいを比くらべて、trueかfalseかを判断はんだんするときに使つかいます。
    • 例れい: score > 80 （scoreは80より大おおきいですか？）
  • 論理演算子ろんりえんざんし
    • 「AかつB」や「AまたはB」のように、複数ふくすうの条件じょうけんを組くみ合あわせるときに使つかいます。
    • 例: age >= 20 && hasTicket （20才さい以上いじょうで、チケットも持もっていますか？）

これらの演算子えんざんしは、プログラムの流ながれをコントロールするためによく使つかわれます。

IV. プログラムの流ながれをコントロールする

プログラムは、いつも上うえから下したへ順番じゅんばんに進すすむだけではありません。まるで私わたしたちが毎日まいにち、「もし雨あめが降ふったら、傘かさを持もっていこう」と考かんがえるように、条件じょうけんによってやることが変かわったり、同おなじことを繰くり返かえしたりします。これを「制御せいぎょフロー」と呼よびます。

  • if文ぶん
    • 「もし〜だったら、この処理しょりをする」というように、条件じょうけんがtrueのときだけコードを実行じっこうします。
  • else
    • if文ぶんの条件じょうけんがfalseだった場合ばあいに、「そうでなければ、こちらを実行じっこうする」という処理しょりを書かくときに使つかいます。
  • switch文ぶん
    • if…else if…がたくさん続つづく代かわりに使つかえる文ぶんです。ひとつの変数へんすうの値あたいによって、たくさんの選択肢せんたくしから処理しょりを選えらびたいときに便利べんりです。
  • for文ぶん
    • 「10回かい繰くり返かえす」のように、決きまった回数かいすうだけ同おなじ処理しょりをしたいときに使つかいます。for (初期しょき設定せってい; 継続けいぞく条件じょうけん; 増減ぞうげん処理しょり)という形かたちで書かきます。
  • while文ぶん
    • 「条件じょうけんがtrueの間あいだはずっと繰くり返かえす」というように、回数かいすうが決きまっていないときに使つかいます。
  • break
    • for文ぶんやwhile文ぶんの繰くり返かえしを、途中とちゅうでやめたいときに使つかいます。
  • continue
    • 繰くり返かえしの中なかで、今回こんかいの処理しょりだけをスキップして、次つぎの回かいに進すすみたいときに使つかいます。

こうしていくつかの処理しょりを作つくっていくと、同おなじようなコードをまとめたくなります。そんな時ときに便利べんりなのが次つぎの機能きのうです。

V. 処理しょりをまとめる

プログラムを書かいていると、同おなじことを何回なんかいもすることがあります。そんなとき、処理しょりをひとつのグループにまとめて、いつでも呼よび出だせるようにすると便利べんりです。これを「関数かんすう」と呼よびます。関数かんすうは、自動じどう販売機はんばいきのようなものです。お金かねを入いれてボタンを押おす（関数かんすうを呼よび出だす）と、いつでも決きまった飲のみ物ものが出でてくる（処理しょりが実行じっこうされる）ように、コードを整理せいりして再利用さいりようしやすくします。

  • 関数かんすう
    • 特定とくていの処理しょりをひとつのグループにまとめたものです。名前なまえを呼よぶだけで、いつでもその処理しょりを実行じっこうできます。
  • 引数ひきすう
    • 関数かんすうに処理しょりをしてもらうために、外そとから渡わたすデータのことです。自動じどう販売機はんばいきで言いうと、お金かねや、どの飲のみ物ものかを選えらぶボタンのようなものです。
  • 戻もどり値ち / return
    • 関数かんすうが処理しょりを終おわった後あと、その結果けっかを呼よび出だした場所ばしょに返かえすことです。自動じどう販売機はんばいきから出でてくるジュースのようなものです。
  • コールバック関数かんすう
    • 他ほかの関数かんすうに引数ひきすうとして渡わたされる、「後あとでこの処理しょりを実行じっこうしてください」とお願いおねがするための関数かんすうです。誰だれかにお願いおねがいする仕事しごとの「指示しじメモ」のようなものです。

これまでプログラムのロジックについて学まなんできましたが、次つぎはJavaScriptが実際じっさいにウェブページをどうやって動うごかすのかを見みていきましょう。

VI ウェブページを操作そうさする - DOM

JavaScriptは、ウェブページの見みた目めや内容ないようを自由じゆうに変かえることができます。そのために使つかうのが「DOM（ドム）」です。DOMは、HTMLページを木きのような構造こうぞうで表あらわした「地図ちず」のようなものです。JavaScriptはこの地図ちずを見みて、特定とくていのHTML要素ようそを探さがしたり、文字もじを変かえたり、新あたらしい要素ようそを追加ついかしたりします。

  • DOM (Document Object Model)
    • HTML文書ぶんしょの構造こうぞうを、JavaScriptが操作そうさできるようにしたものです。
  • window
    • ブラウザのウィンドウやタブそのものを表あらわす、すべてのオブジェクトの親おやとなる一番いちばん上うえにあるオブジェクトです。
  • document
    • 表示ひょうじされているHTMLページ全体ぜんたいを表あらわすオブジェクトで、windowオブジェクトの一部いちぶです。DOM操作そうさはここから始はじまります。
  • セレクタせれくた (selector)
    • 操作そうさしたいHTML要素ようそを見みつけるための「目印めじるし」のことです。CSSを書かくときと同おなじように、IDは’#id-name’、クラスは’.class-name’のように書かきます。
  • getElementById()
    • IDを使つかって、特定とくていのHTML要素ようそをひとつだけ探さがします。
  • querySelector()
    • CSSセレクタを使つかって、条件じょうけんに合あう最初さいしょのHTML要素ようそをひとつ探さがします。
  • querySelectorAll()
    • CSSセレクタを使つかって、条件じょうけんに合あうHTML要素ようそをすべて探さがして、リストとして受うけ取とります。
  • .textContent
    • 要素ようその中なかにあるテキスト（文字もじだけ）を取得しゅとくしたり、書かき換かえたりします。安全あんぜんな方法ほうほうです。
  • .innerHTML
    • 要素ようその中なかにあるHTMLタグも含ふくめた内容ないよう全体ぜんたいを取得しゅとくしたり、書かき換かえたりします。ユーザーからの入力にゅうりょくをそのまま使つかうと危険きけんな場合ばあいがあります。
  • .style
    • 要素ようそのCSS（色いろや大おおきさなど）を変更へんこうします。
  • 属性ぞくせい
    • &lt;a&gt;タグのhrefや&lt;img&gt;タグのsrcなど、HTMLタグに追加ついかされる情報じょうほうのことです。JavaScriptで変更へんこうできます。

ページの内容ないようを変かえるのは、多おおくの場合ばあい、ユーザーが何なにかをしたときです。次つぎに、そのユーザーの操作そうさにどう対応たいおうするかを学まなびましょう。

VII. ユーザーの操作そうさに対応たいおうする - イベント

ウェブページをインタラクティブにするためには、ユーザーの動うごきに反応はんのうする必要ひつようがあります。JavaScriptでは、ユーザーがボタンをクリックしたり、マウスを動うごかしたりすることを「イベント」と呼よびます。JavaScriptはこれらのイベントを「聞きいて」（監視かんしして）、イベントが起おきたときに決きめられた処理しょりを実行じっこうすることができます。

  • イベント (event)
    • ユーザーがボタンをクリックするなど、ウェブページ上じょうで起おこる出来事できごとのことです。
  • イベントハンドラ (event handler)
    • イベントが起おきたときに実行じっこうされる関数かんすうや処理しょりのことです。
  • イベントリスナー (addEventListener)
    • HTML要素ようそに対たいして、「このイベントが起おきたら、この処理しょりをしてください」と設定せっていするための機能きのうです。
  • this
    • イベントが起おきたとき、「今いま、操作そうさされているHTML要素ようそそのもの」を指さす特別とくべつな言葉ことばです。

ユーザーの操作そうさに対応たいおうするとき、たくさんのデータを扱あつかうことがあります。次つぎは、そのデータを便利べんりに管理かんりする方法ほうほうを見みていきましょう。

VIII. データを便利べんりに扱あつかう

プログラムは、たくさんの関連かんれんするデータをまとめて扱あつかう必要ひつようがよくあります。たとえば、たくさんの学生がくせいの名前なまえや、ショッピングサイトの商品しょうひんリストなどです。JavaScriptには、このようなデータの集あつまりを整理せいりして管理かんりするための強力きょうりょくな方法ほうほうとして、「配列はいれつ」と「オブジェクト」があります。

  • 配列はいれつ
    • 複数ふくすうのデータを順番じゅんばんに並ならべた「リスト」のようなものです。
  • インデックス (index)
    • 配列はいれつの中なかのデータが、何番目なんばんめにあるかを示しめす番号ばんごうです。JavaScriptでは必かならず0から始はじまります。最後さいごの要素ようそのインデックスは「配列はいれつの長ながさ - 1」でわかります。
  • .length
    • 配列はいれつにいくつのデータが入はいっているか、その数かずを知しることができます。
  • forEach
    • 配列はいれつの各要素かくようそに、5章しょうで学まなんだコールバック関数かんすうを使つかって同おなじ処理しょりをするためのメソッドです。
  • オブジェクト (object)
    • 名前なまえと値あたいをセットにして、関連かんれんするデータをまとめたものです。RPGのキャラクターのように、「名前なまえ」や「HP」といった情報じょうほうと、「攻撃こうげきする」といった機能きのうを一緒いっしょに管理かんりできます。
  • プロパティぷろぱてぃ (property)
    • オブジェクトが持もっているキャラクターの「名前なまえ」や「HP」のような「情報じょうほう」のことです。
  • メソッド (method)
    • オブジェクトが実行じっこうできる「攻撃こうげきする」や「回復かいふくする」のような「機能きのうやアクション」のことです。オブジェクトに属ぞくしている5章しょうで学まなんだ関数かんすうのことです。
  • オブジェクトの配列はいれつ (オブジェクトの はいれつ)
    • 複数ふくすうのオブジェクトをひとつの配列はいれつにまとめたものです。「顧客こきゃくリスト」のように、同おなじ種類しゅるいのデータをたくさん扱あつかうときに非常ひじょうに便利べんりです。

JavaScriptは、これらのデータを使つかって、ブラウザが持もっている他ほかの便利べんりな機能きのうも操作そうさできます。

VIII. ブラウザの機能きのうを使つかう

Webブラウザには、JavaScriptから使つかえるたくさんの便利べんりな道具どうぐや機能きのうが最初さいしょから入はいっています。これらの機能きのうを使つかうと、コードが正ただしく動うごいているかを確認かくにんしたり、ユーザーとやりとりしたり、時間じかんに関かかわる処理しょりをコントロールしたりすることができます。

  • コンソール (console.log)
    • ブラウザの開発者かいはつしゃツールにある、コードの途中とちゅう経過けいかや変数へんすうの中身なかみを表示ひょうじして、エラーを確認かくにんできる場所ばしょです。
  • prompt()
    • ユーザーに文字もじを入力にゅうりょくしてもらうための、小ちいさなウィンドウを表示ひょうじします。
  • parseInt()
    • 「“100”」のような文字列もじれつのデータを、計算けいさんで使つかえる整数せいすうのデータに変かえます。“55kg“のような文字列もじれつは55になります。
  • parseFloat()
    • 文字列もじれつのデータを、3.14のような小数点しょうすうてんを含ふくむ数値すうちに変かえます。
  • NaN
    • “Not a Number” の略りゃくで、数値すうちへの変換へんかんに失敗しっぱいしたときなどに表示ひょうじされる「数値すうちではない」ことを示しめす特別とくべつな値あたいです。
  • isNaN()
    • ある値あたいがNaNかどうかをチェックするための関数かんすうです。
  • setTimeout()
    • 指定していした時間じかんが過すぎた後あとに、処理しょりを一度いちどだけ実行じっこうします。
  • setInterval()
    • 指定していした時間じかんごとに、処理しょりを繰くり返かえし実行じっこうします。
  • スコープすこーぷ (scope)
    • 変数へんすうが、プログラムのどの範囲はんいから使つかえるかを決きめるルールです。主おもに3種類しゅるいあります。
      • グローバルスコープ: プログラムのどこからでも使つかえる変数へんすうですが、バグの原因げんいんになりやすいので注意ちゅういが必要ひつようです。
      • 関数かんすうスコープ: 関数かんすうの中なかだけで使つかえる変数へんすうで、昔むかしのvarがこれにあたります。
      • ブロックスコープ: {}で囲かこまれた範囲はんいだけで使つかえる変数へんすうです。letやconstがこれにあたり、安全あんぜんで管理かんりしやすいため、現在げんざいはこちらを使つかうのが一般的いっぱんてきです。

この用語集ようごしゅうが、あなたのJavaScript学習がくしゅうの旅たびで、信頼しんらいできる地図ちずになることを願ねがっています。わからない言葉ことばがあったら、いつでもここに戻もどってきて、自分じぶんのペースで確認かくにんしてくださいね。楽たのしく学まなんでいきましょう！
