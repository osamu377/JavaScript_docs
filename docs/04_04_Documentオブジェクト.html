留学生のためのJavaScript学習ガイド

Documentオブジェクト

前回ぜんかい、window オブジェクト はブラウザ全体ぜんたいの「社長しゃちょうさん」だと説明せつめいしましたね。 今回こんかいの document オブジェクト は、window オブジェクトの下したにあるプロパティで、その社長しゃちょうさんの下したで働はたらく 「現場監督げんばかんとく（げんばかんとく）」 です。

Important

オブジェクトは別べつのオブジェクトのプロパティになることがあります。

学生がくせいの方かたは、「ウェブページという建物たてものを管理かんりし、中身なかみを書かき換かえたり、新あたらしくパーツを作つくったりする責任者せきにんしゃ」 と考かんがえると、イメージが湧わきやすくなるかもしれません。

documentオブジェクトとは、ブラウザに表示ひょうじされているHTML（ウェブページの中身なかみ） そのものを指さします。
JavaScriptを使つかって、文字もじの色いろを変かえたり、ボタンが押おされたときに動うごきをつけたりするのは、すべてこの「現場監督げんばかんとく（document）」に命令めいれいを出だしているからです。

これを専門用語せんもんようごで DOM（ドム / Document Object Model） と呼よびます。HTMLを「木きの枝えだ」のような構造こうぞうとして管理かんりしているのが特徴とくちょうです。

DOMツリーについては、次つぎのセクションで、くわしく説明せつめいします。ここでは、Windowとdocumentの違ちがいをしっかり頭あたまに入いれてください。

1. documentオブジェクトとは？

ブラウザに表示ひょうじされているHTML（ウェブページの中身なかみ） そのものを指さします。
JavaScriptを使つかって、文字もじの色いろを変かえたり、ボタンが押おされたときに動うごきをつけたりするのは、すべてこの「現場監督げんばかんとく（document）」に命令めいれいを出だしているからです。

これを専門用語せんもんようごで DOM（ドム / Document Object Model） と呼よびます。HTMLを「木きの枝えだ」のような構造こうぞうとして管理かんりしているのが特徴とくちょうです。

2. よく使つかうプロパティ（ページの情報じょうほう）

現場監督げんばかんとくが知しっている、今いまのページの情報じょうほうです。

  • document.title
    ブラウザのタブに表示ひょうじされている「ページのタイトル」です。JavaScriptで書かき換かえることもできます。
  • document.body
    HTMLの <body> タグの中身全体なかみぜんたいです。ページ全体ぜんたいの背景色はいけいしょくを変かえたいときなどに使つかいます。
  • document.URL 現在開げんざいひらいているページの住所じゅうしょ（URL）を教おしえてくれます。

3. よく使つかうメソッド（現場監督げんばかんとくへの命令めいれい）

これが一番大切いちばんたいせつです！ 特定とくていの場所ばしょを探さがしたり、中身なかみを変かえたりする命令めいれいです。

場所ばしょを探さがす（セレクタ）

  • getElementById("ID名") 特定とくていのIDがついたパーツを1つだけ探さがします。一番速いちばんはやくて正確せいかくです。
  • querySelector("セレクタ")
    CSSと同おなじ書かき方かた（.class や #id）でパーツを探さがせます。とても便利べんりです！

これらは、以前いぜんにも出でてきましたね。実じつはdocumentオブジェクトのメソッドだったのです！

Note

document.getElementById("ID名")のように書かいてもかまいませんが、普通ふつうはdocument.を省略しょうりゃくして、getElementById("ID名")と書かきます。

中身なかみを書かき換かえる・作つくる

  • createElement("タグ名") 新あたらしいパーツ（<div> や <li> など）をメモリの中なかに作つくります。
  • write("文字")
    ページに直接文字ちょくせつもじを書かき込こみます（※あまり使つかいませんが、基本きほんとして覚おぼえておきましょう）。

4. 実際じっさいに動うごかしてみよう！

Visual Studio Code を使つかって、以下いかのようなhtmlを作成さくせいしましょう。名前なまえはdoc_obj.htmlとしましょうか。

<!DOCTYPE html>
<html lang="ja">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Document</title>
    </head>
    <body>
        <h1 id="greeting">こんにちは！</h1>
        
        <p>コンソールを開いて、下のJavaScriptを入力してみましょう。</p>
        
        <pre>
            // 1. IDが "greeting" というパーツを探す
            const message = document.getElementById("greeting");
            // 2. その中身を書き換える
            message.textContent = "こんにちは、日本へようこそ！";
            // 3. スタイル（色）も変えちゃう
            message.style.color = "red";
        </pre>
        
        <a href="javascript:history.back();">戻る</a>
    </body>
</html>

保存ほぞんできたら、Visual Studio Code 上じょうから、Open with Live Severを使つかって、開ひらきましょう。

ブラウザに表示ひょうじされた指示しじに従したがって、コンソールにJavaScriptを入力にゅうりょくしましょう。

コンソールを開ひらくには、F12 キー（ノートPCは Fn + F12） または Ctrl + Shift + I を使つかいます。

オブジェクトと const の意外いがいな関係かんけい

上うえのコードを見みて、疑問ぎもんに思おもいませんでしたか？「const で宣言せんげんされた変数へんすうは、後あとから値あたいを変更へんこうできないはずでは？」そう思おもった人ひとは、変数へんすうの説明せつめいをとてもよく覚おぼえている人ひとです。

しかし、上うえのコードはエラーになりません。それについて、説明せつめいしましょう。

JavaScriptの初心者しょしんしゃが混乱こんらんしやすい点てんのひとつが、オブジェクトと const の意外いがいな関係かんけいです。

「 const で宣言せんげんした変数へんすうは中身なかみを変かえられない」と説明せつめいしましたが、オブジェクトの場合ばあいは少すこし違ちがいます。

  • 名札なふだの固定こてい（参照さんしょうの不変性ふへんせい）：const で作つくったオブジェクトそのものを別べつのオブジェクトに入いれ替かることはできません（別べつの箱はこに名札なふだを付つけ替かえるのは禁止きんし）。
  • 中身なかみの変更へんこうはOK：箱はこの中なかに入はいっている個別こべつのデータ（プロパティ）を書かき換かえることは可能かのうです。

「強力きょうりょくなガムテープで名札なふだが貼はられた箱はこ」をイメージしてください。ガムテープで固定こていされているので、名札なふだを別べつの新あたらしい箱はこに貼はり直なおすことはできません。でも、箱はこのふたをひとつ開あけて、中なかに入はいっているお菓子かしを入いれ替かえたり、ジャムを塗ぬったりすることは自由じゆうなのです。

例たとえるなら、「ファイルの保存場所ほぞんばしょ（パス）」は固定こていされているけれど、「ファイルの中身なかみ」は自由じゆうに書かき換かえられるようなイメージです。

先さきほどの例れいでは、constを使つかって宣言せんげんしたmessageという箱はこを開あけて、中身なかみを“こんにちは、日本にほんへようこそ！“に入いれ替かえました。これはエラーにはなりません。

しかし、

// 1. IDが "greeting" というパーツを探す
const message = document.getElementById("greeting");
// 2. タグがpのパーツを探す
message = document.querySelector("p")

はエラーになります。message というラベルを「“greeting“というIDの箱はこ」からはがして、「“p“というタグの別べつの箱はこ」に貼はろうとしているからです。

const は message というラベルと、それを入いれる入いれ物ものとの関係かんけいを固定こていして、ラベルの張替はりかえを許ゆるしません。

しかし、あくまで ラベルと入いれ物ものとの関係かんけい であって、 入いれ物ものが同おなじであれば、その中身なかみが変かわっても、かまわない のです。

5. 学生がくせいへのアドバイス：window と document の使つかい分わけ

「どっちを使つかえばいいの？」と聞きかれたら、こう答こたえてあげてください。

「ブラウザの機能きのう（タイマー、アラート、URL移動いどう）を使つかいたいときは window」

「ページの中身なかみ（文字もじ、画像がぞう、ボタン）をいじりたいときは document」

まとめテーブル

命令めいれい・情報じょうほうの名前なまえ役割やくわり例たとえ話ばなし
titleページのタイトル本ほんの表紙ひょうしの名前なまえ
getElementById()特定とくていのパーツを指名しめいする「出席番号しゅっせきばんごう○番ばんの人ひと！」と呼よぶ
querySelector()自由じゆうにパーツを探さがす「赤あかい服ふくを着きている人ひと！」と探さがす
textContent文字もじを書かき換かえる看板かんばんの文字もじを書かき直なおす
createElement()新あたらしい要素ようそを作つくる新あたらしいレンガを用意よういする

いかがでしょうか？「現場監督げんばかんとくの document くん」がいれば、ウェブページを思おもった通とおりに操あやつれるようになります。
