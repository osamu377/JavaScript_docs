留学生のためのJavaScript学習ガイド

自分じぶんのオブジェクトを作つくる

以前いぜん、「オブジェクトの中なかを見みてみてみよう」のセクションで見みたように、JavaScriptでは、波括弧なみかっこ { } を使つかって、自分じぶんだけのオブジェクトを作つくる ことができます。

また、「配列はいれつ」セクションの「連想配列れんそうはいれつ」で見みた通とおり、ドット.やブラケット[]を使つかって、中なかのデータを取とり出だすことができます。

Note

思おもい出だしてください。「連想配列れんそうはいれつ」はオブジェクトの一種いっしゅでしたね。

このセクションでは、これまでに説明せつめいしたオブジェクトの特徴とくちょうを振ふり返かえりながら、自分じぶんのオブジェクトを作つくる方法ほうほうをまとめます。

I. 「ユーザー定義ていぎオブジェクト」とは？

前まえの章しょうまでは、ブラウザのオブジェクトやJavaScriptの組くみ込こみオブジェクトなど、あらかじめ作つくられていたり、あるいはnew演算子えんざんしですぐに作つくることのできるものを扱あつかってきました。

しかし、JavaScriptのオブジェクトは、それだけではありません。

JavaScriptの「ユーザー定義ていぎオブジェクト」は、あらかじめ用意よういされている道具どうぐ（ブラウザやシステムが作つくったもの）ではなく、「自分じぶんたちで自由じゆうに作つくる新あたらしいキャラクターや道具どうぐ」 のことです。

たとえば、「学生がくせい（Student）」 をプログラムの中なかで表現ひょうげんしたいとき、名前なまえ、年齢ねんれい、国籍こくせきなどをひとつにまとめて「ユーザー定義ていぎオブジェクト」を作つくることができました。

JavaScriptでは { } を使つかって、このように書かきます。

const student = {
  name: "マリア",  // 名前
  age: 20,         // 年齢
  country: "ブラジル" // 出身
};

また「オブジェクト」は名前なまえや年齢ねんれいといったデータだけでなく、そのオブジェクトの行動こうどうも、書かき加くわえるができます。

この考かんがえ方かたは、ゲームのキャラクターに例たとえると非常ひじょうに分わかりやすくなります。

  • オブジェクト： キャラクター自身じしん（例れい：勇者ゆうしゃアレン）
  • プロパティ： ステータス（例れい：hp や name）
  • メソッド： 行動こうどう（例れい：attack() や heal()）

コードでの例れい:

const hero = {
  name: "Allen"      // 特徴（プロパティ）
  hp: 100,           // 特徴（プロパティ）
  level: 5,          // 特徴（プロパティ）
  
  attack: function() { 
    alert("エイッ！と攻撃しました"); // 動（うご）き（メソッド）
  }
};

II. オブジェクトの「中身なかみ」は2種類しゅるい

オブジェクトの中なかには、この2つが入はいっています。

  1. プロパティ（Property）： そのモノの「特徴とくちょう（データ）」
  • 例れい：名前なまえは「アリ」さん、国籍こくせきは「エジプト」。
  1. メソッド（Method）： そのモノができる「動うごき（仕事しごと）」
  • 例れい：「自己紹介じこしょうかいする」、「テストを受うける」。

III. 書かき方かたのイメージ

こんなコードのイメージを考かんがえてみてください。

// 「学生」という名前のオブジェクトを自分で定義（ていぎ）（ていぎ）する
const student = {
  // プロパティ（特徴：とくちょう）
  name: "Ali",
  country: "Egypt",
  age: 20,

  // メソッド（動き：うごき）
  sayHello: function() {
    console.log("こんにちは！　わたしは " + this.name + " です。");
  }
};

// 使い方
console.log(student.name); // "Ali" が出てくる
student.sayHello();        // "こんにちは！ わたしは Ali です。" としゃべる！

IV. プロパティとメソッドの利用りよう：情報じょうほうの取とり出だしと実行じっこう

作つくったオブジェクトの中身なかみを使つかうには、2つの書かき方かたがあります。

  1. ドット記法きほう： person.name のように、ドット . でつなぎます。プロパティ名めいが分わかっているときに使つかいます。
  2. ブラケット記法きほう： person[“name”] のように、角括弧かくかっこ [ ] を使つかいます。

こうした記法きほうは、これまで学まなんできたものと同おなじです。

「So What?（だから何なに？）」：なぜ2つあるのか

ドット記法きほうは速はやく書かけて便利べんりですが、ブラケット記法きほうは「変数へんすう」を使つかって中身なかみを選えらべるのが強つよみです。

const key = "name";
console.log(person[key]); // "Allen" と表示されます。keyの中身を変えれば、取れるデータも変わります。

また、メソッドを呼よび出だすときに person.greet() と丸括弧まるかっこ () を書かくのは、「そのアクションを今いますぐ動うごかしてください」という合図あいずです。

V. なぜ「自分じぶんだけのオブジェクト」を作つくるのか

なぜオブジェクトが必要ひつようなのか、もう一度いちど、考かんがえてみましょう。

プログラミングを始はじめたばかりのころは、変数へんすうを使つかってデータを保存ほぞんします。しかし、プログラムが複雑ふくざつになると、変数へんすうが多おおすぎて管理かんりが難むずかしくなります。

もし、バラバラの変数へんすうがたくさんあると、どこで何なにを使つかっているか分わからなくなり、ミスが増ふえます。仕事しごとでプログラムを書かく「チーム開発かいはつ」では、これは大おおきな問題もんだいです。他ほかの人ひとがあなたのコードを読よんだとき、すぐに理解りかいできないと、プロジェクトが止とまってしまうからです。

そこで必要ひつようになるのが 「オブジェクト」 です。関連かんれんするデータと機能きのうをひとつの「箱はこ」にまとめることで、コードが整理せいりされ、現実げんじつの世界せかいにあるものをプログラムの中なかで表現ひょうげんしやすくなります。

まとめテーブル

言葉ことば意味いみ覚おぼえ方かたのヒント
ユーザー定義ていぎ自分じぶんで作つくること「私専用わたしせんよう」
プロパティ特徴とくちょう、データ「〜は〜だ」
メソッド仕事しごと、動うごき「〜をする」
インスタンス設計図せっけいずから作つくった実物じつぶつ「アリさん本人ほんにん」

いかがでしょうか？「自分じぶんたちで新あたらしいモノの形かたちを決きめられる」というのが、オブジェクト指向しこうプログラミングの第一歩だいいっぽです。

開発かいはつのアドバイス

  • 名前なまえは英語えいごで： JavaScriptのルールとして、プロパティ名めいは “name” のように意味いみのわかる英語えいごで書かくのが一般的いっぱんてきです。
  • なぜ const なのか？： オブジェクトを作つくるとき、ふつうは const を使つかいます。これは「箱はこそのもの」を変かえないためです。箱はこの中身なかみ（年齢ねんれいなど）が変かわっても、箱自体はこじたい（personという変数へんすう）が別物べつものにならなければ、const で問題もんだいありません。
  • 書かき方かたのコツ： 複数ふくすうのプロパティを書かくときは、カンマ , を忘わすれないでください。忘わすれるとエラーになります。
