Locationオブジェクト

Locationオブジェクト は、今いまブラウザで見みているウェブサイトの「住所じゅうしょ（URL）」を管理かんりするオブジェクトです。

学生がくせいの方かたには、Locationオブジェクトは 「ブラウザの住所録じゅうしょろく（じゅうしょろく）」 や 「カーナビ」 だと教おしえてあげてください。今いまの場所ばしょを知しることもできるし、新あたらしい場所ばしょへ移動いどうすることもできます。

1. Locationオブジェクトとは？

window.location を通とおじてアクセスします。URLを「プロトコル」「ドメイン」「パス」などのパーツに分わけて持もっているので、JavaScriptで簡単かんたんにURLの情報じょうほうを調しらべたり、変更へんこうしたりできます。

2. よく使つかうプロパティ（住所じゅうしょの情報じょうほう）

現在げんざいのURLの「どの部分ぶぶんを知しりたいか」によって使つかい分わけます。 例れい：https://example.com:8080/search?q=js#result というURLの場合ばあい

  • href
    URLの全部ぜんぶです。 console.log(location.href);のように使います。
  • protocol
    「http:」や「https:」の部分ぶぶんです。
  • host
    ドメイン名めいとポート番号ばんごうです。（example.com:8080）
  • pathname
    ドメインの後あとの「フォルダやファイル」の場所ばしょです。（/search）
  • search
    ? から始はじまる「クエリパラメータ」です。検索けんさくキーワードなどが入はいります。（?q=js）
  • hash
    # から始はじまる「アンカー（ページ内ないの場所ばしょ）」です。（#result）

3. よく使つかうメソッド（場所ばしょを移動いどうする）

新あたらしいページへ行いきたいときや、今いまのページをやり直なおしたいときに使つかいます。

assign("URL")

指定していしたURLに移動いどうします。

  • 特徴とくちょう： ブラウザの「戻もどる」ボタンで、前まえのページに戻もどれます。

  • location.assign("https://google.com");

replace("URL")

新あたらしいURLに移動いどうしますが、今いまのページの履歴りれき（ひれき）を消けします。

  • 特徴とくちょう： 「戻もどる」ボタンを押おしても、今いまのページには戻もどれません。ログイン後ごの画面がめんなどでよく使つかいます。

reload()

今いまのページを「再読さいよみ込こみ」します。ブラウザの更新こうしんボタンを押おすのと同おなじです。

4. 実際じっさいに動うごかしてみよう！

学生がくせいがよく使つかう「ボタンを押おして別べつのページへ行いく」コードです。

// 3秒後に自動（じどう）でGoogleへ移動する
setTimeout(function() {
  location.href = "https://google.com";
  // 実は location.assign() と同じ意味になります
}, 3000);
// 「更新（こうしん）ボタン」を作るなら
function refreshPage() {
  location.reload();
}

5. 学生がくせいへのアドバイス：href の書かき換かえが一番人気いちばんにんき

URLを操作そうさする方法ほうほうはたくさんありますが、現場げんばで一番いちばんよく使つかわれるのは location.href への代入だいにゅうです。

「一番簡単いちばんかんたんな移動いどうのやり方かたは、location.href に新あたらしい住所じゅうしょを代入だいにゅうすることだよ。一番覚いちばんおぼえやすくて便利べんりだよ！」

まとめテーブル

プロパティ・メソッド役割やくわり例たとえ話ばなし
hrefURLのすべて正式せいしきな住所じゅうしょ
pathnameファイルの場所ばしょ建物たてものの「何階なんかいの何号室なんごうしつ」か
search検索けんさくデータ住所じゅうしょに添そえられた「おまけ情報じょうほう」
assign()ページを移動いどうする次つぎの目的地もくてきちへ歩あるいていく（戻もどれる）
replace()履歴りれきを残のこさず移動いどう瞬間移動しゅんかんいどうして前まえの場所ばしょを忘わすれる（戻もどれない）
reload()ページを更新こうしんする同おなじ場所ばしょでもう一度いちどやり直なおす

いかがでしょうか？URLをパーツごとに理解りかいできると、特定とくていのページだけで動うごくプログラムを作つくったり、ユーザーを別べつのページに誘導ゆうどうしたりできるようになります。
