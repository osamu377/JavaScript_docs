留学生のためのJavaScript学習ガイド

配列はいれつ

I. 配列はいれつ（Array）の基本きほん

たくさんのデータをバラバラに管理かんりするのは大変たいへんです。そこで使つかうのが「Arrayオブジェクト」という、複数ふくすうのデータをひとつにまとめて管理かんりできるリストのような道具どうぐです。日本語にほんごでは、「配列はいれつ（はいれつ）」と呼よびます。

配列はいれつ（はいれつ）は「ならんだ箱はこ」

たくさんのデータを、ひとつのグループとしてまとめたいときに、「配列はいれつ」を使つかいます。学生がくせいのみなさんには、「番号ばんごうがついたロッカー」 や 「番号ばんごうがついた部屋へやが並ならんでいるマンション」 をイメージすると分わかりやすくなります！

Tip

漢字かんじのヒント
「配はい」 は「くばる」、「列れつ」 は「ならぶ」という意味いみです。
みんなが並ならんでいる様子ようすをイメージすると、覚おぼえやすいですよ！

コンストラクタ

オブジェクトを利用りようするには、new演算子えんざんし と コンストラクタ を使つかって、新あたらしいオブジェクトを生成せいせいします。

a = new array(1,2,3);

ここでは、array() がコンストラクタです。コンストラクタはオブジェクトを生成せいせいするための特別とくべつな関数かんすうで、オブジェクトと同おなじ名前なまえをしています。引数ひきすうはオブジェクトによって違ちがいますが、array()の場合ばあいは、中身なかみをひとつひとつ、,（カンマ）で区切くぎって並ならべます。

また、配列はいれつは、次つぎで説明せつめいするように、角かくかっこを使つかって、作成さくせいすることもできます。

[ ] （角かくかっこ）

JavaScriptで配列はいれつ（はいれつ）を使つかうとき、必かならず出でてくるのが [ ]（角かくかっこ） です。

大おおきく分わけて、2つの使つかい方かた があります。

配列はいれつを「作つくる」ときの [ ]

→「新あたらしいマンションを建たてる」イメージ

一番いちばんはじめに、中身なかみをまとめて入いれるときに使つかいます。

const colors = ["赤", "青", "黄（き）"];
  • [ ：ここからマンションが始はじまります。
  • , ：部屋へや（へや）と部屋へやの間あいだの「かべ」です。
  • ] ：ここでマンションが終おわります。

中身なかみを「指定していする」ときの [ ]

→「ルームナンバーで 呼よぶ」イメージ

作つくったあとで、「○番目ばんめのデータがほしい！」というときに使つかいます。

console.log(colors[0]); // 「赤」が出てくる

ここが大事だいじ！「0番ばん」から始はじまるルール

マンションの「1号室ごうしつ（いちごうしつ）」は、プログラミングでは [0] と書かきます。

  • 1つめ： colors[0]
  • 2つめ： colors[1]
  • 3つめ： colors[2]

Tip

覚おぼえ方かた：
プログラミングの世界せかいでは、「まだ一歩いっぽも動うごいていない状態じょうたい」を 0 と考かんがえます。だから最初さいしょが 0 なんです。 「1つめは 0（ゼロ）！」 と心こころの中なかで3回かい唱となえてください。これだけで、バグが半分はんぶんに減へりますよ！

中身なかみを「書かきかえる」ときの [ ]

→「ロッカーの中身なかみを 入いれ替かえる」イメージ

特定とくていのロッカー番号ばんごうを指定していして、中身なかみを新あたらしくすることもできます。

const snacks = ["チョコ", "グミ"];

snacks[1] = "アイス"; // 1番ロッカー（2つめ）のグミを、アイスに変える

console.log(snacks); // ["チョコ", "アイス"]

この「中身なかみを「書かきかえる」ときの [ ]」を使つかえば、最初さいしょに空からの配列はいれつを作つくって、あとから、中身なかみを入いれることもできます。

const snacks = new array();
snacks[0] = "チョコ";
snacks[1] = "グミ";

Note

ここではsnacks という配列はいれつを、constで宣言せんげんしているのに、配列はいれつの中身なかみを書かきかえています。このことを不思議ふしぎに思おもった人ひとはいますか？　その人ひとは、とてもするどい人ひとです。

しかし、これはOKなんです。なぜなら、constを使つかって宣言せんげんされているsnacksは、配列はいれつの中身なかみではなく、配列はいれつという入いれ物もののほう だからです。ロッカーの中身なかみを入いれ替かえても、ロッカーそのものはもとのままで、少すこしも変かわっていません。それと同おなじです。

まとめ：[ ] の役割やくわり

使つかい方かたやっていること例たとえ話ばなし
[a, b, c]配列はいれつを作つくるマンションを建たてる
[0]データを取とり出だす部屋へやをノックする
[0] = "x"データを入いれ替かえる住人じゅうにんを入いれ替かえる

Note

よくあるミス：
全角ぜんかくの ［ ］ を使つかってしまうとエラーになります。必かならず半角はんかくの [ ] を使つかいましょう！

配列はいれつの要素ようそ

配列はいれつのひとつひとつの箱はこの中なかに入はいっているデータを配列はいれつの「要素ようそ」と言いいます。

配列はいれつの要素ようその数かずはlengthプロパティで、知しることができます。オブジェクトのプロパティを取とり出だすときは、「.（ドット）」 を使つかいます。

  • fruits.length → 今いま、箱はこがいくつあるか（3つ）教おしえてくれます。
console.log(fruits.length); // 3 と表示（ひょうじ）されます。

学生がくせいへのアドバイス

いかがでしょうか？「0から始はじまるリスト」のイメージはつかめましたか？

II. よく使つかうプロパティ・メソッド・演算子えんざんし

配列はいれつには、中身なかみを操作そうさするための「道具どうぐ（メソッド）」や「情報じょうほう（プロパティ）」、そして「特別とくべつな記号きごう（演算子えんざんし）」がたくさんあります。

学生がくせいの方かたに特とくに覚おぼえてほしい、「これだけは外はずせない！」という便利べんりなリストをまとめました。

よく使つかうプロパティ（配列はいれつの情報じょうほう）

プロパティは、配列はいれつが持もっている「データ」のことです。

length（レングス）

配列はいれつの中なかに、今いまいくつデータが入はいっているかを教おしえてくれます。

const students = ["マリア", "ジョン", "リー"];

console.log(students.length); // 3 が出る
  • イメージ： 列れつに並ならんでいる人ひとの数かずをパッと数かぞえるリーダーのような存在そんざいです。

なぜ大切たいせつなの？

配列はいれつの .length プロパティを使つかうことで、「データが今いまいくつあるか」を常つねに知しることができます。これにより、データの数かずが増ふえたり減へったりしても、プログラムを書かき直なおさずに柔軟じゅうなんに対応たいおうできるようになります。

覚おぼえたい便利べんりなメソッド（道具どうぐ）

配列操作はいれつそうさのメソッド

配列はいれつには、中身なかみを操作そうさするための便利べんりなメソッドがたくさんあります。

代表的だいひょうてきなメソッドを、「元もとの配列はいれつが変かわるかどうか」 と 「どこを操作そうさするか」 に注目ちゅうもくして、まとめて解説かいせつします。

配列はいれつを 「電車でんしゃの車両しゃりょう」 や 「人ひとの列れつ」 に例たとえて説明せつめいするのが一番いちばんわかりやすいです。

push（プッシュ）：おしりに追加ついかする

一番いちばん最後さいご（右側みぎがわ）に、新あたらしいデータを追加ついかします。

  • イメージ： 電車でんしゃの最後さいごに、新あたらしい車両しゃりょうをつなげる。
  • 元もとの配列はいれつ： 変かわります。
const train = ["車両（しゃりょう）A", "車両（しゃりょう）B"];

train.push("車両（しゃりょう）C"); 

console.log(train); // ["車両（しゃりょう）A", "車両（しゃりょう）B", "車両（しゃりょう）C"]

pop（ポップ）：おしりをひとつ消けす

一番いちばん最後さいご（右側みぎがわ）のデータを1つ取とり除のぞきます。

  • イメージ： 電車でんしゃの最後さいごの車両しゃりょうを切きり離はな（はな）す。
  • 元もとの配列はいれつ： 変かわります。
const train = ["車両（しゃりょう）A", "車両（しゃりょう）B", "車両（しゃりょう）C"];

const last = train.pop(); 

console.log(last);  // "車両（しゃりょう）C" （消えたもの）
console.log(train); // ["車両（しゃりょう）A", "車両（しゃりょう）B"]

shift（シフト）：先頭せんとうをひとつ消けす

一番いちばん最初さいしょ（左側ひだりがわ・0番目ばんめ）のデータを消けして、残のこりのデータを前まえにずらします。

  • イメージ： お店みせの行列ぎょうれつで、先頭せんとうの人ひとが店みせに入はいり、後うしろの人ひとが全員ぜんいん前まえにずれる。
  • 元もとの配列はいれつ： 変かわります。
const queue = ["1番の人", "2番の人", "3番の人"];

queue.shift();
console.log(queue); // ["2番の人", "3番の人"] （みんな前にずれた！）

unshift（アンシフト）：先頭せんとうにひとつ追加ついかする

配列はいれつの 一番いちばん最初さいしょ（先頭せんとう） に、新あたらしいデータを追加ついかします。

  • イメージ： 行列ぎょうれつの一番前いちばんまえに割わり込こみ（わりこみ）をする感かんじです。
  • 元もとの配列はいれつ： 変かわります。
let queue = ["2番の人", "3番の人"];

// unshift を使って、一番前に「1番の人」を入れます
queue.unshift("1番の人");

// 中身を確認（かくにん）してみましょう
console.log(queue);   // 結果：["1番の人", "2番の人", "3番の人"]

slice（スライス）：一部をコピーする

指定していした場所ばしょだけを、別べつの新あたらしい配列はいれつとして取とり出だします。

  • イメージ： 写真しゃしんを撮とるようなものです。景色けしき（元もとの配列はいれつ）はそのままで、必要ひつような部分ぶぶんだけを切きり取とります。
  • 元もとの配列はいれつ： 変かわりません（ここが重要じゅうよう！）。
const members = ["A", "B", "C", "D"];

// 1番目から3番目の「手前」までコピー
const sub = members.slice(1, 3); 

console.log(sub);     // ["B", "C"]
console.log(members); // ["A", "B", "C", "D"] （元の配列（はいれつ）はそのまま！）

splice（スプライス）：好すきな場所ばしょにデータを出だし入いれする

配列はいれつの 好すきな場所ばしょ のデータを消けしたり、新あたらしく入いれたりします。

  • イメージ： 「手術しゅじゅつ」です。悪わるい部分ぶぶんを切きり取とったり、新あたらしい部品ぶひんを埋う（う）め込こんだりします。
  • 元もとの配列はいれつ： 変かわります。
削除さくじょする例れい

splice のうしろのカッコ ( ) には、2つの数字すうじを書かきます。

配列名はいれつめい.splice(スタートする番号ばんごう, 消けしたい数かず);

  • 1つめの数字すうじ： 何番目なんばんめ（インデックス）から消けし始はじめるか？
  • 2つめの数字すうじ： そこから何個なんこ（いくつ）消けすか？
const fruits = ["りんご", "バナナ", "オレンジ", "メロン"];

// 「バナナ」を消してみましょう
// バナナは [1] 番目（2つめ）です。
fruits.splice(1, 1);

// 中身を確認（かくにん）します
console.log(fruits); 
// 結果：["りんご", "オレンジ", "メロン"] （バナナがいなくなりました！）
入いれ替かわる例れい

splice のうしろのカッコ ( ) には、2つの数字すうじと要素ようそを書かきます。

配列名はいれつめい.splice(スタートする番号ばんごう, 入いれ替かえたい数かず, 入いれ替かえる要素ようそ);

  • 1つめの数字すうじ： 何番目なんばんめ（インデックス）から消けし始はじめるか？
  • 2つめの数字すうじ： そこから何個なんこ（いくつ）入いれ替かえるか？
  • 入いれ替かえる要素ようそ（2つ以上いじょうの場合ばあいは、,で区切くぎって並ならべる）
const colors = ["赤", "青", "緑"];
// 1番目（青）と2番目を消して、代わりに「黄（き）」「白」を入れる
colors.splice(1, 2, "黄（き）", "白"); 
console.log(colors); // ["赤", "黄（き）", "白"]

includes（インクルーズ）:データがあるかないかを調しらべる

そのデータが配列はいれつの中なかに あるかないか を調しらべます。

  • イメージ： 探さがし物ものを見みつける「警察犬けいさつけん」です。
  • 答こたえ： true（ある）か false（ない）で返かえってきます。
// カバンの中に「りんご」「ペン」「ノート」が入っています
const myBag = ["りんご", "ペン", "ノート"];

// 「ペン」が入っているかチェックします
const hasPen = myBag.includes("ペン");
console.log(hasPen); // 結果：true（あります！）

// 「バナナ」が入っているかチェックします
const hasBanana = myBag.includes("バナナ");
console.log(hasBanana); // 結果：false（ありません...）

delete 演算子えんざんし（デリート）

特定とくていの場所ばしょのデータを消けしますが、注意ちゅういが必要ひつよう です。

  • 注意ちゅうい： データは消けえますが、「箱はこ（部屋へや）」は残のこったまま になります。部屋へやが「空から（empty）」の状態じょうたいになり、配列はいれつの長ながさ（length）も変かわりません。
const snacks = ["チョコ", "グミ", "アメ"];
delete snacks[1]; 

console.log(snacks); // ["チョコ", <empty>, "アメ"]
console.log(snacks.length); // 3 のまま！（穴があいた状態）

Important

学生がくせいへのアドバイス：
配列はいれつからきれいにデータを消けしたいときは、delete ではなく splice を使つかうようにしてください。delete は「穴あな」があくので、あまり使つかいません。

スプレッド演算子えんざんし ... （てん・てん・てん）

配列はいれつの中身なかみを バラバラにして取とり出だす 魔法まほうの記号きごうです。

.（どっと）を三みっつ並ならべて書かきます。

  • イメージ： 袋ふくろに入はいったお菓子かしを、テーブルの上うえに全部ぜんぶザーッと広ひろげる感かんじです。
const groupA = ["A", "B"];
const groupB = ["C", "D"];

// 2つの配列（はいれつ）を合体させて、新しい配列（はいれつ）を作る
const all = [...groupA, ...groupB];
console.log(all); // ["A", "B", "C", "D"]

比較ひかく（ひかく）テーブル

種類しゅるい名前なまえ場所ばしょ動うごき元もとの配列はいれつは？
プロパティlengthすべて数かずを数かぞえる変かわらない
メソッドpush最後さいご追加ついかする変かわる
メソッドpop最後さいご消けす変かわる
メソッドshift最初さいしょ消けす（ずれる）変かわる

学生がくせいへのアドバイス

「元もとの配列はいれつが変かわってしまうメソッド（push, pop, shift）」を使つかうときは注意ちゅういが必要ひつようです。もし、元もとのデータを壊こわしたくないときは、slice を使つかってコピーを作つくってから作業さぎょうする のがプロのコツですよ！

Tip

「slice（スライス）」 は、料理りょうりでハムやチーズを薄うすく切きるのと同おなじ言葉ことばです。「元もとの塊かたまりから、一切ひときれ分ぶんをもらう」と覚おぼえると忘わすれません。

Tip

「splice」と「slice」は名前なまえが似にている！
* splice：手術しゅじゅつして 中身なかみをいじる。
* slice：写真しゃしんのように 一部いちぶを撮とるだけ。

この違ちがいを強調きょうちょう（きょうちょう）してあげると、学生がくせいも混乱こんらんしません。

III. 連想配列れんそうはいれつ

「連想配列れんそうはいれつ（れんそうはいれつ）」という言葉ことばは、少すこし難むずかしく聞きこえますよね。 簡単かんたんに言いうと、「番号ばんごうの代かわりに、『名前なまえ（ラベル）』をつけた箱はこ」 のことです。

JavaScriptでは「オブジェクト」の一種いっしゅです。メソッドがなく、データだけをまとめたものです。

1. ふつうの配列はいれつとの違ちがい

普通ふつうの配列はいれつと、連想配列れんそうはいれつの違ちがいを「ロッカー」でイメージしてみましょう。

  • 普通の配列 (Array): 番号ばんごうがついたロッカー。

    • 「0番ばんのロッカー、1番ばんのロッカー……」と、数字すうじ で中身なかみを探さがします。

  • 連想配列 (Associative Array): 名前なまえが書かかれたラベル付つきのロッカー。

    • 「『名前なまえ』のロッカー、『国籍こくせき（こくせき）』のロッカー……」と、言葉ことば で中身なかみを探さがします。

2. 書かき方かたと呼よび方かた

「名前なまえ（Key：キー）」と「中身なかみ（Value：値あたい（あたい））」をセットにして作つくります。

const animals = new array();
animals['dog'] = 'いぬ';
animals['cat'] = 'ねこ';

波なみかっこ{}を使つかって初期化しょきかすることもできます。

// 連想配列（はいれつ）（オブジェクト）を作る
const user = {
  name: "田中",
  age: 20,
  country: "日本"
};

中身なかみを取とり出だすには、ドット.やブラケット[]を使つかいます。

// 中身を取り出す
console.log(user["name"]); // 「田中」が出る
console.log(user.name);    // これでも「田中」が出る（こっちがよく使われます）

3. なぜ「連想れんそう（れんそう）」というの？

「連想れんそう」とは、「Aという言葉ことばから、Bを思おもい出だす」 という意味いみです。

国くにと「食たべ物もの・場所ばしょ」の例れい

それぞれの国くにをイメージしたときに、パッと思おもい浮うかぶものはありませんか？

  • 日本にほん から連想れんそうするのは… 「お寿司すし（すし）」
  • イタリア から連想れんそうするのは… 「ピザ」
  • フランス から連想れんそうするのは… 「エッフェル塔とう（とう）」

このように、例たとえば「国名こくめい（名前なまえ） を聞きいたら、その国くにの 特徴とくちょう（データ） を思おもい出だす」というような心こころの動うごきを、「連想れんそう」と言いいます。

「名前なまえ（キー）」と「中身なかみ（バリュー）」がセットになっている 仕組しくみが、「連想れんそう」の仕組しくみとよく似にているため、「連想配列れんそうはいれつ」と呼よばれるのです。

4. 配列はいれつと連想配列れんそうはいれつのまとめ

種類しゅるい探さがし方かた（呼よび方かた）どんなときに使つかう？
普通ふつうの配列はいれつ0, 1, 2…（数字すうじ）出席番号しゅっせきばんごうや買かい物ものリストなど、順番じゅんばん　が大事だいじなとき
連想配列れんそうはいれつ“name”, “price”…（言葉ことば）プロフィールや商品しょうひんの詳細しょうさいなど、意味いみ が大事だいじなとき

Tip

学生がくせいへのアドバイス：
実じつは「連想配列れんそうはいれつ」という言葉ことばは、もともと他ほかのプログラミング言語げんご（PHPやRubyなど）で使つかわれていた言葉ことばなんです。JavaScriptでは、この「連想配列れんそうはいれつ」のことを 「オブジェクト」 と呼よびます。「名前なまえ（キー）と中身なかみ（バリュー）がセットになっている」状態じょうたいは、「プロパティ名めいとプロパティの値あたいがセットになっている」状態じょうたいと同おなじだからです。書かき方かたも同おなじですね。ただ「連想配列れんそうはいれつ」はデータだけでメソッドはありません。

いかがでしょうか？「数字すうじではなく、名前なまえで探さがすリスト」だと考かんがえれば簡単かんたんですね！

V. 二次元配列にじげんはいれつ

「二次元配列にじげんはいれつ（にじげんはいれつ）」という言葉ことばを聞きくと、なんだか難むずかしそうに感かんじますよね。
でも大丈夫だいじょうぶです。一言ひとことでいうと、「配列はいれつの中なかに、さらに配列はいれつが入はいっているもの」 のことです。

イメージは「マンションの 部屋番号へやばんごう」

普通ふつうの配列はいれつが「一列いちれつにならんだロッカー」だとしたら、二次元配列にじげんはいれつは 「たて と よこ に ならんだマンション」 です。

  • 1つめの数字すうじ： 何階なんがいか？
  • 2つめの数字すうじ： どの部屋へやか？

あるいは 「エクセルの表ひょう」 をイメージした方ほうがわかりやすいかもしれません。

  • 1つめの数字すうじ： 行ぎょう（ぎょう） / Row
  • 2つめの数字すうじ： 列れつ（れつ） / Column

1行
2行
3行

JavaScriptでの書かきかた

学校がっこうのクラスの「座席表ざせきひょう（ざせきひょう）」を例れいに見みてみましょう。

const classMap = [
  ["田中", "鈴木"], // 0番目のグループ（1列目）
  ["佐藤", "マリア"], // 1番目のグループ（2列目）
  ["ジョン", "リー"]  // 2番目のグループ（3列目）
];

1行田中鈴木
2行佐藤マリア

中身なかみを取とり出だすとき

カギかっこを 2つ [ ][ ] 並ならべて書かきます。

console.log(classMap[2][1]); // 「リー」さんが出ます！
  • classMap[2] → 3つめのグループ（[“ジョン”, “リー”]）を選えらびます。
  • [1] → その中なかの、2番目ばんめの人ひと（リー）を選えらびます。

1行[0][0][0][1]
2行[1][0][1][1]

なぜ「二次元にじげん」というの？

  • 一次元いちじげん（いちじげん）： 「線せん」です。横よこ（よこ）だけにデータがならんでいます。
  • 二次元にじげん（にじげん）： 「面めん」です。横よこ（よこ）と縦たて（たて）にデータが広ひろがっています。

Tip

「多次元たじげん（たじげん）」って何なに？
二次元にじげん（たて・よこ）よりもさらに増ふえて、三次元さんじげん（奥行おくゆき・高たかさ）など、もっと複雑ふくざつになったものをまとめて「多次元たじげん」と呼よびます。

どんなときに使つかう？

  • ゲームの地図ちず： どこに宝箱たからばこがあるか、座標ざひょうで決きめるとき。
  • カレンダー： 「○週目しゅうめの、○曜日ようび」というデータ。
  • 写真しゃしんのデータ： デジタルの写真しゃしんは、色いろのついた点てんが縦たてと横よこに並ならんでできています。

学生がくせいへのアドバイス

二次元配列にじげんはいれつを使つかうとき、一番いちばん多おおいミスはこれです。
「どっちの数字すうじが『たて』で、どっちが『よこ』だっけ？」

混乱こんらん（こんらん）したときは、こう教おしえてあげてください。

「左側ひだりがわのカッコが『階かい（かい）』で、右側みぎがわのカッコが『部屋へや』だよ！」

いかがでしょうか？「リストのリスト」という考かんがえ方かたに慣なれると、プログラミングでできることが一気いっきに広ひろがります。

VI. オブジェクトの配列はいれつ

現実げんじつのプログラムでは、以下いかのように「オブジェクト（情報じょうほうのセット）」を配列はいれつにまとめることが多おおいです。これは「顧客名簿こきゃくめいぼ」や「商品しょうひんカタログ」のようなイメージです。

const customers = [
  { name: "山田", age: 30 },
  { name: "佐藤", age: 25 }
];

「[]角かく（かく）かっこ」と「{}波なみ（なみ）かっこ」を使つかったこの書かき方かたを、覚おぼえておいてください。
