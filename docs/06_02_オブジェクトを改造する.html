留学生のためのJavaScript学習ガイド

オブジェクトを改造かいぞうする

すでにあるオブジェクトを自分好じぶんごのみに作つくり変かえることを、プログラミングの世界せかいでは 「拡張かくちょう（かくちょう / Extension）」 や 「カスタマイズ」 と呼よびます。

これは 「買かってきた自転車じてんしゃに、ライトをつけたり色いろをぬったりして改造かいぞうすること」 に例たとえることができます。

I. オブジェクトを改造かいぞうする

1. すでにあるオブジェクトを改造かいぞうする2つの方法ほうほう

JavaScriptでは、すでに動うごいているオブジェクトに後あとから「新あたらしいパーツ」を追加ついかしたり、「古ふるいパーツ」を新あたらしいものに取とり替かえたりできます。

a) 追加ついかする

特定とくていの1人にん（1つのオブジェクト）だけに、新あたらしいプロパティやメソッドを追加ついかします。

  • イメージ： 自分じぶんの自転車じてんしゃだけに、特別とくべつなステッカーを貼はる。
  • 書かき方かた： オブジェクト名.新しい名前 = 値;
const myCar = { brand: "Toyota" };

// 後からプロパティを追加
myCar.color = "Red";

// 後からメソッドを追加
myCar.horn = function() {
  console.log("プップー！");
};

myCar.horn(); // 実行できる！

Note

myCar.horn = function() {... の部分ぶぶんは、myCar.horn に関数かんすうを代入だいにゅうしていいます。
このように、JavaScriptでは関数かんすうも変数へんすうのようにあつかうことができます。 代入だいにゅうしたり、関数かんすうの引数ひきすうにしたり、返かえり値ちにしたりできるのです。

b) オーバーライド（上書うわがき）する

親おやから受うけ継ついだ機能きのうを、自分流じぶんりゅうのやり方かたに書かき換かえます。

  • イメージ： お父とうさんからもらったカメラだけど、レンズを最新さいしんのものに交換こうかんして使つかいやすくする。
  • 書かき方かた： 同おなじ名前なまえで新あたらしく定義ていぎし直なおす。
// 1. robotオブジェクトを作成
const robot = {
  name: "ロビー",
  greet() {
    console.log("ハロー、ロボットです。");
  }
};

// 2. 実行
robot.greet(); // "ハロー、ロボットです。"（元のまま）

// 3. robot のメソッドを上書（うわが）き（オーバーライド）する
robot.greet = function() {
  console.log("こんにちは！ 私は特別なロボットです。");
};

// 4. 実行して比較（ひかく）する
robot.greet(); // "こんにちは！ 私は特別な..."（上書（うわが）きされた！）

Note

robot.greet = function() {... の部分ぶぶんは、robot の greet というメソッド（関数かんすう）に別べつの関数かんすうを再代入さいだいにゅうしています。

2. 例たとえ話ばなし：スマホ

JavaScriptのオブジェクトは、一度いちど作つくったら終おわりではありません。

  1. 直接追加ちょくせつついか： スマホに『お気きに入いりのストラップ』をつけるようなもの。
  2. オーバーライド： 決きまった『着信音ちゃくしんおん』を、自分じぶんの好すきな音楽おんがくに変かえるようなものだよ。

こうやって、元もとの形かたちを壊こわさずに自分じぶんらしく使つかいやすくするのが、JavaScriptの面白おもしろいところなんです。

II. プロトタイプとプロトタイプチェーン

JavaScriptの「プロトタイプ（Prototype）」と「プロトタイプチェーン」は、多おおくの学習者がくしゅうしゃがつまずく難むずかしいところです。

これを皆みなさんがイメージしやすいように、 「家系図かけいず」 や 「秘密ひみつのレシピの受うけ継つぎ」 に例たとえて説明せつめいします。

1. プロトタイプ（Prototype）とは？

JavaScriptでは、多おおくのオブジェクトが「親おや（プロトタイプ）」を持もっています。もし自分じぶんの中なかに必要ひつような道具どうぐ（メソッドやプロパティ）がなくても、「親おやの持もっている道具どうぐを借かりて使つかう」 ことができる仕組しくみです。

2. プロトタイプチェーン（Prototype Chain）とは？

「自分じぶんになければ親おや、親おやになければそのまた親おや…」と、さかのぼって探さがしに行いく「鎖くさり」のようなつながり のことです。

身近みぢかな例たとえ：秘密ひみつのカレーレシピを求もとめて

  1. あなた（インスタンス）： カレーを作つくろうとします。
  2. 自分じぶんのキッチン： レシピがありません。
  3. お父とうさんの家いえ（自分じぶんのプロトタイプ）： 「カレーのレシピある？」と聞ききます。「持もっていない」と答こたえが返かえってきました。
  4. おじいさんの家いえ（自分じぶんの親おやのプロトタイプ）： お父とうさんも持もっていなければ、さらにおじいさんに聞ききに行いきます。「カレーのレシピある？」
  5. 先祖せんぞの家いえ： そんな風ふうに、レシピを持もっている人ひとを見みつけるまで、先祖せんぞをたどって聞ききに行いきます。誰だれかがレシピを持もっていれば、あなたはそれを使つかってカレーが作つくれます。

3. なぜこの仕組しくみがあるの？

もし100人にんの学生がくせいオブジェクトを作つくるとき、全員ぜんいんに「自己紹介じこしょうかいメソッド」を持もたせると、メモリーをたくさん使つかってしまいます。

  • プロトタイプを使つかわない： 全員ぜんいんが自分じぶんの辞書じしょを持もっている（重おもい！）
  • プロトタイプを使つかう： 教室きょうしつに1冊さつだけ辞書じしょを置おき、全員ぜんいんでそれを共有きょうゆうする（軽かるい！）

4. コードで見みる「探さがしに行いく流ながれ」

const animal = {
  eats: true
};

const dog = {
  barks: true
};

// dog の親（プロトタイプ）を animal に設定（せってい）
Object.setPrototypeOf(dog, animal);

console.log(dog.barks); // true (自分の中にある)
console.log(dog.eats);  // true (自分にはないが、親にあるので借りてきた！)
console.log(dog.fly);   // undefined (家系図（かけいず）を最後まで探したけど、どこにもない)

5. プロトタイプを使つかって新あたらしいプロパティやメソッドを追加ついかする

ひとつのオブジェクトだけでなく、そのプロトタイプから生うまれた「全員ぜんいん」に、新あたらしい機能きのうを持もたせることができます。

  • イメージ： マンションの住人じゅうにん全員ぜんいんが使つかえる「共有きょうゆうのラウンジ」に、新あたらしいテレビを置おく。
  • 書かき方かた： クラス名.prototype.メソッド名 = function() { ... };
// 全ての配列（はいれつ）（Array）に「2倍にする」という新しい機能を追加してみる
Array.prototype.double = function() {
  return this.map(n => n * 2);
};

const numbers = [1, 2, 3];
console.log(numbers.double()); // [2, 4, 6]

注意ちゅうい： ここではわかりやすい例れいとしてArrayにメソッドを追加ついかしましたが、ふつう、 Array や Object などの、皆みなが使つかう標準ひょうじゅんの道具どうぐを勝手かってに改造かいぞうはしません。他ほかの人ひとの書かいたブログラムに影響えいきょうする可能性かのうせいがあるからです。

📝 学生がくせいへのアドバイス

改造かいぞうはとても便利べんりだけど、やりすぎると『元もとの形かたちがどうだったか』が分わからなくなって、他ほかの人ひとが困こまることがあります。
特とくに Array.prototype などを改造かいぞうするときは、『みんなの共有きょうゆうスペースに勝手かってに私物しぶつを置おかない』 というマナーがあることも、一緒いっしょに覚おぼえておきましょう！

いかがでしょうか？ 「後あとから自由じゆうに変かえられる」というJavaScriptの柔軟じゅうなんな性格せいかくが伝つたわればバッチリです。
