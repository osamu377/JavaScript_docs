留学生のためのJavaScript学習ガイド

Windowオブジェクト

さて、オブジェクトがどんなものか、を理解りかいしたら、次つぎはブラウザのオブジェクトをもっとくわしく見みてみましょう。こうしたオブジェクトはあらかじめ、JavaScriptに組くみ込こまれているので、そのプロパティもメソッドも、いきなり呼よび出だして使つかうことができます。 ブラウザで動うごくJavaScriptを学習がくしゅうするとき、一番大いちばんおおきな存在そんざいが Windowオブジェクト です。 学生がくせいの方かたには、Windowオブジェクトは 「ブラウザの画面全体がめんぜんたいを管理かんりしている『社長しゃちょうさん』」 だと教おしえてあげてください。JavaScriptでできることのほとんどは、この社長しゃちょうさんにお願ねがいして動うごかしています。

1. Windowオブジェクトとは？

ブラウザの「タブ」ひとつひとつが、ひとつの window です。
JavaScriptを実行じっこうするとき、最初さいしょからそこにいる「グローバルオブジェクト」（一番いちばんえらいオブジェクト）です。 実じつは、私わたしたちが普段使ふだんつかっている console.log() や alert() も、本当ほんとうは window.console.log() や window.alert() という名前なまえです。でも、社長しゃちょうさんは有名ゆうめいすぎるので、window. を省略しょうりゃくして書かくことができます。

2. よく使つかうプロパティ（画面がめんの情報じょうほう）

社長しゃちょうさんが持もっている「今いまのブラウザの状態じょうたい」についての情報じょうほうです。

window.document

今見いまみている「ウェブサイトの中身なかみ（ページ）」そのものです。文字もじの色いろを変かえたり、ボタンを作つくったりするときに使つかいます。

window.location

今いまの「URL（Web上じょうの住所じゅうしょ）」の情報じょうほうです。

  • 例れい： location.href = "https://google.com"; と書かくと、別べつのサイトに移動いどうできます。

window.innerWidth / innerHeight

ブラウザの「中身なかみの横幅よこはばと高たかさ」です。

  • イメージ： 画面がめんの大おおきさに合あわせてデザインを変かえたいときにチェックします。たとえば「パソコンでは、画面がめんの横幅よこはばがスマートフォンより広ひろいので、それに合あわせ横よこにメニューなどを表示ひょうじする」というようなことをしたいときに、使つかいます。

3. よく使つかうメソッド（社長しゃちょうさんができること）

alert() / prompt() / confirm()

ユーザーにメッセージを出だしたり、質問しつもんをしたりする「小ちいさな窓まど（ダイアログ）」を出だします。

alert("こんにちは！"); // メッセージを出す
let name = prompt("お名前は？"); // 名前を入力（にゅうりょく）してもらう

setTimeout() / setInterval()

「タイマー」の仕事しごとです。

  • setTimeout： ○秒後びょうごに1回かいだけ実行じっこうする。
  • setInterval： ○秒びょうごとに、ずっと繰くり返かえす。

open() / close()

新あたらしいタブを開ひらいたり、今いまあるタブを閉とじたりします。

まとめテーブル

種類しゅるい名前なまえやっていること
プロパティdocumentページの内容ないようをいじる

プロパティとメソッド

🌐 別べつのオブジェクト（子分こぶんたち）

  • document（ドキュメント）：

  • 意味いみ： 今画面いまがめんに見みえている「Webページの白しろい紙かみ（HTMLの中身なかみ）」を捕つかまえるとき（document.getElementById）にいつも使つかう超重要ちょうじゅうようプロパティです。

  • history（ヒストリー）：

  • 意味いみ： ブラウザの「戻もどる」「進すすむ」の履歴りれき（歴史れきし）を管理かんりするオブジェクトです。

  • location（ロケーション）：

  • 意味いみ： 今見いまみているWebページの「URL（住所じゅうしょ）」の情報じょうほうです。ここに新あたらしいURLを代入だいにゅうすると、別べつのページに画面がめんが変かわります。

🪟 画面がめんの大おおきさ（サイズ）

  • innerWidth / innerHeight（インナー・ウィズ / ハイト）：

  • 意味いみ： Webページが実際じっさいに見みえている「内側うちがわの白しろい部分ぶぶんの幅はばと高たかさ」（ピクセル単位たんい）です。スクロールバーは含ふくみません。

  • outerWidth / outerHeight（アウター・ウィズ / ハイト）：

  • 意味いみ： ブラウザの枠わくやメニューバーなども全部合ぜんぶあわせた「一番外側いちばんそとがわのウィンドウ全体ぜんたいの幅はばと高たかさ」です。

Note

ユーザーの画面がめんサイズに合あわせて動うごき（レスポンシブ）を変かえたいときは、内側うちがわのサイズである innerWidth をよく使つかいます。また、一覧いちらんの outeWridth や innerheight は大文字小文字おおもじこもじのタイポ（打うち間違まちがい）になりやすいので、innerWidth / innerHeight / outerWidth / outerHeight と正ただしく教おしえてあげてください。

🆕 新あたらしいウィンドウ・タブの状態じょうたい

  • closed（クローズド）：

  • 意味いみ： そのウィンドウが「すでに閉とじられているか・いないか」を true / false で教おしえてくれます。

  • opener（オープナー）：

  • 意味いみ： 自分じぶんのウィンドウを新あたらしく開ひらいてくれた「親おやのウィンドウ」を指さします。

  • name（ネーム）：

  • 意味いみ： ウィンドウにつけられた「名前なまえ」です。リンクを別べつのウィンドウで開ひらくターゲット（target="名前"）に使つかいます。

💬 ブラウザの下したのバー（現在げんざいはあまり使つかわれません）
  • status / defaultStatus（ステータス / デフォルト・ステータス）：
  • 意味いみ： ブラウザの一番下いちばんしたに昔むかしあった「ステータスバー」という場所ばしょに文字もじを表示ひょうじするための設定せっていです。（※現在げんざいのモダンなブラウザでは、セキュリティの理由りゆうでほとんど動うごきません）

2. windowオブジェクトのメソッド（命令めいれい）

🖥️ ウィンドウを動うごかす・開ひらく

  • open() / close()：

  • 意味いみ： 新あたらしいウィンドウ（またはタブ）を**開ひらく**命令めいれいと、今いまあるウィンドウを**閉とじる**命令めいれいです。

  • moveTo(x, y) / moveBy(x, y)：

  • 意味いみ： ウィンドウの画面上がめんじょうの位置いちを動うごかす命令めいれいです。moveTo は指定していした座標ざひょう（絶対位置ぜったいいち）へジャンプし、moveBy は今いまの場所ばしょから指定していした数かずだけ（相対位置そうたいいち）動うごきます。

  • resizeTo(w, h) / resizeBy(w, h)：

  • 意味いみ： ウィンドウの大おおきさを変かえる命令めいれいです。resizeTo は指定していした幅はばと高たかさに変更へんこうし、resizeBy は今いまの大おおきさからプラスマイナスします。

Note

これらの画面自体がめんじたいを動うごかしたりサイズを変かえたりするメソッドは、ユーザーをびっくりさせないよう、現在げんざいの一般的いっぱんてきなブラウザではセキュリティガードがかかり、動うごかない設定せっていになっていることが多おおいです。

  • focus() / blur()：
  • 意味いみ： そのウィンドウを一番前いちばんまえに持もってきてパソコンの主役しゅやくにする（フォーカスを当あてる）命令めいれいと、逆ぎゃくに主役しゅやくから外はずす（フォーカスを外はずす）命令めいれいです。
🚨 ユーザーへのメッセージ（ダイアログ）

  • alert("メッセージ")：

  • 意味いみ： 画面がめんに「OK」ボタンだけの警告けいこくメッセージを出だす、一番いちばんおなじみの命令めいれいです。

  • confirm("いいですか？")：

  • 意味いみ： 「OK」と「キャンセル」の2つのボタンを出だす命令めいれいです。ユーザーが「OK」を押おすと true、「キャンセル」を押おすと false が戻もどり値ちとして返かえってきます。

  • prompt("名前は？")：

  • 意味いみ： 文字もじを入力にゅうりょくできるボックスを出だす命令めいれいです。入力にゅうりょくされた文字もじが戻もどり値ちになります。

⏱️ タイマー（時間じかんをコントロールする）

学生がくせいのゲーム作づくりやWebサイトの動うごき（アニメーション）で大活躍だいかつやくするツートップです！

  • setTimeout(関数, ミリ秒) / clearTimeout(タイマーID)：

  • 意味いみ： 「指定していした秒数びょうすうが経たったあとに、1回かいだけ関数かんすうを実行じっこうする」命令めいれいです（※1000ミリ秒びょう ＝ 1秒びょう）。途中とちゅうでストップしたいときは clearTimeout を使つかいます。

  • setInterval(関数, ミリ秒) / clearInterval(タイマーID)：

  • 意味いみ： 「指定していした秒数びょうすうごとに、ずーっと何回なんかいも関数かんすうを繰くり返かえす」命令めいれいです。時計とけいやアクションゲームの動うごきに使つかいます。止とめるときは必かならず clearInterval で消けす必要ひつようがあります。

3. 学生向がくせいむけのまとめ

JavaScriptの大だいボス window
window オブジェクトは、ブラウザの画面全体がめんぜんたいを支配しはいしている「一番大いちばんおおきなお父とうさん」のようなオブジェクトです。
実じつは、いつも使つかっている alert() も、正ただしくは window.alert() と書かきます。でも、一番大いちばんおおボスの命令めいれいはいちいち window. と書かかなくても、省略しょうりゃくして alert() だけで使つかっていいルールになっています。

  • 中身なかみを知しる（プロパティ）： document（ページの中身なかみ）や innerWidth（画面がめんの幅はば）など、今いまのブラウザの状態じょうたいを教おしえてくれます。
  • タイマーを動うごかす（メソッド）： setTimeout（◯秒後びょうごに1回動かいうごかす）や setInterval（◯秒びょうごとに繰くり返かえし動うごかす）は、Webサイトに楽たのしい動うごきやゲームを作つくるために絶対ぜったいに必要ひつような命令めいれいなので、使つかい方かたをしっかり覚おぼえましょう！

いかがでしょうか。数かずが多おおくて圧倒あっとうされがちですが、実務じつむや課題かだいで今いまでも主役しゅやくとしてよく使つかうのは、「子分こぶんオブジェクト（document, location）」、「ダイアログ（alert, confirm）」、「タイマー（setTimeout, setInterval）」の3大だいグループです。
