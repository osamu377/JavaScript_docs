初めてのウェブサイト

I. はじめてのウェブサイト

1. はじめに：ウェブ開発かいはつの世界せかいへようこそ

みなさん、こんにちは！ ウェブサイトを作つくってみたいと思おもったことはありますか？ 今いまの社会しゃかいでは、自分じぶんの考かんがえや情報じょうほうを世界せかいに伝つたえるために、ウェブサイトを作つくる技術ぎじゅつはとても大おおきな力ちからになります。

特とくに留学生りゅうがくせいのみなさんにとって、ウェブサイトは「言葉ことばの壁かべ」をこえるための強つよい味方みかたです。完全かんぜんな日本語にほんごを話はなすのが難むずかしくても、ウェブサイトなら写真しゃしんやデザイン、図ずを使つかって、あなたの魅力みりょくや才能さいのうを視覚しかく的てきに伝つたえることができます。

「ウェブ開発かいはつはむずかしそう……」と感かんじるかもしれません。確たしかに、Facebook（フェイスブック）のような複雑ふくざつなサイトを、いきなり一人ひとりで作つくることは難むずかしいです。しかし、安心あんしんしてください。自分じぶんだけのシンプルなウェブサイトなら、少すこしずつ進すすむことで、誰だれでも作つくることができます。

このガイドでは、ウェブサイトがどのように動うごいているのか、そしてどうすれば自分じぶんの作品さくひんを世界せかいに広ひろめることができるのかを、やさしく解説かいせつします。自分じぶんで情報じょうほうを広ひろめる力ちからを身みにつけることは、将来しょうらいの仕事しごとや自分じぶんを表現ひょうげんするために、必かならず素晴すばらしいプラスになるはずです。

準備じゅんびはいいですか？ まずは、スタートするために必要ひつようなものを確認かくにんしましょう。

Note

この資料しりょうはMDNの「Your first website」をやさしい日本語にほんごにしたものです。

2. 準備じゅんびするもの：スタートラインに立たつ

実際じっさいにコード（コンピュータへの命令めいれい）を書かき始はじめる前まえに、自分じぶんのコンピュータで作業さぎょうができる準備じゅんびをすることが大切たいせつです。これを「環境かんきょう構築こうちく / パソコンでサイトを作つくるための準備じゅんび」と呼よびます。

まず、以下いかの3つのことがスムーズにできるか確認かくにんしてください。

  1. OS（オペレーティングシステム）の操作そうさ： WindowsやmacOSなどの基本きほん的な使つかい方かたがわかる。
  2. ファイルシステムの理解りかい： ファイルを保存ほぞんしたり、フォルダを作つくって整理せいりしたりできる。
  3. ブラウザの利用りよう： インターネットで検索けんさくをしたり、サイトを見みたりできる。

Note

「2. ファイルシステムの理解りかい」に自信じしんのない人ひとは、補足ほそく資料しりょう集しゅうの「ファイルとフォルダの基本きほん」を見みてください

次つぎに、以下いかの「道具どうぐ」を用意よういしましょう。

  • コードエディター： プログラムのコードを書かくための専用せんようソフトです。Visual Studio Codeを使つかいます。すでに皆みなさんのPCにインストールされています。
  • ウェブブラウザ： 主おもにGoogle Chrome を使つかいます。こちらもんストール済ずみです。

道具どうぐがそろったら、次つぎは「どんなサイトを作つくるか」という計画けいかくを立たてるステップです。

3. 計画けいかくを立たてる：サイトの見みた目めを決きめる

いきなりコードを書かき始はじめるのは、設計図せっけいずなしで家いえを建たてるようなものです。まずは「計画けいかく」から始はじめましょう。最初さいしょにしっかり計画けいかくを立たてることで、作業さぎょうの途中とちゅうで迷まよわなくなり、結果けっかとして「情報じょうほうの整理せいりされた見みやすいサイト」を作つくることができます。

計画けいかくを立たてるときは、以下いかのポイントを整理せいりしてみてください。

  • どんな情報じょうほうを載のせるか： 誰だれに、何なにを伝つたえたいですか？（自己紹介じこしょうかい、趣味しゅみの紹介しょうかいなど）
  • どんなフォントや色いろを使つかうか： 明あかるいイメージですか？ それともクールで落おち着ついたイメージですか？

見みた目めのイメージが固かたまったら、いよいよサイトの「中身なかみ（文章ぶんしょう）」と「形かたち」を作つくっていく段階だんかいに入はいります。

Note

見みた目め: 外そとから見みた物事ものごとのありさま （例れい その車くるまは 見みた目め は美うつくしいが中身なかみは壊こわれている）

4. サイトの「3つの要素ようそ」：HTML、CSS、JavaScript

ウェブサイトは、主おもに3つの技術ぎじゅつが組くみ合あわさってできています。これを「家いえづくり」に例たとえて見みてみましょう。

技術名ぎじゅつめい役割やくわり（家いえの例たとえ）詳くわしい説明せつめい
HTML構造こうぞう段落だんらく、リスト、画像がぞうなど、コンテンツの「意味いみ」や「土台どだい」を作つくります。
CSS見みた目め（かざり）色いろ、サイズ、配置はいち、背景はいけいなど、サイトを「美うつくしく」整ととのえます。
JavaScript動うごきボタンの反応はんのう、アニメーション、ゲームなど「便利べんりな機能きのう」を加くわえます。

これらの技術ぎじゅつは、どれか一ひとつ欠かけてもうまくいきません。たとえば、HTMLだけでは文字もじが並ならんでいるだけで読よみにくく、CSSがないとデザインがバラバラになります。また、JavaScriptがないと動うごきのない静しずかなサイトになってしまいます。

これらを正ただしく組くみ合あわせることで、ユーザーにとって「読よみやすく」「使つかいやすく」「楽たのしい」ウェブサイトが完成かんせいするのです。

Note

段落だんらく：長ながい文章ぶんしょうを内容ないようなどから分わけた、言葉ことばの集あつまり

Note

リスト：複数ふくすうの項目こうもくや要素ようそを集あつめたもの

Note

画像がぞう：写真しゃしんや絵えなど

5. 世界せかいへ公開こうかいする：パブリッシング

自分じぶんのパソコンで作つくったファイルは、そのままでは自分じぶんにしか見みることができません。これをインターネット上じょうにアップロードして、世界中せかいじゅうの誰だれでも見みられる状態じょうたいにすることを「公開こうかい（パブリッシング）」と言いいます。

公開こうかいの手順てじゅんをシンプルにまとめると、以下いかのようになります。

  1. コードを書かき終おえる： HTML、CSS、JavaScriptを完成かんせいさせます。
  2. ファイルを整理せいりする： 画像がぞうやコードのファイルを正ただしいフォルダにまとめます。
  3. オンラインにアップロードする： 「サーバー」と呼よばれる、インターネット上じょうの場所ばしょへファイルを送おくります。

Note

授業じゅぎょうでは、このステップは実施じっししません。興味きょうみのある方かたは、ここをクリックしてMDNの関連かんれんサイトを参照さんしょうしてください。

6. まとめと次つぎのステップ

ここまで、ウェブサイト制作せいさくの全体像ぜんたいぞうを見みてきました。ウェブ開発かいはつの学習がくしゅうは、一度いちどで完璧かんぺきにする必要ひつようはありません。小ちいさな「できた！」を積つみ重かさねていくプロセスそのものが大切たいせつです。
