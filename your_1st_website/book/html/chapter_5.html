初めてのウェブサイト

V. ウェブサイトを動《うご》かすJavaScript《じゃばすくりぷと》

ウェブサイトを見《み》たときに、ボタンを押《お》して画面《がめん》が変《か》わったり、画像《がぞう》が動《うご》いたりすることはありませんか？
それは「JavaScript《じゃばすくりぷと》」という言葉《ことば》が働《はたら》いているからです。

このガイドでは、プログラミングが初《はじ》めての人《ひと》や、日本語《にほんご》を勉強《べんきょう》中《ちゅう》の留学生《りゅうがくせい》にも分《わ》かりやすく、JavaScript《じゃばすくりぷと》の基本《きほん》を説明《せつめい》します。

1. はじめに：JavaScript《じゃばすくりぷと》とは何《なに》か

ウェブサイトを作《つく》るとき、HTMLは「骨組《ほねぐ》み」を、CSSは「見《み》た目《め》」を作《つく》ります。そこに「動《うご》き」を加《くわ》えるのがJavaScript《じゃばすくりぷと》の役割《やくわり》です。

JavaScript《じゃばすくりぷと》を使《つか》うと、ユーザーの操作《そうさ》に合《あ》わせてサイトの表示《ひょうじ》を変《か》えることができます。ただ情報《じょうほう》を読《よ》むだけのページから、ユーザーといっしょに動《うご》く「体験《たいけん》」へと変《か》えることができる、とても大切《たいせつ》な技術《ぎじゅつ》です。

JavaScript《じゃばすくりぷと》でできること

JavaScript《じゃばすくりぷと》を使《つか》って、以下《いか》のような動《うご》きを作《つく》ることができます：

  • チェックする： フォームに入力《にゅうりょく》されたデータが正《ただ》しいか確認《かくにん》します。
  • 動《うご》かす： ボタンをクリックしたときに、何《なに》かを実行《じっこう》します。
  • 計算《けいさん》する： ゲームの点数《てんすう》や、数字《すうじ》の計算《けいさん》を行《おこな》います。
  • デザインを変《か》える： スタイル（色《いろ》や大《おお》きさ）を自由《じゆう》に変《か》えます。
  • アニメーション： 画像《がぞう》や文字《もじ》をスムーズに動《うご》かします。

JavaScript《じゃばすくりぷと》の全体像《ぜんたいぞう》が分《わ》かったところで、次《つぎ》はコードを書くために必要《ひつよう》な「基本《きほん》の道具《どうぐ》」を見《み》ていきましょう。

2. プログラミングの「基本《きほん》の道具箱《どうぐばこ》」

プログラムを作《つく》ることは、いくつかの道具《どうぐ》を組《く》み合《あ》わせて「命令《めいれい》」を作《つく》ることです。
JavaScript《じゃばすくりぷと》を動《うご》かすための大切《たいせつ》な4つの道具《どうぐ》を説明《せつめい》します。

主要《しゅよう》な概念《がいねん》（考《かんが》え方《かた》）

  1. 変数《へんすう》 (Variables)： データを一時的《いちじてき》に入《い》れておく「入《い》れ物《もの》（箱《はこ》）」です。名前《なまえ》をつけて、数字《すうじ》や文字《もじ》を保存《ほぞん》します。
  2. 関数《かんすう》 (Functions)： いくつかの命令《めいれい》を一《ひと》つにまとめた「コードのまとまり」です。一度《いちど》作《つく》れば、何度《なんど》でも同《おな》じ命令《めいれい》を使《つか》うことができます。
  3. 条件《じょうけん》分岐《ぶんき》 (Conditionals)： 「もし〜ならAをする。そうでなければBをする」という「判断《はんだん》の仕組《しく》み」です。
  4. イベント (Events)： 「ボタンをクリックした」など、ブラウザで起《お》きる「きっかけ」です。

3. 実践《じっせん》：ウェブサイトにJavaScript《じゃばすくりぷと》を入《い》れる

HTML、CSS、JavaScript《じゃばすくりぷと》の3つが「いっしょに働《はたら》く（連携《れんけい》する）」ことで、一《ひと》つの動《うご》くページが完成《かんせい》します。

設定《せってい》の手順《てじゅん》

  1. フォルダとファイルを作《つく》る： ウェブサイトのフォルダの中《なか》に scripts というフォルダを作《つく》り、その中《なか》に main.js という名前《なまえ》のファイルを作成《さくせい》します。
  2. HTMLとつなげる： HTMLファイルの <head> タグが終《お》わる直前《ちょくぜん》に、以下《いか》のコードを書《か》きます。

解説《かいせつ》： これはCSSを読《よ》み込《こ》む <link> と同《おな》じ役割《やくわり》です。これでHTMLにJavaScript《じゃばすくりぷと》の力《ちから》が加《くわ》わります。

要素《ようそ》を選《えら》んで動《うご》かす

JavaScript《じゃばすくりぷと》でHTMLを変《か》えるときは、
「まず場所《ばしょ》を選《えら》び、次《つぎ》に内容《ないよう》を変《か》える」 という順番《じゅんばん》で動《うご》きます。

let myHeading = document.querySelector('h1');
myHeading.textContent = 'Hello world!';
  • 1行目《いちぎょうめ》： document.querySelector('h1') で <h1> 要素《ようそ》を選《えら》び、myHeading という変数《へんすう》に入《い》れます。
  • 2行目《にぎょうめ》： 選《えら》んだ場所《ばしょ》の textContent（文字《もじ》の内容《ないよう》）を ‘Hello world!’ に書《か》き換《か》えます。

ヒント： コードの中《なか》に // を書《か》くと、その行《ぎょう》は「コメント（メモ）」になり、ブラウザは読《よ》み飛《と》ばします。

4. 応用《おうよう》：画像《がぞう》チェンジャーと条件《じょうけん》分岐《ぶんき》の考《かんが》え方《かた》

ユーザーが画像《がぞう》をクリックしたときに、別《べつ》の画像《がぞう》に切《き》り替《か》わる仕組《しく》みを作《つく》ってみましょう。
「もし今《いま》の画像《がぞう》がAならBに変《か》える」という 条件《じょうけん》分岐《ぶんき》の考《かんが》え方《かた》 を使《つか》います。

画像《がぞう》切《き》り替《か》えの手順《てじゅん》

  1. クリックされる画像《がぞう》をJavaScript《じゃばすくりぷと》で選《えら》ぶ。
  2. 画像《がぞう》がクリックされるのを「待《ま》つ（イベントハンドラー）」。
  3. クリックされたら、今《いま》の画像《がぞう》の場所《ばしょ》（src）を 確認《かくにん》 する。
  4. もし（if） それが1枚目《いちまいめ》なら、2枚目《にまいめ》に 変《か》える。
  5. そうでなければ（else） 1枚目《いちまいめ》に戻《もど》す。

実践《じっせん》コード

※ images フォルダの中《なか》に「photo1.jpg」「photo2.jpg」の2枚《にまい》が必要《ひつよう》です。

let myImage = document.querySelector('img');

myImage.onclick = function() {
  let mySrc = myImage.getAttribute('src');
  if (mySrc === 'images/images/photo1.jpg') {
    myImage.setAttribute('src', 'images/photo2.jpg');
  } else {
    myImage.setAttribute('src', 'images/photo1.jpg');
  }
}

解説《かいせつ》

  • myImage.onclick： 画像《がぞう》がクリックされたときに動《うご》くきっかけ
  • getAttribute： 今《いま》の画像《がぞう》の情報《じょうほう》を調《しら》べる道具《どうぐ》
  • setAttribute： 新《あたら》しい画像《がぞう》に変《か》える道具《どうぐ》
  • if…else： 条件《じょうけん》に応《おう》じて動作《どうさ》を分《わ》ける仕組《しく》み
