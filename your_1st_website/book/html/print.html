初めてのウェブサイト

I. はじめてのウェブサイト

1. はじめに

ウェブ開発かいはつの世界せかいへようこそ

みなさん、こんにちは！ ウェブサイトを作つくってみたいと思おもったことはありますか？ 今いまの社会しゃかいでは、自分じぶんの考かんがえや情報じょうほうを世界せかいに伝つたえるために、ウェブサイトを作つくる技術ぎじゅつはとても大おおきな力ちからになります。

特とくに留学生りゅうがくせいのみなさんにとって、ウェブサイトは「言葉ことばの壁かべ」をこえるための強つよい味方みかたです。完全かんぜんな日本語にほんごを話はなすのが難むずかしくても、ウェブサイトなら写真しゃしんやデザイン、図ずを使つかって、あなたの魅力みりょくや才能さいのうを視覚しかく的てきに伝つたえることができます。

「ウェブ開発かいはつはむずかしそう……」と感かんじるかもしれません。確たしかに、Facebook（フェイスブック）のような複雑ふくざつなサイトを、いきなり一人ひとりで作つくることは難むずかしいです。しかし、安心あんしんしてください。自分じぶんだけのシンプルなウェブサイトなら、少すこしずつ進すすむことで、誰だれでも作つくることができます。

このガイドでは、ウェブサイトがどのように動うごいているのか、そしてどうすれば自分じぶんの作品さくひんを世界せかいに広ひろめることができるのかを、やさしく解説かいせつします。自分じぶんで情報じょうほうを広ひろめる力ちからを身みにつけることは、将来しょうらいの仕事しごとや自分じぶんを表現ひょうげんするために、必かならず素晴すばらしいプラスになるはずです。

準備じゅんびはいいですか？ まずは、スタートするために必要ひつようなものを確認かくにんしましょう。

Note

この資料しりょうはMDNの「Your first website」をやさしい日本語にほんごにしたものです。

2. 準備じゅんびするもの

スタートラインに立たつ

実際じっさいにコード（コンピュータへの命令めいれい）を書かき始はじめる前まえに、自分じぶんのコンピュータで作業さぎょうができる準備じゅんびをすることが大切たいせつです。これを「環境かんきょう構築こうちく / パソコンでサイトを作つくるための準備じゅんび」と呼よびます。

まず、以下いかの3つのことがスムーズにできるか確認かくにんしてください。

  1. OS（オペレーティングシステム）の操作そうさ： WindowsやmacOSなどの基本きほん的な使つかい方かたがわかる。
  2. ファイルシステムの理解りかい： ファイルを保存ほぞんしたり、フォルダを作つくって整理せいりしたりできる。
  3. ブラウザの利用りよう： インターネットで検索けんさくをしたり、サイトを見みたりできる。

Note

「2. ファイルシステムの理解りかい」に自信じしんのない人ひとは、補足ほそく資料しりょう集しゅうの「ファイルとフォルダの基本きほん」を見みてください

次つぎに、以下いかの「道具どうぐ」を用意よういしましょう。

  • コードエディター： プログラムのコードを書かくための専用せんようソフトです。Visual Studio Codeを使つかいます。すでに皆みなさんのPCにインストールされています。
  • ウェブブラウザ： 主おもにGoogle Chrome を使つかいます。こちらもんストール済ずみです。

道具どうぐがそろったら、次つぎは「どんなサイトを作つくるか」という計画けいかくを立たてるステップです。

3. 計画けいかくを立たてる

サイトの見みた目めを決きめる

いきなりコードを書かき始はじめるのは、設計図せっけいずなしで家いえを建たてるようなものです。まずは「計画けいかく」から始はじめましょう。最初さいしょにしっかり計画けいかくを立たてることで、作業さぎょうの途中とちゅうで迷まよわなくなり、結果けっかとして「情報じょうほうの整理せいりされた見みやすいサイト」を作つくることができます。

計画けいかくを立たてるときは、以下いかのポイントを整理せいりしてみてください。

  • どんな情報じょうほうを載のせるか： 誰だれに、何なにを伝つたえたいですか？（自己紹介じこしょうかい、趣味しゅみの紹介しょうかいなど）
  • どんなフォントや色いろを使つかうか： 明あかるいイメージですか？ それともクールで落おち着ついたイメージですか？

見みた目めのイメージが固かたまったら、いよいよサイトの「中身なかみ（文章ぶんしょう）」と「形かたち」を作つくっていく段階だんかいに入はいります。

Note

見みた目め: 外そとから見みた物事ものごとのありさま （例れい その車くるまは 見みた目め は美うつくしいが中身なかみは壊こわれている）

4. サイトの「3つの要素ようそ」

HTML、CSS、JavaScript

ウェブサイトは、主おもに3つの技術ぎじゅつが組くみ合あわさってできています。これを「家いえづくり」に例たとえて見みてみましょう。

技術名ぎじゅつめい役割やくわり（家いえの例たとえ）詳くわしい説明せつめい
HTML構造こうぞう段落だんらく、リスト、画像がぞうなど、コンテンツの「意味いみ」や「土台どだい」を作つくります。
CSS見みた目め（かざり）色いろ、サイズ、配置はいち、背景はいけいなど、サイトを「美うつくしく」整ととのえます。
JavaScript動うごきボタンの反応はんのう、アニメーション、ゲームなど「便利べんりな機能きのう」を加くわえます。

これらの技術ぎじゅつは、どれか一ひとつ欠かけてもうまくいきません。たとえば、HTMLだけでは文字もじが並ならんでいるだけで読よみにくく、CSSがないとデザインがバラバラになります。また、JavaScriptがないと動うごきのない静しずかなサイトになってしまいます。

これらを正ただしく組くみ合あわせることで、ユーザーにとって「読よみやすく」「使つかいやすく」「楽たのしい」ウェブサイトが完成かんせいするのです。

Note

段落だんらく：長ながい文章ぶんしょうを内容ないようなどから分わけた、言葉ことばの集あつまり

Note

リスト：複数ふくすうの項目こうもくや要素ようそを集あつめたもの

Note

画像がぞう：写真しゃしんや絵えなど

5. 世界せかいへ公開こうかいする

パブリッシング

自分じぶんのパソコンで作つくったファイルは、そのままでは自分じぶんにしか見みることができません。これをインターネット上じょうにアップロードして、世界中せかいじゅうの誰だれでも見みられる状態じょうたいにすることを「公開こうかい（パブリッシング）」と言いいます。

公開こうかいの手順てじゅんをシンプルにまとめると、以下いかのようになります。

  1. コードを書かき終おえる： HTML、CSS、JavaScriptを完成かんせいさせます。
  2. ファイルを整理せいりする： 画像がぞうやコードのファイルを正ただしいフォルダにまとめます。
  3. オンラインにアップロードする： 「サーバー」と呼よばれる、インターネット上じょうの場所ばしょへファイルを送おくります。

Note

授業じゅぎょうでは、このステップは実施じっししません。興味きょうみのある方かたは、ここをクリックしてMDNの関連かんれんサイトを参照さんしょうしてください。

6. まとめと次つぎのステップ

ここまで、ウェブサイト制作せいさくの全体像ぜんたいぞうを見みてきました。ウェブ開発かいはつの学習がくしゅうは、一度いちどで完璧かんぺきにする必要ひつようはありません。小ちいさな「できた！」を積つみ重かさねていくプロセスそのものが大切たいせつです。

II. デザインと計画けいかくのガイドブック

ウェブサイトを作つくるとき、いきなりパソコンでコード（プログラムの言葉ことば）を書かき始はじめるのは、おすすめしません。まずは「計画けいかく（プランニング）」をしましょう。

このガイドブックでは、ウェブ開発かいはつの専門家せんもんかが、留学生りゅうがくせいのみなさんにも分わかりやすい「やさしい日本語にほんご」で、サイト作づくりの準備じゅんびについて教おしえます。

1. はじめに：なぜ「計画けいかく」が大切たいせつなのか

家いえを建たてるときに「設計図せっけいず」が必要ひつようなように、ウェブサイトにも計画けいかくが必要ひつようです。コードを書かく前まえに計画けいかくを立たてるのには、大おおきな理由りゆうがあります。

  • 「作つくり直なおし」をふせぐ： 何なにも決きめずに作つくると、あとで「やっぱり違ちがう！」となって、時間じかんをむだにしてしまいます。
  • 最後さいごまで完成かんせいできる： 最初さいしょにやることを決きめると、迷まよわずに最後さいごまで作つくることができます。

計画けいかくを立たてることは、プロのエンジニアも一番いちばん大切たいせつにしているステップです。

2. ウェブサイトの目的もくてきを整理せいりする

最初さいしょのプロジェクトでは、内容ないようを「シンプル」にすることが成功せいこうのヒミツです。大おおきすぎる目標もくひょうを立たてると、途中とちゅうで嫌いやになって諦あきらめてしまうからです。

まずは、次つぎの3つの質問しつもんに答こたえてみましょう。

  1. このサイトは何なにについてのサイトですか？（例れい：好すきな犬いぬについて、旅行りょこうしたニューヨークについて、パックマン（Pac-Man）についてなど）
  2. どんな情報じょうほうを紹介しょうかいしますか？（ウェブサイトの名前なまえを決きめましょう。そして、1つの「見出みだし（タイトル）」、1つの「画像がぞう」、2〜3個この「段落だんらく（短みじかい文章ぶんしょう）」を考かんがえてください）
  3. どんな見みた目めのサイトにしますか？（背景はいけいは何色なにいろがいいですか？ 文字もじの形かたちは「まじめ」ですか？ それとも「かわいい」ですか？」）

専門家せんもんかの知恵ちえ：デザインガイド

大おおきなプロジェクトでは、「デザインガイド（デザインシステム）」というルールブックを作つくります。例たとえば、Firefoxには「Firefox Acorn Design System」という有名ゆうめいなガイドがあります。これを見みると、プロがどうやって「色いろ」や「文字もじ」のルールを統一とういつして、きれいに見みせているかが分わかります。

目的もくてきが決きまったら、次つぎはそれを絵えに描かいてみましょう。

Note

「プロジェクト」は一ひとつのウェブサイトやアプリケーションを作つくるための計画けいかく、あるいは、その計画けいかくに関かかわる人々ひとびとのグループのことです。そうした計画けいかくのためのデジタル素材そざいやソースコードなどをまとめたものを指さすこともあります。

3. デザインのスケッチ：見みた目めのイメージを作つくる

ペンと紙かみを使つかって、サイトの形かたちを自由じゆうに描えがいてみましょう。これを「スケッチ」と言いいます。

プロも、最初さいしょはパソコンを使つかわず、紙かみに書かくことから始はじめます。ここで大切たいせつなのは、「完璧かんぺきを目指めざさないこと」 です。有名ゆうめいな画家がかのゴッホ（Van Gogh）のように上手じょうずに描かく必要ひつようはありません。どこにタイトルがあり、どこに画像がぞうがあるか、自分じぶんが分わかれば十分じゅうぶんです。

また、ウェブ制作せいさくの現場げんばには、2つの役割やくわりがあります。

デザイナーの種類しゅるいどんな仕事しごとをする人ひと？
グラフィックデザイナーウェブサイトの 見みた目めを きれいに デザインする 人ひと
UXデザイナーユーザーが ボタンを 押おしやすくしたり、情報じょうほうを 見みつけやすくしたりする 人ひと

今いまは、あなたがこの両方りょうほうの仕事しごとをします。自分じぶんのアイデアを自由じゆうに紙かみに書かいてみてください。

4. テーマカラー（色いろの名前なまえとコード）を決きめる

サイトの印象いんしょうを決きめる「色いろ」を選えらびましょう。

  1. 色いろを選えらぶ： カラーピッカーなどのツールで、背景はいけいに使つかいたい色いろを探さがします。
  2. コードをメモする： 色いろを選えらぶと、#660066 のような「6つの英数字えいすうじ」が表示ひょうじされます。これを 16進数しんすうコード（hex code／ヘックスコード） と呼よびます。

Note

16進数しんすうコード（hex code）とは コンピュータが「この色いろです！」と正ただしく理解りかいするための専用せんようの番号ばんごうです。あとでコードを書かくときに使つかうので、必かならずメモしておきましょう。

5. 画像がぞうの準備じゅんび：ルールを守まもって探さがす方法ほうほう

インターネットにある画像がぞうには「持もち主ぬし」があります。これを 著作権ちょさくけん（コピーライト） と言いいます。勝手かってに使つかうと法律ほうりつのトラブルになることがあるので、注意ちゅういしてください。

「自由じゆうに使つかってもいい画像がぞう」をGoogleで探さがす方法ほうほうは、次つぎの通とおりです。

  1. Google画像がぞう検索けんさくを使つかう： 好すきな言葉ことばで検索けんさくします。
  2. ツールを使つかう： 検索結果けんさくけっかの画面がめんにある「ツール」ボタンをクリックします。
  3. ライセンスを選えらぶ： その下したに表示ひょうじされる「使用権しようけん」をクリックし、「クリエイティブ・コモンズ ライセンス」を選えらびます。
  4. 保存ほぞんする： 好すきな画像がぞうを見みつけたら、右みぎクリック（Macは Ctrl + クリック）をして、「名前なまえを付つけて画像がぞうを保存ほぞん」を選えらびます。

6. フォント（文字もじの形かたち）の選択せんたく

フォントには2つのタイプがあります。

  • ウェブセーフフォント： どのパソコンにも最初さいしょから入はいっている安心あんしんなフォントです（例れい：Arial, Times New Roman）。
  • Google Fonts： デザイン性せいが高たかいフォントを無料むりょうで借かりられるサービスです。

ここでは、Google Fontsを使つかう手順てじゅんを説明せつめいします。

  1. Google Fontsへ行いく： サイトのイメージに合あうフォントを探さがします。
  2. コードを取得しゅとくする： 好すきなフォントを選えらび、「Get font」ボタンを押おしてから、「Get embed code（埋うめ込こみコードを取得しゅとく）」をクリックします。
  3. 2つのコードを保存ほぞんする： 画面がめんに表示ひょうじされた 2つのコードブロック（2つのまとまったコード） を両方りょうほうともコピーして、メモ帳ちょうなどに保存ほぞんしてください。フォントを動うごかすには、この2つが両方りょうほう必要ひつようです。

⚠️ 注意ちゅうい：商業利用しょうぎょうりようについて フォントにもライセンスがあります。勉強べんきょうで使つかうのは大丈夫だいじょうぶですが、将来しょうらい、仕事しごとでサイトを作つくるときは、必かならず「商売しょうばい（ビジネス）で使つかってもいいか」を確認かくにんしましょう。

7. まとめと次つぎのステップ

お疲つかれさまでした！これで「サイトの設計図せっけいず」と「素材そざい」がすべて揃そろいました。

  • 計画けいかく： どんな内容ないようにするか決きめた。
  • スケッチ： レイアウトを紙かみに書かいた。
  • 素材そざい： 色いろのコード、画像がぞう、フォントの準備じゅんびができた。

しっかりとした「土台どだい」ができたので、次つぎのステップである「HTMLやCSSを書かく作業さぎょう」を、自信じしんを持もって進すすめることができます。

準備じゅんびはバッチリです。さあ、次つぎは実際じっさいにコンピュータで、あなただけのウェブサイトを形かたちにしていきましょう！

III. ウェブサイトの形かたちを作つくろう

ウェブサイトを作つくるための 最初さいしょの一歩いっぽへ ようこそ！ プログラミングや ウェブ制作せいさくを 始はじめるとき、 最初さいしょに 覚おぼえるのが「HTML」です。

HTMLは ウェブサイトの「骨組ほねぐみ」、つまり 構造こうぞうを 作つくるための 言葉ことばです。この 基本きほんを 正ただしく 知しることは、ウェブサイトを 作つくる プロぷろ（仕事しごとを する 人ひと）に なるために、とても 大切たいせつなことです。

Note

「骨組ほねぐみ」は、もとは「からだの骨ほねの組くみ立たて」のことですが、そこからの「例たとえ」で、建造物けんぞうぶつ・機械きかいなどの基礎きそ的てきな構造こうぞうの部分ぶぶんのことも指さします。

1. HTMLとは何なに？：ウェブの基本きほんを理解りかいする

HTML（HyperText Markup Language） は、テキスト（文字もじ）に「印しるし」を つけて、ウェブサイトの 構造こうぞうを 作つくるための「マークアップ言語げんご」です。

HTMLの 役割やくわりを わかりやすく 例たとえると、「荷物にもつに ラベルを 貼はる 作業さぎょう」 に 似にています。ただの テキストに「これは 見出みだしです」「これは 段落だんらくです」という ラベルを 貼はることで、ブラウザ（Google Chromeなど）が その意味いみを 理解りかいできるようになります。

  • 要素ようそ / Elementとは： テキストを「タグ」と 呼よばれる 記号きごうで 囲かこんだ セットのことです。
  • ブラウザへの 伝言でんごん： タグを 使つかうことで、ブラウザに「ここから ここまでが 段落だんらくだ」と 伝つたえることができます。

HTMLを 使つかう 理由りゆう： もし HTMLが なければ、すべての 文字もじが 一行いちぎょうに つながってしまい、とても 読よみにくくなります。また、目めが 見みえにくい 人ひとが 使つかう「音声おんせい読よみ上あげソフト」も、どこが 大事だいじな 場所ばしょなのか わからなくなってしまいます。HTMLで 正ただしく 構造こうぞうを 作つくることで、誰だれにでも 意味いみが 伝つたわる ページに なります。

2. HTMLファイルの基本きほんの形かたち

ウェブページを 正ただしく 動うごかすためには、決きまった「型かた」が 必要ひつようです。

主要しゅような 構成要素こうせいようそ

MDNの ルールに 基もとづいた、基本きほん的てきな パーツは 以下いかの 通とおりです。

  • <!doctype html>：ページを 正ただしく 表示ひょうじさせるために、ファイルの いちばん 上うえに 書かかなければならない ルールです。
  • <html>：ページの すべての 内容ないようを 包つつむ「 いちばん 外側そとがわの 箱はこ」です。
  • <head>：画面がめんには 見みえないけれど、ブラウザや 検索けんさくエンジンのための 大切たいせつな 情報じょうほう（情報じょうほう/メタデータ）を 入いれる 場所ばしょです。
  • <title>：ブラウザの「タブ」に 出でる 名前なまえや、ブックマーク（お気きに入いり）したときの 名前なまえになります。
  • <body>：実際じっさいに ユーザーが 見みる コンテンツ（文章ぶんしょうや 画像がぞうなど）を すべて 入いれる 場所ばしょです。

メタデータ（大切たいせつな 設定せってい）の 価値かち

<head>の 中なかには、以下いかの ような 設定せっていを 書かきます。

  • 文字もじコード（UTF-8）： これを 書かかないと、日本語にほんごなどが 変へんな 記号きごうに なる「文字化もじばけ」が 起おきることが あります。
  • ビューポート（viewport）： スマートフォンの 画面がめんサイズに 合あわせて、きれいに 表示ひょうじするために 必要ひつようです。

タグの 構造こうぞう：入いれ子こ

HTMLは「タグの 中なかに 別べつの タグが 入はいる」という「入いれ子こ」の 形かたちに なります。

<html> <!--一番外側の箱-->
  <head> <!--ブラウザのための情報の箱-->
    <title> ページの名前 </title>
  </head>
  <body> <!--私たちが見る中身の箱-->
    <h1> タイトル </h1>
    <p> 文章の 段落（だんらく） </p>
  </body>
</html>

Note

「入いれ子こ」: 大おおきな箱はこの中なかに小ちいさな箱はこが入はいっている、というように、あるものの中なかに、よく似にたあるものが入はいっている様子ようすを指さす日本語にほんごです。

3. テキストに意味いみをつける：見出みだし、段落だんらく、リスト

文章ぶんしょうを 分わかりやすくするために、適切てきせつな タグを 使つかいます。

  • 見出みだし（<h1>〜<h6>）： 本ほんの「タイトル」や「章しょう」の ように、情報じょうほうの 優先順位ゆうせんじゅんいを 示しめします。<h1>が もっとも 重要じゅうような タイトルで、数字すうじが 大おおきくなるほど 小ちいさな 見出みだしに なります。
  • 段落だんらく（<p>）： ふつうの 文章ぶんしょうを まとめるための タグです。
  • リスト（箇条書かじょうがき）：
    • <ul>（順序じゅんじょなし リスト）： 買かい物ものリストの ように、順番じゅんばんが 関係かんけいないときに 使つかいます。
    • <ol>（順序じゅんじょあり リスト）： 料理りょうりの 手順てじゅんの ように、順番じゅんばんが 大切たいせつなときに 使つかいます。
    • ※どちらも、中身なかみの 項目こうもくは <li> タグで 囲かこみます。

HTMLコメント（<!-- -->）の メリット： コードの 中なかに <!-- メモ --> と 書かくと、ブラウザには 表示ひょうじされません。これは「自分じぶんや 仲間なかま」のための メモです。あとで 見直みなおしたときに、何なにをしたのか すぐに 分わかるように なります。

4. 画像がぞうを 表示ひょうじする：<img>要素ようその使つかい方かた

画像がぞうを 表示ひょうじするには <img> 要素ようそを 使つかいます。

  • src属性ぞくせい： 画像がぞうが ある 場所ばしょ（パス）を 指定していします。
  • alt属性ぞくせい： 画像がぞうの 説明せつめいを 文字もじで 書かきます。
    • 重要性じゅうようせい： 目めが 不自由ふじゆうな 人ひとが 使つかう ソフトが この文字もじを 読よみ上あげます。また、画像がぞうが エラーで 出でないときにも 代かわりに 表示ひょうじされます。
    • 良よい 例れい： alt=“Firefoxのロゴ：地球ちきゅうを包つつむ燃もえるキツネ” の ように、何なにが 書かいてあるか 具体的ぐたいてきに 書かくのが 正ただしい 使つかい方かたです。

空要素からようそ / void element： <img> は 文章ぶんしょうを 囲かこまないので、終おわりの タグ（</img>）が いりません。これを「空要素からようそ」と 呼よびます。

ファイル管理かんりのアドバイス： 画像がぞうは images/ という 名前なまえの フォルダを 作つくって、その中なかに 入いれましょう。HTMLからは src="images/写真の名前.jpg" の ように 指定していします。こうすることで、たくさんの ファイルを きれいに 整せいりできます。

5. リンクを作つくってページをつなぐ：<a>要素ようそ

ウェブ（蜘蛛くもの巣す：くものす）の 名前なまえの とおり、ページどうしを つなぐのが「リンク」です。

リンクの作つくり方かた

  1. リンクに したい テキストを 選えらびます。
  2. その テキストを <a> タグで 囲かこみます。
  3. href 属性ぞくせいに、行いきたい 先さきの アドレス（URL）を 書かきます。
<a href="https://www.mozilla.org/">Mozillaのウェブサイト</a>

大切たいせつな 注意点ちゅういてん： アドレスを 書かくときは、必かならず https:// などの 通信つうしんの ルール（プロトコル） から 書かき始はじめてください。これがないと、リンクが 正ただしく 動うごきません。また、リンクにする 言葉ことばは「ここを クリック」ではなく「Mozillaの ウェブサイト」の ように、どこに 行いくのか わかる 言葉ことばを 選えらびましょう。

6. まとめ：自分じぶんのウェブサイトを作つくってみよう

「構造こうぞう（HTML）」「テキスト」「画像がぞう」「リンク」が 組くみ合あわさることで、一ひとつの ページが 完成かんせいします。

初心者しょしんしゃのための チェックリスト

公開こうかいする 前まえに、これを 確認かくにんしましょう：

  • タグの 閉とじ忘わすれは ありませんか？（<img> 以外いがい、終おわりのタグが 必要ひつようです）
  • ファイルの名前なまえは 正ただしいですか？（大文字おおもじと 小文字こもじの 間違まちがいは ありませんか？ Index.html と index.html は 違ちがいます）
  • 画像がぞうの パス（フォルダの場所ばしょ）は 正ただしいですか？（images/ フォルダの 中なかに 画像がぞうが ありますか？）
  • リンクの https:// を 忘わすれていませんか？
  • alt属性ぞくせいは わかりやすく 書かきましたか？

次つぎのステップ： HTMLで 形かたちが できたら、次つぎは 「CSS」 を 学まなんで 色いろや デザインを きれいに しましょう。さらに 「JavaScript」 を 使つかえば、動うごきのある ページに なります。

IV. ウェブサイトをデザインするCSS

1. はじめに：CSSとは何なんでしょうか？

ウェブサイトを作つくるとき、文字もじや画像がぞうなどの「内容ないよう」を準備じゅんびするだけでは、まだデザインが完成かんせいしていません。そこで使つかわれるのが CSS（シーエスエス） です。

CSSは、ウェブサイトの「見みた目め」を整ととのえるための専用せんようの言葉ことばです。HTMLで作成さくせいした文章ぶんしょうに色いろをつけたり、大おおきさを変えたり、好すきな場所ばしょに並ならべたりすることができます。

HTML（内容）とCSS（スタイル）の違ちがい

ウェブサイトは、主おもに2つの役割やくわりが組くみ合あわさってできています。

  • HTML（内容ないよう）： 「ここにタイトルがある」「ここに文章ぶんしょうがある」という、サイトの骨組ほねぐみ（土台どだい）を作つくります。
  • CSS（スタイル）： 「タイトルを青色あおいろにする」「文章ぶんしょうの横幅よこはばを600ピクセルにする」といった、見みた目めを美うつくしく飾かざります。

CSSを使つかってデザインを整ととのえることで、ウェブサイトはもっと読よみやすくなり、訪おとずれた人ひとに「使つかいやすい」と感かんじてもらえるようになります。

CSSの定義ていぎ

  • スタイルシート言語げんご： プログラミング言語げんごではなく、見みた目めを指定していするための特別とくべつな言葉ことばです。
  • 要素ようその装飾そうしょく： HTMLで書かかれた特定とくていの場所ばしょを選えらんで、見みた目めを変えることができます。

次つぎのセクションでは、CSSを実際じっさいにどうやって書かくのか、その基本きほんルールを学まなびましょう。

2. CSSの書かき方かた（構文こうぶん）を覚おぼえましょう

CSSを書かくときには、決きまった形かたち（構文こうぶん）があります。「どこの」「何なにを」「どう変えるか」という順番じゅんばんで指示しじを書かきます。

CSSを構成こうせいするパーツ

CSSは、以下いかのパーツを組くみ合あわせて作つくります。

  1. セレクター（選えらびたい場所ばしょ）： デザインを変えたいHTMLの要素ようそを指定していします。
  2. プロパティ（変かえたい項目こうもく）： 色いろ、大おおきさ、場所ばしょなど。
  3. 値あたい（設定せっていする内容ないよう）： 具体的ぐたいてきにどんな色いろにするか、どれくらいの大おおきさにするかを決きめます。

宣言せんげんとルールセット

CSSでは、プロパティと値あたいを組くみ合あわせたペアを 「宣言せんげん」 と呼よびます。また、セレクターと { } で囲かこまれた複数ふくすうの宣言せんげんをまとめたものを「ルールセット（Ruleset）」と呼よびます。

書かき方かたのルールとコード例れい

プロパティの後あとには必かならずコロン : を、値あたいの後あとには必かならずセミコロン ; を書かきます。

p {
  color: red; /* 宣言1：文字の色（プロパティ）を赤（値）にします */
  font-size: 16px; /* 宣言2：文字の大きさ（プロパティ）を16ピクセル（値）にします */
}

書かき方かたを理解りかいしたら、次つぎはCSSをHTMLに読よみ込こませる方法ほうほうを確認かくにんしましょう。

3. HTMLにCSSを読よみ込こませる方法ほうほう

CSSを書かくだけでは、ウェブサイトにデザインは反映はんえいされません。HTMLとCSSを正ただしくつなぐ手順てじゅんが必要ひつようです。

正確せいかくな設定せっていが大切たいせつな理由りゆう

ウェブサイトを作つくるときは、ファイルを整せいりするために styles という名前なまえのフォルダを作つくり、その中なかに style.css を作成さくせいします。

HTMLファイルの <head> （ヘッド：サイトの設定せっていを書く場所ばしょ）内ないに、以下いかの1行を書きます。

<link href="styles/style.css" rel="stylesheet" />

【トラブルを避さけるポイント】
フォルダ名めいやファイル名めいが1文字もじでも間違まちがっていると、デザインは全まったく表示ひょうじされません。
styles/style.css という「道みちすじ（パス）」が実際じっさいのフォルダ構成こうせいと合あっているか慎重しんちょうに確認かくにんしましょう。

4. 文字もじのデザインをきれいにする（フォントとテキスト）

文字もじの見みた目めは、サイトを訪おとずれる人ひとの「読よみやすさ」に大おおきな影響えいきょうがあります。適切てきせつなフォント選びは、サイトを信頼しんらいできる印象いんしょうにするための戦略せんりゃくです。

Google Fonts の利用りよう

標準ひょうじゅんのフォント以外いがいを使つかいたいとき、Google Fonts のサービスを使つかいます。HTML の <head> に 自分のstyle.cssより前 に読よみ込こませます。

<!-- Google Fontsの読み込み例（自分のCSSより前に書きます） -->
<link href="https://fonts.googleapis.com/css?family=Open+Sans" rel="stylesheet" />
<link href="styles/style.css" rel="stylesheet" />

読よみやすさを高たかめるプロパティ

  • font-family： フォントの種しゅ類
  • font-size： 文字もじの大おおきさ
  • text-align： 文ぶんを中なか央に寄よせる
  • line-height： 行間ぎょうかん
  • letter-spacing： 文も字の間隔かんかく

5. すべては「箱はこ（ボックス）」でできている

CSS の世界せかいでは、すべての要素ようそ（見出みだし・文章ぶんしょう・画像がぞうなど）は「箱はこ」の中なかにあると考かんがえます。これを ボックスモデル と呼よびます。

要素ようそやさしい説明せつめい
Content文もん字や画が像が入る中心部
Padding中身なかみと枠線わくせんの内側うちがわの余白よはく
Border枠線わくせんそのもの
Margin枠線わくせんの外側そとがわの余白よはく

6. ページぺーじ全体ぜんたいのレイアウトを整ととのえる（色いろと配置はいち）

背景はいけいに色いろをつけ、body の幅はばを600pxにし、中なか央寄せする典型てんけい的な設定せっていです。

html {
  background-color: #00539F; /* ページ全体の背景を青にします */
}

body {
  width: 600px; /* 全体の幅を600ピクセルに固定します */
  margin: 0 auto; /* 上下は0、左右は「自動（auto）」で分けて中央に寄せます */
  background-color: #FF9500; /* bodyの背景を赤みのあるオレンジにします */
  padding: 0 20px 20px 20px; /* 内側に余白を作ります */
  border: 5px solid black; /* 黒い枠線で囲みます */
}

margin: 0 auto; の仕組しくみ：
ブラウザが左右の空きを半分ずつ割り当て、body が中なか央に配置されます。

タイトルに影かげをつける

h1 {
  text-shadow: 3px 3px 1px black; /* 横に3px、縦に3px、ぼかし1px、黒い影 */
}

画像がぞうを中ちゅう央に置く

img {
  display: block; /* 画像を「ボックス」として扱うように変えます */
  margin: 0 auto; /* これで中央に寄るようになります */
}

7. おわりに：素敵すてきなウェブサイトを作つくるために

CSS の基礎きそは、将来しょうらいのアニメーションや高度レイアウトの土台どだいになります。

  1. 値あたいを変えて効果を確認
  2. 他サイトを箱はことして観察
  3. 1項目ずつ保存しながら確認

楽たのしみながら、美しいサイトを完成させてください！

V. ウェブサイトを動うごかすJavaScript

ウェブサイトを見みたときに、ボタンを押おして画面がめんが変かわったり、画像がぞうが動うごいたりすることはありませんか？
それは「JavaScript」という言葉ことばが働はたらいているからです。

このガイドでは、プログラミングが初はじめての人ひとや、日本語にほんごを勉強べんきょう中の留学生りゅうがくせいにも分わかりやすく、JavaScriptの基本きほんを説明せつめいします。

1. はじめに：JavaScriptとは何なにか

ウェブサイトを作つくるとき、HTMLは「骨組ほねぐみ」を、CSSは「見みた目め」を作つくります。そこに「動うごき」を加くわえるのがJavaScriptの役割やくわりです。

JavaScriptを使つかうと、ユーザーの操作そうさに合あわせてサイトの表示ひょうじを変かえることができます。
ただ情報じょうほうを読むだけのページから、ユーザーといっしょに動うごく「体験たいけん」へと変えることができる、とても大切たいせつな技術ぎじゅつです。

JavaScriptでできること

JavaScriptを使つかって、以い下のような動うごきを作つくることができます：

  • チェックする： フォームに入力にゅうりょくされたデータが正ただしいか確認かくにんします。
  • 動うごかす： ボタンをクリックしたときに、何なにかを実行じっこうします。
  • 計算けいさんする： ゲームの点数てんすうや、数字すうじの計算けいさんをおこないます。
  • デザインを変かえる： スタイル（色いろや大おおきさ）を自由じゆうに変かえます。
  • アニメーション： 画像がぞうや文字もじをスムーズに動うごかします。

2. プログラミングの「基本きほんの道具箱どうぐばこ」

プログラムを作つくるとは、いくつかの道具どうぐを組くみ合あわせて「命令めいれい」をつくることです。JavaScriptを動うごかす4つの大切たいせつな概念がいねんがあります。

  1. 変数へんすう (Variables)： データを一時的いちじてきに入いれておく「入いれ物もの」。
  2. 関数かんすう (Functions)： いくつかの命令めいれいをまとめた便利べんりなセット。
  3. 条件分岐じょうけんぶんき (Conditionals)： 「もし〜ならA、そうでなければB」。
  4. イベント (Events)： 「クリックされた」などの動作どうさのきっかけ。

3. 実践じっせん：ウェブサイトにJavaScriptを入いれる

HTML、CSS、JavaScript の3つが連携れんけいしてページが動うごきます。

設定せっていの手順てじゅん

  1. scripts フォルダを作り、その中に main.js を作成します。
  2. HTMLファイルの <head> の終わる直前に次を書かきます：
<script src="scripts/main.js"></script>
  • CSSの <link> と同じ仕組みで、JavaScript を読よみ込みます。

要素ようそを選えらんで動うごかす

let myHeading = document.querySelector('h1');
myHeading.textContent = 'Hello world!';
  • 1行目： <h1> を選えらび、myHeading に入いれます。
  • 2行目： textContent を “Hello world!” に変かえます。

ヒント： // で書かいた行ぎょうはコメントとして無視むしされます。

4. 応用おうよう：画像がぞうチェンジャーと条件分岐じょうけんぶんき

クリックで画像がぞうが入れ替わる仕組みです。

手順てじゅん

  1. 画像がぞうを JavaScript で選えらぶ
  2. クリックされるのを待つ
  3. 今の src を確認かくにん
  4. if 文で切り替える

実践じっせんコード

let myImage = document.querySelector('img');

myImage.onclick = function() {
  let mySrc = myImage.getAttribute('src');
  if (mySrc === 'images/images/photo1.jpg') {
    myImage.setAttribute('src', 'images/photo2.jpg');
  } else {
    myImage.setAttribute('src', 'images/photo1.jpg');
  }
}
  • myImage.onclick： クリック時のイベント
  • getAttribute： 現在の src を調べる
  • setAttribute： src を書き換える
  • if…else： 条件じょうけんで処理しょりを切り替え

  • HTML/CSS： ページの土台どだいと見みた目め
  • JavaScript： 動うごきを加える技術ぎじゅつ

JavaScript は ゆっくり学べば確実に身につきます。
MDNの教材（日本語 / 英語）もとても良い参考になります。

少しずつ練習して、ぜひあなたのオリジナルの動うごくウェブサイトを作つくってください！

補足ほそく資料しりょう集しゅう

「初はじめてのウェブサイト」を学まなぶ上うえで、補足ほそく・参考さんこうになる資料しりょうをまとめました。

ウェブ開発かいはつのためのファイルとフォルダの基本きほんガイド

ウェブサイトを作つくるとき、たくさんのファイルを使つかいます。このガイドでは、プロのエンジニアが最初さいしょに覚おぼえる「ファイルの整理せいり・整頓せいとん」のルールを、やさしく説明せつめいします。

1. はじめに：なぜファイルの整理せいりが大切たいせつなのか

ウェブサイトは、文字もじのデータ、プログラム、画像がぞうなど、多おおくのファイルで構成こうせいされています。これらのファイルは、お互たがいに呼よび出だし合あって動うごいています。

もしファイルがバラバラな場所ばしょにあると、ウェブサイトは正ただしく動うごきません。最初さいしょにしっかり整理せいりするルールを決きめることが、ウェブサイト作づくりを成功せいこうさせる一番いちばんの近道ちかみちです。

次つぎは、自分じぶんのパソコンのどこにファイルを作つくるべきか説明せつめいします。

2. ウェブサイトの場所ばしょを決きめよう

ウェブサイトのファイルは、一ひとつのフォルダにまとめて入いれます。このフォルダの中身なかみは、インターネット上じょうのコンピュータ（サーバー）に公開こうかいするときと「同おなじ形かたち」にする必要ひつようがあります。これを「ミラー（鏡かがみ）」と呼よびます。自分じぶんのパソコンで動うごくものは、サーバーでも同おなじように動うごかなければいけないからです。

おすすめのフォルダ階層かいそう

MDN（ウェブ開発かいはつの標準ひょうじゅん的な資料しりょう）では、次つぎのような作つくり方かたをすすめています。

(1). まず、すべてのプロジェクトを保存ほぞんする web-projects というフォルダを作つくります。

今回こんかいは、PC > ローカルディスク(C:) > ユーザー > student1 > source の下したにつくりましょう。

  1. ステータスバーの検索窓けんさくまどに「エクスプローラー」と入力にゅうりょくします。

  2. 左ひだりの「PC」の下したの「ローカルディスク(C:)」をクリックします。

  3. 右みぎの「ユーザー」をダブル クリックして、開ひらきます。

  4. 「student1」をダブル クリックして、開ひらきます。

  5. 「source」をダブル クリックして開ひらきます。

  6. 右みぎクリックして、「新規しんき作成さくせい」 →　「フォルダー」 をクリックします。

  7. 「新あたらしいフォルダー」を「web-projects」に書かき換かえます。

(2). すぐに見みつけられるように、クイックアクセスにピン留どめしましょう。

  1. 「web-projects」を一度いちどクリックしてから、右みぎクリックします。

  2. 「クイック アクセスにピン留どめする」をクリックします。

  3. 右みぎのクイック アクセスに「web-projects」が表示ひょうじされるのを確認かくにんします。

(3). 「web-projects」の中なかに個別こべつのサイト用のフォルダを作つくります。

  1. 5.6.と同おなじ手順てじゅんで、「test-site」というフォルダを作つくります。これが今回こんかいの個別こべつのサイト用のフォルダになります。

場所ばしょは、デスクトップやホームフォルダなど、自分じぶんですぐに見みつけられる場所ばしょにしてください。場所ばしょが決きまっていると、作業さぎょうのミスが減へり、開発かいはつのスピードが速はやくなります。

次つぎは、ファイルの名前なまえの付つけ方かたを説明せつめいします。

3. ファイル名めいとフォルダ名めいの絶対ぜったいルール

名前なまえを付つけるときは、世界中せかいじゅうのエンジニアが守まもっている「3つのルール」があります。

  1. すべて小文字こもじにする
    多おおくのサーバー（Linuxなど）は、大文字おおもじと小文字こもじを厳きびしく区別くべつします。MyImage.jpg と myimage.jpg は別べつのファイルだと判断はんだんされるため、大文字おおもじを使つかうとエラーの原因げんいんになります。
  2. 空白くうはく（スペース）を入いれない
    コマンドライン（文字もじで命令めいれいするツール）を使つかうとき、スペースがあるとコンピュータは「2つの別べつのファイル」だと勘違かんちがいしてしまいます。
  3. 言葉ことばを分わけるときはハイフン「-」を使つかう
    アンダースコア「_」も使つかえますが、ハイフンの方ほうがおすすめです。Googleなどの検索けんさくエンジンが、ハイフンを「単語たんごの区切くぎり」として正ただしく認識にんしきしてくれるからです。

次つぎは、フォルダの中なかに何なにを入いれるか説明せつめいします。

4. 標準ひょうじゅん的なフォルダの形かたち

ウェブ開発かいはつでは、誰だれが見みても中身なかみがわかるように、次つぎのような決きまった形かたちでフォルダを作つくります。

  • index.html：ウェブサイトの最初さいしょのページです。
  • images フォルダ：使つかう画像がぞうやイラストをすべて入いれます。
  • styles フォルダ：サイトのデザイン（色いろや形かたち）を決きめるCSSファイルを入いれます。
  • scripts フォルダ：サイトに動うごきをつけるJavaScriptファイルを入いれます。

この「標準ひょうじゅん的な形かたち」を使つかうと、他ほかの開発者かいはつしゃと一緒いっしょに働はたらくときに「どこに何なにがあるか」がすぐに伝つたわります。

次つぎは、Windowsを使つかっている人ひとが最初さいしょに行おこなうべき設定せっていについて説明せつめいします。

5. Windowsの設定せってい：拡張子かくちょうしを表示ひょうじする

Windowsでは、ファイルの種類しゅるいを表あらわす「.html」や「.jpg」などの拡張子かくちょうしが、既定きていの設定せっていでは隠かくれています。

しかし、開発かいはつでは拡張子かくちょうしが重要じゅうようです。.html ファイルなのか、設定せってい用の .env ファイル（ドットファイル）なのかを正ただしく判断はんだんするために、必かならず表示ひょうじさせてください。

拡張子かくちょうしを表示ひょうじする手順てじゅん

  1. フォルダ（エクスプローラー）を開ひらきます。
  2. 上うえにある [表示ひょうじ] タブ、または […] メニューから [オプション] を選えらびます。
  3. [表示ひょうじ] タブをクリックします。
  4. 詳細しょうさい設定せっていの中なかにある [登録とうろくされている拡張子かくちょうしは表示ひょうじしない] のチェックを外はずします。
  5. [OK] をクリックします。

最後さいごに、ファイル同士どうしをつなぐ「ファイルパス」について説明せつめいします。

6. ファイルパス：ファイル同士どうしをつなぐ道みち

「ファイルパス」は、あるファイルから別べつのファイルを探さがしにいくための「道みち」のことです。

書かき方かたのパターン

  • 同おなじ場所ばしょにあるとき index.html から同おなじフォルダのファイルを見る場合ばあい。 例れい：filename.jpg
  • 下したのフォルダにあるとき index.html から images フォルダの中なかのファイルを見る場合ばあい。 例れい：images/filename.jpg
  • 一ひとつ上うえのフォルダにあるとき styles フォルダの中なかのCSSから、外そとにある images フォルダの中なかのファイルを見る場合ばあい。 例れい：../images/filename.jpg（.. は「一ひとつ上うえの階層かいそうへ行いく」という意味いみです）

大切たいせつな注意点ちゅういてん

Windowsではフォルダの区切くぎりに「\（バックスラッシュ）」を使つかいますが、ウェブ開発かいはつでは**必かならず「/（スラッシュ）」**を使つかってください。\ を使つかうと、自分じぶんのパソコンでは動うごいても、インターネットに公開こうかいした瞬間しゅんかんにウェブサイトが壊こわれてしまいます。

まとめ

  • 整理整頓せいりせいとん：web-projects フォルダを作つくり、中身なかみをミラー構造こうぞうで整理せいりしましょう。
  • 名前なまえのルール：小文字こもじ、スペースなし、ハイフンを使つかいましょう。
  • パスの指定してい：ウェブでは必かならず「/（スラッシュ）」を使つかいましょう。

ルールを守まもってフォルダを作つくれば、あとの作業さぎょうがとても楽らくになります。一歩いっぽずつ、楽たのしくウェブサイトを作つくっていきましょう。応援おうえんしています！
