初めてのウェブサイト

I. はじめてのウェブサイト

1. はじめに：ウェブ開発《かいはつ》の世界《せかい》へようこそ

みなさん、こんにちは！ ウェブサイトを作《つく》ってみたいと思《おも》ったことはありますか？ 今《いま》の社会《しゃかい》では、自分《じぶん》の考《かんが》えや情報《じょうほう》を世界《せかい》に伝《つた》えるために、ウェブサイトを作《つく》る技術《ぎじゅつ》はとても大《おお》きな力《ちから》になります。

特《とく》に留学生《りゅうがくせい》のみなさんにとって、ウェブサイトは「言葉《ことば》の壁《かべ》」をこえるための強《つよ》い味方《みかた》です。完全《かんぜん》な日本語《にほんご》を話《はな》すのが難《むずか》しくても、ウェブサイトなら写真《しゃしん》やデザイン、図《ず》を使《つか》って、あなたの魅力《みりょく》や才能《さいのう》を視覚《しかく》的《てき》に伝《つた》えることができます。

「ウェブ開発《かいはつ》はむずかしそう……」と感《かん》じるかもしれません。確《たし》かに、Facebook（フェイスブック）のような複雑《ふくざつ》なサイトを、いきなり一人《ひとり》で作《つく》ることは難《むずか》しいです。しかし、安心《あんしん》してください。自分《じぶん》だけのシンプルなウェブサイトなら、少《すこ》しずつ進《すす》むことで、誰《だれ》でも作《つく》ることができます。

このガイドでは、ウェブサイトがどのように動《うご》いているのか、そしてどうすれば自分《じぶん》の作品《さくひん》を世界《せかい》に広《ひろ》めることができるのかを、やさしく解説《かいせつ》します。自分《じぶん》で情報《じょうほう》を広《ひろ》める力《ちから》を身《み》につけることは、将来《しょうらい》の仕事《しごと》や自分《じぶん》を表現《ひょうげん》するために、必《かなら》ず素晴《すば》らしいプラスになるはずです。

準備《じゅんび》はいいですか？ まずは、スタートするために必要《ひつよう》なものを確認《かくにん》しましょう。

Note

この資料《しりょう》はMDNの「Your first website」をやさしい日本語《にほんご》にしたものです。

2. 準備《じゅんび》するもの：スタートラインに立《た》つ

実際《じっさい》にコード（コンピュータへの命令《めいれい》）を書《か》き始《はじ》める前《まえ》に、自分《じぶん》のコンピュータで作業《さぎょう》ができる準備《じゅんび》をすることが大切《たいせつ》です。これを「環境《かんきょう》構築《こうちく》 （ パソコンでサイトを作《つく》るための準備《じゅんび》）」と呼《よ》びます。

まず、以下《いか》の3つのことがスムーズにできるか確認《かくにん》してください。

  1. OS（オペレーティングシステム）の操作《そうさ》： WindowsやmacOSなどの基本《きほん》的《てき》な使《つか》い方《かた》がわかる。
  2. ファイルシステムの理解《りかい》： ファイルを保存《ほぞん》したり、フォルダを作《つく》って整理《せいり》したりできる。
  3. ブラウザの利用《りよう》： インターネットで検索《けんさく》をしたり、サイトを見《み》たりできる。

Note

「2. ファイルシステムの理解《りかい》」に自信《じしん》のない人《ひと》は、補足《ほそく》資料《しりょう》集《しゅう》の「ファイルとフォルダの基本《きほん》」を見《み》てください。

次《つぎ》に、以下《いか》の「道具《どうぐ》」を用意《ようい》しましょう。

  • コードエディター： プログラムのコードを書くための専用《せんよう》ソフトです。Visual Studio Codeを使《つか》います。すでに皆《みな》さんのPCにインストールされています。
  • ウェブブラウザ： 主《おも》にGoogle Chromeを使《つか》います。こちらもインストール済《ず》みです。

道具《どうぐ》がそろったら、次《つぎ》は「どんなサイトを作《つく》るか」という計画《けいかく》を立《た》てるステップです。

3. 計画《けいかく》を立《た》てる：サイトの見《み》た目《め》を決《き》める

いきなりコードを書《か》き始《はじ》めるのは、設計図《せっけいず》なしで家《いえ》を建《た》てるようなものです。まずは「計画《けいかく》」から始《はじ》めましょう。最初《さいしょ》にしっかり計画《けいかく》を立《た》てることで、作業《さぎょう》の途中《とちゅう》で迷《まよ》わなくなり、結果《けっか》として「情報《じょうほう》の整理《せいり》された見《み》やすいサイト」を作《つく》ることができます。

計画《けいかく》を立《た》てるときは、以下《いか》のポイントを整理《せいり》してみてください。

  • どんな情報《じょうほう》を載《の》せるか： 誰《だれ》に、何《なに》を伝《つた》えたいですか？（自己紹介《じこしょうかい》、趣味《しゅみ》の紹介《しょうかい》など）
  • どんなフォントや色《いろ》を使《つか》うか： 明《あか》るいイメージですか？ それともクールで落《お》ち着《つ》いたイメージですか？

見《み》た目《め》のイメージが固《かた》まったら、いよいよサイトの「中身《なかみ》（文章《ぶんしょう》）」と「形《かたち》」を作《つく》っていく段階《だんかい》に入《はい》ります。

[!note]
見《み》た目《め》: 外《そと》から見《み》た物事《ものごと》のありさま
（例《れい》 その車《くるま》は 見《み》た目《め》 は美《うつく》しいが中身《なかみ》は壊《こわ》れている）

4. サイトの「3つの要素《ようそ》」：HTML、CSS、JavaScript

ウェブサイトは、主《おも》に3つの技術《ぎじゅつ》が組《く》み合《あ》わさってできています。これを「家《いえ》づくり」に例《たと》えて見《み》てみましょう。

技術名《ぎじゅつめい》役割《やくわり》（家《いえ》の例《たと》え）詳《くわ》しい説明《せつめい》
HTML構造《こうぞう》段落《だんらく》、リスト、画像《がぞう》など、コンテンツの「意味《いみ》」や「土台《どだい》」を作《つく》ります。
CSS見《み》た目《め》（かざり）色《いろ》、サイズ、配置《はいち》、背景《はいけい》など、サイトを「美《うつく》しく」整《ととの》えます。
JavaScript動《うご》きボタンの反応《はんのう》、アニメーション、ゲームなど「便利《べんり》な機能《きのう》」を加《くわ》えます。

これらの技術《ぎじゅつ》は、どれか一《ひと》つ欠《か》けてもうまくいきません。たとえば、HTMLだけでは文字《もじ》が並《なら》んでいるだけで読《よ》みにくく、CSSがないとデザインがバラバラになります。また、JavaScriptがないと動《うご》きのない静《しず》かなサイトになってしまいます。

これらを正《ただ》しく組《く》み合《あ》わせることで、ユーザーにとって「読《よ》みやすく」「使《つか》いやすく」「楽《たの》しい」ウェブサイトが完成《かんせい》するのです。

[!note]
段落《だんらく》：長《なが》い文章《ぶんしょう》を内容《ないよう》などから分《わ》けた、言葉《ことば》の集《あつ》まり

[!note]
リスト：複数《ふくすう》の項目《こうもく》や要素《ようそ》を集《あつ》めたもの

[!note]
画像《がぞう》：写真《しゃしん》や絵《え》など

5. 世界《せかい》へ公開《こうかい》する：パブリッシング

自分《じぶん》のパソコンで作《つく》ったファイルは、そのままでは自分《じぶん》にしか見《み》ることができません。これをインターネット上《じょう》にアップロードして、世界中《せかいじゅう》の誰《だれ》でも見《み》られる状態《じょうたい》にすることを「公開《こうかい》（パブリッシング）」と言《い》います。

公開《こうかい》の手順《てじゅん》をシンプルにまとめると、以下《いか》のようになります。

  1. コードを書《か》き終《お》える： HTML、CSS、JavaScriptを完成《かんせい》させます。
  2. ファイルを整理《せいり》する： 画像《がぞう》やコードのファイルを正《ただ》しいフォルダにまとめます。
  3. オンラインにアップロードする： 「サーバー」と呼《よ》ばれる、インターネット上《じょう》の場所《ばしょ》へファイルを送《おく》ります。

[!note]
授業《じゅぎょう》では、このステップは実施《じっし》しません。興味《きょうみ》のある方《かた》は、https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Your_first_website/Publishing_your_websiteしてMDNの関連《かんれん》サイトを参照《さんしょう》してください。

6. まとめと次《つぎ》のステップ

ここまで、ウェブサイト制作《せいさく》の全体像《ぜんたいぞう》を見《み》てきました。ウェブ開発《かいはつ》の学習《がくしゅう》は、一度《いちど》で完璧《かんぺき》にする必要《ひつよう》はありません。小《ちい》さな「できた！」を積《つ》み重《かさ》ねていくプロセスそのものが大切《たいせつ》です。

II. デザインと計画《けいかく》のガイドブック

ウェブサイトを作《つく》るとき、いきなりパソコンでコード（プログラムの言葉《ことば》）を書《か》き始《はじ》めるのは、おすすめしません。まずは「計画《けいかく》（プランニング）」をしましょう。

このガイドブックでは、ウェブ開発《かいはつ》の専門家《せんもんか》が、留学生《りゅうがくせい》のみなさんにも分《わ》かりやすい「やさしい日本語《にほんご》」で、サイト作《づく》りの準備《じゅんび》について教《おし》えます。

1. はじめに：なぜ「計画《けいかく》」が大切《たいせつ》なのか

家《いえ》を建《た》てるときに「設計図《せっけいず》」が必要《ひつよう》なように、ウェブサイトにも計画《けいかく》が必要《ひつよう》です。コードを書《か》く前《まえ》に計画《けいかく》を立《た》てるのには、大《おお》きな理由《りゆう》があります。

  • 「作《つく》り直《なお》し」をふせぐ： 何《なに》も決《き》めずに作《つく》ると、あとで「やっぱり違《ちが》う！」となって、時間《じかん》をむだにしてしまいます。
  • 最後《さいご》まで完成《かんせい》できる： 最初《さいしょ》にやることを決《き》めると、迷《まよ》わずに最後《さいご》まで作《つく》ることができます。

計画《けいかく》を立《た》てることは、プロのエンジニアも一番《いちばん》大切《たいせつ》にしているステップです。

2. ウェブサイトの目的《もくてき》を整理《せいり》する

最初《さいしょ》のプロジェクトでは、内容《ないよう》を「シンプル」にすることが成功《せいこう》のヒミツです。大《おお》きすぎる目標《もくひょう》を立《た》てると、途中《とちゅう》で嫌《いや》になって諦《あきら》めてしまうからです。

まずは、次《つぎ》の3つの質問《しつもん》に答《こた》えてみましょう。

  1. このサイトは何《なに》についてのサイトですか？ （例《れい》：好《す》きな犬《いぬ》について、旅行《りょこう》したニューヨークについて、パックマン（Pac-Man）についてなど）
  2. どんな情報《じょうほう》を紹介《しょうかい》しますか？ （ウェブサイトの名前《なまえ》を決《き》めましょう。そして、1つの「見出《みだ》し（タイトル）」、1つの「画像《がぞう》」、2〜3個《こ》の「段落《だんらく》／短《みじか》い文章《ぶんしょう》」を考《かんが》えてください）
  3. どんな見《み》た目《め》のサイトにしますか？ （背景《はいけい》は何色《なにいろ》がいいですか？ 文字《もじ》の形《かたち》は「まじめ」ですか？ それとも「かわいい」ですか？）

専門家《せんもんか》の知恵《ちえ》：デザインガイド

大《おお》きなプロジェクトでは、「デザインガイド（デザインシステム）」というルールブックを作《つく》ります。例《たと》えば、Firefoxには「Firefox Acorn Design System」という有名《ゆうめい》なガイドがあります。これを見ると、プロがどうやって「色《いろ》」や「文字《もじ》」のルールを統一《とういつ》して、きれいに見《み》せているかが分《わ》かります。

目的《もくてき》が決《き》まったら、次《つぎ》はそれを絵《え》に描《か》いてみましょう。

[!note]
「プロジェクト」は一《ひと》つのウェブサイトやアプリケーションを作《つく》るための計画《けいかく》、あるいは、その計画《けいかく》に関《かか》わる人々《ひとびと》のグループのことです。そうした計画《けいかく》のためのデジタル素材《そざい》やソースコードなどをまとめたものを指《さ》すこともあります。

3. デザインのスケッチ：見《み》た目《め》のイメージを作《つく》る

ペンと紙《かみ》を使《つか》って、サイトの形《かたち》を自由《じゆう》に描《えが》いてみましょう。これを「スケッチ」と言《い》います。

プロも、最初《さいしょ》はパソコンを使《つか》わず、紙《かみ》に書《か》くことから始《はじ》めます。ここで大切《たいせつ》なのは、「完璧《かんぺき》を目指《めざ》さないこと」 です。有名《ゆうめい》な画家《がか》のゴッホ（Van Gogh）のように上手《じょうず》に描《か》く必要《ひつよう》はありません。どこにタイトルがあり、どこに画像《がぞう》があるか、自分《じぶん》が分《わ》かれば十分《じゅうぶん》です。

また、ウェブ制作《せいさく》の現場《げんば》には、2つの役割《やくわり》があります。

デザイナーの種類《しゅるい》どんな仕事《しごと》をする人《ひと》？
グラフィックデザイナーウェブサイトの見《み》た目《め》をきれいにデザインする人《ひと》
UXデザイナーユーザーがボタンを押《お》しやすくしたり、情報《じょうほう》を見《み》つけやすくしたりする人《ひと》

今《いま》は、あなたがこの両方《りょうほう》の仕事《しごと》をします。自分《じぶん》のアイデアを自由《じゆう》に紙《かみ》に書《か》いてみてください。

4. テーマカラー（色《いろ》の名前《なまえ》とコード）を決《き》める

サイトの印象《いんしょう》を決《き》める「色《いろ》」を選《えら》びましょう。

  1. 色《いろ》を選《えら》ぶ： カラーピッカーなどのツールで、背景《はいけい》に使《つか》いたい色《いろ》を探《さが》します。
  2. コードをメモする： 色《いろ》を選《えら》ぶと、#660066 のような「6つの英数字《えいすうじ》」が表示《ひょうじ》されます。これを 16進数《じんすう》コード（hex code／ヘックスコード） と呼《よ》びます。

[!note]
16進数《じんすう》コード（hex code）とは
コンピュータが「この色《いろ》です！」と正《ただ》しく理解《りかい》するための専用《せんよう》の番号《ばんごう》です。あとでコードを書《か》くときに使《つか》うので、必《かなら》ずメモしておきましょう。

5. 画像《がぞう》の準備《じゅんび》：ルールを守《まも》って探《さが》す方法《ほうほう》

インターネットにある画像《がぞう》には「持《も》ち主《ぬし》」があります。これを 著作権《ちょさくけん》（コピーライト） と言《い》います。勝手《かって》に使《つか》うと法律《ほうりつ》のトラブルになることがあるので、注意《ちゅうい》してください。

「自由《じゆう》に使《つか》ってもいい画像《がぞう》」をGoogleで探《さが》す方法《ほうほう》は、次《つぎ》の通《とお》りです。

  1. Google画像《がぞう》検索《けんさく》を使《つか》う： 好《す》きな言葉《ことば》で検索《けんさく》します。
  2. ツールを使《つか》う： 検索結果《けんさくけっか》の画面《がめん》にある「ツール」ボタンをクリックします。
  3. ライセンスを選《えら》ぶ： その下《した》に表示《ひょうじ》される「使用権《しようけん》」をクリックし、「クリエイティブ・コモンズ ライセンス」を選《えら》びます。
  4. 保存《ほぞん》する： 好《す》きな画像《がぞう》を見《み》つけたら、右《みぎ》クリック（Macは Ctrl + クリック）をして、「名前《なまえ》を付《つ》けて画像《がぞう》を保存《ほぞん》」を選《えら》びます。

6. フォント（文字《もじ》の形《かたち》）の選択《せんたく》

フォントには2つのタイプがあります。

  • ウェブセーフフォント： どのパソコンにも最初《さいしょ》から入《はい》っている安心《あんしん》なフォントです（例《れい》：Arial, Times New Roman）。
  • Google Fonts： デザイン性《せい》が高《たか》いフォントを無料《むりょう》で借《か》りられるサービスです。

ここでは、Google Fontsを使《つか》う手順《てじゅん》を説明《せつめい》します。

  1. Google Fontsへ行《い》く： サイトのイメージに合《あ》うフォントを探《さが》します。

III. ウェブサイトの形《かたち》を作《つく》ろう

ウェブサイトを作《つく》るための 最初《さいしょ》の一歩《いっぽ》へ ようこそ！ プログラミングや ウェブ制作《せいさく》を 始《はじ》めるとき、 最初《さいしょ》に 覚《おぼ》えるのが「HTML」です。

HTMLは ウェブサイトの「骨組《ほねぐ》み」、つまり 構造《こうぞう》を 作《つく》るための 言葉《ことば》です。この 基本《きほん》を 正《ただ》しく 知《し》ることは、ウェブサイトを 作《つく》る プロ（仕事《しごと》を する人《ひと》）に なるために、とても 大切《たいせつ》なことです。

Note

「骨組《ほねぐ》み」は、もとは「からだの骨《ほね》の組《く》み立《た》て」のことですが、そこからの「例《たと》え」で、建造物《けんぞうぶつ》・機械《きかい》などの基礎的《きそてき》な構造《こうぞう》の部分《ぶぶん》のことも指《さ》します。

1. HTMLとは何《なに》？：ウェブの基本《きほん》を理解《りかい》する

HTML（HyperText Markup Language） は、テキスト（文字《もじ》）に「印《しるし》」を つけて、ウェブサイトの 構造《こうぞう》を 作《つく》るための「マークアップ言語《げんご》」です。

HTMLの 役割《やくわり》を わかりやすく 例《たと》えると、「荷物《にもつ》に ラベルを 貼《は》る 作業《さぎょう》」 に 似《に》ています。ただの テキストに「これは 見出《みだ》しです」「これは 段落《だんらく》です」という ラベルを 貼《は》ることで、ブラウザ（Google Chromeなど）が その意味《いみ》を 理解《りかい》できるようになります。

  • 要素《ようそ》 / Elementとは： テキストを「タグ」と 呼《よ》ばれる 記号《きごう》で 囲《かこ》んだ セットのことです。
  • ブラウザへの 伝言《でんごん》： タグを 使《つか》うことで、ブラウザに「ここから ここまでが 段落《だんらく》だ」と 伝《つた》えることができます。

HTMLを 使《つか》う 理由《りゆう》：
もし HTMLが なければ、すべての 文字《もじ》が 一行《いちぎょう》に つながってしまい、とても 読《よ》みにくくなります。また、目《め》が 見《み》えにくい 人《ひと》が 使《つか》う「音声《おんせい》読《よ》み上《あ》げソフト」も、どこが 大事《だいじ》な 場所《ばしょ》なのか わからなくなってしまいます。
HTMLで 正《ただ》しく 構造《こうぞう》を 作《つく》ることで、誰《だれ》にでも 意味《いみ》が 伝《つた》わる ページに なります。

2. HTMLファイルの基本《きほん》の形《かたち》

ウェブページを 正《ただ》しく 動《うご》かすためには、決《き》まった「型《かた》」が 必要《ひつよう》です。

主要《しゅよう》な 構成要素《こうせいようそ》

MDNの ルールに 基《もと》づいた、基本的《きほんてき》な パーツは 以下《いか》の 通《とお》りです。

  • <!doctype html>：ページを 正《ただ》しく 表示《ひょうじ》させるために、ファイルの いちばん 上《うえ》に 書《か》かなければならない ルールです。
  • <html>：ページの すべての 内容《ないよう》を 包《つつ》む「 いちばん 外側《そとがわ》の 箱《はこ》」です。
  • <head>：画面《がめん》には 見《み》えないけれど、ブラウザや 検索《けんさく》エンジンのための 大切《たいせつ》な 情報《じょうほう》（メタデータ）を 入《い》れる 場所《ばしょ》です。
  • <title>：ブラウザの「タブ」に 出《で》る 名前《なまえ》や、ブックマーク（お気《き》に入り）したときの 名前《なまえ》に なります。
  • <body>：実際《じっさい》に ユーザーが 見《み》る コンテンツ（文章《ぶんしょう》や 画像《がぞう》など）を すべて 入《い》れる 場所《ばしょ》です。

メタデータ（大切《たいせつ》な 設定《せってい》）の 価値《かち》

<head>の 中《なか》には、以下《いか》の ような 設定《せってい》を 書《か》きます。

  • 文字《もじ》コード（UTF-8）： これを 書《か》かないと、日本語《にほんご》などが 変《へん》な 記号《きごう》に なる「文字化《もじば》け」が 起《お》きることが あります。
  • ビューポート（viewport）： スマートフォンの 画面《がめん》サイズに 合《あ》わせて、きれいに 表示《ひょうじ》するために 必要《ひつよう》です。

タグの 構造《こうぞう》：入《い》れ子《こ》

HTMLは「タグの 中《なか》に 別《べつ》の タグが 入《はい》る」という「入《い》れ子《こ》」の 形《かたち》に なります。

    • <ol>（順序《じゅんじょ》あり リスト）： 料理《りょうり》の 手順《てじゅん》のように、順番《じゅんばん》が 大切《たいせつ》な ときに 使《つか》います。

4. 画像《がぞう》を 表示《ひょうじ》する：<img>要素《ようそ》の使《つか》い方《かた》

IV. ウェブサイトをデザインするCSS《しーえすえす》

1. はじめに：CSS《しーえすえす》とは何《なん》でしょうか？

ウェブサイトを作《つく》るとき、文字《もじ》や画像《がぞう》などの「内容《ないよう》」を準備《じゅんび》するだけでは、まだデザインが完成《かんせい》していません。そこで使《つか》われるのが CSS《しーえすえす》 です。

CSSは、ウェブサイトの「見《み》た目《め》」を整《ととの》えるための専用《せんよう》の言葉《ことば》です。HTMLで作成《さくせい》した文章《ぶんしょう》に色《いろ》をつけたり、大《おお》きさを変《か》えたり、好《す》きな場所《ばしょ》に並《なら》べたりすることができます。

HTML《えいちてぃーえむえる》（内容《ないよう》）とCSS《しーえすえす》（スタイル）の違《ちが》い

ウェブサイトは、主《おも》に2つの役割《やくわり》が組《く》み合《あ》わさってできています。

  • HTML（内容《ないよう》）： 「ここにタイトルがある」「ここに文章《ぶんしょう》がある」という、サイトの骨組《ほねぐ》み（土台《どだい》）を作《つく》ります。
  • CSS（スタイル）： 「タイトルを青色《あおいろ》にする」「文章《ぶんしょう》の横幅《よこはば》を600ピクセルにする」といった、見《み》た目《め》を美《うつく》しく飾《かざ》ります。

CSSを使《つか》ってデザインを整《ととの》えることで、ウェブサイトはもっと読《よ》みやすくなり、訪《おとず》れた人《ひと》に「使《つか》いやすい」と感《かん》じてもらえるようになります。

CSSの定義《ていぎ》

  • スタイルシート言語《げんご》： プログラミング言語《げんご》ではなく、見《み》た目《め》を指定《してい》するための特別《とくべつ》な言葉《ことば》です。
  • 要素《ようそ》（エレメント）の装飾《そうしょく》： HTMLで書《か》かれた特定《とくてい》の場所《ばしょ》を選《えら》んで、その見《み》た目《め》を変《か》えることができます。

次《つぎ》のセクションでは、CSSを実際《じっさい》にどうやって書《か》くのか、その基本《きほん》ルールを学《まな》びましょう。

2. CSSの書《か》き方《かた》（構文《こうぶん》）を覚《おぼ》えましょう

CSSを書《か》くときには、決《き》まった形《かたち》（構文《こうぶん》）があります。「どこの」「何《なに》を」「どう変《か》えるか」という順番《じゅんばん》で指示《しじ》を書《か》きます。

CSSを構成《こうせい》するパーツ

CSSは、以下《いか》のパーツを組《く》み合《あ》わせて作《つく》ります。

  1. セレクター（選《えら》びたい場所《ばしょ》）： デザインを変《か》えたいHTMLの要素《ようそ》（タグなど）を指定《してい》します。
  2. プロパティ（変《か》えたい項目《こうもく》）： 色《いろ》、大《おお》きさ、場所《ばしょ》など、何《なに》を変《か》えるかを選《えら》びます。
  3. 値《あたい》（設定《せってい》する内容《ないよう》）： 具体的《ぐたいてき》にどんな色《いろ》にするか、どのくらいの大《おお》きさにするかを決《き》めます。

宣言《せんげん》とルールセット

CSSでは、プロパティと値《あたい》を組《く》み合《あ》わせたペアを 「宣言《せんげん》」 と呼《よ》びます。そして、セレクターと { } で囲《かこ》まれた複数《ふくすう》の宣言《せんげん》をまとめたものを 「ルールセット」 または 「ルール」 と呼《よ》びます。

  color: red; /* 宣言《せんげん》1：文字《もじ》の色《いろ》（プロパティ）を赤《あか》にします */

}

3. HTMLにCSSを読《よ》み込《こ》ませる方法《ほうほう》

CSSを書《か》くだけでは、ウェブサイトにデザインは反映《はんえい》されません。HTMLとCSSを正《ただ》しく「つなぐ」手順《てじゅん》が必要《ひつよう》です。

正確《せいかく》な設定《せってい》が大切《たいせつ》な理由《りゆう》

ウェブサイトを作《つく》るときは、ファイルを整理《せいり》するために styles という名前《なまえ》のフォルダを作《つく》り、その中《なか》に style.css というファイルを作成《さくせい》するのが一般的《いっぱんてき》です。

HTMLファイルの <head>（ヘッド：サイトの設定《せってい》を書く場所《ばしょ》）の中《なか》に、以下《いか》の1行《いちぎょう》を書《か》き込みます。
