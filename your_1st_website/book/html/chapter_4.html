初めてのウェブサイト

IV. ウェブサイトをデザインするCSS

1. はじめに：CSSとは何なんでしょうか？

ウェブサイトを作つくるとき、文字もじや画像がぞうなどの「内容ないよう」を準備じゅんびするだけでは、まだデザインが完成かんせいしていません。そこで使つかわれるのが CSS（シーエスエス） です。

CSSは、ウェブサイトの「見みた目め」を整ととのえるための専用せんようの言葉ことばです。HTMLで作成さくせいした文章ぶんしょうに色いろをつけたり、大おおきさを変えたり、好すきな場所ばしょに並ならべたりすることができます。

HTML（内容）とCSS（スタイル）の違ちがい

ウェブサイトは、主おもに2つの役割やくわりが組くみ合あわさってできています。

  • HTML（内容ないよう）： 「ここにタイトルがある」「ここに文章ぶんしょうがある」という、サイトの骨組ほねぐみ（土台どだい）を作つくります。
  • CSS（スタイル）： 「タイトルを青色あおいろにする」「文章ぶんしょうの横幅よこはばを600ピクセルにする」といった、見みた目めを美うつくしく飾かざります。

CSSを使つかってデザインを整ととのえることで、ウェブサイトはもっと読よみやすくなり、訪おとずれた人ひとに「使つかいやすい」と感かんじてもらえるようになります。

CSSの定義ていぎ

  • スタイルシート言語げんご： プログラミング言語げんごではなく、見みた目めを指定していするための特別とくべつな言葉ことばです。
  • 要素ようその装飾そうしょく： HTMLで書かかれた特定とくていの場所ばしょを選えらんで、見みた目めを変えることができます。

次つぎのセクションでは、CSSを実際じっさいにどうやって書かくのか、その基本きほんルールを学まなびましょう。

2. CSSの書かき方かた（構文こうぶん）を覚おぼえましょう

CSSを書かくときには、決きまった形かたち（構文こうぶん）があります。「どこの」「何なにを」「どう変えるか」という順番じゅんばんで指示しじを書かきます。

CSSを構成こうせいするパーツ

CSSは、以下いかのパーツを組くみ合あわせて作つくります。

  1. セレクター（選えらびたい場所ばしょ）： デザインを変えたいHTMLの要素ようそを指定していします。
  2. プロパティ（変かえたい項目こうもく）： 色いろ、大おおきさ、場所ばしょなど。
  3. 値あたい（設定せっていする内容ないよう）： 具体的ぐたいてきにどんな色いろにするか、どれくらいの大おおきさにするかを決きめます。

宣言せんげんとルールセット

CSSでは、プロパティと値あたいを組くみ合あわせたペアを 「宣言せんげん」 と呼よびます。また、セレクターと { } で囲かこまれた複数ふくすうの宣言せんげんをまとめたものを「ルールセット（Ruleset）」と呼よびます。

書かき方かたのルールとコード例れい

プロパティの後あとには必かならずコロン : を、値あたいの後あとには必かならずセミコロン ; を書かきます。

p {
  color: red; /* 宣言1：文字の色（プロパティ）を赤（値）にします */
  font-size: 16px; /* 宣言2：文字の大きさ（プロパティ）を16ピクセル（値）にします */
}

書かき方かたを理解りかいしたら、次つぎはCSSをHTMLに読よみ込こませる方法ほうほうを確認かくにんしましょう。

3. HTMLにCSSを読よみ込こませる方法ほうほう

CSSを書かくだけでは、ウェブサイトにデザインは反映はんえいされません。HTMLとCSSを正ただしくつなぐ手順てじゅんが必要ひつようです。

正確せいかくな設定せっていが大切たいせつな理由りゆう

ウェブサイトを作つくるときは、ファイルを整せいりするために styles という名前なまえのフォルダを作つくり、その中なかに style.css を作成さくせいします。

HTMLファイルの <head> （ヘッド：サイトの設定せっていを書く場所ばしょ）内ないに、以下いかの1行を書きます。

<link href="styles/style.css" rel="stylesheet" />

【トラブルを避さけるポイント】
フォルダ名めいやファイル名めいが1文字もじでも間違まちがっていると、デザインは全まったく表示ひょうじされません。
styles/style.css という「道みちすじ（パス）」が実際じっさいのフォルダ構成こうせいと合あっているか慎重しんちょうに確認かくにんしましょう。

4. 文字もじのデザインをきれいにする（フォントとテキスト）

文字もじの見みた目めは、サイトを訪おとずれる人ひとの「読よみやすさ」に大おおきな影響えいきょうがあります。適切てきせつなフォント選びは、サイトを信頼しんらいできる印象いんしょうにするための戦略せんりゃくです。

Google Fonts の利用りよう

標準ひょうじゅんのフォント以外いがいを使つかいたいとき、Google Fonts のサービスを使つかいます。HTML の <head> に 自分のstyle.cssより前 に読よみ込こませます。

<!-- Google Fontsの読み込み例（自分のCSSより前に書きます） -->
<link href="https://fonts.googleapis.com/css?family=Open+Sans" rel="stylesheet" />
<link href="styles/style.css" rel="stylesheet" />

読よみやすさを高たかめるプロパティ

  • font-family： フォントの種しゅ類
  • font-size： 文字もじの大おおきさ
  • text-align： 文ぶんを中なか央に寄よせる
  • line-height： 行間ぎょうかん
  • letter-spacing： 文も字の間隔かんかく

5. すべては「箱はこ（ボックス）」でできている

CSS の世界せかいでは、すべての要素ようそ（見出みだし・文章ぶんしょう・画像がぞうなど）は「箱はこ」の中なかにあると考かんがえます。これを ボックスモデル と呼よびます。

要素ようそやさしい説明せつめい
Content文もん字や画が像が入る中心部
Padding中身なかみと枠線わくせんの内側うちがわの余白よはく
Border枠線わくせんそのもの
Margin枠線わくせんの外側そとがわの余白よはく

6. ページぺーじ全体ぜんたいのレイアウトを整ととのえる（色いろと配置はいち）

背景はいけいに色いろをつけ、body の幅はばを600pxにし、中なか央寄せする典型てんけい的な設定せっていです。

html {
  background-color: #00539F; /* ページ全体の背景を青にします */
}

body {
  width: 600px; /* 全体の幅を600ピクセルに固定します */
  margin: 0 auto; /* 上下は0、左右は「自動（auto）」で分けて中央に寄せます */
  background-color: #FF9500; /* bodyの背景を赤みのあるオレンジにします */
  padding: 0 20px 20px 20px; /* 内側に余白を作ります */
  border: 5px solid black; /* 黒い枠線で囲みます */
}

margin: 0 auto; の仕組しくみ：
ブラウザが左右の空きを半分ずつ割り当て、body が中なか央に配置されます。

タイトルに影かげをつける

h1 {
  text-shadow: 3px 3px 1px black; /* 横に3px、縦に3px、ぼかし1px、黒い影 */
}

画像がぞうを中ちゅう央に置く

img {
  display: block; /* 画像を「ボックス」として扱うように変えます */
  margin: 0 auto; /* これで中央に寄るようになります */
}

7. おわりに：素敵すてきなウェブサイトを作つくるために

CSS の基礎きそは、将来しょうらいのアニメーションや高度レイアウトの土台どだいになります。

  1. 値あたいを変えて効果を確認
  2. 他サイトを箱はことして観察
  3. 1項目ずつ保存しながら確認

楽たのしみながら、美しいサイトを完成させてください！
