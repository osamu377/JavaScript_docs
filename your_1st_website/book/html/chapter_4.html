初めてのウェブサイト

IV. ウェブサイトをデザインするCSS《しーえすえす》

1. はじめに：CSS《しーえすえす》とは何《なん》でしょうか？

ウェブサイトを作《つく》るとき、文字《もじ》や画像《がぞう》などの「内容《ないよう》」を準備《じゅんび》するだけでは、まだデザインが完成《かんせい》していません。そこで使《つか》われるのが CSS《しーえすえす》 です。

CSSは、ウェブサイトの「見《み》た目《め》」を整《ととの》えるための専用《せんよう》の言葉《ことば》です。HTMLで作成《さくせい》した文章《ぶんしょう》に色《いろ》をつけたり、大《おお》きさを変《か》えたり、好《す》きな場所《ばしょ》に並《なら》べたりすることができます。

HTML《えいちてぃーえむえる》（内容《ないよう》）とCSS《しーえすえす》（スタイル）の違《ちが》い

ウェブサイトは、主《おも》に2つの役割《やくわり》が組《く》み合《あ》わさってできています。

  • HTML（内容《ないよう》）： 「ここにタイトルがある」「ここに文章《ぶんしょう》がある」という、サイトの骨組《ほねぐ》み（土台《どだい》）を作《つく》ります。
  • CSS（スタイル）： 「タイトルを青色《あおいろ》にする」「文章《ぶんしょう》の横幅《よこはば》を600ピクセルにする」といった、見《み》た目《め》を美《うつく》しく飾《かざ》ります。

CSSを使《つか》ってデザインを整《ととの》えることで、ウェブサイトはもっと読《よ》みやすくなり、訪《おとず》れた人《ひと》に「使《つか》いやすい」と感《かん》じてもらえるようになります。

CSSの定義《ていぎ》

  • スタイルシート言語《げんご》： プログラミング言語《げんご》ではなく、見《み》た目《め》を指定《してい》するための特別《とくべつ》な言葉《ことば》です。
  • 要素《ようそ》（エレメント）の装飾《そうしょく》： HTMLで書《か》かれた特定《とくてい》の場所《ばしょ》を選《えら》んで、その見《み》た目《め》を変《か》えることができます。

次《つぎ》のセクションでは、CSSを実際《じっさい》にどうやって書《か》くのか、その基本《きほん》ルールを学《まな》びましょう。

2. CSSの書《か》き方《かた》（構文《こうぶん》）を覚《おぼ》えましょう

CSSを書《か》くときには、決《き》まった形《かたち》（構文《こうぶん》）があります。「どこの」「何《なに》を」「どう変《か》えるか」という順番《じゅんばん》で指示《しじ》を書《か》きます。

CSSを構成《こうせい》するパーツ

CSSは、以下《いか》のパーツを組《く》み合《あ》わせて作《つく》ります。

  1. セレクター（選《えら》びたい場所《ばしょ》）： デザインを変《か》えたいHTMLの要素《ようそ》（タグなど）を指定《してい》します。
  2. プロパティ（変《か》えたい項目《こうもく》）： 色《いろ》、大《おお》きさ、場所《ばしょ》など、何《なに》を変《か》えるかを選《えら》びます。
  3. 値《あたい》（設定《せってい》する内容《ないよう》）： 具体的《ぐたいてき》にどんな色《いろ》にするか、どのくらいの大《おお》きさにするかを決《き》めます。

宣言《せんげん》とルールセット

CSSでは、プロパティと値《あたい》を組《く》み合《あ》わせたペアを 「宣言《せんげん》」 と呼《よ》びます。そして、セレクターと { } で囲《かこ》まれた複数《ふくすう》の宣言《せんげん》をまとめたものを 「ルールセット」 または 「ルール」 と呼《よ》びます。

書《か》き方《かた》のルールとコード例《れい》

プロパティの後《あと》には必《かなら》ずコロン : を、値《あたい》の後《あと》には必《かなら》ずセミコロン ; を書《か》くのがルールです。

p {
  color: red; /* 宣言《せんげん》1：文字《もじ》の色《いろ》（プロパティ）を赤《あか》にします */
  font-size: 16px; /* 宣言《せんげん》2：文字《もじ》の大《おお》きさ（プロパティ）を16ピクセル（値《あたい》）にします */
}

書《か》き方《かた》を理解《りかい》したら、次《つぎ》は作成《さくせい》したCSSをHTMLに読《よ》み込《こ》ませる方法《ほうほう》を確認《かくにん》しましょう。

3. HTMLにCSSを読《よ》み込《こ》ませる方法《ほうほう》

CSSを書《か》くだけでは、ウェブサイトにデザインは反映《はんえい》されません。HTMLとCSSを正《ただ》しく「つなぐ」手順《てじゅん》が必要《ひつよう》です。

正確《せいかく》な設定《せってい》が大切《たいせつ》な理由《りゆう》

ウェブサイトを作《つく》るときは、ファイルを整理《せいり》するために styles という名前《なまえ》のフォルダを作《つく》り、その中《なか》に style.css というファイルを作成《さくせい》するのが一般的《いっぱんてき》です。

HTMLファイルの <head>（ヘッド：サイトの設定《せってい》を書く場所《ばしょ》）の中《なか》に、以下《いか》の1行《いちぎょう》を書《か》き込みます。

【トラブルを避《さ》けるポイント】
フォルダ名《めい》やファイル名《めい》が1文字《もじ》でも間違《まちが》っていると、デザインはまったく表示《ひょうじ》されません。
styles/style.css という「道《みち》すじ（パス）」が、実際《じっさい》のフォルダ構成《こうせい》と合《あ》っているか確認《かくにん》しましょう。

4. 文字《もじ》のデザインをきれいにする（フォントとテキスト）

文字《もじ》の見《み》た目《め》は、サイトを訪《おとず》れる人《ひと》の「読《よ》みやすさ」に大《おお》きく影響《えいきょう》します。適切《てきせつ》なフォントを選《えら》ぶことは、サイトを「信頼《しんらい》できるプロのような印象《いんしょう》」にするための大切《たいせつ》な戦略《せんりゃく》です。

Google Fonts《ぐーぐるふぉんつ》の利用《りよう》

標準《ひょうじゅん》のフォント以外《いがい》を使《つか》いたいときは、Google Fontsのサービスを使《つか》います。HTMLの <head> 内《ない》に、自分《じぶん》の CSS（style.css）よりも前《まえ》に読《よ》み込《こ》ませます。

読《よ》みやすさを高《たか》めるプロパティ

  • font-family： フォントの種類《しゅるい》。
  • font-size： 文字《もじ》の大《おお》きさ（例《れい》：10px、20px）。
  • text-align： 文字《もじ》の配置《はいち》。center で中央《ちゅうおう》。
  • line-height： 行《ぎょう》と行《ぎょう》の間隔《かんかく》を広《ひろ》げる。
  • letter-spacing： 文字《もじ》と文字《もじ》の間《あいだ》の隙間《すきま》を調整《ちょうせい》。

5. すべては「箱《はこ》（ボックス）」でできている

CSSの世界《せかい》では、すべての要素《ようそ》（見出《みだ》し・文章《ぶんしょう》・画像《がぞう》など）は「箱《はこ》」に入《はい》っていると考《かんが》えます。これを ボックスモデル と呼《よ》びます。

ボックスを構成《こうせい》する4つのパーツ

要素《ようそ》説明《せつめい》
Content《こんてんつ》中心《ちゅうしん》の部分《ぶぶん》。文字《もじ》や画像《がぞう》が入《はい》る。
Padding《ぱでぃんぐ》内側《うちがわ》の余白《よはく》。
Border《ぼーだー》枠線《わくせん》。
Margin《まーじん》外側《そとがわ》の余白《よはく》。他《ほか》の要素《ようそ》との間《あいだ》。

数値《すうち》を変《か》えることで、要素《ようそ》どうしの距離《きょり》を調整《ちょうせい》できます。

6. ページ全体《ぜんたい》のレイアウトを整《ととの》える（色《いろ》と配置《はいち》）

背景《はいけい》に色《いろ》をつけたり、内容《ないよう》を中央《ちゅうおう》に寄《よ》せることで、プロのような仕上《しあ》がりになります。

全体《ぜんたい》の色《いろ》と幅《はば》を決《き》める

html {
  background-color: #00539F;
}

body {
  width: 600px;
  margin: 0 auto;
  background-color: #FF9500;
  padding: 0 20px 20px 20px;
  border: 5px solid black;
}

text-shadow《てきすとしゃどう》でタイトルに影《かげ》をつける

h1 {
  text-shadow: 3px 3px 1px black;
}

画像《がぞう》を中央《ちゅうおう》に置《お》く

img {
  display: block;
  margin: 0 auto;
}

7. おわりに：素敵《すてき》なウェブサイトを作《つく》るために

今回《こんかい》学《まな》んだ「ルールセットの書《か》き方《かた》」や「ボックスモデル」の考《かんが》え方《かた》は、ウェブ制作《せいさく》でずっと使《つか》う大切《たいせつ》な基礎《きそ》です。

学習《がくしゅう》のアドバイス

  1. 値《あたい》を変《か》えて、画面《がめん》の変化《へんか》を確《たし》かめる。
  2. 他《ほか》のサイトを「箱《はこ》」として観察《かんさつ》してみる。
  3. 1つずつ保存《ほぞん》してブラウザで確認《かくにん》する。

楽しみながら、あなただけの素敵《すてき》なウェブサイトを作《つく》ってください！
