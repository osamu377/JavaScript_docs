# Visual Studio Code の準備

## Live Server拡張機能のインストール

1.  拡張機能アイコンをクリックします

![拡張機能アイコンクリック](img/001/201.jpg)

2.  検索ウィンドウに"Live Server"と入力します

![検索ウィンドウにlive Serverと入力](img/001/202.jpg)

3.  "インストール"をクリックします

![インストール"をクリック](img/001/203.jpg)  

4.  インストールされたことを確認します

![確認](img/001/204.png)

***

## 言語設定

1. 左下隅の歯車アイコンをクリック

![歯車アイコンクリック](img/003/301.jpg)

1. 「設定」をクリック

![設定をクリック](img/003/302.jpg)

1. 検索窓に「emmet variables」と入力  

![emmet variablesと入力](img/003/303.jpg)

1. 項目「lang」に「ja」を指定して「OK」をクリック  

![langにjaを指定](img/003/304.jpg)

## キーの働き

| キー           | 働き                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------------------- |
| →            | 右へ                                                                                       |
| ←            | 左へ                                                                                      |
| ↓            | 下へ                                                                                       |
| ↑            | 上へ                                                                                       |
| Shift+→      | 選択範囲を右へ広げる  |
| Shift+←      | 選択範囲を左へ広げる |
| Shift+↓      | 選択範囲を下へ広げる  |
| Shift+↑      | 選択範囲を上へ広げる  |
| Ctrl+C       | コピー                                                                                                              |
| Ctrl+X       | 切り取り                                                                                   |
| Ctrl+V       | 貼り付け                                                                                   |
| Ctrl+F       | 検索                                                                                     |
| CTrl+H       | 置換                                                                                      |
| Ctrl+N       | 新規ファイル                                                                                  |
| Ctrl+O       | ファイルを開く                                                                                 |
| Ctrl+S       | 保存                                                                                      |
| Ctrl+Shift+S | 名前を付けて保存                              |
