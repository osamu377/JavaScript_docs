# Web開発入門：HTML、CSS、JavaScriptによる動的なウェブサイト構築のための総合ブリーフィング資料

本書は、ウェブ開発の基礎となる3つの基盤技術（HTML、CSS、JavaScript）の役割、相互作用、および基本的な記述規則を整理・統合したブリーフィング資料である。特に、プログラミング初学者や留学生にとって障壁となりやすい概念や技術的な注意点に焦点を当て、ウェブサイトが動く仕組みを体系的に解説する。

## 1. エグゼクティブ・サマリー

ウェブサイトの構築は、構造を司るHTML、外観を整えるCSS、そして動的な制御を可能にするJavaScriptの3つの技術がチームワークを発揮することで成立する。これらは「家づくり」に例えられ、HTMLは「骨組み（柱や壁）」、CSSは「見た目（ペンキやインテリア）」、JavaScriptは「電気や機械装置（動きや機能）」の役割を果たす。

JavaScriptの核心は、ユーザーの操作（イベント）をきっかけに、ウェブページの部品（オブジェクト）に対して明確な命令を出すことにある。学習において最も重要なのは、コンピュータに正しく指示を伝えるための厳格な記述ルール（半角文字の使用、文末のセミコロン等）を遵守することである。

## 2. WWW（ワールド・ワイド・ウェブ）の構造と動作原理

ウェブサイトが表示されるまでのプロセスは、以下の4つのステップで構成される。

1. リクエスト（注文）: ユーザーがブラウザでURLをクリックし、サーバにデータを要求する。
2. 住所の確認（DNS）: ドメイン名を数字の住所であるIPアドレスに変換して場所を探す。
3. レスポンス（返事）: サーバがリクエストを受け、HTMLなどのデータをブラウザへ送り返す。
4. レンダリング（組み立て）: ブラウザが届いたデータを読み取り、デザインを組み立てて表示する。

WWWを動かす主要な要素

|用語|図書館での例え|役割|
|---|---|---|
|クライアント（ブラウザ）|本を読みたい人|リクエストを送り、データを表示するソフト（Chrome, Safari等）|
|ウェブサーバ|図書館のスタッフ|データを管理・保管し、要求に応じて送り返すコンピュータ|
|HTML|本の内容|ウェブサイトの文章や写真のデータそのもの|
|URL|本の整理番号|世界に一つしかないウェブサイトの「住所」|
|HTTP / HTTPS|言葉のルール|情報をやり取りする際の共通の通信プロトコル|

## 3. ウェブページを構成する3つの技術的役割

ウェブ開発において、これら3つの技術は明確に役割が分担されている。

* HTML (HyperText Markup Language): ページの土台となる骨組み。情報の意味（見出し、段落、リンク等）を定義する。
* CSS (Cascading Style Sheets): デザインとレイアウト。文字の大きさ、色、余白、特定の状態（マウスホバー時など）のスタイルを制御する。
* JavaScript: 動的な機能の追加。ユーザーの操作に応じた反応や計算、データの処理を担当する。

## 4. HTML：情報の骨組みと設定

HTMLはタグ（< >）を使用して情報の構造を定義する。

メタ情報（`<head>`内）

ユーザーには見えないが、ブラウザや検索エンジンにとって重要な設定を行う。

* `<title>`: ブラウザのタブに表示される名前。
* 文字コードの設定: 日本語を正しく表示するために不可欠。設定が誤っていると「文字化け」が発生する。

主要なHTMLタグ

* 見出し (`<h1>`〜`<h6>`): 構造を分かりやすくするための見出し。
* リンク (`<a>`): href属性で遷移先のURLを指定する。
* リスト (`<ul>`, `<ol>`, `<li>`): 箇条書き（点、または数字）を作成する。
* テーブル (`<table>`): データを整理して表示するための表構造。
* フォーム (`<form>`): ユーザー入力（テキスト、パスワード、ボタン等）を受け取るための仕組み。データ送信には「GET（URLに含める）」と「POST（秘匿性が高い）」の2種類がある。

## 5. CSS：デザインとJavaScriptとの連携

CSSは「どの場所に（セレクタ）」「何の項目を（プロパティ）」「どう変えるか（値）」というルールで記述する。

* セレクタの重要性: HTMLのid（唯一の名前）やclass（グループ名）をセレクタとして使用することで、特定の要素にスタイルを適用できる。これらはJavaScriptが操作対象を見つけるための「目印」としても機能する。
* JavaScriptからの操作: JavaScriptでCSSプロパティを操作する場合、background-colorのようなハイフンを含む名前は、backgroundColorのようにキャメルケースに書き換える必要がある。

## 6. JavaScript：動的な制御の仕組み

JavaScriptは、ウェブページを「生きているように動かすスイッチ」の役割を果たす。

イベントとイベントハンドラ

「何かが起きた」という合図をイベント、その際の処理をイベントハンドラと呼ぶ。

* onclick: 要素がクリックされた時
* onmouseover / onmouseout: マウスが乗った時、離れた時
* onload: ページが読み込まれた時
* oninput: 文字が入力された時

オブジェクトの概念

ブラウザはHTML/CSSを「オブジェクト」という部品として捉える。JavaScriptは、これらのオブジェクトに対して「誰が」「何をするか」という明確な命令を出すマニュアルである。

JavaScriptの基本的な記述ルール

1. 文末のセミコロン (;): 命令の区切りを明確にする。
2. 変数の宣言 (const, let): データを保存する「名前付きの箱」。値を変えない場合はconst、変える場合はletを優先的に使用する。
3. データ型: 文字列（" "で囲む）、数値、論理型（true/false）、未定義（undefined）など。
4. 半角文字の徹底: 文字列とコメント以外は必ず半角文字で記述する。 全角スペースや全角記号が混入するとプログラムは動作しない。

## 7. 演算子と制御文：知能の実装

JavaScriptに計算や判断をさせるための道具が演算子である。

* 算術演算子: +, -, *, /, %（余り）。
* 比較演算子: ===（厳密に等しい）、>、<など。初学者は、型まで正確にチェックする===を使用すべきである。
* 論理演算子: &&（かつ）、||（または）、!（ではない）。複数の条件を組み合わせるために使用する。
* 制御文: プログラムの流れをコントロールする「脳」にあたる。判断（もし〜なら）や繰り返しを定義する。

## 8. 学習上の重要アドバイス

* 開発者ツール（コンソール）の活用: console.log()を使用して、プログラムが意図通りに動いているか、変数の値や型（typeofで確認）が正しいかを頻繁に確認することが推奨される。
* 外部ファイル化: JavaScriptコードはHTML内に直接書くことも可能だが、プロの開発現場では再利用性を高めるために.jsファイルとして外部化し、</body>タグの直前で読み込ませるのが一般的である。
* 命名規則: 変数や関数には意味のある英語の名前を付け、2つ目以降の単語の先頭を大文字にする「キャメルケース（例: userName）」を使用することで、ケアレスミスを防ぎ、コードの可読性を高めることができる。
