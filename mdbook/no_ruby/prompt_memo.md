以下のルールでHTML５のフリガナを振ってください

- すべての漢字に HTML ルビ <ruby>…<rt>…</rt></ruby> を付与
- Markdown構造・表・画像は原文のまま維持
- バッククォートや記号を壊さないように注意して処理

---ここからフリガナ対象

###### ② `i` フラグ（大文字小文字を無視）をつけたとき

```javascript
const pattern2 = new RegExp("banana", "i"); // 大文字小文字を気にしない

const result2 = text.replace(pattern2, "りんご");
console.log(result2); 
// 結果: "私は りんご が好きです。でも、banana はもっと好きです。"
// ※ 最初に見つかった大文字の "Banana" が置（お）き換（か）わりましたが、2つ目の小文字はそのままです。

```

##### ③ `g` と `i` フラグを【両方】つけたとき： 全部まとめて置き換える！

文章の中にあるターゲットを、大文字小文字に関わらず**すべて一発で置き換えたいとき**は、`gi`（または `ig`）を使います。これが実務でも一番よく使われる形です。

```javascript
const pattern3 = new RegExp("banana", "gi"); // 大文字小文字を気にせず、ぜんぶ！

const result3 = text.replace(pattern3, "りんご");
console.log(result3); 
// 結果: "私は りんご が好きです。でも、りんご はもっと好きです。"
// ※ みごとにすべてのバナナがりんごに変身（へんしん）しました！

```

#### 3. 実務でよくある使い方： 「NGワード（不適切な言葉）」の非表示

Webサイトの掲示板やチャットアプリを作るとき、誰かが悪口や秘密の情報を書き込んだら、自動的に `***` や `[削除]` に置き換えるシステム（フィルター機能）によく使われます。

```javascript
const chatMessage = "お前のバカ！BAKA！本当にもう知らない！";

// 「バカ」という言葉（ことば）を大文字小文字にかかわらず（gi）すべて見つける
const ngWordPattern = new RegExp("バカ|baka", "gi") 

// 安全な文字に置き換える
const safeMessage = chatMessage.replace(ngWordPattern, "***");
console.log(safeMessage); 
// 結果: "お前の***！***！本当にもう知らない！"

```

#### 4. まとめ

> `String` の **`replace()`** メソッドは、正規表現と一緒に使うことで、文章の中の文字を自由自在《じゆうじざい》に書き換えることができます。
> 大切なルールは次の3つです。
> 1. **順番**： `文字列.replace(/探すパターン/, "新しい文字")` の順番で書きます。
> 2. **フラグのパワー**： **/パターン/gi** のように `g` と `i` を一緒につけると、大文字・小文字を気にせず、文章の中にあるターゲットを**全部まとめて**新しい文字に変えてくれます。
> 3. **元の文字は消えない**： `replace()` を使っても、元の変数の中身は変わりません。必ず新しく作った結果を別の変数（`const newText = ...`）に代入《だいにゅう》して使いましょう。
> 
> 
> ユーザーが入力したデータから、いらないスペース（空白）を消したり、危険な文字を隠したりするときにとても役に立つので、ぜひ覚えてくださいね！
