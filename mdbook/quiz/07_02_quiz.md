6. こたえ と せつめい (Answers and Explanations)

1. B : Mathオブジェクトは、数学（すうがく）で つかう いろいろな 道具（どうぐ）が 入（はい）っている「道具箱（どうぐばこ）」です。
2. C : Date（日付）などとは 違（ちが）います。Mathは new を つかわずに、いきなり よびだすことが できます。
3. A : Math.メソッド名() の 形（かたち）で 書（か）きます。
4. C : ブラウザの中（なか）に 最初（さいしょ）から「専門家（せんもんか）」として 座（すわ）っているので、すぐに 仕事（しごと）をしてくれます。
5. A : 自分で むずかしい 計算式（けいさんしき）を 考（かんが）えなくても、道具（メソッド）を えらぶだけで 答（こた）えが 出（で）ます。
6. B : 乱数（らんすう）は、次（つぎ）に 何（なに）が出るか 予測（よそく）できない 数字（すうじ）です。サイコロと同じです。
7. C : Math.random() は 0 から 1 の 間（あいだ）の バラバラな数（かず）を 作（つく）ります。
8. B : Math.round() は 四捨五入（ししゃごにゅう）です。4.6 は .5 以上（いじょう）なので 5 になります。
9. A : 4.4 は .4 以下（いか）なので、切（き）り捨（す）てられて 4 になります。
10. C : 「おみくじ」や「ゲームのダメージ」など、バラバラな数（かず）が ほしいときは Math.random() が 便利（べんり）です。
11. C : Ceiling（セイル / シーリング）は「天井（てんじょう）」という 意味（いみ）です。
12. B : Floor（フロア）は「床（ゆか）」という 意味（いみ）です。
13. C : Math.ceil() は「天井（てんじょう）へ ジャンプ！」します。小数点（しょうすうてん）があれば、上の数字（5）へ ジャンプします。
14. A : Math.floor() は「床（ゆか）へ ダウン！」します。小数点（しょうすうてん）を 消（け）して、下の数字（4）へ ダウンします。
15. A : 小数点（しょうすうてん）を 切り捨てて、下の 整数（せいすう）に する 命令（めいれい）です。
16. C : Math.PI には 円周率（えんしゅうりつ：3.14159...）が 入（はい）っています。円（えん）の 計算（けいさん）で つかいます。
17. B : 高機能（こうきのう）な 電卓（でんたく）にある 特別（とくべつ）な ボタンのようなものです。
18. C : Math.max() は、たくさんの 数字（すうじ）から 一番（いちばん）大（おお）きいものを 教（おし）えてくれます。
19. B : これが 一番（いちばん）よくつかう「魔法（まほう）の式（しき）」です。
20. A : Math.random() * 10 は「0 から 9.999...」までの 数（かず）を作（つく）ります。それを Math.floor() で「ダウン（切（き）り捨（す）て）」するので、0 から 9 までの 整数（せいすう）に なります。
