第1章：JavaScriptの基本と出力（4問）

問1：プログラムを作る人（開発者：かいはつしゃ）が、プログラムのミスを確認するためにメッセージを出す命令（めいれい）はどれですか？ 
A. alert() 
B. console.log() 
C. prompt() 
D. document.write()

【解答】B 【解説】 console.log() は、開発者がプログラムの動きを確認（デバッグ）するために、コンソールへメッセージを出す命令です。Aの alert() は、ユーザーへ知らせるための「拡声器（かくせいき）」のようなもので、画面に小さな窓（まど）が出ます。

問2：JavaScriptの「文（ぶん）」の最後につける、命令の区切りを表す記号は何ですか？ 
A. コロン ( : ) 
B. カンマ ( , ) /
C. セミコロン ( ; ) 
D. ピリオド ( . )

【解答】C 【解説】 JavaScriptでは、1つの完璧（かんぺき）な命令を「文」と呼びます。どこで命令が終わるのかをはっきりさせるために、最後にセミコロン ( ; ) を書くのがルールです。

問3：外部（がいぶ）JavaScriptファイルを読み込むコードを書く場所として、一番良いのはどこですか？ 
A. <head> タグの中 
B. <body> タグのすぐ後 
C. <body> タグの最後（ </body> の直前） 
D. HTMLファイルのどこでもよい

【解答】C 【解説】 ブラウザはHTMLを上から順番（じゅんばん）に読み込みます。プログラムを最後に読み込ませることで、ページの文字や画像を先に見せることができます。そうすることで、「ユーザーを待たせない」スムーズな表示が可能になります。

問4：Windowsのパソコンで、コンソール画面（がめん）を開くためのショートカットキーはどれですか？ 
A. F5 
B. F12 または Ctrl + Shift + I 
C. Ctrl + C 
D. Alt + Tab

【解答】B 【解説】 Windowsでは F12 キー（ノートPCは Fn + F12）または Ctrl + Shift + I を押すと、プログラムの答え（実行結果：じっこうけっか）を確認できるコンソールを開くことができます。

第2章：プログラミングの重要ルール：半角と全角（3問）

問5：JavaScriptのコードを書くとき、絶対に守（まも）らなければならないルールはどれですか？ 
A. すべて全角（ぜんかく）で書く 
B. 基本的にすべて半角（はんかく）で書く 
C. 大文字と小文字はどちらでもよい 
D. スペースは必ず全角にする

【解答】B 【解説】 プログラムは英語がベースなので、すべて半角の「スリムな文字」で書きます。全角の「太っちょな文字」が混ざると、コンピュータはそれを「ナゾの記号」だと思って動かなくなります。文字の「箱のサイズ」が違うと覚えておきましょう。

問6：日本語を入力して、確定（Enter）する前に一瞬（いっしゅん）で「半角」に変換（へんかん）できる便利なキーは何ですか？ 
A. F7 
B. F8 
C. F9 
D. F10

【解答】B 【解説】 日本語を入力したあと、Enterを押す前に F8 キーを押すと、すぐに半角にできます。F9 を押すと全角のアルファベットになります。

問7：プログラムが動かない原因（げんいん）になりやすい、見た目では気づきにくい「見えないモンスター」のようなものは何ですか？ 
A. 全角のカタカナ 
B. 半角のアルファベット 
C. 全角のスペース（空白） 
D. 文の終わりのセミコロン

【解答】C 【解説】 全角スペースは、コードの中に入っても見た目ではただの「空白」に見えます。しかし、これが入っているとプログラムは絶対に動きません。一番ミスしやすいポイントなので注意しましょう！

第3章：変数とデータ型（5問）

問8：JavaScriptの「変数（へんすう）」とは何ですか？ 
A. 画面を光らせるライト 
B. データを保存（ほぞん）するための「名前のついた箱」 
C. ページを削除（さくじょ）する消しゴム 
D. コンピュータの電源ボタン

【解答】B 【解説】 変数は、数字や文字などのデータを取っておくための「名前のついた箱」です。箱に名前（ラベル）を付けることで、あとで何度でもそのデータを使うことができます。

問9：一度決めた値を、あとで変更（へんこう）できない変数を宣言（せんげん）するキーワードはどれですか？ 
A. let 
B. var 
C. const 
D. set

【解答】C &【解説】 const は「箱に貼った固定ラベル」です。一度代入（だいにゅう）した値を「変えない」という約束（やくそく）をします。これを使うことで、プログラムのバグ（ミス）を減らすことができます。プロは基本、この const を使います。

問10：プログラミングで推奨（すいしょう）される「キャメルケース」という名前の付け方はどれですか？ 
A. 1stscore 
B. my score 
C. userName 
D. user_name

【解答】C 【解説】 2つ目の単語の最初を大文字にする書き方を「キャメルケース (camelCase)」と呼びます。userName のように書くのがプロの共通ルールです。数字から始めてはいけない、スペースを入れてはいけない、というルールもあります。

問11：バッククォート（  ）を使い、${ }` で変数を埋（う）め込むことができる書き方を何と呼びますか？ 
A. テンプレートリテラル 
B. シングルクォーテーション 
C. ダブルクォーテーション 
D. ストリングメソッド

【解答】A 【解説】 バッククォート（ ）を使った「テンプレートリテラル」を使うと、文章の中に${userName}` のように変数を簡単に入れることができて便利です。

問12：入力フォームなどから受け取った「文字列」を「数値」に変えるために使う命令はどれですか？ 
A. typeof 
B. String() 
C. parseInt() 
D. isNaN()

【解答】C 【解説】 ユーザーが入力したデータは「文字列」です。計算をするためには、parseInt() や Number() を使って「数値」に変換する必要があります。

第4章：ブラウザのオブジェクトとDOM（4問）

問13：ブラウザ全体を管理している、JavaScriptの世界の「王様（ボス）」にあたるオブジェクトは何ですか？ 
A. document 
B. body 
C. window 
D. location

【解答】C 【解説】 window オブジェクトはすべての「ルート（根っこ）」であり、ブラウザ全体を管理する王様です。王様は、メッセージを出す「拡声器（alert）」や、質問をする「アンケート用紙（prompt）」などの便利な道具も持っています。

問14：HTMLの構造（こうぞう）を「親子関係」などで表した「生きている木」のような形を何と呼びますか？ 
A. HTMLリスト 
B. DOMツリー 
C. CSSボックス 
D. JavaScriptマップ

【解答】B 【解説】 ブラウザがHTMLを読み取り、要素を整理したものを「DOMツリー」と呼びます。親・子・兄弟という「家族（かぞく）」のような関係でつながっています。

問15：HTMLの「ID」を使って、特定のパーツを一つだけ確実に見つける命令（メソッド）はどれですか？ 
A. getElementById 
B. getElementsByClassName 
C. querySelectorAll 
D. getElementsByTagName

【解答】A 【解説】 getElementById は、世界に一つしかない「住所（ID）」を使って要素を探します。一番確実で、早く見つけることができる方法です。

問16：querySelectorAll を使って複数の要素を取得したとき、「0番目」の要素を操作するにはどう書きますか？ 
A. items(0) 
B. items{0} 
C. items[0] 
D. items.0

【解答】C 【解説】 querySelectorAll は「グループ（リスト）」を返します。グループの中から特定の1人を選びたいときは、[0] のように番号で呼びます。JavaScriptでは最初の人を「0番目の人」と呼ぶのがルールです。

第5章：オブジェクトの構造とイベント処理（4問）

問17：オブジェクトが持つ「特徴（とくちょう：名前、色、身長など）」の情報を何と呼びますか？ 
A. メソッド 
B. プロパティ 
C. イベント 
D. 変数

【解答】B 【解説】 オブジェクトの中にある情報のことを「プロパティ」と呼びます。それに対して、走る・計算するなどの「動き（関数）」は「メソッド」と呼びます。

問18：オブジェクトの中から情報を取り出したり、メソッドを動かしたりするときに使う記号は何ですか？ 
A. カンマ ( , ) 
B. ドット ( . ) 
C. アスタリスク ( * ) 
D. スラッシュ ( / )

【解答】B 【解説】 student.name のように、ドット ( . ) を使うことで、オブジェクトの中身にアクセスできます。

問19：addEventListener() を使って「待ち合わせの約束」をするとき、必要（ひつよう）な3つの情報は「だれに？」「いつ？」「どうするか？」です。「いつ？」にあたる部分は次のどれですか？ 
A. 要素 (Target) 
B. イベント名 (Type) 
C. 関数 (Listener) 
D. 変数 (Variable)

【解答】B 【解説】 addEventListener は「ホテルのフロント」への予約のようなものです。「朝の7時（イベント名）になったら、起こして（関数）」と頼みます。フロント（ブラウザ）は、その約束をメモして、耳をすませて待ってくれます。

問20：addEventListener() が、昔の書き方（ onclick など）よりも優（すぐ）れている点はどこですか？ 
A. 文字が短く書ける 
B. 1つの要素に2つ以上の約束（予約）ができる 
C. 半角で書かなくてもよい 
D. HTMLの中に直接書ける

【解答】B 【解説】 addEventListener のすごいところは、1つのボタンに対して「クリックされたら色を変える」と「クリックされたら音を出す」のように、複数の約束を重ねて予約できる点です。
