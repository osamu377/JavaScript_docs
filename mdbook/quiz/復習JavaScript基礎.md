9. 解答と解説

1. 正解: B / 解説: JavaScriptでは、命令（めいれい）の終わりにセミコロン（;）をつけます。
2. 正解: C / 解説: コードを書くときは、全角（太っちょな文字）ではなく、必ず「半角（スリムな文字）」を使います。全角スペースが1つあるだけでエラーになります。
3. 正解: D / 解説: 「キャメルケース」は2つ目の言葉の最初を大文字にします。プロの世界のルールです。
4. 正解: B / 解説: JavaScriptのメモ（コメント）は // で始めます。コンピューターはこれを無視します。
5. 正解: C / 解説: 一度入れたら中身を変えられない「カギをかけた箱」は const（定数）で作ります。
6. 正解: A / 解説: const は箱を作るときに、必ず中身（あたい）を入れなければなりません。これを「初期化（しょきか）」といいます。
7. 正解: B / 解説: 文字（文字列）はダブルクォーテーション " またはシングルクォーテーション ' で囲みます。
8. 正解: C / 解説: 箱（変数）はあるけれど、中身がまだ入っていない状態を undefined といいます。
9. 正解: C / 解説: 文章の中に箱を入れたいときは、バッククォート（ ` ）と ${ } を使います。
10. 正解: B / 解説: Number() という魔法のマシン（関数）を使うと、文字を数字に変えることができます。
11. 正解: C / 解説: % は「割り算の余り」を計算するための便利な記号です。
12. 正解: C / 解説: === を使うと、データ型（数字か文字か）まで正確に調べることができます。== はバグの原因になりやすいので避けましょう。
13. 正解: B / 解説: ++ は、数字を1つ増やす（インクリメント）ための特別な記号です。
14. 正解: C / 解説: 「AかつB（どっちも正しい）」のときは && を使います。
15. 正解: D / 解説: 計算の順番を先にしたいときは ()（かっこ）でグループを作ります。
16. 正解: A / 解説: if文の条件は () で囲み、その後の命令は {}（波かっこ）の中に書きます。
17. 正解: B / 解説: 別の条件を追加したいときは else if を使います。
18. 正解: C / 解説: switch文でどのケースにも合わないときは、default: の場所が動きます。
19. 正解: D / 解説: switch文の各ケースの最後には、外に出るための break; が必要です。
20. 正解: B / 解説: 「かつ（AND）」の条件は && を使ってつなぎます。
21. 正解: A / 解説: for文は (初期設定; 継続条件; 増減処理) の順に、セミコロンで区切って書きます。
22. 正解: B / 解説: 条件がずっと正しいままで、ループが終わらなくなることを「無限ループ」といいます。
23. 正解: C / 解説: break を使うと、繰り返し処理をその場で止めることができます。
24. 正解: D / 解説: continue は、今回の処理だけ飛ばして、すぐに次の繰り返しに進みます。
25. 正解: C / 解説: i < 3 という条件なので、0, 1, 2 まで表示されます。3になるときは条件に合わなくなるので止まります。
26. 正解: B / 解説: 新しいマシン（関数）を作るときは function 名前() { ... } という形にします。
27. 正解: A / 解説: マシンから結果（答え）を出すときは return（戻り値）を使います。
28. 正解: B / 解説: アロー関数は =>（矢印）を使って短く書く、今の現場で一番よく使われる書き方です。
29. 正解: B / 解説: HTMLのボタンでクリックに反応させるには onclick という「きっかけ（ハンドラ）」を使います。
30. 正解: C / 解説: 入力欄に文字が打ち込まれた瞬間に動くのは oninput イベントです。
