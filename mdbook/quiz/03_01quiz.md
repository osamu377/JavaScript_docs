1. 変数（へんすう）と代入（だいにゅう）の基本（きほん）（第（だい）1問（もん）〜第（だい）3問（もん））

第（だい）1問（もん）：プログラミングにおける「変数（へんすう）」とは何（なに）ですか？ 
A. 計算（けいさん）の結果（けっか）だけを表示（ひょうじ）する命令（めいれい） 
B. データを保存（ほぞん）しておくための「名前（なまえ）のついた箱（はこ）」

* 解答（かいとう）： B
* 解説（かいせつ）： 変数（へんすう）は、数値（すうち）や文字列（もじれつ）などのデータを整理（せいり）して保存（ほぞん）しておくための「入（い）れ物（もの）」の役割（やくわり）をします。

第（だい）2問（もん）：プログラミングで「score = 100」と書（か）いたとき、正（ただ）しい意味（いみ）は何（なに）ですか？ 
A. 「score」と「100」が数学（すうがく）のように同（おな）じ値（あたい）であることを示（しめ）す 
B. 左側（ひだりがわ）の「score」にあるデータを、右側（みぎがわ）の「100」に移動（いどう）させる 
C. 右側（みぎがわ）にある「100」というデータを、左側（ひだりがわ）の「score」という変数（へんすう）に入（い）れる 
D. 「score」という言葉（ことば）の長（なが）さが 100文字（もじ）であることを確認（かくにん）する

* 解答（かいとう）： C
* 解説（かいせつ）： プログラミングの「＝（イコール）」は「代入（だいにゅう）」と言（い）います。右側（みぎがわ）にあるデータを左側（ひだりがわ）の箱（はこ）に入（い）れるという動（うご）きをします。

第（だい）3問（もん）：一度（いちど）、変数（へんすう）に値（あたい）を入（い）れたあとで、別（べつ）の値（あたい）を入れなおすことを何（なん）と言（い）いますか？

* 解答（かいとう）： B
* 解説（かいせつ）： すでに値（あたい）が入（い）っている変数（へんすう）に、新（あたら）しいデータを入れなおすことを「再代入（さいだいにゅう）」と呼（よ）びます。

2. letとconstの違い（ちがい）（第（だい）4問（もん）〜第（だい）6問（もん））

第（だい）4問（もん）：値（あたい）をあとで変（か）えることができる（再代入（さいだいにゅう）ができる）変数（へんすう）のキーワードはどれですか？ 
A. const 
B. static 
C. let 
D. final

* 解答（かいとう）： C
* 解説（かいせつ）： let で宣言（せんげん）した変数（へんすう）は、プログラムの途中（とちゅう）で中身（なかみ）を書きかえることが可能（かのう）です。

第（だい）5問（もん）：一度（いちど）代入（だいにゅう）したら、あとで値（あたい）を変（か）えることができないキーワードはどれですか？ 
A. let 
B. const 
C. var 
D. change

* 解答（かいとう）： B
* 解説（かいせつ）： const は、あとで値（あたい）を変（か）えることができない変数（へんすう）を作（つく）るときに使（つか）います。

第（だい）6問（もん）：JavaScriptでコードを書（か）くとき、おすすめのルールはどれですか？ 
A. すべて let を使（つか）い、const は絶対（ぜったい）に使（つか）わない 
B. 基本（きほん）は const を使（つか）い、どうしても値（あたい）を変（か）える必要（ひつよう）があるときだけ let を使（つか）う 
C. 昔（むかし）の書（か）き方（かた）である var だけを使（つか）うのが一番（いちばん）安全（あんぜん）である 
D. キーワードは何も書（か）かずに変数名（へんすうめい）だけを書（か）く

* 解答（かいとう）： B
* 解説（かいせつ）： 値（あたい）が変（か）わらないことが約束（やくそく）されている const を優先（ゆうせん）して使（つか）うことで、ミスを減（へ）らすことができます。

💡先生（せんせい）のヒント： 「定数（ていすう）」である const を多（おお）く使（つか）うと、コードを読（よ）んだ人（ひと）が「この値（あたい）はずっと変（か）わらないんだな」と安心（あんしん）して読（よ）めるようになります。プロのエンジニアも大切（たいせつ）にしているルールです。

3. 変数名（へんすうめい）のルールと慣習（かんしゅう）（第（だい）7問（もん）〜第（だい）9問（もん））

第（だい）7問（もん）：変数名（へんすうめい）として「使（つか）えない」ものはどれですか？ 
A. _userName （アンダースコアから始（はじ）まる）

* 解答（かいとう）： C
* 解説（かいせつ）： 変数名（へんすうめい）に数字（すうじ）を使（つか）うことはできますが、最初（さいしょ）に数字（すうじ）を使（つか）うことはできないというルールがあります。

第（だい）8問（もん）：「camelCase（キャメルケース）」という書（か）き方の説明（せつめい）として正（ただ）しいものはどれですか？

* 解答（かいとう）： B
* 解説（かいせつ）： いくつかの単語（たんご）をつなげるとき、2つ目（め）の言葉（ことば）の最初（さいしょ）を大文字（おおもじ）にする書（か）き方（かた）です。プログラミングでよく使（つか）われるルールです。

第（だい）9問（もん）：留学生（りゅうがくせい）がJavaScriptを書（か）くとき、最も注意（ちゅうい）すべきエラーの原因（げんいん）は何（なに）ですか？

4. データ型（がた）の種類（しゅるい）：文字列（もじれつ）（第（だい）10問（もん）〜第（だい）12問（もん））

* 解説（かいせつ）： 文字列（もじれつ）はシングルクォーテーション（ ' ' ）またはダブルクォーテーション（ " " ）で囲（かこ）む必要（ひつよう）があります。

第（だい）11問（もん）：バッククォート（ ` ）と ${ } を使（つか）って、変数（へんすう）を埋（う）め込（こ）む書（か）き方を何（なん）と言（い）いますか？ 
A. テンプレートリテラル

* 解答（かいとう）： A
* 解説（かいせつ）： テンプレートリテラルを使（つか）うと、文字列（もじれつ）の中（なか）に変数を簡単（かんたん）に入（い）れたり、改行（かいぎょう）したりすることができます。

第（だい）12問（もん）：文字列（もじれつ）として「こんにちは」と表示（ひょうじ）させたい場合（ばあい）、正（ただ）しい書（か）き方（かた）はどれですか？

5. データ型（がた）の種類（しゅるい）：数値（すうち）と計算（けいさん）（第（だい）13問（もん）〜第（だい）15問（もん））

* 解説（かいせつ）： JavaScriptでは整数（せいすう）も小数（しょうすう）も、すべて同（おな）じ数値型（Number）として管理（かんり）されます。

第（だい）15問（もん）：計算（けいさん）で「あまり」を求（もと）めたいときに使（つか）う記号（きごう）はどれですか？

第（だい）17問（もん）：「undefined（アンディファインド）」とは、どのような状態（じょうたい）ですか？ 
A. 変数（へんすう）の名前（なまえ）が長（なが）すぎること
