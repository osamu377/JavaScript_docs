JavaScript「関数（かんすう）」の基礎：復習テスト（全15問）

このテストは、JavaScriptの「関数（かんすう）」の基本（きほん）をどれくらい理解（りかい）できているかを確認（かくにん）するためのものです。留学生（りゅうがくせい）の皆さんが直感（ちょっかん）で理解（りかい）できるよう、料理（りょうり）や自動販売機（じどうはんばいき）の例（たと）えを使って作られています。

1. 用語（ようご）の整理（せいり）

第1問：演算子（えんざんし）について プログラミングで「+」や「-」、「==」などの記号（きごう）を何と呼びますか？また、料理（りょうり）に例（たと）えると何ですか？


A. 式（しき）／ 材料（ざいりょう） 
B. 演算子（えんざんし）／ 道具（どうぐ） 
C. 文（ぶん）／ 料理の完成品（かんせいひん） 
D. 関数（かんすう）／ レシピ

解答：B 解説： 「+」や「==」などの記号は、計算（けいさん）したり比（くら）べたりするための**演算子（えんざんし）です。包丁（ほうちょう）やお鍋（なべ）のように、材料（データ）を加工（かこう）するための「道具（どうぐ）」**の役割（やくわり）をします。

第2問：文（ぶん）とセミコロンについて コンピューターへの「命令（めいれい）」を何と呼びますか？また、その命令の終わりに付ける記号（きごう）は何ですか？


A. 文（ぶん）／ セミコロン（;） 
B. 式（しき）／ カンマ（,） 
C. 演算子（えんざんし）／ ピリオド（.） 
D. ブロック ／ コロン（:）

解答：A 解説： コンピューターへのひとつの完璧（かんぺき）な指示（しじ）を**「文（ぶん）」と言います。JavaScriptでは、日本語の「。」と同じように、文の最後にセミコロン（;）**を付けるのがルールです。

2. 関数の概念（がいねん）

第3問：関数のイメージについて 関数（かんすう）を「ジューサー（ミキサー）」に例（たと）えたとき、ジューサーの中（なか）で行われる「リンゴを細（こま）かくつぶす」といった具体的（ぐたいてき）な動きを何と呼びますか？


A. 引数（ひきすう） 
B. 戻（もど）り値（ち） 
C. 処理（しょり） 
D. 呼び出し

解答：C 解説： 関数は「材料（データ）」を入れて「結果」を出すマシンです。ジューサーの中（なか）で行われる具体的な仕事（しごと）や動きのことを**「処理（しょり）」**と言います。自動販売機（じどうはんばいき）なら「お金を数える」「在庫（ざいこ）を確認（かくにん）する」といった動きが処理にあたります。

第4問：関数を使うメリットについて プログラムの中で「関数」を使う理由（りゆう）として、正しいものはどれですか？


A. 1ヶ所を直せば全部が変わるので、なおしやすくなる。 
B. コードを整理（せいり）しやすくなり、見た目がスッキリする。 
C. 同じコードを何度も書かなくてよくなる（楽ができる）。 
D. A、B、Cすべて正しい。

解答：D 解説： 資料（しりょう）にある関数のメリットは「楽ができる（再利用）」「なおしやすくなる（修正のしやすさ）」「整理（せいり）しやすくなる」の3つです。これらを活用（かつよう）することで、賢（かしこ）くプログラムを書くことができます。

3. 関数の作り方（定義：てぎ）と命名規則（めいめいきそく）

第5問：基本の書き方について JavaScriptで関数を新しく作る（定義する）ときの正しい書き方はどれですか？


A. make function () { } 
B. function 関数名() { 実行したい命令 } 
C. def 関数名[] { 実行したい命令 } 
D. 関数名 function () ;

解答：B 解説： 関数を作るときは、まず「これから関数を作ります」という合図（あいず）の**function**を書きます。その後に名前（関数名）、カッコ()、そして命令（めいれい）を包（つつ）む中カッコ{ }（ブロック）を書くのが正しいルールです。

第6問：名前の付け方について プログラミングの世界（せかい）で推奨（すいしょう）される、2つ目以降（いこう）の単語（たんご）の最初（さいしょ）を大文字（おおもじ）にする書き方（例：showMessage）を何と呼びますか？


A. スネークケース 
B. キャメルケース 
C. フォルダケース 
D. ボックスケース

解答：B 解説： これを**「キャメルケース（camelCase）」**と呼びます。途中に大文字がある形（かたち）がラクダ（Camel）のコブのように見えるためです。関数名は「何をするものか」がすぐ分かるように、show（見せる）などの動詞（どうし）から始めるのがルールです。

4. 関数の実行（呼び出し）

第7問：呼び出し方について 作った関数（例：sayHello）を実際に動かしたいとき、どのように書けばよいですか？


A. sayHello; 
B. sayHello[] 
C. sayHello() 
D. run sayHello

解答：C 解説： 関数は、名前のあとに**()（カッコ）**をつけることで初めて動き出します。これを「呼び出し」と言います。カッコは「スイッチ」のようなもので、これを忘（わす）れるとマシンは動きません。

第8問：イベントとの連携（れんけい）について HTMLのボタンがクリックされた時（とき）に、JavaScriptの関数を動かす仕組みを何と呼びますか？


A. イベントハンドラ 
B. 演算子（えんざんし） 
C. ブロックスコープ 
D. グローバル変数

解答：A 解説： ウェブページで「ボタンを押した」などのきっかけで関数を呼び出すことを**「イベントハンドラ」**と言います。HTMLの onclick などを使って、JavaScriptと連携（れんけい）させます。

5. 引数（ひきすう）と戻り値（もどりち）

第9問：引数（ひきすう）の役割について 関数というマシンに外から入れる「材料（ざいりょう）」や「データ」のことを何と呼びますか？


A. 変数（へんすう） 
B. 引数（ひきすう） 
C. 戻（もど）り値（ち） 
D. セミコロン

解答：B 解説： 関数に渡（わた）すデータのことを**「引数（ひきすう）」**と呼びます。「材料を引き連（つ）れてくる数」と覚えると、読み方も覚えやすいです。

第10問：戻り値（もどりち）について 関数が処理（しょり）を終（お）えたあと、マシンの外に出してくれる「結果（けっか）」を何と呼びますか？また、その時に使うキーワードは何ですか？


A. 引数（ひきすう） ／ get 
B. 文（ぶん） ／ out 
C. 戻（もど）り値（ち） ／ return 
D. 式（しき） ／ give

解答：C 解説： 自動販売機から出てくる飲み物のように、返（かえ）ってくる結果を**「戻（もど）り値（ち）」**と言います。プログラムでは、英語で「返す」という意味の return を使って結果を外に出します。

第11問：仮引数（かりひきすう）と実引数（じつひきすう）の違いについて 次のコードで、name（箱の名前）と "田中"（実際の中身）の呼び方の組み合わせとして正しいものはどれですか？ function sayHello(name) { ... } sayHello("田中");


A. name：実引数 ／ "田中"：仮引数 
B. name：仮引数 ／ "田中"：実引数 
C. name：戻り値 ／ "田中"：演算子 
D. name：グローバル ／ "田中"：ローカル

解答：B 解説： 関数側（かんすがわ）で用意した「データの箱」の名前（name）を**「仮引数（かりひきすう）」と言います。呼び出すときに実際に箱へ入れるデータ（"田中"）を「実引数（じつひきすう）」**と言います。「名前が書いてある空の箱（仮）」に、「実際の中身（実）」を入れるイメージです。

6. 変数のスコープ（Scope）

第12問：スコープの種類（しゅるい）について 「公園（こうえん）にある時計（とけい）」のように、プログラムのどこからでも見える（使える）範囲（はんい）を何と言いますか？


A. グローバルスコープ 
B. ローカルスコープ（関数スコープ） 
C. インターネットスコープ 
D. パブリックスコープ

解答：A 解説： どこからでも有効（ゆうこう）な範囲を**「グローバルスコープ」**と言います。逆に、「家の中のリモコン」のように、その関数の中でしか使えない範囲を「ローカルスコープ」と言います。

第13問：ブロックスコープについて if 文や for 文などの { }（ブロック）の中だけで有効（ゆうこう）な変数の範囲を何と呼びますか？


A. 関数スコープ 
B. グローバルスコープ 
C. ブロックスコープ 
D. 演算子（えんざんし）スコープ

解答：C 解説： { } の中で let や const を使って作った変数は、その中だけでしか使えません。これを**「ブロックスコープ」**と言います。「お弁当箱（べんとうばこ）の中のおかず」のように、外（ブロックの外）にはこぼれない（使えない）イメージです。※ var はこのルールを守らず外に出てしまうので注意が必要です。

7. var, let, const の使い分け

第14問：変数の宣言（せんげん）について 今のJavaScriptで推奨（すいしょう）される、一番安全（あんぜん）な変数の作り方はどれですか？


A. 基本は const を使い、値が変わる時だけ let を使う。var は使わない。 
B. すべて var を使うのが一番自由で良い。 
C. すべて let を使い、const は使わない。 
D. 変数の名前の前に何も書かない。

解答：A 解説： var はルールがゆるすぎてミスが起きやすいため、今は使いません。基本は、一度入れたら中身を変えられない**「カギをかけた箱（const）」を使います。途中で値（あたい）を書き換える必要がある時だけ、「カギのない箱（let）」**を使います。

8. 無名関数（むめいかんすう）とアロー関数

第15問：アロー関数について =>（矢印：アロー）を使った最新（さいしん）の書き方の名前と、その特徴（とくちょう）として正しいものはどれですか？


A. 矢印（やじるし）関数 ／ 処理（しょり）がとても遅（おそ）くなる。 
B. アロー関数 ／ 短（みじか）くスッキリ書けて、現代（げんだい）の現場（げんば）で90%くらい使われている。 
C. 普通（ふつう）の関数 ／ 昔（むかし）の書き方なので、今はあまり使われない。 
D. 看板（かんばん）関数 ／ 名前が絶対に必要（ひつよう）になる。

解答：B 解説： **「アロー関数」**は、function と書かなくていいため、見た目がスッキリします。非常に便利なため、プログラミングの現場（げんば）では 90% くらい この書き方が使われています。今のうちに慣（な）れておきましょう！
