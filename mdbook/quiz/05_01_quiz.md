JavaScript復習テスト：組み込みオブジェクトと配列の基礎

留学生（りゅうがくせい）のみなさん、こんにちは！ このテストは、JavaScriptの「組み込み（くみこみ）オブジェクト」と「配列（はいれつ）」について、どれくらい分かっているかを確認（かくにん）するためのものです。

プログラミングの「中級者（ちゅうきゅうしゃ）」になるための、とても大切（たいせつ）なステップです。マンションやロッカー、電車のイメージを思（おも）い出（だ）して、合格（ごうかく）を目指（めざ）して頑張（がんば）りましょう！

【第1部：組み込みオブジェクトの基本】

問題 1：
JavaScriptに最初（さいしょ）から入っている、プログラムを助（たす）けてくれる「便利な道具箱（べんりなどうぐばこ）」のことを何と呼びますか？ 
A) ブラウザオブジェクト 
B) 組み込み（くみこみ）オブジェクト 
C) 外部（がいぶ）ライブラリ 
D) ユーザー定義（ていぎ）オブジェクト

解答：B 解説：JavaScriptには最初からたくさんの「便利な道具箱」が用意されています。これを「組み込みオブジェクト」と呼びます。

問題 2：
オブジェクトの中にある、名前や色（いろ）などの「特徴（とくちょう：データ）」のことを何と呼びますか？ 
A) メソッド 
B) プロパティ 
C) コンストラクタ 
D) インデックス

解答：B 解説：名前や値段（ねだん）などの「データ」を「プロパティ」、「走る（はしる）」や「話す（はなす）」などの「動き（関数：かんすう）」を「メソッド」と呼びます。

【第2部：配列の基本とアクセス】

問題 3：
配列（はいれつ）を「新しいマンションを建（た）てる」イメージで作るとき、正しい記号（きごう）はどれですか？ 
A) { } 
B) ( ) 
C) [ ] 
D) < >

解答：C 解説：JavaScriptで配列（ならんだ箱）を作るときは、[ ]（角かっこ：かくかっこ）を使います。 漢字（かんじ）のヒント：「配（はい）」は「くばる」、「列（れつ）」は「ならぶ」という意味です。データが並んでいる様子をイメージしましょう。

問題 4：
配列の「1つめ」のデータを取り出すとき、インデックス（番号：ばんごう）は何番から始まりますか？ 
A) 1 
B) -1 
C) 0 
D) 100

解答：C 解説：プログラミングの世界では「まだ一歩（いっぽ）も動いていない状態（じょうたい）」を0と考えます。「1つめは 0（ゼロ）！」と覚えましょう。

問題 5：
次（つぎ）のコードを実行（じっこう）すると、配列 snacks はどうなりますか？

const snacks = ["チョコ", "グミ"];

snacks[1] = "アイス";



A) ["アイス", "グミ"] 
B) ["チョコ", "グミ", "アイス"] 
C) ["チョコ", "アイス"] 
D) ["アイス"]

解答：C 解説：snacks[1] は2つめのデータ（グミ）を指します。そこに「アイス」を代入（だいにゅう）すると、グミが消えてアイスに書き換（か）わります。

問題 6：
配列の中に今いくつのデータ（要素：ようそ）が入っているかを教えてくれるプロパティは何ですか？ 
A) count 
B) size 
C) length 
D) number

解答：C 解説：.length（レングス）は、列に並んでいる人の数をパッと数えてくれる「リーダーのような存在（そんざい）」です。

【第3部：配列を操作するメソッド】

問題 7：
配列の「おしり（最後：さいご）」に、新しいデータを追加（ついか）するメソッドはどれですか？ 
A) pop 
B) push 
C) shift 
D) unshift

解答：B 解説：push（プッシュ）は電車の最後尾（さいこうび）に新しい車両（しゃりょう）をつなげるイメージです。元の配列は変わります。

問題 8：
配列の「おしり（最後）」のデータを1つ消すメソッドはどれですか？ 
A) pop 
B) push 
C) shift 
D) unshift

解答：A 解説：pop（ポップ）は電車の最後の車両を「切り離（はな）す」イメージです。

問題 9：
配列の「先頭（せんとう：一番前）」のデータを1つ消して、後ろのデータを前にずらすメソッドはどれですか？ 
A) pop 
B) push 
C) shift 
D) unshift

解答：C 解説：shift（シフト）は、お店の行列の先頭の人が店に入り、後ろの人が全員（ぜんいん）前にずれるイメージです。

問題 10：
配列の「先頭（せんとう：一番前）」に、新しいデータを「割り込み（わりこみ）」で追加するメソッドはどれですか？ 
A) pop 
B) push 
C) shift 
D) unshift

解答：D 解説：unshift（アンシフト）は、行列の一番前に割り込みをするイメージです。

問題 11：
slice（スライス）メソッドの特徴（とくちょう）として、正しい説明はどれですか？ 
A) 元の配列を直接（ちょくせつ）書き換える。 
B) 配列の一部をコピーして新しい配列を作る。元の配列は変わらない。 
C) 配列のすべてのデータを削除（さくじょ）する。 
D) 配列の中身をバラバラに広げる。

解答：B 解説：slice は「写真（しゃしん）」を撮るようなものです。料理でハムやチーズを薄（うす）く切るのと同じイメージで、元の塊（かたまり）はそのままで、一切れ分をもらいます。

問題 12：
splice（スプライス）メソッドは、何に例（たと）えられますか？ 
A) 写真撮影（さつえい） 
B) 手術（しゅじゅつ） 
C) 警察犬（けいさつけん） 
D) リーダー

解答：B 解説：splice は「手術」です。指定（してい）した場所を切り取ったり、新しいデータを埋（う）め込んだりして、元の配列を直接書き換えます。

問題 13：
slice と splice の一番大きな違いは何ですか？ 
A) アルファベットの文字数 
B) 元の配列が変わるか、変わらないか 
C) 使えるブラウザの種類（しゅるい） 
D) 実行するスピード

解答：B 解説：slice は「コピーなので元の配列は変わらない」、splice は「手術なので元の配列が変わる」という点が一番重要（じゅうよう）です。

問題 14：
配列の中に特定のデータがあるかないかを調べ、true か false を返してくれる「警察犬（けいさつけん）」のようなメソッドはどれですか？ 
A) find 
B) check 
C) includes 
D) has

解答：C 解説：includes（インクルーズ）は、配列の中に探し物があるかチェックしてくれます。

問題 15：
delete 演算子（えんざんし）を使って配列のデータを消すと、どうなりますか？ 
A) 配列の長さ（length）が自動的に短くなる。 
B) 消した場所が「穴あき（empty）」の状態になり、長さは変わらない。 
C) エラーになって止まる。 
D) 前のデータが後ろに移動する。

解答：B 解説：delete を使うと「部屋（箱）は残って中身だけが消える」ため、穴があいた状態になります。きれいに消したいときは splice を使いましょう。

【第4部：応用的な配列の操作】

問題 16：
スプレッド演算子 ...（てん・てん・てん）のイメージに最も近いものはどれですか？ 
A) マンションを建てる。 
B) 袋に入ったお菓子をテーブルにザーッと広げる。 
C) 警察犬が犯人を追いかける。 
D) 手術で中身を入れ替える。

解答：B 解説：スプレッド演算子は、配列の中身をバラバラにして取り出す「魔法（まほう）の記号」です。2つの配列を合体させるときなどに便利です。

問題 17：
連想配列（れんそうはいれつ）とは、何を使ってデータを探す仕組みですか？ 
A) 部屋の番号（数字） 
B) 名前（ラベル・キー） 
C) データの重さ 
D) ファイルの大きさ

解答：B 解説：普通の配列は「番号」で探しますが、連想配列は「名前（ラベル）」で中身を探すロッカーのような仕組みです。

問題 18：
JavaScriptで連想配列（名前と値のセット）を作るときの正しい形はどれですか？ 
A) [ key = value ] 
B) { key: value } 
C) < key: value > 
D) ( key -> value )

解答：B 解説：JavaScriptでは「名前（キー）」と「中身（値）」を { } と : を使ってセットにします。これを「オブジェクト」と呼びます。

問題 19：
二次元配列（にじげんはいれつ）をマンションに例えたとき、2つのカッコ [ ][ ] はそれぞれ何を表しますか？ 
A) [ 階（かい） ] [ 部屋（へや） ] 
B) [ 部屋 ] [ 階 ] 
C) [ 名前 ] [ 番号 ] 
D) [ 建物 ] [ 住所 ]

解答：A 解説：二次元配列は「配列の中の配列」です。左側のカッコが「どのグループ（階）か」、右側のカッコが「その中のどのデータ（部屋）か」を表します。

問題 20：
次のコードから「リー」さんを取り出す正しい書き方はどれですか？

const classMap = [

  ["田中", "鈴木"], 

  ["佐藤", "マリア"], 

  ["ジョン", "リー"] 

];



A) classMap[3][2] 
B) classMap[2][1] 
C) classMap[1][2] 
D) classMap[2][2]

解答：B 解説：リーさんは、3番目のグループ（2階：インデックスは2）の、2番目の人（1号室：インデックスは1）です。ですから、classMap[2][1] と書きます。
