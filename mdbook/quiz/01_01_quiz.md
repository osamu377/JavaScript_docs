HTML基礎 復習テスト：学習内容の理解度確認

このテストは、Web制作の土台（どだい）となるHTMLの知識を確認するためのものです。ITの世界で活躍するためには、まず「骨組み（ほねぐみ）」を正しく理解することが欠かせません。プロのクリエイターを目指して、自信を持って回答していきましょう。


--------------------------------------------------------------------------------


1. Webページの基本構造と3つの役割に関する問題

Webサイトを新しく作るとき、私たちは「HTML」「CSS」「JavaScript」という3つの技術を使い分けます。これらはよく「家を建てること」に例えられます。HTMLは家の柱や壁といった「骨組み」です。この土台がしっかりしていないと、あとから色を塗ったり（CSS）、便利な機械を動かしたり（JavaScript）することができません。ここでは、それぞれの技術がどうして大切なのか、その理由を復習しましょう。

【問題1】 Webサイトを「家」に例えたとき、HTMLが担当する役割として最も適切なものはどれですか。

1. 家の壁に塗る「ペンキ」や、部屋を飾る「インテリア」
2. 家の「電気」や「エレベーター」など、便利な動きを作る部分
3. 家の「柱」や「壁」など、建物の土台となる「骨組み」
4. 家の中に保存されている「写真」や「文章」などのデータそのもの

【問題2】 「ボタンを押すと画面の色が変わる」「メニューが開く」といった、Webページに「動きや機能」を加える役割を担うのはどの技術ですか。

1. HTML
2. CSS
3. JavaScript
4. メタ情報

基本的な役割を理解した後は、Webページの「見えない設定」であるメタ情報の重要性を確認しましょう。

2. メタ情報（設定）と文字コードに関する問題

ユーザーがブラウザで見る画面には直接表示されませんが、ブラウザや検索エンジンに対して「このページはどのようなページか」を伝える大切な情報が「メタ情報」です。特に、文字を正しく表示するための設定は、Webサイトの信頼（しんらい）に直結します。設定を間違えると、ユーザーに正しい情報を届けることができなくなるため、注意が必要です。

【問題3】 Webページのメタ情報を書く場所として、正しいタグはどれですか。

1. <body>タグの中
2. <head>タグの中
3. <title>タグの中
4. <footer>タグの中

【問題4】 ブラウザの「タブ」に表示される名前を設定するために使うタグはどれですか。

1. <meta>
2. <link>
3. <title>
4. <h1>

【問題5】 Webページを開いたとき、文字が「読めない記号（文字化け）」になってしまいました。これを直すために確認すべき設定は何ですか。

1. 画像を表示するためのパス（src属性）
2. JavaScriptの動きを作るプログラム
3. 日本語などを正しく出すための「文字コード」の設定
4. 他のページへ行くためのリンク（href属性）

ページ全体の設定が完了した後は、実際に画面に表示される具体的な要素（タグ）の使い分けに進みます。

3. 基本的なHTMLタグと特殊記号の使い分けに関する問題

HTMLタグは、その情報の「意味」を決めるものです。単に見た目を大きくするためではなく、情報の構造（こうぞう）を正しく伝えるためにタグを使い分けることが大切です。また、HTMLのルール上、特別な意味を持つ記号を文字として表示するための「エスケープ処理」についても学びましょう。

【問題6】 見出し（Heading）タグの使い方について、正しい説明はどれですか。

1. <h1>が一番小さく、<h6>が一番大きい
2. 画面の文字を大きくして目立たせるためだけに使う
3. <h1>から<h6>まであり、ページの構造をわかりやすくするために使う
4. 小さな見出しから順番に（<h6>から<h1>へ）使わなければならない

【問題7】 他のページへ行くためのリンクを作るとき、移動先の住所（URL）を指定するために使う「属性（ぞくせい）」はどれですか。

1. src属性
2. alt属性
3. href属性
4. type属性

【問題8】 言葉を「強く見せる（強調する）」ために使い、ブラウザで太い文字として表示されるタグはどれですか。

1. <p>
2. <strong>
3. <hr>
4. <pre>

【問題9】 文章のまとまり（段落）を作る<p>タグと、話題が変わるときに線を引く<hr>タグの説明として正しいものはどれですか。

1. <p>は線を引くために使い、<hr>は文章を書くために使う
2. <p>は文章の段落を作り、<hr>は水平線を引くために使う
3. どちらのタグも、必ず終わりのタグ（</p>や</hr>）が必要である
4. <p>は改行のためだけに使い、<hr>は文字を太くするために使う

【問題10】 新しい段落を作らずに、今の行の中で「改行」したいときに使うタグはどれですか。

1. <p>
2. <br>
3. <li>
4. <pre>

【問題11】 <img>タグのalt属性（オルト属性）には、どのような大切な役割がありますか。

1. 画像のサイズを大きくしたり小さくしたりする
2. 画像が表示されないときや、目が見えない人のために画像の内容を言葉で伝える
3. 画像をどこに保存しているか（場所）をブラウザに教える
4. 画像をクリックしたときに、別のページへ飛ぶようにする

【問題12】 プログラムのコードのように、スペースや改行を「書いた通りの形」でそのまま表示したいときに使うタグはどれですか。

1. <strong>
2. <pre>
3. <ul>
4. <a>

【問題13】 「1, 2, 3...」と数字がつくリストを作りたいとき、一番外側を囲むタグ（①）と、中の一つ一つのアイテムを入れるタグ（②）の組み合わせで正しいものはどれですか。

1. ① <ul> 　② <li>
2. ① <ol> 　② <li>
3. ① <li> 　② <ol>
4. ① <ol> 　② <ul>

【問題14】 HTMLで「<」や「>」という記号を文字として画面に出したいとき、そのまま書いてはいけない理由は何ですか。

1. 記号をそのまま書くと、文字が汚く見えてしまうから
2. ブラウザが「タグの始まりや終わり」だと勘違いして、正しく表示されないから
3. サーバーに負担がかかって、ページの読み込みが遅くなるから
4. JavaScriptが動かなくなってしまうから

【問題15】 HTMLの特殊記号（エスケープ）の書き方について、正しい説明はどれですか。

1. 「&」は特殊記号の始まりを教える記号なので、&amp; と書く
2. ダブルクォーテーション（"）は、そのまま書いても属性と間違われることはない
3. 「<」を表示したいときは、&gt; と書く
4. 特殊記号はすべて数字で書かなければならない

テキストや画像の配置を学んだ後は、データを整理して見せる「テーブル」と、JavaScriptで操作するための「目印」の付け方を検討します。

4. データの整理（テーブル）と識別子（id/class）に関する問題

たくさんのデータを整理して見せる「テーブル」は、タグの中にタグを入れる「入れ子（いれこ）」の構造を理解するのに最適です。また、将来的にJavaScriptを使って特定の場所を動かすためには、HTML要素に適切な「名前（目印）」を付けておく必要があります。

【問題16】 テーブル（表）を作るとき、タグを重ねる順番（外側から内側へ）として最も適切なものはどれですか。

1. <tr> → <table> → <td>
2. <table> → <tbody> → <tr> → <td>
3. <td> → <tr> → <tbody> → <table>
4. <table> → <td> → <tr> → <th>

【問題17】 Webページの中で、特定の1か所だけを見つけるための「たった1つ」の固有の名前（目印）を付ける属性は何ですか。

1. class属性
2. src属性
3. id属性
4. href属性

【問題18】 「このグループのボタンは全部赤くする」というように、複数の要素をグループにまとめて名前を付けたい場合、どの属性を使いますか。

1. id属性
2. class属性
3. alt属性
4. type属性

データの表示方法を理解した後は、ユーザーから情報を取得するための「フォーム」と、その送信プロセスに焦点を当てます。

5. ユーザー入力（フォーム）とデータ送信に関する問題

フォームは、Webサイトとユーザーが会話をするための窓口です。パスワードなどの大切な情報を取り扱うときは、使いやすさだけでなく「セキュリティ（安全）」も重要です。データを送る方法（メソッド）のルールを理解しましょう。

【問題19】 入力した文字が「●」などで隠れて、後ろの人に見えないようにする設定はどれですか。

1. <input type="text">
2. <input type="checkbox">
3. <input type="password">
4. <input type="radio">

【問題20】 パスワードや個人情報など、秘密（ひみつ）のデータをサーバーに送る際、URLにデータが表示されない安全な送信方法はどれですか。

1. GET（データがURLに含まれて送られる）
2. POST（データが外からは見えない形で送られる）
3. HREF（リンクとして送られる）
4. SUBMIT（ボタンとして送られる）

全ての設問を終えた後は、復習をより深めるための解答と詳細な解説を確認しましょう。

6. 解答とやさしい日本語による解説

1. 正解：3 HTMLは、建物の「柱」や「壁」と同じです。Webページの「骨組み（ほねぐみ）」を作る大切な役割があります。
2. 正解：3 JavaScriptは、家の「電気」や「機械」の役割です。ボタンを押したときの「動き」を作ります。
3. 正解：2 メタ情報は、Webページの設定（せってい）です。ユーザーの画面には出さない情報なので、<head>タグの中に書きます。
4. 正解：3 <title>タグに書いた名前は、ブラウザの一番上にある「タブ」に表示されます。
5. 正解：3 「文字化（もじば）け」が起きたときは、文字コードの設定を確認します。これを正しく設定すると、日本語が読めるようになります。
6. 正解：3 見出しは、ページの内容を整理してわかりやすく伝える「構造（こうぞう）」のために使います。
7. 正解：3 href（エイチレフ）は、リンク先の住所（URL）を教えるための「属性（ぞくせい）」です。
8. 正解：2 <strong>を使うと、文字が太くなります。ブラウザに「この言葉は大切です」と伝えることができます。
9. 正解：2 <p>は文章の「段落」を作ります。<hr>は、話題を変えるときなどに引く「水平線」のことです。
10. 正解：2 <br>は、新しい段落を作らずに、その場で「改行（かいぎょう）」するためのタグです。終わりのタグはいりません。
11. 正解：2 alt（オルト）は、画像が出ないときや、目が見えない人のために「画像の説明」を伝えるためのものです。みんなが使いやすいサイト（アクセシビリティ）にするために大切です。
12. 正解：2 <pre>は「整形（せいけい）済みテキスト」です。書いた通りのスペースや改行がそのまま画面に出ます。
13. 正解：2 数字のリストは <ol>（Ordered List）を使います。中身のアイテムは、どちらのリストでも <li> を使います。
14. 正解：2 「<」などの記号をそのまま書くと、ブラウザが「ここからタグが始まるのかな？」と迷（まよ）ってしまい、画面が正しく表示されません。
15. 正解：1 特殊記号は、必ず「&（アンパサンド）」から書き始めます。「<」は &lt;、「>」は &gt; です。
16. 正解：2 テーブルは「入れ子（いれこ）」構造です。大きな箱（<table>）の中に、見出しや内容のグループ（<thead>や<tbody>）を入れ、その中に行（<tr>）、さらにその中にマス目（<td>）を入れます。
17. 正解：3 idは、そのページで世界に「たった1つ」だけの特別な目印です。JavaScriptで特定の場所を探すときに使います。
18. 正解：2 classは、同じグループの仲間に同じ名前を付けるときに使います。
19. 正解：3 type="password" を使うと、入力した文字が隠れるので、安全にパスワードを入力できます。
20. 正解：2 POST（ポスト）はデータがURLに見えないので、秘密（ひみつ）の情報を送るのに向いています。反対に、GETはURLにデータが出るので、秘密の情報には使いません。
