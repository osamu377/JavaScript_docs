2. 【第1部】算術演算子とインクリメント（問1〜問5）



問1：次のプログラムの計算結果は何ですか？



let result = 6 * 2;







A. 8 

B. 3 

C. 12 

D. 4



* 解答： C

* 解説： * は掛け算の記号です。演算子は料理でいう「包丁」や「鍋」のような「料理の道具」です。材料（数値）をこの道具で加工して、新しい結果を作ります。



問2：次の計算で、変数 amari に入る数字は何ですか？



let amari = 10 % 3;







A. 1 

B. 3 

C. 0 

D. 10



* 解答： A

* 解説： % は「余り」を出すための道具です。計算機のボタンを押すのと同じですね。10 ÷ 3 は 3 余り 1 なので、答えは1になります。



問3：インクリメント（++）を使うと、数字はどうなりますか？



let count = 5;

count++;







A. 5のまま変わらない 

B. 1増えて「6」になる 

C. 1減って「4」になる 

D. 2倍になって「10」になる



* 解答： B

* 解説： ++ は値を「1」増やす特別なボタンのような道具です。ループ（繰り返し）で「あと何回」と数えるときによく使う魔法のような記号です。



問4：デクリメント（--）を使うと、数字はどうなりますか？



let count = 5;

count--;







A. 1増えて「6」になる 

B. 0になる 

C. 5のまま変わらない 

D. 1減って「4」になる



* 解答： D

* 解説： -- は値を「1」減らす道具です。これも計算機の特別なボタンだと思ってください。カウントダウンをするときにとても便利です。



問5：次のプログラムの結果はどうなりますか？



let result = "100" + 1;







A. 101 

B. "1001" 

C. "100" 

D. エラーになる



* 解答： B

* 解説： + は文字をつなげる「のり（接着剤）」のような役割もします。でも注意してください！文字の "100" に数字の 1 を足すと、計算されずにくっついて "1001" になってしまいます。これはよくある「計算の罠（わな）」です。

3. 【第2部】Number()関数、式、比較演算子（問6〜問10）



問6：正しく「101」と計算させるために、どの「魔法」を使えばいいですか？



let result = ________("100") + 1;







A. String() 

B. Calculator() 

C. Number() 

D. Text()



* 解答： C

* 解説： Number() は、「文字の数字」を「本物の数値」に変える**「魔法」**です。この魔法を使えば、文字の "100" が数値の 100 になり、正しく足し算ができるようになります。



問7：JavaScriptで「式（Expression）」の説明として正しいものはどれですか？ 

A. ただの文字のこと 

B. 演算子を使って、答え（値）を出すもの 

C. 画面を白くする命令のこと 

D. 料理の材料そのもののこと



* 解答： B

* 解説： 料理でいうと「野菜を切る」というアクションそのものが「式」です。アクションをすると「切った野菜」という「答え（結果）」が生まれます。このように、何かをして答えを出すフレーズを「式」と呼びます。



問8：次の比較の結果（checkの中身）はどうなりますか？



let check = 10 > 5;







A. true 

B. false 

C. 10 

D. 5



* 解答： A

* 解説： > は左の方が大きいか調べる道具です。10は5より大きいので、正しいという意味の「true（真）」という答えが生まれます。



問9：変数（箱）に値を入れるときと、同じか調べるときの記号の組み合わせで正しいものはどれですか？ 

A. 入れる：=== ／ 調べる：= 

B. 入れる：= ／ 調べる：+ 

C. 入れる：= ／ 調べる：=== 

D. 入れる：== ／ 調べる：=



* 解答： C

* 解説： = は右の値を左の「箱（変数）」に入れる「代入」の記号です。比べる記号ではありません。同じかどうかを調べるときは === を使います。この違いはとても大切です！



問10：なぜ == ではなく === を使うべきなのですか？ 

A. === のほうがキーボードで打ちやすいから 

B. === はデータの種類（数字か文字か）まで正確に調べるから 

C. == はインターネットの速度が遅くなるから 

D. === を使うと文字が自動的に消えるから



* 解答： B

* 解説： == を使うと、JavaScriptが**「お節介（おせっかい）」**を焼いて、文字と数字を勝手に同じだと思い込んでしまいます（例：5 == "5" が true になる）。これがバグの原因になります。正確に調べるために、種類まで厳しくチェックする === を使いましょう。

4. 【第3部】論理演算子と計算の優先順位（問11〜問15）



問11：論理積（&&）のルールで正しいものはどれですか？ 

A. 片方だけ true なら、全体が true になる 

B. すべての条件が true のときだけ、全体が true になる 

C. どちらも false のとき、true になる 

D. 結果を必ず false にする



* 解答： B

* 解説： && は「かつ（AND）」という意味です。「18歳以上」で、かつ「お金を払った」というように、すべての条件が正しいときだけ true になる厳しいルールです。



問12：論理和（||）のルールで正しいものはどれですか？ 

A. どれか1つでも true なら、全体が true になる 

B. すべてが true でないと、true にならない 

C. 結果を反対にする 

D. 数値を足し算する



* 解答： A

* 解説： || は「または（OR）」という意味です。どれか1つでも条件に合っていれば true になる、優しいルールです。



問13：論理否定（!）を使うと、結果はどうなりますか？ 

A. true が false になる（反対になる） 

B. 数字が 100 増える 

C. プログラムがそこで終了する 

D. 文字がすべて数字に変わる



* 解答： A

* 解説： ! は「〜ではない（NOT）」という意味です。結果を「くるっ」と反対にします。正しいものを間違いに、間違いを正しいものに入れ替えます。



問14：次の計算の答えは何ですか？



let result = 10 + 2 * 5;







A. 60 

B. 20 

C. 17 

D. 100



* 解答： B

* 解説： JavaScriptも「算数のルール」と同じ順番で計算します。足し算（+）よりも先に、掛け算（*）を計算します。 2 * 5 = 10 を計算してから、10 + 10 をするので 20 になります。



問15：「10 + 2 * 5」で、足し算を先に計算させて、答えを「60」にしたいときはどうすればいいですか？ 

A. 計算の行を分ける 

B. 括弧 ( ) を使う 

C. Number() をたくさん使う 

D. 数字の間にスペースをたくさん入れる



* 解答： B

* 解説： (10 + 2) * 5 のように括弧を使うと、その中を一番先に計算してくれます。

  * プロとしてのコツ： 複雑な計算では、必ず括弧 ( ) を使って順番をはっきりさせましょう。そうすることで、**「チームの仲間」**があなたの書いたコードを読んだときに、迷わずに理解できるようになります。

5. 全体へのアドバイスとまとめ



テストお疲れ様でした！最後までよく頑張りましたね。



演算子は、プログラムに「知能（判断力）」や「動き」という「心」を与えるためのとても大切な道具です。



★ プロからのアドバイス：



1. 括弧 ( ) を使いましょう： 計算の順番をはっきりさせることで、間違いのない「綺麗なコード」になります。これはチームで仕事をするプロのエンジニアにとって大切なマナーです。

2. コンソールは「最高の友達」です： ブラウザの「デベロッパーツール」にあるコンソールを使って、どんどん練習しましょう。 console.log(10 * 5 === 50); と入力して、自分の目で true が出るのを確認するのが一番の近道です。

3. JavaScriptの「お節介」に注意： == ではなく === を使う癖をつけましょう。
