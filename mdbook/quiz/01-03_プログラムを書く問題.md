### JavaScript プログラミング練習問題（全10問）


#### 問題1：メッセージを表示しよう
ブラウザのコンソール（開発者用画面）に、「はじめてのプログラム」というメッセージを出してください。
- 解答例： console.log("はじめてのプログラム");
- 解説： 開発者がプログラムの動きを確認（デバッグ）するときは console.log() を使います。文の最後には ;（セミコロン）を付けましょう。

#### 問題2：変数（へんすう）と定数（ていすう）
自分の名前を入れる「ずっと変わらない箱」と、テストの点数を入れる「あとで変えられる箱」をそれぞれ作ってください。
- 解答例： 
  const myName = "アリ";
  let testScore = 80;
- 解説： 中身を変えないときは const、変える可能性があるときは let を使います。名前は userName のように英語で付けるのがプロのルールです。

#### 問題3：計算をしてみよう
「10」を「3」で割（わ）ったときの「余り（あまり）」を計算して、コンソールに表示してください。
- 解答例： console.log(10 % 3);
- 解説： 割り算の余りを出すときは %（剰余演算子）という記号を使います。この場合は「1」が表示されます。

#### 問題4：文字をつなげよう
変数 country に "日本" という文字を代入（だいにゅう）し、テンプレートリテラル（  と ${ }）を使って、「私は日本に住んでいます」と表示してください。
- 解答例： 
  const country = "日本";
  console.log(私は${country}に住んでいます);
- 解説： バッククォート（  ）を使うと、文字列の中に ${変数名} で変数の内容を入れることができて便利です。

#### 問題5：文字を数字に変えよう
文字列の "100" に数字の 50 を足して、正しく 150 と計算されるようにしてください。
- 解答例： 
  let textNum = "100";
  console.log(Number(textNum) + 50);
- 解説： 文字の "100" と数字をそのまま + でつなぐと "10050" という文字になってしまいます。計算したいときは Number() を使って数値に変える必要があります。

#### 問題6：もし〜なら（条件分岐）
変数 age が 18 以上のときに、「お酒が買えます」とコンソールに出すプログラムを書いてください。
- 解答例： 
  let age = 20;
  if (age >= 18) { console.log("お酒が買えます"); }
- 解説： 「もし〜なら」という判断には if 文を使います。比較には >=（以上）などの記号を使います。

#### 問題7：厳密（げんみつ）な比較
変数 answer が、数値の 10 と「種類まで同じ」かどうかを調べる条件式（if文）を書いてください。
- 解答例： if (answer === 10) { ... }
- 解説： JavaScriptでは、値だけでなくデータの型（数字か文字か）まで正確に比べるために === を使うのがプロのルールです。

#### 問題8：複数の条件（かつ / または）
「点数（score）が 80点以上」かつ（AND）「出席率（attendance）が 80%以上」のときに「合格」と表示してください。
- 解答例： if (score >= 80 && attendance >= 80) { console.log("合格"); }
- 解説： 2つの条件が両方とも正しい（かつ）ときは && という記号を使います。

#### 問題9：繰り返しの処理
for 文を使って、コンソールに 0 から 4 までの数字を順番に（合計5回）表示してください。
- 解答例： 
  for (let i = 0; i < 5; i++) { console.log(i); }
- 解説： 決まった回数を繰り返すときは for 文が便利です。「初期設定」「続ける条件」「1増やす処理」の3つを書きます。

#### 問題10：一番大切なルール（半角文字）
次のコードが動かない理由を答えてください。
  ｌｅｔ　ｎａｍｅ　＝　”田中”；
- 解答例： コードがすべて「全角（ぜんかく）」で書かれているから。
- 解説： JavaScriptのプログラム（letや記号など）は、必ず半角（はんかく）で書かなければなりません。全角のスペースや記号が混ざると、エラーになって絶対に動きません。
