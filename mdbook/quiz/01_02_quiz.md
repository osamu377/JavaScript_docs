「JavaScript学習者のためのCSS基本ガイド」理解度確認テスト（全20問）

1. はじめに：本テストの目的（もくてき）と学習（がくしゅう）の重要性（じゅうようせい）

JavaScript（ジャバスクリプト）を学ぶ前に、なぜCSS（シーエスエス）の知識（ちしき）が必要（ひつよう）なのでしょうか。それには3つの戦略的（せんりゃくてき）なメリットがあります。

1. CSSを知らないとJavaScriptが書けない： 背景（はいけい）の色を変える命令（めいれい）を出すとき、CSSの用語（ようご）を知らなければプログラムが書けません。
2. 無駄（むだ）なコードが減（へ）る： CSSだけでできることを知っていれば、JavaScriptのコードを短（みじか）く、シンプルに保（たも）つことができます。
3. エラーを減らせる： 仕組みを理解（りかい）していれば、プログラムが「なぜか動かない」というミスを防（ふせ）ぐことができます。

このテストでは、単（たん）に正解（せいかい）を選ぶだけでなく、「JavaScriptでどう操作（そうさ）するか」をイメージしながら解いてみてください。

2. カテゴリA：CSSを学ぶ理由と基本構造（問1〜問3）

CSSとJavaScriptの関係（かんけい）と、CSSのルールについて確認（かくにん）します。

問1：JavaScriptを学習する人が、CSSを学ぶべき最も大きな理由（りゆう）は何ですか？

1. JavaScriptはCSSの代わりになる言語（げんご）だから。
2. CSSのプロパティ名を知らないと、JavaScriptでデザインを変える命令（めいれい）が書けないから。
3. CSSを使わなければ、JavaScriptの計算（けいさん）機能（きのう）が動かなくなるから。
4. HTMLを書く必要（ひつよう）がなくなるから。

問2：マウスを乗せた時に色を変えるなどの変化（へんか）を、CSSだけで作成（さくせい）するメリットは何ですか？

1. ページの表示（ひょうじ）速度（そくど）を無理（むり）やり上げることができるから。
2. JavaScriptのコードを短（みじか）く、シンプルに保（たも）つことができるから。
3. HTMLのタグをすべて消（け）すことができるから。
4. JavaScriptで計算（けいさん）するよりも、色（いろ）がきれいになるから。

問3：CSSの基本的な書き方の構成（こうせい）として、正しい組み合わせはどれですか？

1. セレクタ（場所）・プロパティ（項目）・値（どう変えるか）
2. タグ（名前）・リンク（接続）・アクション（動き）
3. 命令（コマンド）・対象（オブジェクト）・結果（リザルト）
4. スタイル（見た目）・クラス（グループ）・ID（番号）

基礎（きそ）知識（ちしき）が身につくと、それらが具体的にどのように文字（もじ）のデザイン（スタイル）へ反映（はんえい）されるかが理解（りかい）しやすくなります。

3. カテゴリB：文字のスタイルとセレクタの基礎（問4〜問8）

Webサイトの情報の読みやすさ（UX）を左右（さゆう）する文字設定（せってい）と、要素（ようそ）を特定（とくてい）する「セレクタ」の問題（もんだい）です。

1. text-style
2. font-size

問5：文字の色（いろ）を指定（してい）する正しいプロパティはどれですか？

1. font-color
2. background

4. text-decoration

問6：文字を中央（ちゅうおう）に寄せたい場合に、text-align プロパティに指定（してい）する値（あたい）はどれですか？

1. left
2. middle
3. center
4. right

問7：CSSの「セレクタ」についての説明（せつめい）として、JavaScriptとの関連（かんれん）を含めて正しいものはどれですか？

1. JavaScriptでは全く使われない、CSS専用（せんよう）の合言葉（あいことば）である。
2. 操作（そうさ）したい「場所（ばしょ）」を探（さが）すためのヒントであり、JavaScriptでオブジェクトを指定（してい）する際（さい）にも利用（りよう）する。
3. 文字のフォントの種類（しゅるい）を決めるための特別な命令（めいれい）である。
4. プログラムの計算（けいさん）結果（けっか）を一時的に保存（ほぞん）する場所のことである。

問8：タグセレクタ（h1やpなど）を使ってスタイルを指定する大きなメリットは何ですか？

1. ページ全体のデザインを一箇所（いっかしょ）ずつ個別に設定できること。
2. ページ内の同じタグに対して、一度（いちど）にまとめてデザインを適用（てきよう）できること。
3. JavaScriptを使わずに、複雑（ふくざつ）な計算（けいさん）処理（しょり）ができるようになること。
4. クラス名を考える手間（てま）が完全（かんぜん）に無（な）くなること。

文字のデザインの次は、複数の要素（ようそ）が組み合わさった「表（テーブル）」という、より複雑な構造（こうぞう）のデザインについて学びましょう。

4. カテゴリC：テーブル（表）のスタイル設定（問9〜問12）

情報の整理（せいり）に欠（か）かせないテーブルのデザインと、その特殊（とくしゅ）な設定（せってい）に関する問題（もんだい）です。

1. border: 1px solid black; （太さ・種類・色）
2. border: black 1px; （色・太さのみ）

問11：隣り合う2本の枠線を1本にまとめ、スッキリとした見た目にするための「魔法（まほう）の言葉」は何ですか？

1. border-style: single;
2. border-collapse: collapse;
3. border-join: true;

4. テーブルのデザインでは border を使ってはいけない。

タグへの直接（ちょくせつ）指定は便利（べんり）ですが、ページが複雑（ふくざつ）になると限界（げんかい）があります。JavaScriptで特定のグループだけを狙（ねら）って動かすために、次（つぎ）の「クラス」を学びましょう。

6. カテゴリE：疑似クラスとJavaScriptからの操作（問17〜問20）

ユーザーの操作（そうさ）への反応（はんのう）と、JavaScriptからCSSを書き換（か）える際の重要（じゅうよう）なルールに関する問題（もんだい）です。

問17：疑似（ぎじ）クラス :hover（ホバー）の役割（やくわり）は何ですか？

1. 要素（ようそ）の上にマウスカーソルが乗（の）った時の状態（じょうたい）を指定する。
2. ページを読み込んだ瞬間の状態を指定する。
3. リンクをクリックして別のページに移動（いどう）した後の状態を指定する。
4. 要素を画面（がめん）から消（け）すための命令である。

問18：CSSの :hover と JavaScriptの onmouseover / out の使い分けの指針（ししん）として適切なものはどれですか？

1. どちらを使っても全く同じなので、好（す）きな方（ほう）を使えば良い。
2. データの保存（ほぞん）などの機能（きのう）はCSSで行い、色の変更はJavaScriptで行う。
3. 見た目の変更（色を明るくするなど）はCSSを使い、複雑（ふくざつ）な機能の追加はJavaScriptを使う。

問19：JavaScriptでCSSのプロパティを操作（そうさ）するとき、正しい変換（へんかん）ルールはどれですか？

問20：JavaScriptで色を変えるまでの「道のり（パス）」の順序（じゅんじょ）として正しいものはどれですか？

1. document → 場所を見つける（getElementByIdなど） → style（担当者） → プロパティ（colorなど）

7. 解答（かいとう）と解説（かいせつ）

[問1：正解 2] [解説] JavaScriptの役割はCSSを操作してデザインを動的に変えることです。backgroundColor などの名前を知らないと、プログラムが書けません。

[問2：正解 2] [解説] CSSでできることを知っていれば、JavaScriptのコードを短く、シンプルに保つことができ、エラーも少なくなります。

[問3：正解 1] [解説] CSSは、**「どの場所に（セレクタ）」「何の項目を（プロパティ）」「どう変えるか（値）」**というルールで書くのが基本（きほん）です。

[問4：正解 2] [解説] 文字（font）の大きさ（size）を指定するのは font-size です。

[問5：正解 3] [解説] 文字の色を指定するプロパティは color です。

[問6：正解 3] [解説] 文字を中央（真ん中）に揃（そろ）える値は center です。

[問7：正解 2] [解説] セレクタはJavaScriptでも非常に重要（じゅうよう）です。仕事をしてもらうオブジェクト（要素）を指定する際に利用します。

[問8：正解 2] [解説] タグセレクタを使うと、ページ内の同じタグ（例：すべての pタグ）に対して一度にまとめてデザインを適用できるため、効率的（こうりつてき）です。

[問9：正解 1] [解説] border は、**「1px（太さ）」「solid（種類：実線）」「black（色）」**のように情報を組み合わせて指定します。

[問10：正解 3] [解説] **padding（内側の余白）**を調整（ちょうせい）することで、セルの中の文字と枠線の間のスペースを広げ、読みやすさを向上（こうじょう）させます。

[問11：正解 2] [解説] border-collapse: collapse; は、2本の線を1本にする**「魔法の言葉」**です。これを使うだけで、見た目がスッキリとプロらしくなります。

[問12：正解 2] [解説] 枠線（border）は各（かく）セルに、線をまとめる命令（border-collapse）は親要素である <table> に設定するのが正しいルールです。

[問13：正解 2] [解説] クラス（Class）は、プログラマが自分で名前をつけて特定のグループにスタイルを適用するための仕組みです。

[問14：正解 3] [解説] CSSでクラスを指定するときは、名前の始まりに必ず .（ドット） をつける決（き）まりがあります。

[問15：正解 3] [解説] JavaScriptと同じ camelCase（例：.submitButton） を使うと、名前の付け方が統一（とういつ）され、ケアレスミスを減らすことができます。

[問16：正解 2] [解説] getElementsByClassName() は、CSSで設定したクラス名を使って、JavaScriptから要素を見つけ出す命令です。

[問17：正解 1] [解説] **:hover（ホバー）**は、要素の上にマウスカーソルが乗ったときの「特別な状態（じょうたい）」を指定する疑似クラスです。

[問18：正解 3] [解説] 「色を明るくする」などの見た目の変更はCSSで行い、「データを保存する」などの機能の追加はJavaScriptで行うのが正しい使い分けです。

[問19：正解 2] [解説] JavaScriptでは、font-size を fontSize にするように、**ハイフンを消して次の文字を大文字にする「キャメルケース」**に書き換える必要があります。

[問20：正解 1] [解説] JavaScriptの操作は、document（書類）から目的の場所（IDなど）を見つけ、style（担当者）を通じて、color（プロパティ）を書き換えるという「道のり（パス）」で考えます。
