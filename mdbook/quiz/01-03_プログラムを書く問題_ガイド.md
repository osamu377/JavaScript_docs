### 💡 プログラミング問題の解き方ガイド

#### 例題1：変数（へんすう）と計算
**【問題】** 
1. 変数 `apple` に `150` を入れてください。
2. 変数 `orange` に `100` を入れてください。
3. 2つの合計（ごうけい）を計算して、コンソールに表示してください。

**【考え方のステップ】**
*   **ステップ1：** 「ずっと変わらない数字」なら `const`、「変わるかもしれない数字」なら `let` を使って箱を作ります。
*   **ステップ2：** `=`（イコール）を使って、右の数字を左の変数に入れます（代入）。
*   **ステップ3：** `+` 記号を使って足し算をします。
*   **ステップ4：** `console.log()` を使って結果を確認します。

**【解答例】**
```javascript
const apple = 150;
const orange = 100;
console.log(apple + orange); 
```
**【ポイント】**
*   最後に `;`（セミコロン）を忘れないようにしましょう。
*   すべて**半角（はんかく）**で書きます。全角（ぜんかく）のスペースが混ざると動きません。

#### 例題2：もし〜なら（条件分岐：じょうけんぶんき）
**【問題】**
変数 `score` が `80` 以上のときに、「合格（ごうかく）」と表示するプログラムを書いてください。

**【考え方のステップ】**
*   **ステップ1：** `let score = 85;` のように、まずは比べるための数字を変数に入れます。
*   **ステップ2：** 「もし〜なら」は `if` 文を使います。
*   **ステップ3：** 「〜以上」は `>=` という記号を使います。
*   **ステップ4：** 実行したい命令は `{ }`（波括弧：なみかっこ）の中に書きます。

**【解答例】**
```javascript
let score = 85;
if (score >= 80) {
    console.log("合格");
}
```
**【ポイント】**
*   `if` のあとの条件は `( )` で囲みます。
*   プロの世界では、データの種類まで正しく比べるために `===` を使うのがルールです。

---

### ⚠️ プログラミングを書くときの「3つの約束」

1.  **すべて半角（はんかく）で書く！**
    *   `let` や `if` 、`( )` 、`{ }` 、さらにスペース（空白）も、すべて「スリムな文字（半角）」で書きます。これが一番大切です。
2.  **エラーは「ヒント」！**
    *   もし動かなくても、コンソールに出る赤い文字を読みましょう。どこが間違っているか、ブラウザが教えてくれています。
3.  **最後にセミコロン `;` をつける！**
    *   命令（文）の終わりには `;` をつけて、「ここで命令が終わります」と伝えましょう。
