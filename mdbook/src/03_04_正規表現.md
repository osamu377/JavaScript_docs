# 正規表現

## 7. 正規表現（Regular Expression）

※ここからは基本的な論理の応用（おうよう）として紹介します。

Webサイトで「メールアドレスの形式が正しいか」などをチェックしたいとき、特定の「パターン」を探す必要があります。

* 役割: 文字列の中から特定のルールに合う文字の並びを見つけ出します。

So What?（なぜ大切なの？） if 文だけで複雑な文字チェックを書くと、コードが何十行にもなります。正規表現を学べば、複雑なパターンチェックもわずかな記述で解決でき、コードがすっきりします。
