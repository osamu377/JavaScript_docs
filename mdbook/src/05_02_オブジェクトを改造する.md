## III. プロトタイプ：JavaScriptの共通のルール

JavaScriptには、最初から便利な機能がたくさん備（そな）わっています。例えば、文字列を大文字にする toUpperCase() などです。これらが使えるのは、すべてのオブジェクトが **「プロトタイプ（Prototype）」という共通（きょうつう）の設計図（せっけいず）** を持っているからです。

これは、すべてのオブジェクトが利用（りよう）できる「公共（こうきょう）の図書館（としょかん）」のようなものです。

* 戦略的利点（せんりゃくてきりてん）： すべてのオブジェクトが共通の機能を共有（きょうゆう）することで、メモリを節約（せつやく）し、プログラムを効率（こうりつ）よく動かせます。一からすべてを作る必要（ひつよう）はなく、先人が作った便利な仕組みを借りる（Stand on the shoulders of giants）ことができるのです。


既存のオブジェクトを自分好みに作り変えることを、プログラミングの世界では**「拡張（かくちょう / Extension）」**や**「カスタマイズ」**と呼びます。

留学生の方には、これを**「買ってきた自転車（じてんしゃ）に、ライトをつけたり色をぬったりして改造（かいぞう）すること」**に例えて説明してあげましょう。

### 1. 既存のオブジェクトを改造する3つの方法

JavaScriptでは、すでに動いているオブジェクトに後から「新しいパーツ」を追加したり、「古いパーツ」を新しいものに取り替えたりできます。

#### **① 直接（ちょくせつ）追加する**

特定の1人（1つのインスタンス）だけに、新しいプロパティやメソッドを追加します。

* **イメージ：** 自分の自転車だけに、特別なステッカーを貼る。
* **書き方：** `オブジェクト名.新しい名前 = 値;`

```javascript
const myCar = { brand: "Toyota" };

// 後からプロパティを追加
myCar.color = "Red";

// 後からメソッドを追加
myCar.horn = function() {
  console.log("プップー！");
};

myCar.horn(); // 実行できる！

```

#### **② プロトタイプを使って「全員」に追加する**

そのクラスから生まれた「全員」に、新しい機能を持たせます。

* **イメージ：** マンションの住人全員が使える「共有のラウンジ」に、新しいテレビを置く。
* **書き方：** `クラス名.prototype.メソッド名 = function() { ... };`

```javascript
// 全ての配列（Array）に「2倍にする」という新しい機能を追加してみる
Array.prototype.double = function() {
  return this.map(n => n * 2);
};

const numbers = [1, 2, 3];
console.log(numbers.double()); // [2, 4, 6]

```

> **注意：** `Array` や `Object` などの標準（ひょうじゅん）の道具を勝手に改造するのは、他のプログラムとぶつかる可能性があるので、プロの世界では慎重（しんちょう）に行います。

#### **③ オーバーライド（上書き）する**

親から受け継いだ機能を、自分流のやり方に書き換えます。

* **イメージ：** お父さんから譲り受けたカメラだけど、レンズを最新のものに交換して使いやすくする。
* **書き方：** 同じ名前で新しく定義し直す。

```javascript
class Robot {
  greet() {
    console.log("ハロー、ロボットデス。");
  }
}

class JapaneseRobot extends Robot {
  // 親の greet を上書き（オーバーライド）
  greet() {
    console.log("こんにちは、ロボットです。");
  }
}

const robo = new JapaneseRobot();
robo.greet(); // 「こんにちは...」が出る

```

### 2. 留学生への例え話：スマホのケースとアプリ

> 「JavaScriptのオブジェクトは、一度作ったら終わりじゃないんだ。
> 1. **直接追加：** スマホに『お気に入りのストラップ』をつけるようなもの。そのスマホだけの特別。
> 2. **プロトタイプ追加：** OSをアップデートして『全員のスマホに新しい計算機アプリ』を入れるようなもの。
> 3. **オーバーライド：** 決まった『着信音（ちゃくしんおん）』を、自分の好きな音楽に変えるようなものだよ。
> 
> 
> こうやって、元の形を壊さずに自分らしく使いやすくするのが、JavaScriptの面白いところなんだ！」

---

### まとめテーブル

| 改造（かいぞう）の名前 | どうなる？ | 誰に影響（えいきょう）する？ |
| --- | --- | --- |
| **プロパティ追加** | 新しいデータを足す | そのオブジェクトだけ |
| **メソッド追加** | 新しい動きを足す | そのオブジェクト（または全員） |
| **オーバーライド** | 古い動きを新しい動きに変える | その子クラスから生まれた人全員 |

---

### 📝 留学生へのアドバイス

> 特に **`Array.prototype`** などを改造するときは、**『みんなの共有スペースに勝手に私物を置かない』** というマナーがあることも、一緒に覚えておこうね！」
