## II. よく<ruby>使<rt>つか</rt></ruby>う「4つの<ruby>道具<rt>どうぐ</rt></ruby>（メソッド）」

これだけ<ruby>覚<rt>おぼ</rt></ruby>えれば、<ruby>日常<rt>にちじょう</rt></ruby>のプログラミングで<ruby>困<rt>こま</rt></ruby>ることはありません。

### **① `Math.random()`：サイコロを<ruby>振<rt>ふ</rt></ruby>る**

0から1の<ruby>間<rt>あいだ</rt></ruby>で、バラバラな<ruby>数字<rt>すうじ</rt></ruby>（<ruby>乱数<rt>らんすう</rt></ruby>）を<ruby>作<rt>つく</rt></ruby>ります。

* **<ruby>使<rt>つか</rt></ruby>い<ruby>道<rt>みち</rt></ruby>：** ゲームのダメージ<ruby>計算<rt>けいさん</rt></ruby>、おみくじ、ラッキーカラーなど。
* **イメージ：** ガラガラ<ruby>抽選器<rt>ちゅうせんき</rt></ruby>を<ruby>回<rt>まわ</rt></ruby>す。

* **<ruby>使<rt>つか</rt></ruby>い<ruby>道<rt>みち</rt></ruby>：** <ruby>平均点<rt>へいきんてん</rt></ruby>（へいきんてん）をきれいな<ruby>数字<rt>すうじ</rt></ruby>にするとき。

### **③ `Math.ceil()` と `Math.floor()`：<ruby>天井<rt>てんじょう</rt></ruby>と<ruby>床<rt>ゆか</rt></ruby>**

* **`Math.ceil()`（<ruby>切<rt>き</rt></ruby>り<ruby>上<rt>あ</rt></ruby>げ）：** <ruby>小数点<rt>しょうすうてん</rt></ruby>があれば、<ruby>上<rt>うえ</rt></ruby>の<ruby>数字<rt>すうじ</rt></ruby>へジャンプ！

## III. コードで<ruby>見<rt>み</rt></ruby>てみよう！

<ruby>学生<rt>がくせい</rt></ruby>と<ruby>一緒<rt>いっしょ</rt></ruby>に、コンソールで<ruby>試<rt>ため</rt></ruby>してみてください。

```javascript

console.log(Math.ceil(4.1));    // 5（天井：切（き）り上（あ）げ）

// 1から10までのランダムな整数（せいすう）を作る魔法（まほう）の式

```
