### 2. <ruby>正規表現<rt>せいきひょうげん</rt></ruby>の `g` フラグによる<ruby>動<rt>うご</rt></ruby>きの<ruby>変化<rt>へんか</rt></ruby>

### 3. `i` フラグの `i` は<ruby>何<rt>なに</rt></ruby>の<ruby>略<rt>りゃく</rt></ruby>？

この `i` は、<ruby>英語<rt>えいご</rt></ruby>の **IgnoreCase（イグノア・ケース：<ruby>大文字小文字<rt>おおもじこもじ</rt></ruby>を<ruby>無視<rt>むし</rt></ruby>する）** という<ruby>言葉<rt>ことば</rt></ruby>の<ruby>頭文字<rt>かしらもじ</rt></ruby>です。

<ruby>通常<rt>つうじょう</rt></ruby>、JavaScriptの<ruby>正規表現<rt>せいきひょうげん</rt></ruby>は<ruby>大文字<rt>おおもじ</rt></ruby>と<ruby>小文字<rt>こもじ</rt></ruby>を「<ruby>完全<rt>かんぜん</rt></ruby>に<ruby>別<rt>べつ</rt></ruby>の<ruby>文字<rt>もじ</rt></ruby>」として<ruby>区別<rt>くべつ</rt></ruby>します。しかし、`i` フラグをつけると、それらを **<ruby>同<rt>おな</rt></ruby>じ<ruby>文字<rt>もじ</rt></ruby>** として<ruby>扱<rt>あつか</rt></ruby>ってくれるようになります。

#### コードで<ruby>見<rt>み</rt></ruby>る<ruby>違<rt>ちが</rt></ruby>い（フラグがある<ruby>時<rt>とき</rt></ruby>・ない<ruby>時<rt>とき</rt></ruby>）

<ruby>自分<rt>じぶん</rt></ruby>のパソコンのブランド（Apple）について<ruby>書<rt>か</rt></ruby>いた<ruby>文章<rt>ぶんしょう</rt></ruby>から<ruby>文字<rt>もじ</rt></ruby>を<ruby>探<rt>さが</rt></ruby>してみましょう。

このように、パターンのスラッシュの<ruby>後<rt>あと</rt></ruby>ろに `/パターン/i` と<ruby>書<rt>か</rt></ruby>くだけで、`Apple` も `apple` も `APPLE` も、ぜんぶ<ruby>一緒<rt>いっしょ</rt></ruby>に<ruby>見<rt>み</rt></ruby>つけてくれるようになります。

#### <ruby>前<rt>まえ</rt></ruby>に<ruby>習<rt>なら</rt></ruby>った `g` フラグと<ruby>一緒<rt>いっしょ</rt></ruby>に<ruby>使<rt>つか</rt></ruby>える？

はい、**<ruby>一緒<rt>いっしょ</rt></ruby>に<ruby>使<rt>つか</rt></ruby>えます！** <ruby>順番<rt>じゅんばん</rt></ruby>は `ig` でも `gi` でもどちらでも<ruby>大丈夫<rt>だいじょうぶ</rt></ruby>です。

<ruby>前<rt>まえ</rt></ruby>に<ruby>学<rt>まな</rt></ruby>んだフラグを<ruby>使<rt>つか</rt></ruby>うことで、<ruby>文字<rt>もじ</rt></ruby>の<ruby>置<rt>お</rt></ruby>き<ruby>換<rt>か</rt></ruby>え<ruby>方<rt>かた</rt></ruby>がガラリと<ruby>変<rt>か</rt></ruby>わります。ここが<ruby>留学生<rt>りゅうがくせい</rt></ruby>のコードの<ruby>楽<rt>たの</rt></ruby>しさであり、つまずきやすいポイントでもあります。

```javascript
// 結果（けっか）: "私は Banana が好きです。でも、りんご はもっと好きです。"
// ※ 小文字の "banana" だけが置（お）き換（か）わり、最初にある大文字の "Banana" は無視（むし）されました。
```

###### ② `i` フラグ（<ruby>大文字小文字<rt>おおもじこもじ</rt></ruby>を<ruby>無視<rt>むし</rt></ruby>）をつけたとき

##### ③ `g` と `i` フラグを【<ruby>両方<rt>りょうほう</rt></ruby>】つけたとき： <ruby>全部<rt>ぜんぶ</rt></ruby>まとめて<ruby>置<rt>お</rt></ruby>き<ruby>換<rt>か</rt></ruby>える！

<ruby>文章<rt>ぶんしょう</rt></ruby>の<ruby>中<rt>なか</rt></ruby>にあるターゲットを、<ruby>大文字小文字<rt>おおもじこもじ</rt></ruby>に<ruby>関<rt>かか</rt></ruby>わらず**すべて<ruby>一発<rt>いっぱつ</rt></ruby>で<ruby>置<rt>お</rt></ruby>き<ruby>換<rt>か</rt></ruby>えたいとき**は、`gi`（または `ig`）を<ruby>使<rt>つか</rt></ruby>います。これが<ruby>実務<rt>じつむ</rt></ruby>でも<ruby>一番<rt>いちばん</rt></ruby>よく<ruby>使<rt>つか</rt></ruby>われる<ruby>形<rt>かたち</rt></ruby>です。

```javascript

```

#### 3. <ruby>実務<rt>じつむ</rt></ruby>でよくある<ruby>使<rt>つか</rt></ruby>い<ruby>方<rt>かた</rt></ruby>： 「NGワード（<ruby>不適切<rt>ふてきせつ</rt></ruby>な<ruby>言葉<rt>ことば</rt></ruby>）」の<ruby>非表示<rt>ひひょうじ</rt></ruby>

Webサイトの<ruby>掲示板<rt>けいじばん</rt></ruby>やチャットアプリを<ruby>作<rt>つく</rt></ruby>るとき、<ruby>誰<rt>だれ</rt></ruby>かが<ruby>悪口<rt>わるくち</rt></ruby>や<ruby>秘密<rt>ひみつ</rt></ruby>の<ruby>情報<rt>じょうほう</rt></ruby>を<ruby>書<rt>か</rt></ruby>き<ruby>込<rt>こ</rt></ruby>んだら、<ruby>自動的<rt>じどうてき</rt></ruby>に `***` や `[<ruby>削除<rt>さくじょ</rt></ruby>]` に<ruby>置<rt>お</rt></ruby>き<ruby>換<rt>か</rt></ruby>えるシステム（フィルター<ruby>機能<rt>きのう</rt></ruby>）によく<ruby>使<rt>つか</rt></ruby>われます。

#### 4. まとめ

> `String` の **`replace()`** メソッドは、<ruby>正規表現<rt>せいきひょうげん</rt></ruby>と<ruby>一緒<rt>いっしょ</rt></ruby>に<ruby>使<rt>つか</rt></ruby>うことで、<ruby>文章<rt>ぶんしょう</rt></ruby>の<ruby>中<rt>なか</rt></ruby>の<ruby>文字<rt>もじ</rt></ruby>を<ruby>自由自在<rt>じゆうじざい</rt></ruby>《じゆうじざい》に<ruby>書<rt>か</rt></ruby>き<ruby>換<rt>か</rt></ruby>えることができます。  
> <ruby>大切<rt>たいせつ</rt></ruby>なルールは<ruby>次<rt>つぎ</rt></ruby>の3つです。  
> 1. **<ruby>順番<rt>じゅんばん</rt></ruby>**： `文字列.replace(/探すパターン/, "新しい文字")` の<ruby>順番<rt>じゅんばん</rt></ruby>で<ruby>書<rt>か</rt></ruby>きます。  
> 2. **フラグのパワー**：**/パターン/gi** のように `g` と `i` を<ruby>一緒<rt>いっしょ</rt></ruby>につけると、<ruby>大文字<rt>おおもじ</rt></ruby>・<ruby>小文字<rt>こもじ</rt></ruby>を<ruby>気<rt>き</rt></ruby>にせず、<ruby>文章<rt>ぶんしょう</rt></ruby>の<ruby>中<rt>なか</rt></ruby>にあるターゲットを**<ruby>全部<rt>ぜんぶ</rt></ruby>まとめて**<ruby>新<rt>あたら</rt></ruby>しい<ruby>文字<rt>もじ</rt></ruby>に<ruby>変<rt>か</rt></ruby>えてくれます。  
> 3. **<ruby>元<rt>もと</rt></ruby>の<ruby>文字<rt>もじ</rt></ruby>は<ruby>消<rt>き</rt></ruby>えない**： `replace()` を<ruby>使<rt>つか</rt></ruby>っても、<ruby>元<rt>もと</rt></ruby>の<ruby>変数<rt>へんすう</rt></ruby>の<ruby>中身<rt>なかみ</rt></ruby>は<ruby>変<rt>か</rt></ruby>わりません。<ruby>必<rt>かなら</rt></ruby>ず<ruby>新<rt>あたら</rt></ruby>しく<ruby>作<rt>つく</rt></ruby>った<ruby>結果<rt>けっか</rt></ruby>を<ruby>別<rt>べつ</rt></ruby>の<ruby>変数<rt>へんすう</rt></ruby>（`const newText = ...`）に<ruby>代入<rt>だいにゅう</rt></ruby>《だいにゅう》して<ruby>使<rt>つか</rt></ruby>いましょう。  
>  
>  
> ユーザーが<ruby>入力<rt>にゅうりょく</rt></ruby>したデータから、いらないスペース（<ruby>空白<rt>くうはく</rt></ruby>）を<ruby>消<rt>け</rt></ruby>したり、<ruby>危険<rt>きけん</rt></ruby>な<ruby>文字<rt>もじ</rt></ruby>を<ruby>隠<rt>かく</rt></ruby>したりするときにとても<ruby>役<rt>やく</rt></ruby>に<ruby>立<rt>た</rt></ruby>つので、ぜひ<ruby>覚<rt>おぼ</rt></ruby>えてくださいね！
