#### <ruby>中身<rt>なかみ</rt></ruby>を「<ruby>書<rt>か</rt></ruby>きかえる」ときの `[ ]`

## II. よく<ruby>使<rt>つか</rt></ruby>うプロパティ・メソッド・<ruby>演算子<rt>えんざんし</rt></ruby>

<ruby>配列<rt>はいれつ</rt></ruby>には、<ruby>中身<rt>なかみ</rt></ruby>を<ruby>操作<rt>そうさ</rt></ruby>するための「<ruby>道具<rt>どうぐ</rt></ruby>（メソッド）」や「<ruby>情報<rt>じょうほう</rt></ruby>（プロパティ）」、そして「<ruby>特別<rt>とくべつ</rt></ruby>な<ruby>記号<rt>きごう</rt></ruby>（<ruby>演算子<rt>えんざんし</rt></ruby>）」がたくさんあります。

<ruby>学生<rt>がくせい</rt></ruby>の<ruby>方<rt>かた</rt></ruby>に<ruby>特<rt>とく</rt></ruby>に<ruby>覚<rt>おぼ</rt></ruby>えてほしい、**「これだけは<ruby>外<rt>はず</rt></ruby>せない！」という<ruby>便利<rt>べんり</rt></ruby>なリスト**をまとめました。

### よく<ruby>使<rt>つか</rt></ruby>うプロパティ（<ruby>配列<rt>はいれつ</rt></ruby>の<ruby>情報<rt>じょうほう</rt></ruby>）

プロパティは、<ruby>配列<rt>はいれつ</rt></ruby>が<ruby>持<rt>も</rt></ruby>っている「データ」のことです。

<ruby>配列<rt>はいれつ</rt></ruby>の<ruby>中<rt>なか</rt></ruby>に、**<ruby>今<rt>いま</rt></ruby>いくつデータが<ruby>入<rt>はい</rt></ruby>っているか**を<ruby>教<rt>おし</rt></ruby>えてくれます。

**なぜ<ruby>大切<rt>たいせつ</rt></ruby>なの？**

<ruby>配列<rt>はいれつ</rt></ruby>の .length プロパティを<ruby>使<rt>つか</rt></ruby>うことで、「データが<ruby>今<rt>いま</rt></ruby>いくつあるか」を<ruby>常<rt>つね</rt></ruby>に<ruby>知<rt>し</rt></ruby>ることができます。これにより、データの<ruby>数<rt>かず</rt></ruby>が<ruby>増<rt>ふ</rt></ruby>えたり<ruby>減<rt>へ</rt></ruby>ったりしても、プログラムを<ruby>書<rt>か</rt></ruby>き<ruby>直<rt>なお</rt></ruby>さずに<ruby>柔軟<rt>じゅうなん</rt></ruby>に<ruby>対応<rt>たいおう</rt></ruby>できるようになります。

### <ruby>覚<rt>おぼ</rt></ruby>えたい<ruby>便利<rt>べんり</rt></ruby>なメソッド（<ruby>道具<rt>どうぐ</rt></ruby>）

**<ruby>配列操作<rt>はいれつそうさ</rt></ruby>のメソッド**

<ruby>配列<rt>はいれつ</rt></ruby>には、<ruby>中身<rt>なかみ</rt></ruby>を<ruby>操作<rt>そうさ</rt></ruby>するための<ruby>便利<rt>べんり</rt></ruby>なメソッドがたくさんあります。

<ruby>代表的<rt>だいひょうてき</rt></ruby>なメソッドを、**「<ruby>元<rt>もと</rt></ruby>の<ruby>配列<rt>はいれつ</rt></ruby>が<ruby>変<rt>か</rt></ruby>わるかどうか」** と **「どこを<ruby>操作<rt>そうさ</rt></ruby>するか」** に<ruby>注目<rt>ちゅうもく</rt></ruby>して、まとめて<ruby>解説<rt>かいせつ</rt></ruby>します。

<ruby>配列<rt>はいれつ</rt></ruby>を **「<ruby>電車<rt>でんしゃ</rt></ruby>の<ruby>車両<rt>しゃりょう</rt></ruby>」** や **「<ruby>人<rt>ひと</rt></ruby>の<ruby>列<rt>れつ</rt></ruby>」** に<ruby>例<rt>たと</rt></ruby>えて<ruby>説明<rt>せつめい</rt></ruby>するのが<ruby>一番<rt>いちばん</rt></ruby>わかりやすいです。

<ruby>一番<rt>いちばん</rt></ruby><ruby>最後<rt>さいご</rt></ruby>（<ruby>右側<rt>みぎがわ</rt></ruby>）に、<ruby>新<rt>あたら</rt></ruby>しいデータを<ruby>追加<rt>ついか</rt></ruby>します。

* **イメージ：** <ruby>電車<rt>でんしゃ</rt></ruby>の<ruby>最後<rt>さいご</rt></ruby>に、<ruby>新<rt>あたら</rt></ruby>しい<ruby>車両<rt>しゃりょう</rt></ruby>をつなげる。


<ruby>一番<rt>いちばん</rt></ruby><ruby>最後<rt>さいご</rt></ruby>（<ruby>右側<rt>みぎがわ</rt></ruby>）のデータを1つ<ruby>取<rt>と</rt></ruby>り<ruby>除<rt>のぞ</rt></ruby>きます。

* **イメージ：** <ruby>電車<rt>でんしゃ</rt></ruby>の<ruby>最後<rt>さいご</rt></ruby>の<ruby>車両<rt>しゃりょう</rt></ruby>を<ruby>切<rt>き</rt></ruby>り<ruby>離<rt>はな</rt></ruby>（はな）す。
* **<ruby>元<rt>もと</rt></ruby>の<ruby>配列<rt>はいれつ</rt></ruby>：** **<ruby>変<rt>か</rt></ruby>わります。**


#### `shift`（シフト）：<ruby>先頭<rt>せんとう</rt></ruby>をひとつ<ruby>消<rt>け</rt></ruby>す

<ruby>一番<rt>いちばん</rt></ruby><ruby>最初<rt>さいしょ</rt></ruby>（<ruby>左側<rt>ひだりがわ</rt></ruby>・0<ruby>番目<rt>ばんめ</rt></ruby>）のデータを<ruby>消<rt>け</rt></ruby>して、<ruby>残<rt>のこ</rt></ruby>りのデータを<ruby>前<rt>まえ</rt></ruby>にずらします。

* **イメージ：** お<ruby>店<rt>みせ</rt></ruby>の<ruby>行列<rt>ぎょうれつ</rt></ruby>で、<ruby>先頭<rt>せんとう</rt></ruby>の<ruby>人<rt>ひと</rt></ruby>が<ruby>店<rt>みせ</rt></ruby>に<ruby>入<rt>はい</rt></ruby>り、<ruby>後<rt>うし</rt></ruby>ろの<ruby>人<rt>ひと</rt></ruby>が<ruby>全員<rt>ぜんいん</rt></ruby><ruby>前<rt>まえ</rt></ruby>にずれる。

<ruby>配列<rt>はいれつ</rt></ruby>の **<ruby>一番<rt>いちばん</rt></ruby><ruby>最初<rt>さいしょ</rt></ruby>（<ruby>先頭<rt>せんとう</rt></ruby>）** に、<ruby>新<rt>あたら</rt></ruby>しいデータを<ruby>追加<rt>ついか</rt></ruby>します。

* **イメージ：** <ruby>行列<rt>ぎょうれつ</rt></ruby>の<ruby>一番前<rt>いちばんまえ</rt></ruby>に<ruby>割<rt>わ</rt></ruby>り<ruby>込<rt>こ</rt></ruby>み（わりこみ）をする<ruby>感<rt>かん</rt></ruby>じです。

## V. <ruby>二次元配列<rt>にじげんはいれつ</rt></ruby>

「<ruby>二次元配列<rt>にじげんはいれつ</rt></ruby>（にじげんはいれつ）」という<ruby>言葉<rt>ことば</rt></ruby>を<ruby>聞<rt>き</rt></ruby>くと、なんだか<ruby>難<rt>むずか</rt></ruby>しそうに<ruby>感<rt>かん</rt></ruby>じますよね。

### イメージは「マンションの <ruby>部屋番号<rt>へやばんごう</rt></ruby>」

<ruby>普通<rt>ふつう</rt></ruby>の<ruby>配列<rt>はいれつ</rt></ruby>が「<ruby>一列<rt>いちれつ</rt></ruby>にならんだロッカー」だとしたら、<ruby>二次元配列<rt>にじげんはいれつ</rt></ruby>は **「たて と よこ に ならんだマンション」** です。

* **1つめの<ruby>数字<rt>すうじ</rt></ruby>：** <ruby>何階<rt>なんがい</rt></ruby>か？
* **2つめの<ruby>数字<rt>すうじ</rt></ruby>：** どの<ruby>部屋<rt>へや</rt></ruby>か？

あるいは **「エクセルの<ruby>表<rt>ひょう</rt></ruby>」** をイメージした<ruby>方<rt>ほう</rt></ruby>がわかりやすいかもしれません。

* **1つめの<ruby>数字<rt>すうじ</rt></ruby>：** <ruby>行<rt>ぎょう</rt></ruby>（ぎょう） / Row
* **2つめの<ruby>数字<rt>すうじ</rt></ruby>：** <ruby>列<rt>れつ</rt></ruby>（れつ） / Column

|    | 1列 | 2列 | 3列 |
| -- | -- | -- | -- |
| 1行 |    |    |    |
| 2行 |    |    |    |
| 3行 |    |    |    |

### JavaScriptでの<ruby>書<rt>か</rt></ruby>きかた

<ruby>学校<rt>がっこう</rt></ruby>のクラスの「<ruby>座席表<rt>ざせきひょう</rt></ruby>（ざせきひょう）」を<ruby>例<rt>れい</rt></ruby>に<ruby>見<rt>み</rt></ruby>てみましょう。

```javascript

  ["田中", "鈴木"], // 0番目のグループ（1列目）
```

|    | 1列  | 2列  |
| -- | --- | --- |
| 1行 | 田中  | 鈴木  |
| 2行 | 佐藤  | マリア |

#### <ruby>中身<rt>なかみ</rt></ruby>を<ruby>取<rt>と</rt></ruby>り<ruby>出<rt>だ</rt></ruby>すとき

カギかっこを **2つ `[ ][ ]`** <ruby>並<rt>なら</rt></ruby>べて<ruby>書<rt>か</rt></ruby>きます。

* **`classMap[2]`** → 3つめのグループ（["ジョン", "リー"]）を<ruby>選<rt>えら</rt></ruby>びます。
* **`[1]`** → その<ruby>中<rt>なか</rt></ruby>の、2<ruby>番目<rt>ばんめ</rt></ruby>の<ruby>人<rt>ひと</rt></ruby>（リー）を<ruby>選<rt>えら</rt></ruby>びます。

| -- | -------- | -------- |
| 1行 | [0][0] | [0][1] |
| 2行 | [1][0] | [1][1] |
| 3行 | [2][0] | [2][1] |

### なぜ「<ruby>二次元<rt>にじげん</rt></ruby>」というの？

* **<ruby>一次元<rt>いちじげん</rt></ruby>（いちじげん）：** 「<ruby>線<rt>せん</rt></ruby>」です。<ruby>横<rt>よこ</rt></ruby>（よこ）だけにデータがならんでいます。
* **<ruby>二次元<rt>にじげん</rt></ruby>（にじげん）：** 「<ruby>面<rt>めん</rt></ruby>」です。<ruby>横<rt>よこ</rt></ruby>（よこ）と<ruby>縦<rt>たて</rt></ruby>（たて）にデータが<ruby>広<rt>ひろ</rt></ruby>がっています。

> [!TIP]  
> **「<ruby>多次元<rt>たじげん</rt></ruby>（たじげん）」って<ruby>何<rt>なに</rt></ruby>？**  
> <ruby>二次元<rt>にじげん</rt></ruby>（たて・よこ）よりもさらに<ruby>増<rt>ふ</rt></ruby>えて、<ruby>三次元<rt>さんじげん</rt></ruby>（<ruby>奥行<rt>おくゆ</rt></ruby>き・<ruby>高<rt>たか</rt></ruby>さ）など、もっと<ruby>複雑<rt>ふくざつ</rt></ruby>になったものをまとめて「<ruby>多次元<rt>たじげん</rt></ruby>」と<ruby>呼<rt>よ</rt></ruby>びます。

### どんなときに<ruby>使<rt>つか</rt></ruby>う？

* **ゲームの<ruby>地図<rt>ちず</rt></ruby>：** どこに<ruby>宝箱<rt>たからばこ</rt></ruby>があるか、<ruby>座標<rt>ざひょう</rt></ruby>で<ruby>決<rt>き</rt></ruby>めるとき。
* **カレンダー：** 「○<ruby>週目<rt>しゅうめ</rt></ruby>の、○<ruby>曜日<rt>ようび</rt></ruby>」というデータ。
* **<ruby>写真<rt>しゃしん</rt></ruby>のデータ：** デジタルの<ruby>写真<rt>しゃしん</rt></ruby>は、<ruby>色<rt>いろ</rt></ruby>のついた<ruby>点<rt>てん</rt></ruby>が<ruby>縦<rt>たて</rt></ruby>と<ruby>横<rt>よこ</rt></ruby>に<ruby>並<rt>なら</rt></ruby>んでできています。

### <ruby>学生<rt>がくせい</rt></ruby>へのアドバイス

<ruby>二次元配列<rt>にじげんはいれつ</rt></ruby>を<ruby>使<rt>つか</rt></ruby>うとき、<ruby>一番<rt>いちばん</rt></ruby><ruby>多<rt>おお</rt></ruby>いミスはこれです。
