# ユーザー定義オブジェクト

JavaScriptの「ユーザー定義オブジェクト」は、あらかじめ用意されている道具（ブラウザやシステムが作ったもの）ではなく、**「自分たちで自由に作る新しいキャラクターや道具」**のことです。

留学生の方には、**「RPGゲームのキャラクター図鑑（ずかん）」**を作るイメージで説明してあげると、ワクワクしながら理解してもらえます。

---

### 1. ユーザー定義オブジェクトとは？

JavaScriptでは、波括弧 `{ }` を使って、**自分だけのオブジェクトを作る** ことができます。これを「オブジェクト リテラル」と呼びます。

たとえば、**「学生（Student）」**という新しいモノをプログラムの中で作りたいとき、名前、年齢、国籍などを一つにまとめたのが「ユーザー定義オブジェクト」です。

---

### 2. オブジェクトの「中身」は2種類

オブジェクトの中には、必ずこの2つが入っています。

1. **プロパティ（Property）：** そのモノの「特徴（データ）」
* 例：名前は「アリ」さん、国籍は「エジプト」。


2. **メソッド（Method）：** そのモノができる「動き（仕事）」
* 例：「自己紹介する」、「テストを受ける」。


---

### 3. 書き方のイメージ：自分だけの図鑑作り

留学生と一緒に、こんなコードのイメージを考えてみてください。

```javascript
// 「学生」という名前のオブジェクトを自分で定義（ていぎ）する
const student = {
  // プロパティ（特徴）
  name: "Ali",
  country: "Egypt",
  age: 20,

  // メソッド（動き）
  sayHello: function() {
    console.log("こんにちは！私は " + this.name + " です。");
  }
};

// 使い方
console.log(student.name); // "Ali" が出てくる
student.sayHello();        // "こんにちは！私は Ali です。" としゃべる！

```
## 4. プロパティとメソッドの利用：情報の取り出しと実行

作ったオブジェクトの中身を使うには、2つの書き方があります。

1. ドット記法（きほう）： person.name のように、ドット . でつなぎます。プロパティ名が分かっているときに使います。
2. ブラケット記法： person["name"] のように、角括弧 [ ] を使います。

こうした記法は、これまで学んできたものと同じです。

「So What?（だから何？）」：なぜ2つあるのか

ドット記法は速く書けて便利ですが、ブラケット記法は「変数」を使って中身を選べるのが強（つよ）みです。

```javascript
const key = "name";
console.log(person[key]); // "Allen" と表示されます。keyの中身を変えれば、取れるデータも変わります。
```

また、メソッドを呼び出すときに `person.greet()` と丸括弧 () を書くのは、「そのアクションを今すぐ動かしてください」という合図（あいず）です。


---

### 5. 留学生への例え話：お弁当箱（べんとうばこ）

> 「変数が『1つのリンゴ』だとしたら、オブジェクトは **『お弁当箱』** だよ。
> お弁当箱の中に、ご飯（名前）、おかず（年齢）、デザート（国籍）をきれいに並べて、**『これはアリさんのお弁当です』**と名前をつけて管理するんだ。
> バラバラに持ち運ぶより、箱に入っていたほうが分かりやすいし、使いやすいよね！」

---

### 6. なぜ「ユーザー定義」が必要なの？

> 「たくさんの学生のデータを扱うとき、変数だけで書くと `name1`, `name2`, `age1`, `age2`...と、頭がパニックになってしまうよ。
> **『1人の人間には、たくさんの情報がつまっている』** という現実の世界と同じ考え方をプログラムに持ち込むために、自分でオブジェクトを作るんだよ。」

---

### まとめテーブル

| 言葉 | 意味 | 覚え方のヒント |
| --- | --- | --- |
| **ユーザー定義** | 自分で作ること | 「私専用（せんよう）」 |
| **プロパティ** | 特徴、データ | 「〜は〜だ」 |
| **メソッド** | 仕事、動き | 「〜をする」 |
| **インスタンス** | 設計図から作った実物 | 「アリさん本人」 |

---

いかがでしょうか？「自分たちで新しいモノの形を決められる」というのが、オブジェクト指向プログラミングの第一歩です。
留学生のみなさんの「自己紹介（じこしょうかい）カード」をオブジェクトにしてみましょう。

**開発（かいはつ）のアドバイス**

* 名前は英語で： JavaScriptのルールとして、プロパティ名は name のように意味（いみ）のわかる英語で書くのが一般的（いっぱんてき）です。
* なぜ const なのか？： オブジェクトを作るとき、よく const を使います。これは「箱そのもの」を変えないためです。箱の中身（年齢など）が変わっても、箱自体（personという変数）が別物にならなければ、const で問題（もんだい）ありません。
* 書き方のコツ： 複数のプロパティを書くときは、カンマ , を忘れないでください。忘れるとエラーになります。
