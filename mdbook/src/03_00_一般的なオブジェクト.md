# 一般的なオブジェクト

**JavaScriptの便利な道具「組み込みオブジェクト」を学ぼう**

みなさん、こんにちは！ 留学生のみなさんがプログラミングを学ぶとき、日本語の壁と技術の壁、両方を感じることがあるかもしれません。でも安心してください。JavaScript（ジャバスクリプト）の世界には、最初から用意されている「便利な道具箱」がたくさんあります。これを **組み込み（くみこみ）オブジェクト** と呼びます。

このドキュメントでは、プログラミングの基礎から、データを上手に扱うためのテクニックまで、やさしい日本語で解説していきます。

そこで「組み込みオブジェクト」です。組み込みオブジェクトは、JavaScriptがあらかじめ用意している機械のようなものなので、あなたがデータを入れれば、すぐに使うことができます。


--------------------------------------------------------------------------------

## 1. オブジェクトとは（復習）

「オブジェクト」という言葉を覚えていますか？ 一言でいうと、オブジェクトは **「関係（かんけい）がある 情報を まとめたもの」** でしたね。

そして、オブジェクトのすごいところは、**データ（特徴）** だけでなく、**関数（動き）** も一緒にまとめられることでした。

* **プロパティ（特徴）：** 名前、身長、色、値段など
* **メソッド（動き）：** 走る、話す、計算するなど

## 9. 変数のスコープとまとめ

最後に、変数が「どこから見えるか」というスコープ（守備範囲）について学びましょう。

**スコープの種類**

* グローバルスコープ: プログラムのどこからでも見えますが、使いすぎるとデータの混乱を招きます。
* ブロックスコープ（let/const）: {}（波括弧）の中でしか使えません。今のJavaScriptではこちらが基本です。

**初心者が最も混乱する「const」の不変性**

const で宣言したオブジェクトには、大切なルールがあります。

* 名札（変数名）の付け替え（再代入：さいだいにゅう）はできません。
* しかし、中身（プロパティ）の変更はできます。

「ガムテープで名札が貼られた箱」をイメージしてください。ガムテープで固定されているので、名札を別の新しい箱に貼り直すことはできません。でも、箱の蓋（ふた）を開けて、中に入っているおもちゃを入れ替えたり、色を塗ったりすることは自由なのです。

**全体まとめ**

JavaScriptの組み込みオブジェクトを学ぶことは、留学生のみなさんがプログラミングの「初心者」から「中級者」へステップアップするための大きな一歩です。

1. 配列やオブジェクトでデータをきれいに並べ、
2. forEachやfor-inで効率よく処理し、
3. StringやMath、Dateで情報を賢く加工する。

**最終メッセージ**

プログラミングの学習は、一歩ずつ進めば大丈夫です。一度に全部覚えようとしなくていいですよ。「あ、あんな便利な道具があったな」と思い出せれば合格です。

留学生のみなさん、これからも楽しくコードを書いていきましょう。あなたの成長を心から応援しています！

## 6. オブジェクト型 (Object)：関連する情報をセットにする

現実世界の情報を扱うとき、一つの変数だけでは足りないことがあります。例えばRPGの「キャラクター」なら、名前、レベル、HPなどの情報をセットで管理したいはずです。これを可能にするのが「オブジェクト型」です。

**波括弧 { } で作る構造**

オブジェクトは、プロパティ（名前と値のペア）をセットにして管理します。

```
const character = {
  name: "アレン",   // プロパティ（ステータス）
  level: 10,
  hp: 1450,
  attack: function() { // メソッド（行動）
    console.log("攻撃した！");
  }
};

// ドット記法でアクセス
console.log(character.name); // "アレン"
```

💡 オブジェクトと const の意外な関係

「 const は中身を変えられない箱」と説明しましたが、オブジェクトの場合は少し違います。

* 名札の固定（参照の不変性）：const で作ったオブジェクトそのものを別のオブジェクトに入れ替えることはできません（別の箱に名札を付け替えるのは禁止）。
* 中身の変更はOK：箱の中に入っている個別のデータ（プロパティ）を書き換えることは可能です。

例えるなら、「ファイルの保存場所（パス）」は固定されているけれど、「ファイルの中身」は自由に書き換えられるようなイメージです。
