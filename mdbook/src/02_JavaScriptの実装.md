# JavaScriptの実装

**留学生のためのJavaScript入門：最初の一歩を始めよう**

みなさん、こんにちは！日本でITを学ぶ留学生のみなさんを応援するプログラミング・メンターです。

プログラミングは、最初は難しく感じるかもしれません。でも、ルールを知れば、自分の思い通りにWebページを動かせる「魔法」のような技術です。このドキュメントでは、JavaScript（ジャバスクリプト）の基本を、IT業界の標準的な考え方と一緒に「やさしい日本語」で解説します。

--------------------------------------------------------------------------------


## 1. JavaScriptの役割とWebページの仕組み

Webページは、主に3つの技術が協力して作られています。これを「家」に例えて考えてみましょう。

* HTML（骨組み）： 家の「柱」や「壁」です。ページの構造（見出しや段落）を作ります。
* CSS（見た目）： 家の「ペンキ」や「インテリア」です。色やデザインを整えます。
* JavaScript（動き）： 家の**「電気や機械装置」**です。スイッチを押すと電気がついたり、自動ドアが開いたりする「機能」を担当します。

プロの開発現場では、これら3つの役割をしっかり分けることが「業界の標準（スタンダード）」です。役割を分けることで、チームで開発するときにミスが減り、効率よく作業ができるようになります。さあ、JavaScriptという「電気」をWebページに通す準備を始めましょう！


--------------------------------------------------------------------------------


## 2. 初めてのプログラム：Hello World! とポップアップ

プログラミングの第一歩は、自分の指示がブラウザに伝わったことを確認することです。画面にメッセージを出す2つの方法を学びましょう。

**alert()：ユーザーへの通知**

ブラウザに小さなウィンドウを出して、ユーザーに大切なメッセージを伝えます。

```
alert("こんにちは！");
```

**console.log()：開発者のための確認（デバッグ）**

「デバッグ（プログラムのミスを見つけて直すこと）」のために使います。ユーザーには見えない、開発者のための「確認用メッセージ」をコンソールに出力します。

```
console.log("プログラムがここまで動きました");
```

**「コンソール」の開き方**

自分の書いた「意図（やりたいこと）」がブラウザに正しく伝わったかどうかは、ここで確認します。

|OS|操作方法|
|---|---|
|Windows|F12 キー（ノートPCは Fn + F12） または Ctrl + Shift + I|
|Mac|Command + Option + I|

自分の書いた1行のコードでブラウザが反応したとき、その「喜び」がこれからの学習の力になります！

## 3. イベントとイベントハンドラ：動きを作るきっかけ

JavaScriptは、ユーザーの「クリック」などの操作に反応して動き出します。この「きっかけ」を理解すると、Webサイトに命を吹き込むことができます。

**スイッチと電球の関係**

* イベント（操作）： ユーザーがボタンを押す「スイッチ」です。
* ハンドラ（処理）： スイッチが入ったときに実行される「電球がつく」という動きです。

よく使われるイベントハンドラ（きっかけ）を整理しました。

|カテゴリ|イベント名|きっかけ（タイミング）|使用例|
|---|---|---|---|
|マウス|onclick|クリックされたとき|ボタンを押して計算を始める|
|マウス|onmouseover|マウスが上に乗ったとき|画像の色を変える|
|ページ|onload|ページを読み込み終わったとき|「ようこそ」と挨拶を出す|
|フォーム|oninput|文字を入力したとき|リアルタイムで文字数を数える|
|フォーム|onfocus|入力欄を選択したとき|入力欄の色を明るくする|

記述例： HTMLのボタンに「クリックされたらアラートを出す」魔法をかけるときは、こう書きます。

```
<button onclick="alert('ボタンが押されました！')">クリックしてね</button>
```
これをブラウザで読み込むと、以下のようになります。

<button onclick="alert('ボタンが押されました！')">クリックしてね</button>

## 4. JavaScriptの呼び出し方と外部ファイル化

コードが増えてくると、書き場所が重要になります。整理整頓されたコードは、プロの世界の「マナー」です。

1. 内部JavaScript： HTMLの中に <script> タグで直接書く方法です。
2. 外部JavaScript： .js という別のファイルに分ける方法です。

**外部ファイル化のメリット（戦略的意義）**

プロの開発では、必ず「外部ファイル」を使います。理由は、**「再利用性（一つのファイルを多くのページで使い回せること）」**が高まり、修正も一箇所で済むためです。

**読み込みの手順**

* .js ファイル（例：script.js）を作成し、JavaScriptだけを書きます。
* HTMLの <body> タグの最後（閉じタグ </body> の直前） に読み込みコードを書きます。

なぜ <body> の最後に書くの？ ブラウザは上から順番に読み込みます。プログラムを最後に読み込ませることで、ページの文字や画像を先に出し、ユーザーを待たせない「スムーズな表示」が可能になります。

## 5. ブラウザオブジェクト（BOM/DOM）の概要

JavaScriptが操作するのは、ブラウザ全体やWebページそのものです。これらは「ツリー構造（木の枝のような形）」で整理されています。

**ブラウザ世界の構造**

一番上のボスは window オブジェクト です。

* window (ブラウザ全体)
  * location (URLの情報)
  * document (Webページの内容)
    * html
      * body (ページの本文)

**RPGのキャラクターに例えると**

「オブジェクト」の考え方は、ゲームのキャラクターに例えると非常に分かりやすくなります。

* オブジェクト： キャラクター自身（例：勇者アレン）
* プロパティ： ステータス（例：hp や name）
* メソッド： 行動（例：attack() や heal()）

コードでの例： document.body.style.backgroundColor = "red"; このコードは、documentの中のbody（オブジェクト）の、backgroundColor（プロパティ）を"red"に変えるという命令です。

**魔法の杖：getElementById()**

特定の要素を見つけるための「セレクタ（目印）」として、document.getElementById('ID名') を使います。 IDはキャラクターの「名前」のようなものです。これを使って、Webページの特定の場所をピンポイントで操作する魔法をかけます。

## 6. まとめ：JavaScript学習のルールと習慣

**JavaScriptの書き方：これだけは守りたい8つのルール**

最後に、ミスを防ぐための大切なルールをまとめました。

プログラミングは世界共通のルールです。なぜ英語（えいご）で名前を付けるのか？ それは世界中のプログラマーが共通して使う「公式（こうしき）の言葉」だからです。

以下のルールを「チェックリスト」として使いましょう。

1. 文の終わりにはセミコロン（;）： 命令の区切りをはっきりさせます。
2. 変数の宣言（せんげん）は let と const： 値を入れる「箱（はこ）」を作ります。
  * const：一度決めたら変えられない 「箱に貼った固定ラベル」 です。基本はこちらを使います。
  * let：あとで中身を入れ替えられる箱です。
3. 文字列は " " または ' ' で囲む： 「こんにちは」などの言葉は引用符（いんようふ）で囲みます。
4. インデント（字下げ）： コードの行の最初をスペースで揃えて、見やすくします。
5. コメント（//）： 自分のためのメモです。コンピュータは無視します。
6. 名前は英語（えいご）で付ける： let namae ではなく let userName と書くのがプロのルールです。
7. 命名にキャメルケース (camelCase)： 2つ目の単語を大文字にします（例：userName）。
8. 大文字と小文字を分ける： MyName と myname は、コンピュータには違う箱に見えます。
9. コメントを書く： `//` でメモを書きます。自分の母国語でメモを残すと学習がはかどります。
10. すべて「半角（はんかく）」で書く： これが一番大切です。文字列の中とコメント以外で 「全角（ぜんかく）」を使うと、コードは絶対に動きません。

**留学生へのメッセージ**

プログラミングの世界へようこそ！ 特に「全角・半角」のミスは、ベテランでもやってしまうことがあります。**「文字列の中とコメント以外は、必ず半角」**を習慣にしましょう。

最初はエラーが出るのが当たり前です。エラーメッセージはブラウザからの「ヒント」だと思って、楽しみながら挑戦してください。あなたが自由自在にコードを書けるようになるまで、応援しています！
