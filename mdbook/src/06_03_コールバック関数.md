# コールバック<ruby>関数<rt>かんすう</rt></ruby>

留学生（りゅうがくせい）のみなさんにもわかりやすいように、**「コールバック<ruby>関数<rt>かんすう</rt></ruby>」**をやさしい日本語で説明（せつめい）します。

---

## I. コールバック<ruby>関数<rt>かんすう</rt></ruby>を一言（ひとこと）でいうと？

**「あとで やってね！という お願（ねが）いのメモ」** です。

ふつうのプログラムは、上から下へ順番（じゅんばん）に進（すす）みます。
でも、コールバック<ruby>関数<rt>かんすう</rt></ruby>は「今すぐ」ではなく、**「ある時（とき）が来たら」** 動くように予約（よ予約）する命令（めいれい）です。

---

## II. 「お店でのちゅうもん」で たとえてみましょう

あなたがレストランへ行きました。

1. **あなた（メインプログラム）：** 店員さんに「オムライスをください。**できあがったら、ベルを鳴（な）らしてください**」と言いました。
2. **店員さん（forEachメソッド）：** 料理（りょうり）を作ります。
3. **ベルを鳴らす（コールバック<ruby>関数<rt>かんすう</rt></ruby>）：** 料理ができたタイミングで、店員さんがベルを鳴らします。

この「できあがったら、〇〇してね」という**「〇〇」の部分**がコールバック<ruby>関数<rt>かんすう</rt></ruby>です。

---

## III. `forEach` の中での<ruby>動<rt>うご</rt></ruby>き

`forEach` は、<ruby>配列<rt>はいれつ</rt></ruby>（はいれつ／データのリスト）の中身を一つずつ見（み）ていく命令です。

```javascript
// 果物（くだもの）の名前のリスト
const fruits = ["りんご", "バナナ", "みかん"];

// fruits.forEach( ここに書くのがコールバック<ruby>関数<rt>かんすう</rt></ruby> );
fruits.forEach((item) => {
  console.log(item + "を食べます");
});

```

### プログラムの中の会話（かいわ）

* **forEach:** 「リストの中身を一つずつ取り出すよ！ 取り出すたびに、何をすればいい？」
* **コールバック<ruby>関数<rt>かんすう</rt></ruby>:** 「取り出したものに『を食べます』をつけて<ruby>表示<rt>ひょうじ</rt></ruby>してね！」
* **forEach:** 「わかった！ じゃあ、『りんご』を取り出したから、君（コールバック<ruby>関数<rt>かんすう</rt></ruby>）に渡（わた）すね。実行（じっこう）して！」
* **コールバック<ruby>関数<rt>かんすう</rt></ruby>:** 「はい！『りんごを食べます』と出します！」

これを、リストが終わるまで繰り返（くりかえ）します。

---

## IV. なぜ「コールバック」という名前なの？

英語（えいご）の **"Call back"（電話をかけなおす）** と同じ意味です。

* **ふつうの<ruby>関数<rt>かんすう</rt></ruby>：** あなたが<ruby>関数<rt>かんすう</rt></ruby>を「呼ぶ（Call）」。
* **コールバック<ruby>関数<rt>かんすう</rt></ruby>：** 相手（forEachなど）が、あとであなたを「呼び出す（Call back）」。

このように、**「主役（しゅやく）が入れ替（いれかえ）わる」** のがポイントです。

---

### まとめ

* **コールバック<ruby>関数<rt>かんすう</rt></ruby>** ＝ 他のプログラムに「これ、あとで使ってね」と渡す<ruby>関数<rt>かんすう</rt></ruby>のこと。
* **forEach** ＝ リストのデータ一つずつに、コールバック<ruby>関数<rt>かんすう</rt></ruby>を動かしてあげる役（やく）割。


---

## V. プログラム<ruby>例<rt>れい</rt></ruby>

「数字（すうじ）の合計（ごうけい）」を計算（けいさん）するコードを書いてみます。やさしい日本語（にほんご）で説明（せつめい）しながら書（か）きます。


### 1. 合計（ごうけい）を計算するプログラム

このプログラムは、リストの中にある数字を全部（ぜんぶ）足（た）して、最後（さいご）に答えを出します。

```javascript
// 1. 数字のリストを作ります
const numbers = [10, 20, 30, 40];

// 2. 合計を入れる「空（から）の箱」を作ります。最初は 0 です。
let total = 0;

// 3. forEach を使って、一つずつ足していきます
numbers.forEach((num) => {
  // ここがコールバック<ruby>関数<rt>かんすう</rt></ruby>です！
  total = total + num; 
  console.log(num + " を足しました。今は " + total + " です。");
});

// 4. 最後に答えを<ruby>表示<rt>ひょうじ</rt></ruby>します
console.log("ぜんぶの合計は " + total + " です！");

```

---

### 2. プログラムの動（うご）きを解説（かいせつ）

#### ① `let total = 0;`

これは、計算（けいさん）の結果（けっか）を入れておくための**「貯金箱（ちょきんばこ）」**のようなものです。最初は何も入っていないので `0` にしておきます。

#### ② コールバック<ruby>関数<rt>かんすう</rt></ruby>の仕事（しごと）

`numbers.forEach((num) => { ... });` の中（なか）が、お願（ねが）いしたメモ（コールバック<ruby>関数<rt>かんすう</rt></ruby>）です。

* `forEach` がリストから `10` を見つける。
* コールバック<ruby>関数<rt>かんすう</rt></ruby>に `10` を渡（わた）す。
* <ruby>関数<rt>かんすう</rt></ruby>が **「今の合計（0）に 10 を足してね！」** と実行（じっこう）する。
* 次の `20` でも同じことをする。

これを繰り返（くりかえ）すことで、貯金箱の中身がどんどん増（ふ）えていきます。

---

### 3. もっと短（みじか）く書く方法

プログラミングに<ruby>慣<rt>な</rt></ruby>れてきたら、こんな<ruby>書<rt>か</rt></ruby>き<ruby>方<rt>かた</rt></ruby>もできます。

* `total = total + num;`
* **`total += num;`** （これでも同じ意味になります！）
