getElementByID()メソッド

コンソールを開いて、下のJavaScriptを入力してみましょう。


        // 1. IDが "main-title" というパーツを探す
        const message = document.getElementById("main-title");

        // 2. その中身を書き換える
        message.textContent = "こんにちは、日本へようこそ！";

        // 3. スタイル（色）も変えちゃう
        message.style.color = "red";

            // 1. IDが "menu-item" というパーツを探す
