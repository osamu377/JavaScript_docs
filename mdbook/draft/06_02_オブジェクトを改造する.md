# オブジェクトを<ruby>改造<rt>かいぞう</rt></ruby>する

すでにあるオブジェクトを<ruby>自分好<rt>じぶんごの</rt></ruby>みに<ruby>作<rt>つく</rt></ruby>り<ruby>変<rt>か</rt></ruby>えることを、プログラミングの<ruby>世界<rt>せかい</rt></ruby>では **「<ruby>拡張<rt>かくちょう</rt></ruby>（かくちょう / Extension）」** や **「カスタマイズ」** と<ruby>呼<rt>よ</rt></ruby>びます。

これは **「<ruby>買<rt>か</rt></ruby>ってきた<ruby>自転車<rt>じてんしゃ</rt></ruby>に、ライトをつけたり<ruby>色<rt>いろ</rt></ruby>をぬったりして<ruby>改造<rt>かいぞう</rt></ruby>すること」** に<ruby>例<rt>たと</rt></ruby>えることができます。

## I. オブジェクトを<ruby>改造<rt>かいぞう</rt></ruby>する

### 1. すでにあるオブジェクトを<ruby>改造<rt>かいぞう</rt></ruby>する2つの<ruby>方法<rt>ほうほう</rt></ruby>

JavaScriptでは、すでに<ruby>動<rt>うご</rt></ruby>いているオブジェクトに<ruby>後<rt>あと</rt></ruby>から「<ruby>新<rt>あたら</rt></ruby>しいパーツ」を<ruby>追加<rt>ついか</rt></ruby>したり、「<ruby>古<rt>ふる</rt></ruby>いパーツ」を<ruby>新<rt>あたら</rt></ruby>しいものに<ruby>取<rt>と</rt></ruby>り<ruby>替<rt>か</rt></ruby>えたりできます。

#### a) **<ruby>追加<rt>ついか</rt></ruby>する**

<ruby>特定<rt>とくてい</rt></ruby>の1<ruby>人<rt>にん</rt></ruby>（1つのオブジェクト）だけに、<ruby>新<rt>あたら</rt></ruby>しいプロパティやメソッドを<ruby>追加<rt>ついか</rt></ruby>します。

* **イメージ：** <ruby>自分<rt>じぶん</rt></ruby>の<ruby>自転車<rt>じてんしゃ</rt></ruby>だけに、<ruby>特別<rt>とくべつ</rt></ruby>なステッカーを<ruby>貼<rt>は</rt></ruby>る。
* **<ruby>書<rt>か</rt></ruby>き<ruby>方<rt>かた</rt></ruby>：** `オブジェクト名.新しい名前 = 値;`

```javascript
const myCar = { brand: "Toyota" };

// 後からプロパティを追加
myCar.color = "Red";

// 後からメソッドを追加
myCar.horn = function() {
  console.log("プップー！");
};

myCar.horn(); // 実行できる！
```

> [!note]  
> `myCar.horn = function() {...` の<ruby>部分<rt>ぶぶん</rt></ruby>は、`myCar.horn` に<ruby>関数<rt>かんすう</rt></ruby>を<ruby>代入<rt>だいにゅう</rt></ruby>していいます。  
> このように、**JavaScriptでは<ruby>関数<rt>かんすう</rt></ruby>も<ruby>変数<rt>へんすう</rt></ruby>のようにあつかうことができます。** <ruby>代入<rt>だいにゅう</rt></ruby>したり、<ruby>関数<rt>かんすう</rt></ruby>の<ruby>引数<rt>ひきすう</rt></ruby>にしたり、<ruby>返<rt>かえ</rt></ruby>り<ruby>値<rt>ち</rt></ruby>にしたりできるのです。

#### b) **オーバーライド（<ruby>上書<rt>うわが</rt></ruby>き）する**

<ruby>親<rt>おや</rt></ruby>から<ruby>受<rt>う</rt></ruby>け<ruby>継<rt>つ</rt></ruby>いだ<ruby>機能<rt>きのう</rt></ruby>を、<ruby>自分流<rt>じぶんりゅう</rt></ruby>のやり<ruby>方<rt>かた</rt></ruby>に<ruby>書<rt>か</rt></ruby>き<ruby>換<rt>か</rt></ruby>えます。

* **イメージ：** お<ruby>父<rt>とう</rt></ruby>さんからもらったカメラだけど、レンズを<ruby>最新<rt>さいしん</rt></ruby>のものに<ruby>交換<rt>こうかん</rt></ruby>して<ruby>使<rt>つか</rt></ruby>いやすくする。
* **<ruby>書<rt>か</rt></ruby>き<ruby>方<rt>かた</rt></ruby>：** <ruby>同<rt>おな</rt></ruby>じ<ruby>名前<rt>なまえ</rt></ruby>で<ruby>新<rt>あたら</rt></ruby>しく<ruby>定義<rt>ていぎ</rt></ruby>し<ruby>直<rt>なお</rt></ruby>す。

```javascript
// 1. robotオブジェクトを作成
const robot = {
  name: "ロビー",
  greet() {
    console.log("ハロー、ロボットです。");
  }
};

// 2. 実行
robot.greet(); // "ハロー、ロボットです。"（元のまま）

// 3. robot のメソッドを上書（うわが）き（オーバーライド）する

  console.log("こんにちは！ 私は特別なロボットです。");
};

// 4. 実行して比較（ひかく）する
robot.greet(); // "こんにちは！ 私は特別な..."（上書（うわが）きされた！）
```

> [!note]  
> `robot.greet = function() {...` の<ruby>部分<rt>ぶぶん</rt></ruby>は、`robot` の `greet` というメソッド（<ruby>関数<rt>かんすう</rt></ruby>）に<ruby>別<rt>べつ</rt></ruby>の<ruby>関数<rt>かんすう</rt></ruby>を<ruby>再代入<rt>さいだいにゅう</rt></ruby>しています。

### 2. <ruby>例<rt>たと</rt></ruby>え<ruby>話<rt>ばなし</rt></ruby>：スマホ

> JavaScriptのオブジェクトは、<ruby>一度<rt>いちど</rt></ruby><ruby>作<rt>つく</rt></ruby>ったら<ruby>終<rt>お</rt></ruby>わりではありません。  
> 1. **<ruby>直接追加<rt>ちょくせつついか</rt></ruby>：** スマホに『お<ruby>気<rt>き</rt></ruby>に<ruby>入<rt>い</rt></ruby>りのストラップ』をつけるようなもの。  
> 2. **オーバーライド：** <ruby>決<rt>き</rt></ruby>まった『<ruby>着信音<rt>ちゃくしんおん</rt></ruby>』を、<ruby>自分<rt>じぶん</rt></ruby>の<ruby>好<rt>す</rt></ruby>きな<ruby>音楽<rt>おんがく</rt></ruby>に<ruby>変<rt>か</rt></ruby>えるようなものだよ。  
>  
>  
> こうやって、<ruby>元<rt>もと</rt></ruby>の<ruby>形<rt>かたち</rt></ruby>を<ruby>壊<rt>こわ</rt></ruby>さずに<ruby>自分<rt>じぶん</rt></ruby>らしく<ruby>使<rt>つか</rt></ruby>いやすくするのが、JavaScriptの<ruby>面白<rt>おもしろ</rt></ruby>いところなんです。

## II. プロトタイプとプロトタイプチェーン

JavaScriptの「プロトタイプ（Prototype）」と「プロトタイプチェーン」は、<ruby>多<rt>おお</rt></ruby>くの<ruby>学習者<rt>がくしゅうしゃ</rt></ruby>がつまずく<ruby>難<rt>むずか</rt></ruby>しいところです。

これを<ruby>皆<rt>みな</rt></ruby>さんがイメージしやすいように、 **「<ruby>家系図<rt>かけいず</rt></ruby>」** や **「<ruby>秘密<rt>ひみつ</rt></ruby>のレシピの<ruby>受<rt>う</rt></ruby>け<ruby>継<rt>つ</rt></ruby>ぎ」** に<ruby>例<rt>たと</rt></ruby>えて<ruby>説明<rt>せつめい</rt></ruby>します。

### 1. プロトタイプ（Prototype）とは？

JavaScriptでは、<ruby>多<rt>おお</rt></ruby>くのオブジェクトが「<ruby>親<rt>おや</rt></ruby>（プロトタイプ）」を<ruby>持<rt>も</rt></ruby>っています。もし<ruby>自分<rt>じぶん</rt></ruby>の<ruby>中<rt>なか</rt></ruby>に<ruby>必要<rt>ひつよう</rt></ruby>な<ruby>道具<rt>どうぐ</rt></ruby>（メソッドやプロパティ）がなくても、**「<ruby>親<rt>おや</rt></ruby>の<ruby>持<rt>も</rt></ruby>っている<ruby>道具<rt>どうぐ</rt></ruby>を<ruby>借<rt>か</rt></ruby>りて<ruby>使<rt>つか</rt></ruby>う」** ことができる<ruby>仕組<rt>しく</rt></ruby>みです。

### 2. プロトタイプチェーン（Prototype Chain）とは？

「<ruby>自分<rt>じぶん</rt></ruby>になければ<ruby>親<rt>おや</rt></ruby>、<ruby>親<rt>おや</rt></ruby>になければそのまた<ruby>親<rt>おや</rt></ruby>…」と、**さかのぼって<ruby>探<rt>さが</rt></ruby>しに<ruby>行<rt>い</rt></ruby>く「<ruby>鎖<rt>くさり</rt></ruby>」のようなつながり** のことです。

#### **<ruby>身近<rt>みぢか</rt></ruby>な<ruby>例<rt>たと</rt></ruby>え：<ruby>秘密<rt>ひみつ</rt></ruby>のカレーレシピを<ruby>求<rt>もと</rt></ruby>めて**

1. **あなた（インスタンス）：** カレーを<ruby>作<rt>つく</rt></ruby>ろうとします。
2. **<ruby>自分<rt>じぶん</rt></ruby>のキッチン：** レシピがありません。
3. **お<ruby>父<rt>とう</rt></ruby>さんの<ruby>家<rt>いえ</rt></ruby>（<ruby>自分<rt>じぶん</rt></ruby>のプロトタイプ）：** 「カレーのレシピある？」と<ruby>聞<rt>き</rt></ruby>きます。「<ruby>持<rt>も</rt></ruby>っていない」と<ruby>答<rt>こた</rt></ruby>えが<ruby>返<rt>かえ</rt></ruby>ってきました。
4. **おじいさんの<ruby>家<rt>いえ</rt></ruby>（<ruby>自分<rt>じぶん</rt></ruby>の<ruby>親<rt>おや</rt></ruby>のプロトタイプ）：** お<ruby>父<rt>とう</rt></ruby>さんも<ruby>持<rt>も</rt></ruby>っていなければ、さらにおじいさんに<ruby>聞<rt>き</rt></ruby>きに<ruby>行<rt>い</rt></ruby>きます。「カレーのレシピある？」
5. **<ruby>先祖<rt>せんぞ</rt></ruby>の<ruby>家<rt>いえ</rt></ruby>：** そんな<ruby>風<rt>ふう</rt></ruby>に、レシピを<ruby>持<rt>も</rt></ruby>っている<ruby>人<rt>ひと</rt></ruby>を<ruby>見<rt>み</rt></ruby>つけるまで、<ruby>先祖<rt>せんぞ</rt></ruby>をたどって<ruby>聞<rt>き</rt></ruby>きに<ruby>行<rt>い</rt></ruby>きます。<ruby>誰<rt>だれ</rt></ruby>かがレシピを<ruby>持<rt>も</rt></ruby>っていれば、あなたはそれを<ruby>使<rt>つか</rt></ruby>ってカレーが<ruby>作<rt>つく</rt></ruby>れます。

### 3. なぜこの<ruby>仕組<rt>しく</rt></ruby>みがあるの？

もし100<ruby>人<rt>にん</rt></ruby>の<ruby>学生<rt>がくせい</rt></ruby>オブジェクトを<ruby>作<rt>つく</rt></ruby>るとき、<ruby>全員<rt>ぜんいん</rt></ruby>に「<ruby>自己紹介<rt>じこしょうかい</rt></ruby>メソッド」を<ruby>持<rt>も</rt></ruby>たせると、メモリーをたくさん<ruby>使<rt>つか</rt></ruby>ってしまいます。

* **プロトタイプを<ruby>使<rt>つか</rt></ruby>わない：** <ruby>全員<rt>ぜんいん</rt></ruby>が<ruby>自分<rt>じぶん</rt></ruby>の<ruby>辞書<rt>じしょ</rt></ruby>を<ruby>持<rt>も</rt></ruby>っている（<ruby>重<rt>おも</rt></ruby>い！）
* **プロトタイプを<ruby>使<rt>つか</rt></ruby>う：** <ruby>教室<rt>きょうしつ</rt></ruby>に1<ruby>冊<rt>さつ</rt></ruby>だけ<ruby>辞書<rt>じしょ</rt></ruby>を<ruby>置<rt>お</rt></ruby>き、<ruby>全員<rt>ぜんいん</rt></ruby>でそれを<ruby>共有<rt>きょうゆう</rt></ruby>する（<ruby>軽<rt>かる</rt></ruby>い！）

### 4. コードで<ruby>見<rt>み</rt></ruby>る「<ruby>探<rt>さが</rt></ruby>しに<ruby>行<rt>い</rt></ruby>く<ruby>流<rt>なが</rt></ruby>れ」

```javascript
const animal = {
  eats: true
};

const dog = {
  barks: true
};

// dog の親（プロトタイプ）を animal に設定（せってい）
Object.setPrototypeOf(dog, animal);

console.log(dog.barks); // true (自分の中にある)
console.log(dog.eats);  // true (自分にはないが、親にあるので借りてきた！)
console.log(dog.fly);   // undefined (家系図（かけいず）を最後まで探したけど、どこにもない)
```

### 5. プロトタイプを<ruby>使<rt>つか</rt></ruby>って<ruby>新<rt>あたら</rt></ruby>しいプロパティやメソッドを<ruby>追加<rt>ついか</rt></ruby>する

ひとつのオブジェクトだけでなく、そのプロトタイプから<ruby>生<rt>う</rt></ruby>まれた「<ruby>全員<rt>ぜんいん</rt></ruby>」に、<ruby>新<rt>あたら</rt></ruby>しい<ruby>機能<rt>きのう</rt></ruby>を<ruby>持<rt>も</rt></ruby>たせることができます。

* **イメージ：** マンションの<ruby>住人<rt>じゅうにん</rt></ruby><ruby>全員<rt>ぜんいん</rt></ruby>が<ruby>使<rt>つか</rt></ruby>える「<ruby>共有<rt>きょうゆう</rt></ruby>のラウンジ」に、<ruby>新<rt>あたら</rt></ruby>しいテレビを<ruby>置<rt>お</rt></ruby>く。
* **<ruby>書<rt>か</rt></ruby>き<ruby>方<rt>かた</rt></ruby>：** `クラス名.prototype.メソッド名 = function() { ... };`

```javascript
// 全ての配列（はいれつ）（Array）に「2倍にする」という新しい機能を追加してみる
Array.prototype.double = function() {
  return this.map(n => n * 2);
};

const numbers = [1, 2, 3];
console.log(numbers.double()); // [2, 4, 6]
```

> **<ruby>注意<rt>ちゅうい</rt></ruby>：** ここではわかりやすい<ruby>例<rt>れい</rt></ruby>として`Array`にメソッドを<ruby>追加<rt>ついか</rt></ruby>しましたが、ふつう、 `Array` や `Object` などの、<ruby>皆<rt>みな</rt></ruby>が<ruby>使<rt>つか</rt></ruby>う<ruby>標準<rt>ひょうじゅん</rt></ruby>の<ruby>道具<rt>どうぐ</rt></ruby>を<ruby>勝手<rt>かって</rt></ruby>に<ruby>改造<rt>かいぞう</rt></ruby>はしません。<ruby>他<rt>ほか</rt></ruby>の<ruby>人<rt>ひと</rt></ruby>の<ruby>書<rt>か</rt></ruby>いたブログラムに<ruby>影響<rt>えいきょう</rt></ruby>する<ruby>可能性<rt>かのうせい</rt></ruby>があるからです。
