# 留学生のためのJavaScript学習ガイド：Webを動かす魔法を学ぼう

留学生（りゅうがくせい）のみなさん、こんにちは！プログラミングの世界へようこそ。

みなさんが毎日使っているスマートフォンやパソコンの<ruby>画面<rt>がめん</rt></ruby>。ボタンを押すとメニューが出てきたり、地図が動いたりしますね。これはすべて「JavaScript（ジャバスクリプト）」という言葉が命令（めいれい）を出して動かしています。

このガイドでは、JavaScriptが「なぜ大切（たいせつ）なのか（<ruby><ruby>戦略<rt>せんりゃく</rt></ruby><rt>せんりゃく</rt></ruby>的重要性）」を理解して、自分でWebサイトを動かせるようになるための基礎（きそ）をやさしく解説します。

1. はじめに：JavaScriptで何ができるようになるのか

JavaScriptを学ぶことは、Webサイトに「命（いのち）」を<ruby>吹<rt>ふ</rt></ruby>き<ruby>込<rt>こ</rt></ruby>む魔法を覚えるようなものです。

これまでのWebサイトは、ただ情報を<ruby>表示<rt>ひょうじ</rt></ruby>するだけの「紙のポスター」のようなものでした。しかし、JavaScriptを使うことで、Webサイトはユーザーと「<ruby>対話<rt>たいわ</rt></ruby>（たいわ）」ができる便利な道具に変わります。

なぜJavaScriptを学ぶのが大切（たいせつ）なのですか？

今のデジタル社会では、JavaScriptは世界中で最も使われている技術の一つです。これを覚えると、世界中のプログラマーと同じ「共通（きょうつう）の言葉」で会話ができるようになります。

JavaScriptは他の言葉（C言語など）に比べて、<ruby>書<rt>か</rt></ruby>き<ruby>方<rt>かた</rt></ruby>が自由で「柔軟（じゅうなん：フレキシブル）」です。初心者でもすぐに結果が見えるので、最初に学ぶのにぴったりな言葉です。

「プログラマーのように考える」コツ

コードを書く前に、次の3つのマインドセット（考え方）を大切にしてください。

* 大きな問題を小さく分ける： 「ゲームを作りたい」ではなく、「まずボタンを押したら数字が増えるようにしよう」と、小さく分けて考えます。
* <ruby>手順<rt>てじゅん</rt></ruby>（ステップ）を紙に書く： コンピュータに命令する順番を、言葉で書き出してみます。
* エラーは「成長のヒント」： コードが動かないとき、コンピュータは「ここが違うよ」と教えてくれています。失敗ではありません。



3. 私たちの舞台：WWW（ワールド・ワイド・ウェブ）とは何か

**WWW（ワールド・ワイド・ウェブ）**は、世界中のコンピュータが「クモの巣（Web）」のようにつながって、情報を<ruby>共有<rt>きょうゆう</rt></ruby>する<ruby>仕組<rt>しく</rt></ruby>みのことです。

これを、**「図書館（としょかん）」**に<ruby>例<rt>たと</rt></ruby>えて、やさしく説明しますね。

---

### 1. 3つの大切な「道具」

WWWを動かすために、3つの主役（しゅやく）がいます。

* **Webブラウザ（お客さん）**
ChromeやSafariなど、私たちがサイトを見るためのソフトです。「本を読みたい人」です。
* **Webサーバ（図書館のスタッフ）**
世界中のどこかにある、24時間動いているコンピュータです。「本を管理している人」です。
* **HTML（本の内容）**
ウェブサイトに書いてある文章や写真のデータです。これが「本」そのものです。

---

### 2. ウェブサイトが<ruby>表示<rt>ひょうじ</rt></ruby>されるまでの「4つのステップ」

あなたがブラウザでURLを<ruby>入力<rt>にゅうりょく</rt></ruby>してから、<ruby>画面<rt>がめん</rt></ruby>が出るまでの流れを見てみましょう。

1. **リクエスト（注文）：**
あなたが「このページを見たい！」とURLをクリックします。これは図書館のスタッフに「あの本を貸してください」と頼むのと同じです。
2. **住所の確認（DNS）：**
インターネットの世界では、`google.com`のような名前ではなく、数字の住所（IPアドレス）で場所を探します。
3. **レスポンス（返事）：**
サーバがあなたのリクエストを受けて、HTMLなどのデータをあなたのブラウザに送り返します。「はい、どうぞ！」と本を渡してくれるイメージです。
4. **レンダリング（<ruby>組<rt>く</rt></ruby>み<ruby>立<rt>た</rt></ruby>て）：**
ブラウザが、届いたHTMLデータを読み取って、きれいなデザインに<ruby>組<rt>く</rt></ruby>み<ruby>立<rt>た</rt></ruby>てて<ruby>表示<rt>ひょうじ</rt></ruby>します。

---

### 3. WWWで使われる「魔法の言葉」

ウェブの世界には、共通のルール（プロトコル）があります。

* **HTTP / HTTPS：**
情報をやり取りするときの「言葉のルール」です。
* **URL：**
ウェブサイトの「住所」です。世界に一つしかありません。

2. Webサイトを作る「3つの力」：HTML・CSS・JavaScriptの役割

Webサイトは、3つの技術がチームワークを発揮してできています。これを「家づくり」に<ruby>例<rt>たと</rt></ruby>えてみましょう。

技術名	役割（やくわり）	家づくりに<ruby>例<rt>たと</rt></ruby>えると？
HTML	<ruby>骨組<rt>ほねぐ</rt></ruby>み・構造	柱、壁、床（ゆか）
CSS	<ruby>見<rt>み</rt></ruby>た<ruby>目<rt>め</rt></ruby>・デザイン	ペンキの色、インテリア、<ruby>壁紙<rt>かべがみ</rt></ruby>
JavaScript	<ruby>動<rt>うご</rt></ruby>き・機能（きのう）	電気（でんき）、機械装置（きかいそうち）

JavaScriptの役割：電気を通すこと

HTMLとCSSだけでは、家は完成しても「電気が通っていない」状態です。JavaScriptという電気が通ることで、スイッチを押せばライトがつき、自動ドアが開き、エレベーターが動くようになります。

💡 先生のアドバイス： JavaScriptを書く場所（<script>タグ）は、HTMLの </body>の直前（ちょくぜん） に書くのがベストです。そうすることで、Webサイトの<ruby>読<rt>よ</rt></ruby>み<ruby>込<rt>こ</rt></ruby>みがスムーズになり、エラーも起きにくくなります。

**次は、ブラウザがHTMLを読み取ったあとに作る「DOMツリー」という、JavaScriptの本当の仕事場についてお<ruby>話<rt>はなし</rt></ruby>ししましょうか？**


私たちが書いたコードが動く場所は、ブラウザ（ChromeやEdgeなど）の中です。

ブラウザは「JavaScriptのエンジン」

世界中の情報が「リンク」でつながっている巨大なネットワークをWWWと呼びます。ブラウザは、この広大なネットワークから情報を取ってきて<ruby>表示<rt>ひょうじ</rt></ruby>するだけでなく、JavaScriptを動かすための「エンジン」を積んでいます。

なぜJavaScriptは便利（べんり）なのですか？

JavaScriptのすごいところは、特別なソフトを入れなくても、ブラウザさえあれば誰でもすぐに動かせることです。あなたが書いた魔法は、リンクを通じて世界中の人のブラウザで動かすことができるのです。

4. JavaScriptの<ruby>書<rt>か</rt></ruby>き<ruby>方<rt>かた</rt></ruby>：これだけは守りたい8つのルール

プログラミングは世界共通のルールです。なぜ英語（えいご）で名前を付けるのか？ それは世界中のプログラマーが共通して使う「公式（こうしき）の言葉」だからです。

以下のルールを「チェックリスト」として使いましょう。

1. 文の終わりにはセミコロン（;）： 命令の<ruby>区切<rt>くぎ</rt></ruby>りをはっきりさせます。
2. 変数の宣言（せんげん）は let と const： 値を入れる「箱（はこ）」を作ります。
  * const：一度決めたら変えられない 「箱に貼った固定ラベル」 です。基本はこちらを使います。
  * let：あとで中身を入れ替えられる箱です。
3. 文字列は " " または ' ' で囲む： 「こんにちは」などの言葉は引用符（いんようふ）で囲みます。
4. インデント（字下げ）： コードの行の最初をスペースで<ruby>揃<rt>そろ</rt></ruby>えて、見やすくします。
5. コメント（//）： 自分のためのメモです。コンピュータは無視します。
6. 名前は英語（えいご）で付ける： let namae ではなく let userName と書くのがプロのルールです。
7. 大文字と小文字を分ける： MyName と myname は、コンピュータには違う箱に見えます。
8. すべて「<ruby>半角<rt>はんかく</rt></ruby>」で書く： これが一番大切です。文字列の中とコメント以外で 「<ruby>全角<rt>ぜんかく</rt></ruby>」を使うと、コードは絶対に<ruby>動<rt>うご</rt></ruby>きません。

⚠️ 注意：目に見えない「<ruby>全角<rt>ぜんかく</rt></ruby>スペース」の恐怖

日本語<ruby>入力<rt>にゅうりょく</rt></ruby>のままスペースを押すと、エラーになります。

* ❌ ダメな<ruby>例<rt>れい</rt></ruby>：let age = 20;（= のあとに <ruby>全角<rt>ぜんかく</rt></ruby>スペース がある）
* ✅ 正しい<ruby>例<rt>れい</rt></ruby>：let age = 20;（すべて <ruby>半角<rt>はんかく</rt></ruby>スペース）

5. イベントと関数：ユーザーの操作に<ruby>反応<rt>はんのう</rt></ruby>させる

JavaScriptの面白さは、ユーザーの<ruby>動<rt>うご</rt></ruby>きに<ruby>反応<rt>はんのう</rt></ruby>（リアクション）することです。

イベント：魔法が発動する「きっかけ」

「クリックされたとき」などのきっかけをイベントと呼びます。

カテゴリ	イベント名	きっかけ
マウス	onclick	クリックされたとき
	onmouseover	マウスが上に乗ったとき
<ruby>入力<rt>にゅうりょく</rt></ruby>	oninput	文字が<ruby>入力<rt>にゅうりょく</rt></ruby>されたとき

関数（かんすう）：魔法の「自動販売機（じどうはんばいき）」

命令をまとめたものを「関数」と呼びます。自動販売機で<ruby>例<rt>たと</rt></ruby>えるとこうなります。

* 引数（ひきすう）： お金を入れること。（関数にわたすデータ）
* 関数の中身： 機械がジュースを選んで冷やす処理（しょり）。
* 戻り値（もどりち）： 出てきたジュース。（処理の結果）

DOM（ドム）ツリー：HTMLを操作する手

JavaScriptがHTMLを動かすとき、Webページを「木の枝（DOMツリー）」のような構造としてとらえます。 document.querySelector("#id名") という命令を使うことで、JavaScriptは特定のHTML要素をつかんで、文字を書き換えたり色を変えたりできます。

6. まとめ：コンソールを味方につけて学習を続けよう

最後に、一番大切な道具 「コンソール（Console）」 を紹介します。

コンソールは「コンピュータとの<ruby>対話<rt>たいわ</rt></ruby>窓口」

プログラムが動かないとき、コンソールはどこが間違っているか教えてくれます。また、console.log() を使うと、変数の箱の中に今何が入っているかを確認できます。

コンソールの開き方：

* Mac (Chrome)： Command + Option + I キーを押す

学習のステップ

1. ブラウザのコンソールを開く。
2. console.log("Hello World"); と打ってみる。
3. エラーが出たら、落ち着いて英語のメッセージを読んでみる。

これであなたはJavaScriptの入り口に立ちました。小さなボタンを動かすことから始めて、Webの世界で自分だけの魔法を広げていきましょう！
