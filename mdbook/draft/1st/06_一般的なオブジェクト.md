JavaScriptの便利な道具「組み込みオブジェクト」を学ぼう

みなさん、こんにちは！留学生のみなさんがプログラミングを学ぶとき、日本語の壁と技術の壁、両方を感じることがあるかもしれません。でも安心してください。JavaScript（ジャバスクリプト）の世界には、最初から用意されている「便利な道具箱」がたくさんあります。これを組み込みオブジェクトと呼びます。

このドキュメントでは、プログラミングの基礎から、データを上手に扱うためのテクニックまで、やさしい日本語で解説していきます。

1. JavaScriptの役割と基本ルール

Webサイトを作るとき、JavaScriptは「<ruby>動<rt>うご</rt></ruby>き」や「機能」を追加する役割を持っています。まずはその立ち位置と、コードを書くときの「お作法（ルール）」を確認しましょう。

Webの3つの技術の役割

Webサイトは、よく「家」に<ruby>例<rt>たと</rt></ruby>えられます。

* HTML（骨組み）: 家の「柱」や「壁」です。見出しや<ruby><ruby>段落<rt>だんらく</rt></ruby><rt>だんらく</rt></ruby>などの構造を作ります。
* CSS（<ruby>見<rt>み</rt></ruby>た<ruby>目<rt>め</rt></ruby>）: 家の「ペンキ」や「インテリア」です。色やサイズ、レイアウトを整えます。
* JavaScript（<ruby>動<rt>うご</rt></ruby>き）: 家の「電気」や「機械装置」です。ボタンを押したときにメッセージを出したり、計算をしたりします。

これだけは守ろう！記述ルールの要約

初心者が間違いやすいポイントをまとめました。エラーを防ぐために、このルールを習慣にしましょう。

* 文の終わりにはセミコロン（;）をつける: 命令の終わりをはっきりさせます。
* let / const を使い分ける: 値を変えるなら let（変数）、変えないなら const（定数）を使います。
* 半角（はんかく）文字を使う: ここが一番重要です！ 文字列の中やコメント以外で、全角のスペースや記号を使うとプログラムは<ruby>動<rt>うご</rt></ruby>きません。
* キャメルケース（Camel Case）を使う: showMessage のように、2つ目以降の単語の頭文字を大文字にします。ラクダのコブのような形のことです。

So What?（なぜ大切なの？） これらのルールを守ることは、単なるマナーではありません。チーム<ruby>開発<rt>かいはつ</rt></ruby>において他の人がコードを読みやすくなり、また、自分自身がバグ（間違い）を見つけやすくするために不可欠です。特に const を正しく使うことで、間違えて値を書き換えてしまうミスを未然に防ぐことができます。

次は、JavaScriptが最初から持っている便利な「道具箱」について見ていきましょう。

2. 配列（Array）の基本

たくさんのデータをバラバラに管理するのは大変です。そこで使うのが「配列（はいれつ）」という、複数のデータを一つにまとめて管理できるリストのような道具です。

配列の<ruby>仕組<rt>しく</rt></ruby>み

配列は []（角括弧：かくかっこ）を使って宣言（せんげん：はじめの準備）します。

* インデックス（添字：そえじ）: データが入っている場所の番号です。JavaScriptでは、必ず 0から 始まります。

C言語との比較

留学生のみなさんの中には、以前にC言語を学んだことがある人もいるでしょう。JavaScriptの配列は、C言語よりもずっと自由で使いやすいのが特徴です。

特徴	C言語の配列	JavaScriptの配列
データ型	単一の型（intだけ等）	混合可能（数値、文字列、オブジェクトが混ざってもOK）
長さ	固定（後から変えられない）	可変（自<ruby>動的<rt>どうてき</rt></ruby>に伸び縮みする）
メモリの<ruby>仕組<rt>しく</rt></ruby>み	ポインタ（最初の要素の場所を指す）	オブジェクト（実体は特殊なデータの集まり）
安全性	範囲外アクセスは危険（クラッシュする）	範囲外は undefined が返るだけで安全

So What?（なぜ大切なの？） 配列の .length プロパティを使うことで、「データが今いくつあるか」を常に知ることができます。これにより、データの数が増えたり減ったりしても、プログラムを書き直さずに柔軟に対応できるようになります。

3. 配列の応用とforEach

大量のデータを効率よく処理するために、JavaScriptには forEach（フォーイーチ）という便利な道具があります。

forEachとコールバック関数

以前、関数は「自動販売機（じどうはんばいき）」のようなものだと学びましたね。ボタン（呼び出し）を押すと、中に入れた処理が実行されて結果が出てきます。

forEach を使うときは、この関数をさらに便利に使います。

* <ruby>例<rt>たと</rt></ruby>え話: forEach は「店員さん」、渡す関数は「店員さんに渡すチェックメモ（コールバック関数）」です。 店員さんは、配列の中身（リンゴなど）を一つ取るたびに、あなたが渡したメモを読んで「傷がないか確認する」などの作業を行ってくれます。

オブジェクトの配列

現実のプログラムでは、以下のように「オブジェクト（情報のセット）」を配列にまとめることが多いです。これは「顧客名簿」や「商品カタログ」のようなイメージです。

const customers = [
  { name: "山田", age: 30 },
  { name: "佐藤", age: 25 }
];


So What?（なぜ大切なの？） | 従来の for 文 | forEach メソッド | | :--- | :--- | | 繰り返しの回数を自分で管理する | 配列が自<ruby>動的<rt>どうてき</rt></ruby>に回数を決めてくれる | | コードが長くなりやすい | 短く、読みやすくなる |

コードが読みやすくなると、<ruby>開発<rt>かいはつ</rt></ruby>のスピードが上がり、ミスも減ります。

4. 文字列（String）の応用

Webサイトで扱う情報の多くは「テキスト（文字列）」です。これをどう操作するかが、プログラミングの腕の見せ所です。

文字列の作成と結合

最新のJavaScriptでは、テンプレートリテラル（  バッククォート）を使うのがとても便利です。

* 変数の埋め込み: `こんにちは、${name}さん！` のように、${} で変数を入れられます。
* <ruby>改行<rt>かいぎょう</rt></ruby>（かいぎょう）: テンプレートリテラルは、コードの中で<ruby>改行<rt>かいぎょう</rt></ruby>した場所をそのまま文字として扱ってくれます。HTMLのコードを文字として作りたいときに非常に役立ちます。

数値への変換

prompt()（プロンプト：<ruby>入力<rt>にゅうりょく</rt></ruby><ruby>画面<rt>がめん</rt></ruby>）でユーザーが<ruby>入力<rt>にゅうりょく</rt></ruby>した数字は、<ruby>見<rt>み</rt></ruby>た<ruby>目<rt>め</rt></ruby>が数字でも、プログラム上は「文字列」です。計算するには変換が必要です。

* parseInt(): 整数（1, 2, 3...）に変換します。
* parseFloat(): 小数点を含む数値に変換します。

So What?（なぜ大切なの？） 数字ではない文字を無理に数値に変えようとすると NaN（Not a Number：数値ではないというエラー値）になります。Web<ruby>開発<rt>かいはつ</rt></ruby>ではユーザーが何を打つか分かりません。isNaN() 関数を使って「これは本当に数字かな？」とチェックすることは、プログラムが止まってしまう「クラッシュ」を防ぐためのプログラマーの責任です。

5. 数学（Math）と日付（Date）

正確な計算や日時の管理ができるようになると、ランキング機能や時計<ruby>表示<rt>ひょうじ</rt></ruby>など、サイトの価値がぐっと上がります。

Mathオブジェクト（数学の道具）

* Math.random(): 0から1未満のランダムな数字を作ります。
* Math.floor(): 小数点を切り捨てます。ランダムな数字を整数にしたいときにセットで使います。

Dateオブジェクト（日付の道具）

日付を扱うときは new Date() と書きます。ここで「プリミティブ型」と「オブジェクト型」の違いを理解しましょう。

* プリミティブ型（数値や文字列）: データそのものが変数に入っています。
* オブジェクト型（Dateなど）: データそのものではなく、データが保存されているメモリ上の「場所（参照：さんしょう）」が変数に入っています。

new を使うことで、メモリの中に新しい「日付というデータの箱（実体）」を作り、その場所を指し示すようになります。

So What?（なぜ大切なの？） これらの組み込みオブジェクトを使いこなすことは、プログラミングの世界で「車輪の再発明（しゃりんのさいはつめい：すでにあるものを一から作る無駄なこと）」を防ぐことになります。用意された道具を使うことで、<ruby>開発<rt>かいはつ</rt></ruby>スピードを劇的に速めることができます。

7. 繰り返し処理の応用：for-in文

※オブジェクトの性質を利用した応用的な繰り返し処理です。

配列ではなく「オブジェクト」の中身（プロパティ）をすべて確認したいときは、for-in 文を使います。

ループの種類	対象	使いどころ
for文	数値の回数、配列	決まった回数繰り返したいとき
while文	条件	条件が満たされるまで続けたいとき
for-in文	オブジェクトのプロパティ	オブジェクトの「キー」を全部調べたいとき

So What?（なぜ大切なの？） オブジェクトの中にどんなデータがいくつ入っているか、事前にはわからない場合があります。for-in を使えば、どんなに項目が多くても漏れなくすべて処理できるため、柔軟なプログラムが作れます。

8. 変数のスコープとまとめ

最後に、変数が「どこから見えるか」というスコープ（守備範囲）について学びましょう。

スコープの種類

* グローバルスコープ: プログラムのどこからでも見えますが、使いすぎるとデータの混乱を招きます。
* ブロックスコープ（let/const）: {}（波括弧）の中でしか使えません。今のJavaScriptではこちらが基本です。

初心者が最も混乱する「const」の不変性

const で宣言したオブジェクトには、大切なルールがあります。

* 名札（変数名）の付け替え（再代入：さいだいにゅう）はできません。
* しかし、中身（プロパティ）の変更はできます。

「ガムテープで名札が貼られた箱」をイメージしてください。ガムテープで固定されているので、名札を別の新しい箱に貼り直すことはできません。でも、箱の蓋（ふた）を開けて、中に入っているおもちゃを入れ替えたり、色を塗ったりすることは自由なのです。

全体まとめ
