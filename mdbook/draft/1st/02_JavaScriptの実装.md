1. JavaScriptの役割とWebページの<ruby>仕組<rt>しく</rt></ruby>み

Webページは、主に3つの技術が協力して作られています。これを「家」に<ruby>例<rt>たと</rt></ruby>えて考えてみましょう。

* HTML（骨組み）： 家の「柱」や「壁」です。ページの構造（見出しや<ruby>段落<rt>だんらく</rt></ruby>）を作ります。
* CSS（<ruby>見<rt>み</rt></ruby>た<ruby>目<rt>め</rt></ruby>）： 家の「ペンキ」や「インテリア」です。色やデザインを整えます。
* JavaScript（<ruby>動<rt>うご</rt></ruby>き）： 家の**「電気や機械装置」**です。スイッチを押すと電気がついたり、自動ドアが開いたりする「機能」を担当します。

プロの<ruby>開発<rt>かいはつ</rt></ruby>現場では、これら3つの役割をしっかり分けることが「<ruby>業界<rt>ぎょうかい</rt></ruby>の標準（スタンダード）」です。役割を分けることで、チームで<ruby>開発<rt>かいはつ</rt></ruby>するときにミスが減り、<ruby>効率<rt>こうりつ</rt></ruby>よく作業ができるようになります。さあ、JavaScriptという「電気」をWebページに通す準備を始めましょう！

2. 初めてのプログラム：Hello World! とポップアップ

プログラミングの第一歩は、自分の指示がブラウザに伝わったことを確認することです。<ruby>画面<rt>がめん</rt></ruby>にメッセージを出す2つの方法を学びましょう。

console.log("プログラムがここまで<ruby>動<rt>うご</rt></ruby>きました");


「コンソール」の開き方

自分の書いた「<ruby>意図<rt>いと</rt></ruby>（やりたいこと）」がブラウザに正しく伝わったかどうかは、ここで確認します。

OS	操作方法
Windows	F12 キー（ノートPCは Fn + F12） または Ctrl + Shift + I
Mac	Command + Option + I

自分の書いた1行のコードでブラウザが<ruby>反応<rt>はんのう</rt></ruby>したとき、その「喜び」がこれからの学習の力になります！

3. イベントとイベントハンドラ：<ruby>動<rt>うご</rt></ruby>きを作るきっかけ

JavaScriptは、ユーザーの「クリック」などの操作に<ruby>反応<rt>はんのう</rt></ruby>して<ruby>動<rt>うご</rt></ruby>き出します。この「きっかけ」を理解すると、Webサイトに命を<ruby>吹<rt>ふ</rt></ruby>き<ruby>込<rt>こ</rt></ruby>むことができます。

スイッチと電球の関係

* イベント（操作）： ユーザーがボタンを押す「スイッチ」です。
* ハンドラ（処理）： スイッチが入ったときに実行される「電球がつく」という<ruby>動<rt>うご</rt></ruby>きです。

よく使われるイベントハンドラ（きっかけ）を整理しました。

カテゴリ	イベント名	きっかけ（タイミング）	使用<ruby>例<rt>れい</rt></ruby>
マウス	onclick	クリックされたとき	ボタンを押して計算を始める
マウス	onmouseover	マウスが上に乗ったとき	<ruby>画像<rt>がぞう</rt></ruby>の色を変える
ページ	onload	ページを<ruby>読<rt>よ</rt></ruby>み<ruby>込<rt>こ</rt></ruby>み終わったとき	「ようこそ」と挨拶を出す
フォーム	oninput	文字を<ruby>入力<rt>にゅうりょく</rt></ruby>したとき	リアルタイムで文字数を数える
フォーム	onfocus	<ruby>入力<rt>にゅうりょく</rt></ruby>欄を選択したとき	<ruby>入力<rt>にゅうりょく</rt></ruby>欄の色を明るくする

<ruby>記述<rt>きじゅつ</rt></ruby><ruby>例<rt>れい</rt></ruby>： HTMLのボタンに「クリックされたらアラートを出す」魔法をかけるときは、こう書きます。

4. JavaScriptの呼び出し方と<ruby>外部<rt>がいぶ</rt></ruby>ファイル化

コードが増えてくると、書き場所が重要になります。整理<ruby>整頓<rt>せいとん</rt></ruby>されたコードは、プロの世界の「マナー」です。

1. <ruby>内部<rt>ないぶ</rt></ruby>JavaScript： HTMLの中に <script> タグで直接書く方法です。
2. <ruby>外部<rt>がいぶ</rt></ruby>JavaScript： .js という別のファイルに分ける方法です。

<ruby>外部<rt>がいぶ</rt></ruby>ファイル化のメリット（<ruby>戦略<rt>せんりゃく</rt></ruby>的意義）

プロの<ruby>開発<rt>かいはつ</rt></ruby>では、必ず「<ruby>外部<rt>がいぶ</rt></ruby>ファイル」を使います。理由は、**「再利用性（一つのファイルを多くのページで使い回せること）」**が高まり、修正も一箇所で済むためです。

<ruby>読<rt>よ</rt></ruby>み<ruby>込<rt>こ</rt></ruby>みの<ruby>手順<rt>てじゅん</rt></ruby>

* .js ファイル（<ruby>例<rt>れい</rt></ruby>：script.js）を作成し、JavaScriptだけを書きます。
* HTMLの <body> タグの最後（閉じタグ </body> の直前） に<ruby>読<rt>よ</rt></ruby>み<ruby>込<rt>こ</rt></ruby>みコードを書きます。

なぜ <body> の最後に書くの？ ブラウザは上から順番に<ruby>読<rt>よ</rt></ruby>み<ruby>込<rt>こ</rt></ruby>みます。プログラムを最後に<ruby>読<rt>よ</rt></ruby>み<ruby>込<rt>こ</rt></ruby>ませることで、ページの文字や<ruby>画像<rt>がぞう</rt></ruby>を先に出し、ユーザーを待たせない「スムーズな<ruby>表示<rt>ひょうじ</rt></ruby>」が可能になります。

5. ブラウザオブジェクト（BOM/DOM）の概要

JavaScriptが操作するのは、ブラウザ全体やWebページそのものです。これらは「ツリー構造（木の枝のような形）」で整理されています。

ブラウザ世界の構造

一番上のボスは window オブジェクト です。

* window (ブラウザ全体)
  * location (URLの情報)
  * document (Webページの内容)
    * html
      * body (ページの本文)

RPGのキャラクターに<ruby>例<rt>たと</rt></ruby>えると

「オブジェクト」の考え方は、ゲームのキャラクターに<ruby>例<rt>たと</rt></ruby>えると非常に分かりやすくなります。

* オブジェクト： キャラクター自身（<ruby>例<rt>れい</rt></ruby>：勇者アレン）
* プロパティ： ステータス（<ruby>例<rt>れい</rt></ruby>：hp や name）
* メソッド： 行動（<ruby>例<rt>れい</rt></ruby>：attack() や heal()）

コードでの<ruby>例<rt>れい</rt></ruby>： document.body.style.backgroundColor = "red"; このコードは、documentの中のbody（オブジェクト）の、backgroundColor（プロパティ）を"red"に変えるという命令です。

魔法の杖：getElementById()

特定の要素を見つけるための「セレクタ（目印）」として、document.getElementById('ID名') を使います。 IDはキャラクターの「名前」のようなものです。これを使って、Webページの特定の場所をピンポイントで操作する魔法をかけます。
