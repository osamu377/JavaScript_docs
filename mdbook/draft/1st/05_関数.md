1. はじめに：<ruby>関数<rt>かんすう</rt></ruby><ruby>関数<rt>かんすう</rt></ruby>とは何か？

<ruby>関数<rt>かんすう</rt></ruby>とは、いくつかの命令（めいれい）を一つにまとめた**「セット」のことです。イメージしやすいように、「自動販売機（じどうはんぱいき）」**の<ruby>例<rt>たと</rt></ruby>えで考えてみましょう。

* お金を入れる・ボタンを押す： これが、<ruby>関数<rt>かんすう</rt></ruby>に渡（わた）すデータ**「<ruby>引数<rt>ひきすう</rt></ruby>（ひきすう）」**です。

プログラムをバラバラに書くのではなく、<ruby>関数<rt>かんすう</rt></ruby>として「セット」にするメリットは2つあります。

2. <ruby>関数<rt>かんすう</rt></ruby>の作り方（<ruby>定義<rt>ていぎ</rt></ruby>：ていぎ）

<ruby>関数<rt>かんすう</rt></ruby>を新しく作ることを「<ruby>定義<rt>ていぎ</rt></ruby>（ていぎ）」と言います。 JavaScriptでは、誰が見ても分かりやすいように、名前の付け方に世界共通のルールがあります。

良い名前をつけるルール

プログラマーは、<ruby>関数<rt>かんすう</rt></ruby>が「何をするものか」すぐ分かるように、以下のルールを守ります。

1. 動詞（どうし）から始める： get（取る）、show（見せる）、calculate（計算する）、handle（処理する）などの動詞を使います。
2. キャメルケース（camelCase）： 2つ目以降の単語の最初を大文字にします。<ruby>例<rt>れい</rt></ruby>：showMessage, calculateTotal

3. <ruby>関数<rt>かんすう</rt></ruby>の呼び出し（実行：じっこう）

<ruby>関数<rt>かんすう</rt></ruby>を作っただけでは、プログラムは<ruby>動<rt>うご</rt></ruby>きません。作った<ruby>関数<rt>かんすう</rt></ruby>を動かすことを**「呼び出し」**と言います。<ruby>初心者<rt>しょしんしゃ</rt></ruby>の方は「<ruby>定義<rt>ていぎ</rt></ruby>（準備）」と「呼び出し（実行）」を分けて考えることがとても大切です。

<ruby>引数<rt>ひきすう</rt></ruby>（ひきすう）の活用と注意点

<ruby>関数<rt>かんすう</rt></ruby>にデータを渡すことで、処理を柔軟（じゅうなん）に変えることができます。

4. <ruby>変数<rt>へんすう</rt></ruby>のスコープ（Scope）：<ruby>変数<rt>へんすう</rt></ruby>の見える範囲

<ruby>変数<rt>へんすう</rt></ruby>は、どこからでも見えるわけではありません。この「見える範囲」をスコープと呼びます。スコープを正しく使うことで、プログラムのミス（バグ）を減らすことができます。

スコープの種類	使える範囲	安全性と評価
グローバルスコープ	プログラム全体	危険（きけん）： どこでも値が変わってしまうため。
ブロックスコープ	{} の中だけ	安全： その場所だけで使うので、ミスが起きにくい。

var は使わない、const を使おう

JavaScriptには<ruby>変数<rt>へんすう</rt></ruby>の作り方が3つありますが、安全性のために<ruby>使<rt>つか</rt></ruby>い<ruby>分<rt>わ</rt></ruby>けが重要です。

1. const (定数)： 【一番おすすめ】 一度決めたら変えられないので、最も安全です。
2. let (<ruby>変数<rt>へんすう</rt></ruby>)： 値を変える必要があるときだけ使います。
3. var (古い<ruby>書<rt>か</rt></ruby>き<ruby>方<rt>かた</rt></ruby>)： 【非<ruby>推奨<rt>すいしょう</rt></ruby>（ひすいしょう）】 範囲があいまいで、混乱（こんらん）やミスを招きやすいため、使わないようにしましょう。

6. <ruby>関数<rt>かんすう</rt></ruby>のネスト（入れ子構造）

<ruby>関数<rt>かんすう</rt></ruby>の中に、さらに<ruby>関数<rt>かんすう</rt></ruby>を書くことができます。これを**「ネスト（入れ子）」と呼びます。これは、プログラムを整理して情報を守る「カプセル化（情報の保護）」**に役立ちます。

<ruby>親子<rt>おやこ</rt></ruby>関係とスコープ

これはDOMツリーの「親要素（div）」と「子要素（p）」の関係に似ています。

* ルール： <ruby>内側<rt>うちがわ</rt></ruby>の<ruby>関数<rt>かんすう</rt></ruby>（子供）は、<ruby>外側<rt>そとがわ</rt></ruby>の<ruby>関数<rt>かんすう</rt></ruby>（親）にある<ruby>変数<rt>へんすう</rt></ruby>を見ることができます。
* <ruby>例<rt>たと</rt></ruby>え： 「子供は自分の家の冷蔵庫（親の<ruby>変数<rt>へんすう</rt></ruby>）を開けて中身を見ることができます。でも、外にいる隣の人（外の<ruby>関数<rt>かんすう</rt></ruby>）は、その家の中を見ることはできません。」

このように構造（こうぞう）を作ることで、大切なデータを外から勝手に触られないように守ることができます。

7. まとめ

JavaScriptの「<ruby>関数<rt>かんすう</rt></ruby>」をマスターするために、5つのポイントを振り返りましょう。

* 呼び出し： <ruby>関数<rt>かんすう</rt></ruby>名のあとの () を忘れずにつけて実行しましょう。
* スコープ： <ruby>変数<rt>へんすう</rt></ruby>は const を使い、なるべく {} の中で安全に管理しましょう。
* 無名<ruby>関数<rt>かんすう</rt></ruby>： 一度きりの処理は、名前をつけずにスマートに書きましょう。
* ネスト： <ruby>関数<rt>かんすう</rt></ruby>を入れ子にして、大切な情報を守りながら整理しましょう。
