1. <ruby>変数<rt>へんすう</rt></ruby>とは何か：データを保存する「名前付きの箱」

プログラミングにおける「<ruby>変数<rt>へんすう</rt></ruby>」とは、データを一時的に保存しておくための名前付きの箱です。

空港で荷物を預けるシーンを想像してみてください。たくさんのスーツケースがあるとき、どれが誰のものか、中身が何かを判別するために「名前のラベル」を貼りますよね。これが<ruby>変数<rt>へんすう</rt></ruby>です。ラベル（<ruby>変数<rt>へんすう</rt></ruby>名）があるからこそ、<ruby>後<rt>あと</rt></ruby>で必要なときに迷わずそのデータを取り出すことができます。

letとconstの<ruby>使<rt>つか</rt></ruby>い<ruby>分<rt>わ</rt></ruby>け

JavaScriptには、主に2種類の箱があります。プログラムを<ruby>効率<rt>こうりつ</rt></ruby>的に、そしてミスなく作るためには、これらを<ruby>戦略<rt>せんりゃく</rt></ruby>的に<ruby>使<rt>つか</rt></ruby>い<ruby>分<rt>わ</rt></ruby>けることが重要です。

種類	特徴	使いどき（<ruby>戦略<rt>せんりゃく</rt></ruby>的判断）
let	中身を<ruby>入<rt>い</rt></ruby>れ<ruby>替<rt>かえ</rt></ruby>られる箱	スコアや回数など、<ruby>後<rt>あと</rt></ruby>で値が変わるもの
const	一度入れたら変えられない箱	名前、誕生日、<ruby>設定<rt>せってい</rt></ruby>値など、ずっと同じもの

💡 プロの視点：なぜ const を<ruby>優先<rt>ゆうせん</rt></ruby>するのか？ 現代のプログラミングでは、可能な限り const を使うことが<ruby>推奨<rt>すいしょう</rt></ruby>されます。一度決めた値が「変わらない」と保証されていると、後からコードを<ruby>読<rt>よ</rt></ruby>み<ruby>返<rt>かえ</rt></ruby>したときに混乱せず、予期せぬバグ（ミス）を劇的に減らすことができるからです。

⚠️ 留学生への重要アドバイス：<ruby>半角<rt>はんかく</rt></ruby>と<ruby>全角<rt>ぜんかく</rt></ruby>

JavaScriptのコードを書く際、最も多いエラーの原因は<ruby>全角<rt>ぜんかく</rt></ruby>文字の使用です。

* **コードはすべて「<ruby>半角<rt>はんかく</rt></ruby>（half-width）」**で書きます。
* 特に「<ruby>全角<rt>ぜんかく</rt></ruby>スペース」や「<ruby>全角<rt>ぜんかく</rt></ruby>のセミコロン（；）」、「<ruby>全角<rt>ぜんかく</rt></ruby>のカッコ（（ ））」が混じると、プログラムは<ruby>動<rt>うご</rt></ruby>きません。日本語<ruby>入力<rt>にゅうりょく</rt></ruby>（IME）を使っているときは、常に<ruby>半角<rt>はんかく</rt></ruby>になっているか確認しましょう。

命名規則：意味のわかる英語を使おう

<ruby>変数<rt>へんすう</rt></ruby>の名前（ラベル）は、誰が見ても中身がわかるように「意味のある英語」で付けるのが鉄則です。

* キャメルケース (camelCase)：userName や testScore のように、2つ目の単語の先頭を大文字にします。
* 脱・ローマ字（No Romaji）：ringoCount ではなく appleCount と書きましょう。将来、世界中のエンジニアと一緒に働くための大切な習慣です。

2. 文字列型 (String)：テキストデータを扱う

Webページで「こんにちは」というメッセージを<ruby>表示<rt>ひょうじ</rt></ruby>したり、ユーザーの名前を扱ったりする際に使われるのが「文字列」です。

文字列の<ruby>定義<rt>ていぎ</rt></ruby>

文字列を作るには、テキストを**<ruby>引用符<rt>いんようふ</rt></ruby>（クォーテーション）**で囲みます。

* シングルクォーテーション：'こんにちは'
* ダブルクォーテーション："こんにちは" どちらを使っても構いませんが、一つのプログラムの中で統一するのが良い習慣です。

バッククォート（ ` ）と ${ } を使った「テンプレートリテラル」を使うと、<ruby>変数<rt>へんすう</rt></ruby>の<ruby>埋<rt>う</rt></ruby>め<ruby>込<rt>こ</rt></ruby>みや<ruby>改行<rt>かいぎょう</rt></ruby>が非常に簡単になります。

// テンプレートリテラルなら、そのまま<ruby>改行<rt>かいぎょう</rt></ruby>もできます

二行目
三行目`;


💡 プロの視点：テンプレートリテラルのメリット 従来の + 記号を使った<ruby>結合<rt>けつごう</rt></ruby>（<ruby>例<rt>れい</rt></ruby>："こんにちは、" + name + "さん！"）に比べ、<ruby>引用符<rt>いんようふ</rt></ruby>の閉じ忘れやスペースの入れ忘れといったケアレスミスを劇的に防ぐことができます。

文字の次は、計算に欠かせない「<ruby>数値<rt>すうち</rt></ruby>」の扱いに進みます。

3. <ruby>数値<rt>すうち</rt></ruby>型 (Number) と特別な値 (NaN / Infinity)

JavaScriptでは、整数（100）も小数（3.14）も、すべて同じ「<ruby>数値<rt>すうち</rt></ruby>型」として扱います。

<ruby>算術<rt>さんじゅつ</rt></ruby><ruby>演算<rt>えんざん</rt></ruby>子（計算の記号）

<ruby>数値<rt>すうち</rt></ruby>を使って、算数と同じように計算ができます。

* +（<ruby>足<rt>た</rt></ruby>し<ruby>算<rt>ざん</rt></ruby>） / -（<ruby>引<rt>ひ</rt></ruby>き<ruby>算<rt>ざん</rt></ruby>） / *（<ruby>掛<rt>か</rt></ruby>け<ruby>算<rt>ざん</rt></ruby>） / /（<ruby>割<rt>わ</rt></ruby>り<ruby>算<rt>ざん</rt></ruby>） / %（余り）

特別な<ruby>数値<rt>すうち</rt></ruby>：NaNとInfinity

<ruby>数値<rt>すうち</rt></ruby>型には、注意が必要な特殊な値があります。

* NaN (Not a Number)：「数字ではない」状態です。<ruby>例<rt>たと</rt></ruby>えば、文字列を無理やり計算しようとした時に発生します。

⚠️ 注意点：NaN の放置は危険 NaN が発生したまま放置すると、その後の計算がすべて狂ってしまいます。計算の前に isNaN(値) を使って、そのデータが「有効な数字かどうか」をチェックする習慣をつけましょう。

4. <ruby>論理<rt>ろんり</rt></ruby>型 (Boolean)：YesかNoかの判断基準

プログラムが「もし〜なら、これをする」という意思決定（条件分岐）を行う際、その<ruby>土台<rt>どだい</rt></ruby>となるのが「<ruby>論理<rt>ろんり</rt></ruby>型」です。

2つの値だけ

<ruby>論理<rt>ろんり</rt></ruby>型には、true（<ruby>真<rt>しん</rt></ruby>／正しい） と false（<ruby>偽<rt>ぎ</rt></ruby>／間違い） の2つの値しか存在しません。

比較<ruby>演算<rt>えんざん</rt></ruby>子を使うと、結果として<ruby>論理<rt>ろんり</rt></ruby>型の値が得られます。

* score === 100 （スコアは100と<ruby>厳密<rt>げんみつ</rt></ruby>に等しいか？）
* age >= 20 （年齢は20以上か？）

また、<ruby>論理<rt>ろんり</rt></ruby><ruby>演算<rt>えんざん</rt></ruby>子を使って複数の条件を<ruby>組<rt>く</rt></ruby>み<ruby>合<rt>あ</rt></ruby>わせることもできます。

<ruby>演算<rt>えんざん</rt></ruby>子	意味	覚えるポイント
&&	〜かつ〜 (AND)	すべて true のときだけ true
**`		`**
!	〜ではない (NOT)	true と false を逆転させる

<ruby>論理<rt>ろんり</rt></ruby>型を正しく理解することは、複雑なシステムの判断ロジックを整理し、ユーザーの<ruby>入力<rt>にゅうりょく</rt></ruby>に対して「正確に<ruby>反応<rt>はんのう</rt></ruby>する」プログラムを構築するための<ruby>土台<rt>どだい</rt></ruby>となります。

6. オブジェクト型 (Object)：関連する情報をセットにする

現実世界の情報を扱うとき、一つの<ruby>変数<rt>へんすう</rt></ruby>だけでは足りないことがあります。<ruby>例<rt>たと</rt></ruby>えばRPGの「キャラクター」なら、名前、レベル、HPなどの情報をセットで管理したいはずです。これを可能にするのが「オブジェクト型」です。

波括弧 { } で作る構造

オブジェクトは、プロパティ（名前と値のペア）をセットにして管理します。

const character = {
  name: "アレン",   // プロパティ（ステータス）
  level: 10,
  hp: 1450,
  attack: function() { // メソッド（行動）
    console.log("攻撃した！");
  }
};

// ドット記法でアクセス
console.log(character.name); // "アレン"


💡 オブジェクトと const の意外な関係

「 const は中身を変えられない箱」と説明しましたが、オブジェクトの場合は少し違います。

* 名札の固定（参照の不変性）：const で作ったオブジェクトそのものを別のオブジェクトに<ruby>入<rt>い</rt></ruby>れ<ruby>替<rt>かえ</rt></ruby>ることはできません（別の箱に名札を付け替えるのは禁止）。
* 中身の変更はOK：箱の中に入っている<ruby>個別<rt>こべつ</rt></ruby>のデータ（プロパティ）を<ruby>書<rt>か</rt></ruby>き<ruby>換<rt>かえ</rt></ruby>えることは可能です。

<ruby>例<rt>たと</rt></ruby>えるなら、「ファイルの保存場所（パス）」は固定されているけれど、「ファイルの中身」は自由に<ruby>書<rt>か</rt></ruby>き<ruby>換<rt>かえ</rt></ruby>えられるようなイメージです。

1. はじめに：<ruby>変数<rt>へんすう</rt></ruby>とは何か？

プログラミングを始めるとき、一番(いちばん)大切(たいせつ)な言葉(ことば)があります。それが「<ruby>変数<rt>へんすう</rt></ruby>」です。

<ruby>変数<rt>へんすう</rt></ruby>は、データを入れるための「名前(なまえ)がついた箱(はこ)」だとイメージしてください。コンピュータはとても頭(あたま)がいいですが、名前をつけて保存(ほぞん)しないと、すぐにその情報を忘(わす)れてしまいます。

<ruby>変数<rt>へんすう</rt></ruby>を使うメリット（いいところ）

1. 記憶(きおく)できる： ユーザーが<ruby>入力<rt>にゅうりょく</rt></ruby>した名前や計算(けいさん)の結果(けっか)を、後(あと)で使うために取っておくことができます。<ruby>変数<rt>へんすう</rt></ruby>を使わないと、その行(ぎょう)の処理(しょり)が終わった瞬間にデータは消(き)えてしまいます。
2. 再利用(さいりよう)できる： 一度(いちど)箱に入れたデータは、プログラムの中で何度(なんど)でも呼び出(だ)して使うことができます。

<ruby>変数<rt>へんすう</rt></ruby>のイメージがわきましたか？次は、実際にその「箱」を作るためのルールを学びましょう。

2. <ruby>変数<rt>へんすう</rt></ruby>の作り方：let と const の<ruby>使<rt>つか</rt></ruby>い<ruby>分<rt>わ</rt></ruby>け

JavaScriptで<ruby>変数<rt>へんすう</rt></ruby>の箱を用意(ようい)することを「<ruby>宣言<rt>せんげん</rt></ruby>（せんげん）」と言います。主に使うキーワードは let（レット）と const（コンスト）の2つです。

キーワード	役割(やくわり)	特徴(とくちょう)
let	<ruby>変数<rt>へんすう</rt></ruby>	中身(なかみ)をあとで変えることができる箱です。
const	定数	一度(いちど)中身を入れたら、変えられない箱です。

「名札（なふだ）」と「箱」の<ruby>例<rt>たと</rt></ruby>え

プログラムを正しく動かすためには、この2つの<ruby>使<rt>つか</rt></ruby>い<ruby>分<rt>わ</rt></ruby>けがとても重要(じゅうよう)です。

* let（マジックテープの名札）： 値(あたい)がどんどん変わる場合に使います。名札をペリッと剥(は)がして、別の箱に貼り替(か)えることができるイメージです。
* const（ボンドで貼った名札）： 一度名前をつけたら、その名札を別の箱に付け替える（再<ruby>代入<rt>だいにゅう</rt></ruby>(さいだいにゅう)）ことができません。これにより、間違(まちが)えて大切なデータを<ruby>書<rt>か</rt></ruby>き<ruby>換<rt>かえ</rt></ruby>えてしまうミスを防(ふせ)ぐことができます。

【大事なポイント：オブジェクトの場合】 const で作った箱でも、中身が「オブジェクト型（あとで説明します）」のときは、箱の中にある小さなデータの値を変えることはできます。「名札を別の箱に付け替えること」はできませんが、「箱の中身を整理(せいり)すること」はできるのです。

現代(げんだい)のJavaScriptでは、**「まずは const を使い、どうしても値を変えたいときだけ let を使う」**のが一番(いちばん)安全(あんぜん)な方法です。

3. データの種類（型）：5つの重要なポイント

JavaScriptでは、箱に入れるデータの種類のことを「データ型（かた）」と呼びます。

① 文字列型 (String)

名前やメッセージなどの「文字」です。

* ルール： " "（ダブルクォーテーション）か ' '（シングルクォーテーション）で囲(かこ)みます。
* 便利(べんり)な機能： バッククォート（ ` ）で囲む「テンプレートリテラル」を使うと、${<ruby>変数<rt>へんすう</rt></ruby>名} と書くだけで、文字の中に<ruby>変数<rt>へんすう</rt></ruby>を入れられます。
  * <ruby>例<rt>れい</rt></ruby>： `こんにちは、${name}さん`

② <ruby>数値<rt>すうち</rt></ruby>型 (Number)

数字(すうじ)です。整数(せいすう)も小数(しょうすう)も扱(あつか)えます。

* 特殊(とくしゅ)な値：
  * NaN (Not a Number)： 「<ruby>数値<rt>すうち</rt></ruby>ではない」という意味です。文字を無理(むり)やり計算しようとすると発生します。
  * Infinity： 無限(むげん)に大きい数字のことです。

③ <ruby>論理<rt>ろんり</rt></ruby>型 (Boolean)

「正しい」か「間違い」かの2つだけです。

* true（<ruby>真<rt>しん</rt></ruby>）： 正しい。
* false（<ruby>偽<rt>ぎ</rt></ruby>）： 間違い。 プログラムが「もし〜なら、これをする」と判断(はんだん)するときに使います。

④ オブジェクト型 (Object)

複数の情報をひとつにまとめる箱です。

4. 型の<ruby>変換<rt>へんかん</rt></ruby>：データをもっと自由に扱う

プログラムでは「文字」を「数字」に変えて計算したいことがよくあります。

特に prompt()（プロンプト）という<ruby>関数<rt>かんすう</rt></ruby>でユーザーから数字を受け取るときは注意(ちゅうい)が必要です。

* 失敗の<ruby>例<rt>れい</rt></ruby>： prompt() で受け取った値は、<ruby>見<rt>み</rt></ruby>た<ruby>目<rt>め</rt></ruby>が数字でも必ず「文字列」になります。そのため "10" + "20" を計算すると、数字の30ではなく、文字がつながって "1020" になってしまいます。

正しく計算するために、以下のステップで型を<ruby>変換<rt>へんかん</rt></ruby>(へんかん)しましょう。

型を<ruby>変換<rt>へんかん</rt></ruby>する<ruby>関数<rt>かんすう</rt></ruby>

<ruby>関数<rt>かんすう</rt></ruby>	使い方	<ruby>例<rt>れい</rt></ruby>
Number()	文字を<ruby>数値<rt>すうち</rt></ruby>に変える	Number("10") → 10
parseInt()	文字から「整数」を取り出す	parseInt("55kg") → 55
parseFloat()	小数点(.)を含めて取り出す	parseFloat("55.5kg") → 55.5
String()	<ruby>数値<rt>すうち</rt></ruby>を文字に変える	String(100) → "100"

【注意！ isNaN() について】 parseInt("A123") のように、数字ではない文字から始めると結果は NaN になります。NaN は特殊で、NaN === NaN と書いても true になりません。そのため、値が NaN かどうか調べたいときは、必ず isNaN(値) という<ruby>専用<rt>せんよう</rt></ruby>(せんよう)の命令を使ってください。

💡 最重要ポイント

* 基本は const を使う： 安全のために const を使い、値を変えるときだけ let を使いましょう。
* <ruby>数値<rt>すうち</rt></ruby><ruby>変換<rt>へんかん</rt></ruby>(すうちへんかん)を忘れずに： prompt() などで受け取ったデータは Number() や parseInt() で数字に変えてから計算しましょう。

⚠️ <ruby>初心者<rt>しょしんしゃ</rt></ruby>が間違えやすいポイント

* <ruby>引用符<rt>いんようふ</rt></ruby>（クォーテーション）の忘れ： 文字を書くときは必ず " " で囲んでください。囲まないと<ruby>変数<rt>へんすう</rt></ruby>だと勘違(かんちが)いされてエラーになります。
* <ruby>全角<rt>ぜんかく</rt></ruby>(ぜんかく)文字の使用： プログラムのコード（let, const, ; など）は、必ず<ruby>半角<rt>はんかく</rt></ruby>(はんかく)の<ruby>英数字<rt>えいすうじ</rt></ruby>で書いてください。<ruby>全角<rt>ぜんかく</rt></ruby>のスペースがひとつあるだけでも、プログラムは動かなくなります。

これで<ruby>変数<rt>へんすう</rt></ruby>の基本は<ruby>完璧<rt>かんぺき</rt></ruby>(かんぺき)です。さあ、実際にコードを書いてみましょう！


# JavaScriptの「<ruby>演算<rt>えんざん</rt></ruby>子（えんざんし）」：プログラムに計算や判断をさせる道具

1. はじめに：<ruby>演算<rt>えんざん</rt></ruby>子（えんざんし）とは何か

プログラミングを学ぶとき、一番大切な道具が「<ruby>演算<rt>えんざん</rt></ruby>子（えんざんし）」です。これは、データを使って計算をしたり、正しいか間違いかを調べたりするための「記号」のことです。

<ruby>演算<rt>えんざん</rt></ruby>子を「料理の道具」に<ruby>例<rt>たと</rt></ruby>えてみましょう。材料（データ）を<ruby>包丁<rt>ほうちょう</rt></ruby>で切ったり、鍋で煮たりするように、<ruby>演算<rt>えんざん</rt></ruby>子を使ってデータを<ruby>加工<rt>かこう</rt></ruby>します。また、<ruby>演算<rt>えんざん</rt></ruby>子は「計算機のボタン」にも似ています。ボタンを押すことで、計算機に「何をすべきか」を伝えます。

プロ講師として皆さんに伝えたいことがあります。<ruby>演算<rt>えんざん</rt></ruby>子がないプログラムは、ただの「動かない文字の集まり」です。 <ruby>演算<rt>えんざん</rt></ruby>子を使うことで初めて、プログラムに「知能（判断力）」や「<ruby>動<rt>うご</rt></ruby>き」という「心」が生まれます。

まずは、プログラムの<ruby>動<rt>うご</rt></ruby>きを作る基本中の基本、「計算の<ruby>演算<rt>えんざん</rt></ruby>子」から学んでいきましょう。


--------------------------------------------------------------------------------


2. 計算の<ruby>演算<rt>えんざん</rt></ruby>子（<ruby>算術<rt>さんじゅつ</rt></ruby><ruby>演算<rt>えんざん</rt></ruby>子：さんじゅつえんざんし）

<ruby>数値<rt>すうち</rt></ruby>を計算するときに使う記号です。算数のルールと似ていますが、<ruby>掛<rt>か</rt></ruby>け<ruby>算<rt>ざん</rt></ruby>や<ruby>割<rt>わ</rt></ruby>り<ruby>算<rt>ざん</rt></ruby>の記号がプログラミング<ruby>特有<rt>とくゆう</rt></ruby>のものになっています。

基本的な計算の記号

プログラムでは、計算の結果を<ruby>画面<rt>がめん</rt></ruby>に出したり、<ruby>変数<rt>へんすう</rt></ruby>（箱）に保存して次の処理に使ったりします。

<ruby>演算<rt>えんざん</rt></ruby>子	意味	<ruby>例<rt>れい</rt></ruby>	結果
+	<ruby>足<rt>た</rt></ruby>し<ruby>算<rt>ざん</rt></ruby>（<ruby>加算<rt>かさん</rt></ruby>）	5 + 3	8
-	<ruby>引<rt>ひ</rt></ruby>き<ruby>算<rt>ざん</rt></ruby>（<ruby>減算<rt>げんさん</rt></ruby>）	10 - 4	6
*	<ruby>掛<rt>か</rt></ruby>け<ruby>算<rt>ざん</rt></ruby>（<ruby>乗算<rt>じょうさん</rt></ruby>）	6 * 2	12
/	<ruby>割<rt>わ</rt></ruby>り<ruby>算<rt>ざん</rt></ruby>（<ruby>除算<rt>じょさん</rt></ruby>）	10 / 2	5
%	余り（<ruby>剰余<rt>よじょう</rt></ruby>）	10 % 3	1（10÷3の余り）

数を1つずつ増やす・減らす

「あと何回繰り返すか」を数えるときなど、ループ処理で非常によく使う特別な記号があります。

* インクリメント（++）: 値を「1」増やします。（<ruby>例<rt>れい</rt></ruby>：count++）
* デクリメント（--）: 値を「1」減らします。（<ruby>例<rt>れい</rt></ruby>：count--）

文字列の<ruby>結合<rt>けつごう</rt></ruby>と「Number()」の魔法

+ <ruby>演算<rt>えんざん</rt></ruby>子は文字をつなげることもできますが、注意が必要です。

* "こんにちは" + "田中さん" → "こんにちは田中さん"
* "100" + 1 → "1001" （文字の100と数字の1がくっついてしまう）

このように、文字として数字を扱ってしまうと計算ミス（バグ）になります。そこで便利なのが Number() <ruby>関数<rt>かんすう</rt></ruby> です。これは、**「文字の "100" を<ruby>数値<rt>すうち</rt></ruby>の 100 に変える魔法」**です。

* Number("100") + 1 → 101 （正しく計算できます！）

計算ができるようになったら、次はプログラムに「はい」か「いいえ」を判断させる方法を見てみましょう。

3. 条件式で使う<ruby>演算<rt>えんざん</rt></ruby>子（比較<ruby>演算<rt>えんざん</rt></ruby>子：ひかくんざんし）

プログラムに「もし〜なら」という判断をさせるためには、2つの値を比べる必要があります。このときに使うのが比較<ruby>演算<rt>えんざん</rt></ruby>子です。これはプログラムが自分で考えて動くための「心臓部」です。

値の大きさを比べる

比較した結果は、正しいなら true（<ruby>真<rt>しん</rt></ruby>）、間違いなら false（<ruby>偽<rt>ぎ</rt></ruby>） という「ブール値」で返されます。

* > ：左の方が大きい
* < ：右の方が大きい
* >= ：左の方が右と同じか、大きい（以上）
* <= ：左の方が右と同じか、小さい（以下）

「同じ」かどうかを調べる（ここは一番大切です！）

「同じ」を調べるとき、JavaScriptには2つの<ruby>書<rt>か</rt></ruby>き<ruby>方<rt>かた</rt></ruby>がありますが、<ruby>初心者<rt>しょしんしゃ</rt></ruby>は絶対に === を使ってください。

* ==（等しい）: 値が同じか「<ruby>大<rt>おお</rt></ruby>まかに」調べます。
* ===（<ruby>厳密<rt>げんみつ</rt></ruby>に等しい）: 値だけでなく「データの種類（数字か文字か）」まで正確に調べます。

なぜ === がいいのか？ == を使うと、JavaScriptが勝手に「お<ruby>節介<rt>せっかい</rt></ruby>（おせっかい）」を焼いて、データの種類を変えて比較してしまいます。<ruby>例<rt>たと</rt></ruby>えば、5 == "5" は true になってしまいます。このようにJavaScriptが勝手に型を変えてしまうことが、<ruby>予想<rt>よそう</rt></ruby>外のバグの原因になります。正確なプログラムを作るために、型までチェックする === を使いましょう。

次は、複数の条件を<ruby>組<rt>く</rt></ruby>み<ruby>合<rt>あ</rt></ruby>わせる「<ruby>論理<rt>ろんり</rt></ruby><ruby>演算<rt>えんざん</rt></ruby>子」について説明します。

4. <ruby>論理<rt>ろんり</rt></ruby><ruby>演算<rt>えんざん</rt></ruby>子（ろんりえんざんし）：複数の条件を<ruby>組<rt>く</rt></ruby>み<ruby>合<rt>あ</rt></ruby>わせる

「18歳以上、かつ、会員である」のように、複雑な判断を行いたいときに使うのが<ruby>論理<rt>ろんり</rt></ruby><ruby>演算<rt>えんざん</rt></ruby>子です。

3つの基本ルール

1. <ruby>論理<rt>ろんり</rt></ruby><ruby>積<rt>せき</rt></ruby>（&&）: 「かつ（AND）」。すべての条件が true のときだけ全体が true になります。
2. <ruby>論理<rt>ろんり</rt></ruby>和（||）: 「または（OR）」。どれか1つでも true なら全体が true になります。
3. <ruby>論理<rt>ろんり</rt></ruby>否定（!）: 「ではない（NOT）」。結果を反対にします（true を false に変える）。

<ruby>値表）

条件A	条件B	A && B (かつ)	A || B (または)	! A (ではない)
true	true	true	true	false
true	false	false	true	false
false	true	false	true	true
false	false	false	false	true

複雑な条件をこれらの記号でシンプルに整理することが、ミスのない綺麗なコードを書くコツです。

5. <ruby>演算<rt>えんざん</rt></ruby>の<ruby>優先<rt>ゆうせん</rt></ruby>度（えんざんのゆうせんど）：計算の正しい順番

1つの行にたくさんの<ruby>演算<rt>えんざん</rt></ruby>子があるとき、どの順番で処理されるかが重要です。順番を間違えると、計算結果がめちゃくちゃになってしまいます。

基本のルール

算数と同じで、**「<ruby>掛<rt>か</rt></ruby>け<ruby>算<rt>ざん</rt></ruby>・<ruby>割<rt>わ</rt></ruby>り<ruby>算<rt>ざん</rt></ruby>（*, /）は、<ruby>足<rt>た</rt></ruby>し<ruby>算<rt>ざん</rt></ruby>・<ruby>引<rt>ひ</rt></ruby>き<ruby>算<rt>ざん</rt></ruby>（+, -）よりも先」**に計算されます。

括弧 () でコントロールする

「<ruby>足<rt>た</rt></ruby>し<ruby>算<rt>ざん</rt></ruby>を先にしたい」というときは 括弧 () を使います。

* 10 + 2 * 5 → 20
* (10 + 2) * 5 → 60

プロとしてのコツ

1行で長く書くのではなく、括弧を使って順番をはっきりさせたり、計算をいくつかの行に分けたりしましょう。そうすることで、自分だけでなく、チームの仲間があなたのコードを読んだときに迷わなくて済むようになります。
