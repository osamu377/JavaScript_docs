1. 変数とは何か：データを保存する「名前付きの箱」

プログラミングにおける「変数」とは、データを一時的に保存しておくための名前付きの箱です。

空港で荷物を預けるシーンを想像してみてください。たくさんのスーツケースがあるとき、どれが誰のものか、中身が何かを判別するために「名前のラベル」を貼りますよね。これが変数です。ラベル（変数名）があるからこそ、後で必要なときに迷わずそのデータを取り出すことができます。

letとconstの使い分け

JavaScriptには、主に2種類の箱があります。プログラムを効率的に、そしてミスなく作るためには、これらを戦略的に使い分けることが重要です。

種類	特徴	使いどき（戦略的判断）
let	中身を入れ替えられる箱	スコアや回数など、後で値が変わるもの
const	一度入れたら変えられない箱	名前、誕生日、設定値など、ずっと同じもの

💡 プロの視点：なぜ const を優先するのか？ 現代のプログラミングでは、可能な限り const を使うことが推奨されます。一度決めた値が「変わらない」と保証されていると、後からコードを読み返したときに混乱せず、予期せぬバグ（ミス）を劇的に減らすことができるからです。

⚠️ 留学生への重要アドバイス：半角と全角

JavaScriptのコードを書く際、最も多いエラーの原因は全角文字の使用です。

* **コードはすべて「半角（half-width）」**で書きます。
* 特に「全角スペース」や「全角のセミコロン（；）」、「全角のカッコ（（ ））」が混じると、プログラムは<ruby>動<rt>うご</rt></ruby>きません。日本語<ruby>入力<rt>にゅうりょく</rt></ruby>（IME）を使っているときは、常に半角になっているか確認しましょう。

命名規則：意味のわかる英語を使おう

変数の名前（ラベル）は、誰が見ても中身がわかるように「意味のある英語」で付けるのが鉄則です。

* キャメルケース (camelCase)：userName や testScore のように、2つ目の単語の先頭を大文字にします。
* 脱・ローマ字（No Romaji）：ringoCount ではなく appleCount と書きましょう。将来、世界中のエンジニアと一緒に働くための大切な習慣です。

箱の使い方がわかったところで、次は、その箱に入れる「データの種類」について詳しく見ていきましょう。

2. 文字列型 (String)：テキストデータを扱う

Webページで「こんにちは」というメッセージを<ruby>表示<rt>ひょうじ</rt></ruby>したり、ユーザーの名前を扱ったりする際に使われるのが「文字列」です。

文字列の定義

文字列を作るには、テキストを**引用符（クォーテーション）**で囲みます。

* シングルクォーテーション：'こんにちは'
* ダブルクォーテーション："こんにちは" どちらを使っても構いませんが、一つのプログラムの中で統一するのが良い習慣です。

テンプレートリテラル：最新のスマートな書き方

バッククォート（ ` ）と ${ } を使った「テンプレートリテラル」を使うと、変数の埋め込みや改行が非常に簡単になります。

const name = "佐藤";
// 変数を文章の中に埋め込む
const greeting = `こんにちは、${name}さん！`; 

// テンプレートリテラルなら、そのまま改行もできます
const multiLine = `一行目
二行目
三行目`;


💡 プロの視点：テンプレートリテラルのメリット 従来の + 記号を使った結合（例："こんにちは、" + name + "さん！"）に比べ、引用符の閉じ忘れやスペースの入れ忘れといったケアレスミスを劇的に防ぐことができます。

文字の次は、計算に欠かせない「数値」の扱いに進みます。

3. 数値型 (Number) と特別な値 (NaN / Infinity)

JavaScriptでは、整数（100）も小数（3.14）も、すべて同じ「数値型」として扱います。

算術演算子（計算の記号）

数値を使って、算数と同じように計算ができます。

* +（足し算） / -（引き算） / *（掛け算） / /（割り算） / %（余り）

特別な数値：NaNとInfinity

数値型には、注意が必要な特殊な値があります。

* NaN (Not a Number)：「数字ではない」状態です。例えば、文字列を無理やり計算しようとした時に発生します。
* Infinity：無限に大きな数値です。

データの抽出：parseInt()

文字列の中から数字だけを取り出す便利な機能もあります。

console.log(parseInt("55kg"));    // 55 （数字の部分だけ取り出す）
console.log(parseInt("12.99ドル")); // 12 （整数部分だけ取り出す）
console.log(parseInt("A123"));    // NaN （先頭が文字だと失敗する）


⚠️ 注意点：NaN の放置は危険 NaN が発生したまま放置すると、その後の計算がすべて狂ってしまいます。計算の前に isNaN(値) を使って、そのデータが「有効な数字かどうか」をチェックする習慣をつけましょう。

計算の次は、プログラムが「正しいか間違いか」を判断するためのデータを見てみましょう。

4. 論理型 (Boolean)：YesかNoかの判断基準

プログラムが「もし〜なら、これをする」という意思決定（条件分岐）を行う際、その土台となるのが「論理型」です。

2つの値だけ

論理型には、true（真／正しい） と false（偽／間違い） の2つの値しか存在しません。

比較と組み合わせ

比較演算子を使うと、結果として論理型の値が得られます。

* score === 100 （スコアは100と厳密に等しいか？）
* age >= 20 （年齢は20以上か？）

また、論理演算子を使って複数の条件を組み合わせることもできます。

演算子	意味	覚えるポイント
&&	〜かつ〜 (AND)	すべて true のときだけ true
**`		`**
!	〜ではない (NOT)	true と false を逆転させる

論理型を正しく理解することは、複雑なシステムの判断ロジックを整理し、ユーザーの<ruby>入力<rt>にゅうりょく</rt></ruby>に対して「正確に<ruby>反応<rt>はんのう</rt></ruby>する」プログラムを構築するための土台となります。

5. 未定義型 (Undefined)：値が決まっていない状態

変数を作ったけれど、中身をまだ何も入れていないとき、JavaScriptはその状態を undefined と表現します。

「空の箱」と「存在しない箱」の違い

初心者の方が間違いやすいのが、以下の違いです。

* undefined：箱（変数）はあるけれど、中身がまだ入っていない状態。
* ReferenceError：そもそも箱（変数）自体が存在していない、または名前を間違えている状態。

💡 デバッグのヒント 実行結果に undefined と<ruby>表示<rt>ひょうじ</rt></ruby>されたら、「データの代入を忘れていないか？」「スペルミスをしていないか？」を疑ってみましょう。これはミスを特定するための重要な手がかりになります。

6. オブジェクト型 (Object)：関連する情報をセットにする

現実世界の情報を扱うとき、一つの変数だけでは足りないことがあります。例えばRPGの「キャラクター」なら、名前、レベル、HPなどの情報をセットで管理したいはずです。これを可能にするのが「オブジェクト型」です。

波括弧 { } で作る構造

オブジェクトは、プロパティ（名前と値のペア）をセットにして管理します。

const character = {
  name: "アレン",   // プロパティ（ステータス）
  level: 10,
  hp: 1450,
  attack: function() { // メソッド（行動）
    console.log("攻撃した！");
  }
};

// ドット記法でアクセス
console.log(character.name); // "アレン"


💡 オブジェクトと const の意外な関係

「 const は中身を変えられない箱」と説明しましたが、オブジェクトの場合は少し違います。

* 名札の固定（参照の不変性）：const で作ったオブジェクトそのものを別のオブジェクトに入れ替えることはできません（別の箱に名札を付け替えるのは禁止）。
* 中身の変更はOK：箱の中に入っている個別のデータ（プロパティ）を書き換えることは可能です。

例えるなら、「ファイルの保存場所（パス）」は固定されているけれど、「ファイルの中身」は自由に書き換えられるようなイメージです。

安全な数値<ruby>入力<rt>にゅうりょく</rt></ruby>の受け取りフロー

1. はじめに：変数（へんすう）とは何か？

プログラミングを始めるとき、一番(いちばん)大切(たいせつ)な言葉(ことば)があります。それが「変数（へんすう）」です。

変数は、データを入れるための「名前(なまえ)がついた箱(はこ)」だとイメージしてください。コンピュータはとても頭(あたま)がいいですが、名前をつけて保存(ほぞん)しないと、すぐにその情報を忘(わす)れてしまいます。

変数を使うメリット（いいところ）

1. 記憶(きおく)できる： ユーザーが<ruby>入力<rt>にゅうりょく</rt></ruby>した名前や計算(けいさん)の結果(けっか)を、後(あと)で使うために取っておくことができます。変数を使わないと、その行(ぎょう)の処理(しょり)が終わった瞬間にデータは消(き)えてしまいます。
2. 再利用(さいりよう)できる： 一度(いちど)箱に入れたデータは、プログラムの中で何度(なんど)でも呼び出(だ)して使うことができます。

変数のイメージがわきましたか？次は、実際にその「箱」を作るためのルールを学びましょう。

2. 変数の作り方：let と const の使い分け

JavaScriptで変数の箱を用意(ようい)することを「宣言（せんげん）」と言います。主に使うキーワードは let（レット）と const（コンスト）の2つです。

キーワード	役割(やくわり)	特徴(とくちょう)
let	変数	中身(なかみ)をあとで変えることができる箱です。
const	定数	一度(いちど)中身を入れたら、変えられない箱です。

「名札（なふだ）」と「箱」の例え

プログラムを正しく動かすためには、この2つの使い分けがとても重要(じゅうよう)です。

* let（マジックテープの名札）： 値(あたい)がどんどん変わる場合に使います。名札をペリッと剥(は)がして、別の箱に貼り替(か)えることができるイメージです。
* const（ボンドで貼った名札）： 一度名前をつけたら、その名札を別の箱に付け替える（再代入(さいだいにゅう)）ことができません。これにより、間違(まちが)えて大切なデータを書き換えてしまうミスを防(ふせ)ぐことができます。

【大事なポイント：オブジェクトの場合】 const で作った箱でも、中身が「オブジェクト型（あとで説明します）」のときは、箱の中にある小さなデータの値を変えることはできます。「名札を別の箱に付け替えること」はできませんが、「箱の中身を整理(せいり)すること」はできるのです。

現代(げんだい)のJavaScriptでは、**「まずは const を使い、どうしても値を変えたいときだけ let を使う」**のが一番(いちばん)安全(あんぜん)な方法です。

3. データの種類（型）：5つの重要なポイント

JavaScriptでは、箱に入れるデータの種類のことを「データ型（かた）」と呼びます。

① 文字列型 (String)

名前やメッセージなどの「文字」です。

* ルール： " "（ダブルクォーテーション）か ' '（シングルクォーテーション）で囲(かこ)みます。
* 便利(べんり)な機能： バッククォート（ ` ）で囲む「テンプレートリテラル」を使うと、${変数名} と書くだけで、文字の中に変数を入れられます。
  * 例： `こんにちは、${name}さん`

② 数値型 (Number)

数字(すうじ)です。整数(せいすう)も小数(しょうすう)も扱(あつか)えます。

* 特殊(とくしゅ)な値：
  * NaN (Not a Number)： 「数値ではない」という意味です。文字を無理(むり)やり計算しようとすると発生します。
  * Infinity： 無限(むげん)に大きい数字のことです。

③ 論理型 (Boolean)

「正しい」か「間違い」かの2つだけです。

* true（真）： 正しい。
* false（偽）： 間違い。 プログラムが「もし〜なら、これをする」と判断(はんだん)するときに使います。

④ オブジェクト型 (Object)

複数の情報をひとつにまとめる箱です。

* 例え： RPGのキャラクターをイメージしてください。「名前」「体力(HP)」「職業(Job)」をセットで保存できます。

const hero = {
  name: "アレン",
  hp: 100,
  job: "剣士"
};


⑤ 未定義型 (Undefined)

「箱はあるけれど、まだ何も中身を入れていない」という空(から)っぽの状態(じょうたい)です。

4. 型の変換：データをもっと自由に扱う

プログラムでは「文字」を「数字」に変えて計算したいことがよくあります。

特に prompt()（プロンプト）という関数でユーザーから数字を受け取るときは注意(ちゅうい)が必要です。

* 失敗の例： prompt() で受け取った値は、<ruby>見<rt>み</rt></ruby>た<ruby>目<rt>め</rt></ruby>が数字でも必ず「文字列」になります。そのため "10" + "20" を計算すると、数字の30ではなく、文字がつながって "1020" になってしまいます。

正しく計算するために、以下のステップで型を変換(へんかん)しましょう。

型を変換する関数

関数	使い方	例
Number()	文字を数値に変える	Number("10") → 10
parseInt()	文字から「整数」を取り出す	parseInt("55kg") → 55
parseFloat()	小数点(.)を含めて取り出す	parseFloat("55.5kg") → 55.5
String()	数値を文字に変える	String(100) → "100"

【注意！ isNaN() について】 parseInt("A123") のように、数字ではない文字から始めると結果は NaN になります。NaN は特殊で、NaN === NaN と書いても true になりません。そのため、値が NaN かどうか調べたいときは、必ず isNaN(値) という専用(せんよう)の命令を使ってください。

# JavaScriptの「演算子（えんざんし）」：プログラムに計算や判断をさせる道具

1. はじめに：演算子（えんざんし）とは何か

プログラミングを学ぶとき、一番大切な道具が「演算子（えんざんし）」です。これは、データを使って計算をしたり、正しいか間違いかを調べたりするための「記号」のことです。

演算子を「料理の道具」に例えてみましょう。材料（データ）を包丁で切ったり、鍋で煮たりするように、演算子を使ってデータを加工します。また、演算子は「計算機のボタン」にも似ています。ボタンを押すことで、計算機に「何をすべきか」を伝えます。

プロ講師として皆さんに伝えたいことがあります。演算子がないプログラムは、ただの「動かない文字の集まり」です。 演算子を使うことで初めて、プログラムに「知能（判断力）」や「<ruby>動<rt>うご</rt></ruby>き」という「心」が生まれます。

まずは、プログラムの<ruby>動<rt>うご</rt></ruby>きを作る基本中の基本、「計算の演算子」から学んでいきましょう。


--------------------------------------------------------------------------------


2. 計算の演算子（算術演算子：さんじゅつえんざんし）

数値を計算するときに使う記号です。算数のルールと似ていますが、掛け算や割り算の記号がプログラミング特有のものになっています。

基本的な計算の記号

プログラムでは、計算の結果を<ruby>画面<rt>がめん</rt></ruby>に出したり、変数（箱）に保存して次の処理に使ったりします。

演算子	意味	例	結果
+	足し算（加算）	5 + 3	8
-	引き算（減算）	10 - 4	6
*	掛け算（乗算）	6 * 2	12
/	割り算（除算）	10 / 2	5
%	余り（剰余）	10 % 3	1（10÷3の余り）

数を1つずつ増やす・減らす

「あと何回繰り返すか」を数えるときなど、ループ処理で非常によく使う特別な記号があります。

* インクリメント（++）: 値を「1」増やします。（例：count++）
* デクリメント（--）: 値を「1」減らします。（例：count--）

文字列の結合と「Number()」の魔法

+ 演算子は文字をつなげることもできますが、注意が必要です。

* "こんにちは" + "田中さん" → "こんにちは田中さん"
* "100" + 1 → "1001" （文字の100と数字の1がくっついてしまう）

このように、文字として数字を扱ってしまうと計算ミス（バグ）になります。そこで便利なのが Number() 関数 です。これは、**「文字の "100" を数値の 100 に変える魔法」**です。

* Number("100") + 1 → 101 （正しく計算できます！）

計算ができるようになったら、次はプログラムに「はい」か「いいえ」を判断させる方法を見てみましょう。


--------------------------------------------------------------------------------


3. 条件式で使う演算子（比較演算子：ひかくんざんし）

プログラムに「もし〜なら」という判断をさせるためには、2つの値を比べる必要があります。このときに使うのが比較演算子です。これはプログラムが自分で考えて動くための「心臓部」です。

値の大きさを比べる

比較した結果は、正しいなら true（真）、間違いなら false（偽） という「ブール値」で返されます。

* > ：左の方が大きい
* < ：右の方が大きい
* >= ：左の方が右と同じか、大きい（以上）
* <= ：左の方が右と同じか、小さい（以下）

「同じ」かどうかを調べる（ここは一番大切です！）

「同じ」を調べるとき、JavaScriptには2つの書き方がありますが、初心者は絶対に === を使ってください。

* ==（等しい）: 値が同じか「大まかに」調べます。
* ===（厳密に等しい）: 値だけでなく「データの種類（数字か文字か）」まで正確に調べます。

なぜ === がいいのか？ == を使うと、JavaScriptが勝手に「お節介（おせっかい）」を焼いて、データの種類を変えて比較してしまいます。例えば、5 == "5" は true になってしまいます。このようにJavaScriptが勝手に型を変えてしまうことが、予想外のバグの原因になります。正確なプログラムを作るために、型までチェックする === を使いましょう。

次は、複数の条件を組み合わせる「論理演算子」について説明します。


--------------------------------------------------------------------------------


4. 論理演算子（ろんりえんざんし）：複数の条件を組み合わせる

「18歳以上、かつ、会員である」のように、複雑な判断を行いたいときに使うのが論理演算子です。

3つの基本ルール

1. 論理積（&&）: 「かつ（AND）」。すべての条件が true のときだけ全体が true になります。
2. 論理和（||）: 「または（OR）」。どれか1つでも true なら全体が true になります。
3. 論理否定（!）: 「ではない（NOT）」。結果を反対にします（true を false に変える）。

真偽値の結果（真理値表）

条件A	条件B	A && B (かつ)	A || B (または)	! A (ではない)
true	true	true	true	false
true	false	false	true	false
false	true	false	true	true
false	false	false	false	true

複雑な条件をこれらの記号でシンプルに整理することが、ミスのない綺麗なコードを書くコツです。


--------------------------------------------------------------------------------


5. 演算の優先度（えんざんのゆうせんど）：計算の正しい順番

1つの行にたくさんの演算子があるとき、どの順番で処理されるかが重要です。順番を間違えると、計算結果がめちゃくちゃになってしまいます。

基本のルール

算数と同じで、**「掛け算・割り算（*, /）は、足し算・引き算（+, -）よりも先」**に計算されます。

括弧 () でコントロールする

「足し算を先にしたい」というときは 括弧 () を使います。

* 10 + 2 * 5 → 20
* (10 + 2) * 5 → 60

プロとしてのコツ

1行で長く書くのではなく、括弧を使って順番をはっきりさせたり、計算をいくつかの行に分けたりしましょう。そうすることで、自分だけでなく、チームの仲間があなたのコードを読んだときに迷わなくて済むようになります。


--------------------------------------------------------------------------------

演算子はJavaScriptで「<ruby>動<rt>うご</rt></ruby>き」を作るための大切な道具です。これらを使いこなせば、あなたのアイデアを自由にプログラムにすることができます。

* = と === の混同: = は「代入（右の値を左に入れる）」、=== は「比較（同じか調べる）」です。
