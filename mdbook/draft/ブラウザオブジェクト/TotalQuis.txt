JavaScript ブラウザオブジェクト クイズ：基礎《きそ》マスター編《へん》

1. はじめに：学習《がくしゅう》の目的《もくてき》と構成《こうせい》

JavaScript（ジャバスクリプト）を学《まな》ぶ上《うえ》で、ブラウザがどのようにお互《たが》いに関係《かんけい》し合《あ》って動《うご》いているかを知《し》ることは非常《ひじょう》に重要《じゅうよう》です。このクイズは、JavaScriptがブラウザを操作《そうさ》するための仕組《しく》みである「BOM（Browser Object Model）」と「DOM（Document Object Model）」の基礎《きそ》を確実《かくじつ》に理解《りかい》するために作《つく》られました。

私《わたし》たちのプログラムは、ブラウザという「家《いえ》」の中《なか》にある「道具《どうぐ》」を動《うご》かすためのマニュアルです。特《とく》に window（ウィンドウ）、document（ドキュメント）、location（ロケーション）といったオブジェクトの役割《やくわり》を知《し》ることは、プロの現場《げんば》で役立《やくだ》つ動《うご》きのあるウェブサイトを作《つく》るための戦略的《せんりゃくてき》な第一歩《だいいっぽ》となります。

それでは、最初《さいしょ》にブラウザオブジェクトの「頂点《ちょうてん》」に立《た》つ存在《そんざい》についての問題《もんだい》を解《と》いてみましょう。

2. 

問題《もんだい》1：Window（ウィンドウ）オブジェクトの基本《きほん》

window オブジェクトは、ブラウザの画面全体《がめんぜんたい》を管理《かんり》する「社長《しゃちょう》さん」のような存在《そんざい》です。すべてのオブジェクトの階層《かいそう》の頂点《ちょうてん》にあり、ユーザーに直接《ちょくせつ》メッセージを届《とど》ける仕事《しごと》も持《も》っています。

【問題《もんだい》】 ユーザーの画面《がめん》に、下《した》のような「OK」ボタンが付《つ》いた警告《けいこく》ボックスを表示《ひょうじ》させるための正《ただ》しいコードは、A,Bのどちらですか？


A.


// Aのコード：関数を使ってメッセージを出します

function showHello() {

  const message = "こんにちは！";

  window.alert(message);

  console.log("警告《けいこく》ボックスを表示《ひょうじ》しました");

}





B.



// Bのコード：関数を使ってメッセージを出します

function showHello() {

  const message = "こんにちは！";

  window.messageBox(message);

  console.log("警告《けいこく》ボックスを表示《ひょうじ》しました");

}


問題《もんだい》2：Document（ドキュメント）オブジェクトと要素《ようそ》の取得《しゅとく》


document オブジェクトは、社長《しゃちょう》である window を支《ささ》える「秘書《ひしょ》」のような役割《やくわり》です。DOMツリーの中《なか》から部品《ぶひん》を見《み》つけることは、街《まち》の中《なか》から特定《とくてい》の家《いえ》を住所《じゅうしょ》で探《さが》し出《だ》すことに似《に》ています。


【問題《もんだい》】 HTMLの中《なか》にある、世界《せかい》に一《ひと》つしかない id="main-title" というID（住所《じゅうしょ》）を見《み》つけて、文字《もじ》の色《いろ》を赤《あか》に変《か》える正《ただ》しいコードはどちらですか？

------

A.



// Aのコード：IDを使って要素を取得《しゅとく》します

const title = document.getElementById("main-title");

if (title) {

  title.style.color = "red";

  console.log("タイトルを赤色《あかいろ》に変《か》えました");

}

------


------


B.



// Bのコード：クラスを使って要素を取得《しゅとく》します

const title = document.getElementsByClassName("main-title");

if (title) {

  title.style.color = "red";

  console.log("タイトルを赤色《あかいろ》に変《か》えました");

}

問題《もんだい》3：Location（ロケーション）オブジェクトと移動《いどう》

location オブジェクトは、今《いま》見《み》ているページのURL（ウェブ上の住所《じゅうしょ》）を管理《かんり》しています。ブラウザにおける「カーナビ」のような役割《やくわり》を持《も》っており、プログラムで新《あたら》しい場所《ばしょ》へ移動《いどう》することができます。

【問題《もんだい》】 今《いま》見《み》ているページから、Google（https://google.com）へ自動《じどう》で移動《いどう》させたい時《とき》、プロの現場《げんば》で最も一般的《いっぱんてき》に使《つか》われるプロパティはどちらですか？

------
A.

// Aのコード：URLを代入《だいにゅう》して移動します

function jumpToGoogle() {

  const url = "https://google.com";

  location.href = url;

  console.log("Googleへ移動《いどう》を開始《かいし》します");

}
------





------
B.

// Bのコード：URLを代入《だいにゅう》して移動します

function jumpToGoogle() {

  const url = "https://google.com";

  location.url = url;

  console.log("Googleへ移動《いどう》を開始《かいし》します");

}

5. 
問題《もんだい》4：タイマー機能《きのう》：setInterval（セットインターバル）


JavaScriptには、時間《じかん》をコントロールする「タイマー」の機能《きのう》があります。これはウェブサイトのアニメーションや、決《き》まった時間《じかん》ごとにデータを確認《かくにん》する処理《しょり》などで非常《ひじょう》に役立《やくだ》ちます。


【問題《もんだい》】 「3秒《びょう》ごと（3000ミリ秒《びょう》ごと）」に、特定《とくてい》のメッセージをずっと繰《く》り返《かえ》して表示《ひょうじ》させたい場合《ばあい》、どちらの命令《めいれい》を使《つか》いますか？

------

A.

// Aのコード：繰り返し処理を実行《じっこう》します

const timerId = setInterval(function() {

  console.log("3秒《びょう》が経過《けいか》しました");

  console.log("現在《げんざい》も繰り返し実行中《じっこうちゅう》です");

}, 3000);

------


------

B.


// Bのコード：一度だけの処理を実行《じっこう》します

const timerId = setTimeout(function() {

  console.log("3秒《びょう》が経過《けいか》しました");

  console.log("一度《いちど》だけ実行《じっこう》して終《お》わります");

問題《もんだい》5：画面《がめん》のサイズ（innerWidth）


ウェブサイトをスマートフォンやパソコンに合《あ》わせる「レスポンシブデザイン」を考《かんが》える際《さい》、今《いま》の画面《がめん》の幅《はば》を調《しら》べることは欠《か》かせません。


【問題《もんだい》】 ブラウザの「実際《じっさい》にページが見《み》えている内側《うちがわ》の白《しろ》い部分《ぶぶん》の幅《はば》」を正《ただ》しく取得《しゅとく》できるプロパティはどちらですか？

// Aのコード：画面の幅を調べて表示します

  console.log("※スクロールバーは含《ふく》みません");

7. 正解《せいかい》と解説《かいせつ》

全《ぜん》5問《もん》、お疲《つか》れさまでした！それでは、正解《せいかい》を確認《かくにん》して、学《まな》びを深《ふか》めましょう。

問題《もんだい》	正解《せいかい》	重要《じゅうよう》なポイント
問題《もんだい》1	A	alert() メソッド（警告《けいこく》）
問題《もんだい》2	A	getElementById（IDで正確《せいかく》に取得）
問題《もんだい》3	A	href プロパティ（プロの現場《げんば》で主流）
問題《もんだい》4	A	setInterval（ずっと繰り返《くりかえ》す）
問題《もんだい》5	A	innerWidth（Wは大文字《おおもじ》）

【詳細解説《しょうさいかいせつ》】

* 問題《もんだい》1の解説《かいせつ》： 正解《せいかい》は A です。alert() は画面《がめん》にメッセージを表示《ひょうじ》する「拡声器《かくせいき》」のようなメソッドです。社長《しゃちょう》である window の命令《めいれい》の中《なか》でも特《とく》に有名《ゆうめい》なため、本来《ほんらい》は window.alert() と書《か》きますが、window. を省略《しょうりゃく》することもできます。messageBox という命令《めいれい》はJavaScriptには存在《そんざい》しません。
* 問題《もんだい》2の解説《かいせつ》： 正解《せいかい》は A です。getElementById は「世界《せかい》に一《ひと》つしかない絶対的《ぜったいてき》な住所《じゅうしょ》」で要素《ようそ》を探《さが》すため、最《もっと》も確実《かくじつ》な方法《ほうほう》です。一方《いっぽう》、Bの getElementsByClassName は同《おな》じクラス名《めい》を持《も》つ人《ひと》をまとめて「グループ（リスト）」として取得《しゅとく》します。そのため、Aのように書《か》いてしまうと、特定《とくてい》の一人《ひとり》に命令《めいれい》が届《とど》かない（エラーになる）ので注意《ちゅうい》が必要《ひつよう》です。
* 問題《もんだい》3の解説《かいせつ》： 正解《せいかい》は A です。location.href プロパティに新《あたら》しいURLを代入《だいにゅう》するのは、プロの現場《げんば》で最もよく使《つか》われる「人気《にんき》の移動方法《いどうほうほう》」です。カーナビの目的地《もくてきち》をセットするようなイメージですね。location.url というプロパティは存在《そんざい》しませんので、間違《まちが》えないように覚《おぼ》えましょう。
* 問題《もんだい》4の解説《かいせつ》： 正解《せいかい》は A です。setInterval は「指定《してい》した秒数《びょうすう》ごとに、止《と》めるまで何回《なんかい》も繰り返《くりかえ》す」タイマーです。Bの setTimeout は「指定《してい》した時間《じかん》が過《す》ぎた後《あと》に、一度《いちど》だけ実行《じっこう》して終《お》わる」命令《めいれい》です。時計《とけい》やループするアニメーションを作《つく》りたいときは setInterval を選《えら》びましょう。
* 問題《もんだい》5の解説《かいせつ》： 正解《せいかい》は A です。JavaScriptは「大文字《おおもじ》」と「小文字《こもじ》」を厳《きび》しく区別《くべつ》します。innerWidth のように、途中《とちゅう》の W を必《かなら》ず大文字《おおもじ》で書《か》くのが正《ただ》しいルールです。また、このプロパティは「スクロールバーを含《ふく》まない内側《うちがわ》の幅《はば》」を教《おし》えてくれるため、正確《せいかく》なレイアウト調整《ちょうせい》に向《む》いています。

【まとめ：大切《たいせつ》な定義《ていぎ》】

* BOM（ブラウザオブジェクトモデル）：window（社長）や location（ナビ）など、ブラウザ全体《ぜんたい》を操作《そうさ》する仕組《しく》み。
* DOM（ドキュメントオブジェクトモデル）：document（秘書）を通《とお》して、ページの中身《なかみ》や文字《もじ》を操作《そうさ》する仕組《しく》み。
* メソッド：alert() のように、何《なに》かのアクションを行《おこな》う「命令《めいれい》」。
* プロパティ：innerWidth や href のように、今《いま》の状態《じょうたい》を教《おし》えてくれる「情報《じょうほう》」。

これらの基礎《きそ》をマスターすれば、ウェブサイトに自由《じゆう》な動《うご》きをつける準備《じゅんび》はバッチリです！
