---

### 解答と解説

1.  **解答：C
    *   **解説：** window社長の下で、ウェブページという建物を管理し、中身を書き換えたりパーツを作ったりする責任者なので「現場監督」です。
2.  **解答：B
    *   **解説：** documentオブジェクトは、ブラウザに表示されているHTML（中身）そのものを指します。
3.  **解答：B
    *   **解説：** Document Object Modelの略でDOM（ドム）と呼びます。HTMLを「木の枝」のように管理するのが特徴です。
4.  **解答：C
    *   **解説：** document.title を使うと、JavaScriptでタブのタイトルを変えることもできます。
5.  **解答：B
    *   **解説：** document.URL プロパティを使うと、現在のページのURLがわかります。
6.  **解答：A
    *   **解説：** document.body は <body> タグ全体を指し、背景色を変えるときなどに使われます。
7.  **解答：B
    *   **解説：** getElementById("ID名") は特定のIDを指名して探すため、一番速くて正確です。
8.  **解答：D
    *   **解説：** querySelector("セレクタ") はCSSと同じ書き方でパーツを探せる非常に便利な命令です。
9.  **解答：B
    *   **解説：** 特定のIDで指名するのは、学校で出席番号を呼ぶのに似ています。
10. **解答：C
    *   **解説：** createElement("タグ名") は、新しい要素をメモリの中に作ります。資料では「新しいレンガを用意する」と例えられています。
11. **解答：A
    *   **解説：** textContent を使うと、看板の文字を書き直すようにパーツ内の文字を変えられます。
12. **解答：A
    *   **解説：** const はラベル（名札）を固定しますが、箱の中身（プロパティ）を書き換えることは許可されています。
13. **解答：C
    *   **解説：** const はラベルと箱の関係を固定するため、ラベルを別の箱に貼り直す（変数を別のオブジェクトに入れ替える）ことはできません。
14. **解答：B
    *   **解説：** ページの中身（文字やボタンなど）をいじる担当は document です。
15. **解答：A
    *   **解説：** ブラウザ全体の機能（タイマーやアラートなど）を使う担当は window です。
