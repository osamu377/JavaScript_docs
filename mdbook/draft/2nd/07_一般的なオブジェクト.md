## 1. オブジェクトとは（復習）

「オブジェクト」という言葉を覚えていますか？ 一言でいうと、オブジェクトは **「関係（かんけい）がある 情報を まとめたもの」** でしたね。

そして、オブジェクトのすごいところは、**データ（特徴）** だけでなく、**<ruby>関数<rt>かんすう</rt></ruby>（<ruby>動<rt>うご</rt></ruby>き）** も一緒にまとめられることでした。

* **プロパティ（特徴）：** 名前、身長、色、値段など
* **メソッド（<ruby>動<rt>うご</rt></ruby>き）：** 走る、話す、計算するなど

では、最初の<ruby>組<rt>く</rt></ruby>み<ruby>込<rt>こ</rt></ruby>みオブジェクトとして、「<ruby>配列<rt>はいれつ</rt></ruby>（はいれつ）」について、みてみましょう。

## 2. <ruby>配列<rt>はいれつ</rt></ruby>（Array）の基本

たくさんのデータをバラバラに管理するのは大変です。そこで使うのが「<ruby>配列<rt>はいれつ</rt></ruby>（はいれつ）」という、複数のデータを一つにまとめて管理できるリストのような道具です。

### <ruby>配列<rt>はいれつ</rt></ruby>（はいれつ）は「ならんだ箱」

たくさんのデータを、ひとつのグループとしてまとめたいときに、「<ruby>配列<rt>はいれつ</rt></ruby>」を使います。留学生のみなさんには、**「番号がついたロッカー」** をイメージすると分かりやすくなります！

> [!TIP]
> **漢字のヒント**
> **「配」** は「くばる」、**「列」** は「ならぶ」という意味です。
> みんなが並んでいる様子をイメージすると、覚えやすいですよ！

JavaScriptで<ruby>配列<rt>はいれつ</rt></ruby>（はいれつ）を使うとき、必ず出てくるのが **`[ ]`（角（かど）かっこ）** です。

大きく分けて、**2つの使い方**があります。

#### <ruby>配列<rt>はいれつ</rt></ruby>を「作る」ときの `[ ]`

**→「新しいマンションを建てる」イメージ**

一番はじめに、中身（なかみ）をまとめて入れるときに使います。

```javascript
const colors = ["赤", "青", "黄"];

```

* **`[`** ：ここからマンションが始まります。
* **`,`** ：部屋（へや）と部屋の間の「かべ」です。
* **`]`** ：ここでマンションが終わります。


#### 中身を「指定する」ときの `[ ]`

**→「部屋番号（へやばんごう）で 呼ぶ」イメージ**

作ったあとで、「○番目のデータがほしい！」というときに使います。

```javascript
console.log(colors[0]); // 「赤」が出てくる

```

**ここが大事！「0番」から始まるルール**

マンションの「1階（いっかい）」は、プログラミングでは **`[0]`** と書きます。

* **1つめ：** `colors[0]`
* **2つめ：** `colors[1]`
* **3つめ：** `colors[2]`

> [!TIP]
> **覚え方：**
> プログラミングの世界では、**「まだ一歩（いっぽ）も動いていない状態」を 0** と考えます。だから最初が 0 なんです。

> [!TIP]
> **留学生へのアドバイス：**
> 「1つめは 0（ゼロ）！」と心の中で3回唱（とな）えてください。これだけで、バグが半分に減りますよ！

#### 中身を「書きかえる」ときの `[ ]`

**→「住んでいる人を 入れかえる」イメージ**

特定の部屋番号を指定して、中身を新しくすることもできます。

```javascript
let snacks = ["チョコ", "グミ"];

snacks[1] = "アイス"; // 1番（2つめ）のグミを、アイスに変える

console.log(snacks); // ["チョコ", "アイス"]

```

---

#### まとめ：`[ ]` の役割（やくわり）

| 使い方 | やっていること | <ruby>例<rt>たと</rt></ruby>え話 |
| --- | --- | --- |
| **`[a, b, c]`** | <ruby>配列<rt>はいれつ</rt></ruby>を作る | マンションを建てる |
| **`[0]`** | データを取り出す | 部屋をノックする |
| **`[0] = "x"`** | データを入れかえる | 住人を入れかえる |

> [!NOTE]
> **よくあるミス：**
> <ruby>全角<rt>ぜんかく</rt></ruby>の **`［ ］`** を使ってしまうとエラーになります。必ず<ruby>半角<rt>はんかく</rt></ruby>の **`[ ]`** を使いましょう！

**<ruby>配列<rt>はいれつ</rt></ruby>の要素**

<ruby>配列<rt>はいれつ</rt></ruby>の一つひとつの箱の中に入っているデータを<ruby>配列<rt>はいれつ</rt></ruby>の「要素（ようそ）」と言います。

<ruby>配列<rt>はいれつ</rt></ruby>の要素の数は`length`プロパティで、知ることができます。オブジェクトのプロパティを取り出すときは、**「.（ドット）」** を使います。

* `fruits.length` → 今、箱がいくつあるか（3つ）教えてくれます。

```
console.log(fruits.length); // 3 と<ruby>表示<rt>ひょうじ</rt></ruby>されます。
```



**よく使う便利なメソッド**

**<ruby>配列<rt>はいれつ</rt></ruby>操作のメソッド**

<ruby>配列<rt>はいれつ</rt></ruby>には、中身を操作（そうさ）するための便利なメソッドがたくさんあります。

4つの代表的（だいひょうてき）なメソッドを、**「元の<ruby>配列<rt>はいれつ</rt></ruby>が変わるかどうか」**と **「どこを操作するか」** に注目して、まとめて解説します。

留学生の方には、<ruby>配列<rt>はいれつ</rt></ruby>を **「電車（でんしゃ）の車両（しゃりょう）」** や **「人の列（れつ）」** に<ruby>例<rt>たと</rt></ruby>えて説明するのが一番わかりやすいです。

### <ruby>配列<rt>はいれつ</rt></ruby>操作の「4つの<ruby>魔法<rt>まほう</rt></ruby>」まとめ

まずは、この図でイメージをつかみましょう。

#### 1. push（プッシュ）：おしりに追加する

一番最後（右側）に、新しいデータを追加します。

* **イメージ：** 電車の最後に、新しい車両を連結（れんけつ）する。
* **元の<ruby>配列<rt>はいれつ</rt></ruby>：** **変わります。**

```javascript
const train = ["車両A", "車両B"];
train.push("車両C"); 
console.log(train); // ["車両A", "車両B", "車両C"]

```

#### 2. pop（ポップ）：おしりを1つ消す

一番最後（右側）のデータを1つ取り除きます。

* **イメージ：** 電車の最後の車両を切り離（はな）す。
* **元の<ruby>配列<rt>はいれつ</rt></ruby>：** **変わります。**

```javascript
const train = ["車両A", "車両B", "車両C"];
const last = train.pop(); 
console.log(last);  // "車両C" （消えたもの）
console.log(train); // ["車両A", "車両B"]

```

#### 3. shift（シフト）：先頭を1つ消す

一番最初（左側・0番目）のデータを消して、残りのデータを前にずらします。

* **イメージ：** お店の行列で、先頭の人が店に入り、後ろの人が全員前にずれる。
* **元の<ruby>配列<rt>はいれつ</rt></ruby>：** **変わります。**

```javascript
const queue = ["1番の人", "2番の人", "3番の人"];
queue.shift();
console.log(queue); // ["2番の人", "3番の人"] （みんな前にずれた！）

```

#### 4. slice（スライス）：一部をコピーする

指定（してい）した場所だけを、別の新しい<ruby>配列<rt>はいれつ</rt></ruby>として取り出します。

* **イメージ：** 写真を撮（と）るようなものです。景色（元の<ruby>配列<rt>はいれつ</rt></ruby>）はそのままで、必要な部分だけを切り取ります。
* **元の<ruby>配列<rt>はいれつ</rt></ruby>：** **変わりません（ここが重要！）。**

```javascript
const members = ["A", "B", "C", "D"];
// 1番目から3番目の「手前」までコピー
const sub = members.slice(1, 3); 
console.log(sub);     // ["B", "C"]
console.log(members); // ["A", "B", "C", "D"] （元の<ruby>配列<rt>はいれつ</rt></ruby>はそのまま！）

```


### 比較（ひかく）テーブル

留学生の方に、この表をメモしてもらうと便利です。

| メソッド | 場所 | <ruby>動<rt>うご</rt></ruby>き | 元の<ruby>配列<rt>はいれつ</rt></ruby>は？ |
| --- | --- | --- | --- |
| **push** | 最後 | 追加する | **変わる** |
| **pop** | 最後 | 消す | **変わる** |
| **shift** | 最初 | 消す（ずれる） | **変わる** |
| **slice** | どこでも | コピーする | **変わらない** |



### 留学生へのアドバイス

「元の<ruby>配列<rt>はいれつ</rt></ruby>が変わってしまうメソッド（push, pop, shift）」を使うときは注意が必要です。もし、元のデータを壊（こわ）したくないときは、**`slice` を使ってコピーを作ってから作業する** のがプロのコツですよ！

> [!TIP]
> **「slice（スライス）」** は、料理（りょうり）でハムやチーズを薄（うす）く切るのと同じ言葉です。「元の塊（かたまり）から、一切れ分をもらう」と覚えると忘れません。

いかがでしょうか？「0から始まるリスト」のイメージはつかめましたか？

**So What?（なぜ大切なの？）**

 <ruby>配列<rt>はいれつ</rt></ruby>の .length プロパティを使うことで、「データが今いくつあるか」を常に知ることができます。これにより、データの数が増えたり減ったりしても、プログラムを書き直さずに柔軟に対応できるようになります。

## 3. <ruby>配列<rt>はいれつ</rt></ruby>の応用とforEach

大量のデータを<ruby>効率<rt>こうりつ</rt></ruby>よく処理するために、JavaScriptには forEach（フォーイーチ）という便利な道具があります。

**forEachとコールバック<ruby>関数<rt>かんすう</rt></ruby>**

以前、<ruby>関数<rt>かんすう</rt></ruby>は「自動販売機（じどうはんばいき）」のようなものだと学びましたね。ボタン（呼び出し）を押すと、中に入れた処理が実行されて結果が出てきます。

forEach を使うときは、この<ruby>関数<rt>かんすう</rt></ruby>をさらに便利に使います。

* <ruby>例<rt>たと</rt></ruby>え話: forEach は「店員さん」、渡す<ruby>関数<rt>かんすう</rt></ruby>は「店員さんに渡すチェックメモ（コールバック<ruby>関数<rt>かんすう</rt></ruby>）」です。 店員さんは、<ruby>配列<rt>はいれつ</rt></ruby>の中身（リンゴなど）を一つ取るたびに、あなたが渡したメモを読んで「傷がないか確認する」などの作業を行ってくれます。

**サンプルプログラム: 合計（ごうけい）を計算する**

このプログラムは、リストの中にある数字を全部（ぜんぶ）足（た）して、最後（さいご）に答えを出します。

```javascript
// 1. 数字の「<ruby>配列<rt>はいれつ</rt></ruby>」を作ります。
const numbers = [10, 20, 30, 40];

// 2. 合計を入れる「空（から）の箱」を作ります。最初は 0 です。
let total = 0;

// 3. forEach （上の<ruby>例<rt>たと</rt></ruby>えでは「店員さん」）は、<ruby>配列<rt>はいれつ</rt></ruby>の中身を一つずつ取って、メモ通りに処理します。
numbers.forEach((num) => {
  // ここがコールバック<ruby>関数<rt>かんすう</rt></ruby>です！ 店員さんに「この仕事をしてください」と渡すメモです！
  total = total + num; 
  console.log(num + " を足しました。今は " + total + " です。");
});

// 4. 最後に答えを<ruby>表示<rt>ひょうじ</rt></ruby>します
console.log("ぜんぶの合計は " + total + " です！");

```

*プログラムの動（うご）きを解説（かいせつ）*

① `let total = 0;`

これは、計算（けいさん）の結果（けっか）を入れておくための**「貯金箱（ちょきんばこ）」**のようなものです。最初は何も入っていないので `0` にしておきます。

② コールバック<ruby>関数<rt>かんすう</rt></ruby>の仕事（しごと）

`numbers.forEach((num) => { ... });` の中（なか）が、お願（ねが）いしたメモ（コールバック<ruby>関数<rt>かんすう</rt></ruby>）です。

* `forEach` がリストから `10` を見つける。
* コールバック<ruby>関数<rt>かんすう</rt></ruby>に `10` を渡（わた）す。
* <ruby>関数<rt>かんすう</rt></ruby>が **「今の合計（0）に 10 を足してね！」** と実行（じっこう）する。
* 次の `20` でも同じことをする。

これを繰り返（くりかえ）すことで、貯金箱の中身がどんどん増（ふ）えていきます。

## 5. 文字列（String）の応用

Webサイトで扱う情報の多くは「テキスト（文字列）」です。これをどう操作するかが、プログラミングの腕の見せ所です。

**文字列の作成と<ruby>結合<rt>けつごう</rt></ruby>**

<ruby>最新<rt>さいしん</rt></ruby>のJavaScriptでは、テンプレートリテラル（  バッククォート）を使うのがとても便利です。

* <ruby>変数<rt>へんすう</rt></ruby>の<ruby>埋<rt>う</rt></ruby>め<ruby>込<rt>こ</rt></ruby>み: `こんにちは、${name}さん！` のように、${} で<ruby>変数<rt>へんすう</rt></ruby>を入れられます。
* <ruby>改行<rt>かいぎょう</rt></ruby>（かいぎょう）: テンプレートリテラルは、コードの中で<ruby>改行<rt>かいぎょう</rt></ruby>した場所をそのまま文字として扱ってくれます。HTMLのコードを文字として作りたいときに非常に役立ちます。

**<ruby>数値<rt>すうち</rt></ruby>への<ruby>変換<rt>へんかん</rt></ruby>**

prompt()（プロンプト：<ruby>入力<rt>にゅうりょく</rt></ruby><ruby>画面<rt>がめん</rt></ruby>）でユーザーが<ruby>入力<rt>にゅうりょく</rt></ruby>した数字は、<ruby>見<rt>み</rt></ruby>た<ruby>目<rt>め</rt></ruby>が数字でも、プログラム上は「文字列」です。計算するには<ruby>変換<rt>へんかん</rt></ruby>が必要です。

* parseInt(): 整数（1, 2, 3...）に<ruby>変換<rt>へんかん</rt></ruby>します。
* parseFloat(): 小数点を含む<ruby>数値<rt>すうち</rt></ruby>に<ruby>変換<rt>へんかん</rt></ruby>します。

So What?（なぜ大切なの？） 数字ではない文字を無理に<ruby>数値<rt>すうち</rt></ruby>に変えようとすると NaN（Not a Number：<ruby>数値<rt>すうち</rt></ruby>ではないというエラー値）になります。Web<ruby>開発<rt>かいはつ</rt></ruby>ではユーザーが何を打つか分かりません。isNaN() <ruby>関数<rt>かんすう</rt></ruby>を使って「これは<ruby>本当<rt>ほんとう</rt></ruby>に数字かな？」とチェックすることは、プログラムが止まってしまう「クラッシュ」を防ぐためのプログラマーの責任です。

## 6. 数学（Math）と日付（Date）

正確な計算や日時の管理ができるようになると、ランキング機能や時計<ruby>表示<rt>ひょうじ</rt></ruby>など、サイトの価値がぐっと上がります。

**Mathオブジェクト（数学の道具）**

* Math.random(): 0から1未満のランダムな数字を作ります。
* Math.floor(): 小数点を切り捨てます。ランダムな数字を整数にしたいときにセットで使います。

**Dateオブジェクト（日付の道具）**

日付を扱うときは new Date() と書きます。ここで「プリミティブ型」と「オブジェクト型」の違いを理解しましょう。

* プリミティブ型（<ruby>数値<rt>すうち</rt></ruby>や文字列）: データそのものが<ruby>変数<rt>へんすう</rt></ruby>に入っています。
* オブジェクト型（Dateなど）: データそのものではなく、データが保存されているメモリ上の「場所（参照：さんしょう）」が<ruby>変数<rt>へんすう</rt></ruby>に入っています。

new を使うことで、メモリの中に新しい「日付というデータの箱（実体）」を作り、その場所を指し示すようになります。

So What?（なぜ大切なの？） これらの<ruby>組<rt>く</rt></ruby>み<ruby>込<rt>こ</rt></ruby>みオブジェクトを使いこなすことは、プログラミングの世界で「車輪の再発明（しゃりんのさいはつめい：すでにあるものを一から作る無駄なこと）」を防ぐことになります。用意された道具を使うことで、<ruby>開発<rt>かいはつ</rt></ruby>スピードを劇的に速めることができます。

## 8. <ruby>繰<rt>く</rt></ruby>り<ruby>返<rt>かえ</rt></ruby>し処理の応用：for-in文

※オブジェクトの性質を利用した応用的な<ruby>繰<rt>く</rt></ruby>り<ruby>返<rt>かえ</rt></ruby>し処理です。

<ruby>配列<rt>はいれつ</rt></ruby>ではなく「オブジェクト」の中身（プロパティ）をすべて確認したいときは、for-in 文を使います。

|ループの種類|対象|使いどころ|
|---|---|---|
|for文|<ruby>数値<rt>すうち</rt></ruby>の回数、<ruby>配列<rt>はいれつ</rt></ruby>|決まった回数<ruby>繰<rt>く</rt></ruby>り<ruby>返<rt>かえ</rt></ruby>したいとき|
|while文|条件|条件が満たされるまで続けたいとき|
|for-in文|オブジェクトのプロパティ|オブジェクトの「キー」を全部調べたいとき|

So What?（なぜ大切なの？） オブジェクトの中にどんなデータがいくつ入っているか、事前にはわからない場合があります。for-in を使えば、どんなに項目が多くても漏れなくすべて処理できるため、柔軟なプログラムが作れます。

## 9. <ruby>変数<rt>へんすう</rt></ruby>のスコープとまとめ

最後に、<ruby>変数<rt>へんすう</rt></ruby>が「どこから見えるか」というスコープ（守備範囲）について学びましょう。

**スコープの種類**

* グローバルスコープ: プログラムのどこからでも見えますが、使いすぎるとデータの混乱を招きます。
* ブロックスコープ（let/const）: {}（波括弧）の中でしか使えません。今のJavaScriptではこちらが基本です。

**<ruby>初心者<rt>しょしんしゃ</rt></ruby>が最も混乱する「const」の不変性**

const で<ruby>宣言<rt>せんげん</rt></ruby>したオブジェクトには、大切なルールがあります。

* 名札（<ruby>変数<rt>へんすう</rt></ruby>名）の付け替え（再<ruby>代入<rt>だいにゅう</rt></ruby>：さいだいにゅう）はできません。
* しかし、中身（プロパティ）の変更はできます。

「ガムテープで名札が貼られた箱」をイメージしてください。ガムテープで固定されているので、名札を別の新しい箱に貼り直すことはできません。でも、箱の蓋（ふた）を開けて、中に入っているおもちゃを<ruby>入<rt>い</rt></ruby>れ<ruby>替<rt>かえ</rt></ruby>たり、色を塗ったりすることは自由なのです。

**全体まとめ**

JavaScriptの<ruby>組<rt>く</rt></ruby>み<ruby>込<rt>こ</rt></ruby>みオブジェクトを学ぶことは、留学生のみなさんがプログラミングの「<ruby>初心者<rt>しょしんしゃ</rt></ruby>」から「中級者」へステップアップするための大きな一歩です。

1. <ruby>配列<rt>はいれつ</rt></ruby>やオブジェクトでデータをきれいに並べ、
2. forEachやfor-inで<ruby>効率<rt>こうりつ</rt></ruby>よく処理し、
3. StringやMath、Dateで情報を<ruby><rt>賢</rt>かしこ</ruby>く<ruby>加工<rt>かこう</rt></ruby>する。

**最終メッセージ**

プログラミングの学習は、一歩ずつ進めば大丈夫です。一度に全部覚えようとしなくていいですよ。「あ、あんな便利な道具があったな」と思い出せれば合格です。
