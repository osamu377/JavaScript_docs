# 高度なループ処理

JavaScriptでデータを順番に処理する「ループ（繰り返し）」にはいくつか種類があります。

留学生の方には、これらを **「名簿（めいぼ）を確認する方法の違い」* *として説明してあげると、シチュエーションに合わせて使い分けができるようになります。

---

## I. 3つの`for`

### 1. 古典的な `for` 文（自由度No.1）

「何番目から、何番目まで」を細かく指定できる、一番基本の形です。

* **イメージ：** 「出席番号 **1番から10番まで**、**1つ飛ばしで** 名前を呼んで！」
* **特徴：** 途中で止める、逆から数える、2つ飛ばしにするなど、自由にカスタマイズできます。

```javascript
const colors = ["赤", "青", "緑"];

for (let i = 0; i < colors.length; i++) {
  console.log(i + "番目は" + colors[i]);
}

```

---

### 2. `for ... in` 文（オブジェクトの「中身」用）

配列（Array）ではなく、主に**オブジェクト（連想配列）**のプロパティを調べるときに使います。

* **イメージ：** 「このカバンの中に、**どんな種類の持ち物**が入っているか全部教えて！」
* **特徴：** 「名前（キー）」を一つずつ取り出します。※配列に使うとバグの原因になりやすいので注意。

```javascript
const user = { name: "アリ", age: 20, country: "エジプト" };

for (let key in user) {
  console.log(key + " は " + user[key]);
}
// 結果: name は アリ, age は 20...

```

---

### 3. `.forEach()` メソッド（配列の「全員」用）

配列専用の「おまかせ」ループです。最近のJavaScriptではこれが一番よく使われます。

* **イメージ：** 「この列に並んでいる **全員（ぜんいん）に**、同じお菓子を配って！」
* **特徴：** 番号（i）を気にせず、中身を直接取り出せます。コードが短く、読みやすいです。

```javascript
const fruits = ["りんご", "バナナ", "みかん"];

fruits.forEach(function(fruit) {
  console.log(fruit + "を食べます");
});

```

---

### 比較テーブル（使い分けのガイド）

留学生に「どれを使えばいい？」と聞かれたら、この表を見せてあげてください。

| 種類 | おすすめの使い道 | 留学生への例え話 |
| --- | --- | --- |
| **古典的な `for**` | 複雑なループ（逆順など） | 「1つ飛ばし」などの細かい指示 |
| **`for ... in`** | **オブジェクト** の中身を見る | カバンの中の「持ち物リスト」作り |
| **`.forEach()`** | **配列** の中身を全部処理する | 列に並んだ人へ「全員配布」 |

---

### 📝 留学生へのアドバイス

> 「まずは、配列には **`.forEach()`** を使うのが一番モダンでミスが少ないからおすすめだよ！
> でも、もし **『途中でループを止めたい（breakしたい）』** 時は、`.forEach()` は止まれないから、**古典的な `for**` を使うんだ。
> 状況に合わせて『道具』を選べるようになると、カッコいいエンジニアになれるよ！」

## II. `.map()` と `.filter()`

JavaScriptの配列（Array）を操作する上で、**`map()`** と **`filter()`** は最も重要で便利な道具です。

留学生の方には、これらを **「工場のベルトコンベア」** や **「カフェの注文」** に例えて説明してあげると、イメージがパッと湧きます。



### 1. `map()`：全員を「変身」させる

`map()` は、配列の **全員に同じ加工（かこう）をして、新しい配列を作る** ときに使います。

* **イメージ：** 「生（なま）のジャガイモ」が入ったカゴを機械に通して、全部「フライドポテト」に変える。
* **特徴：** 元の配列と同じ数だけ、新しい中身の配列ができあがります。

#### **コードの例（値段を10%引きにする）**

```javascript
const prices = [1000, 2000, 3000];

// 全員を 0.9倍（10%引き）に変身させる
const salePrices = prices.map(price => price * 0.9);

console.log(salePrices); // [900, 1800, 2700]

```



### 2. `filter()`：条件に合う人を「選ぶ」

`filter()` は、配列の中から**条件に合格（ごうかく）した人だけを取り出して、新しい配列を作る**ときに使います。

* **イメージ：** 「コーヒーを注文した人」だけを列から選び出す。
* **特徴：** 条件に合わない人は捨てられ、合格した人だけの新しい配列ができます。

#### **コードの例（合格点の人だけ選ぶ）**

```javascript
const scores = [45, 80, 60, 95, 30];

// 60点以上の人だけをパスさせる
const passScores = scores.filter(score => score >= 60);

console.log(passScores); // [80, 60, 95]

```


### 3. `map()` と `filter()` の使い分けまとめ

留学生に教えるときは、この「ひとこと」を伝えてください。

| メソッド | ひとこと説明 | 数はどうなる？ |
| --- | --- | --- |
| **`map()`** | **全員変身！** | 変わらない（3個→3個） |
| **`filter()`** | **合格者だけ！** | 減るかもしれない（3個→1個） |



### 4. 留学生への例え話：カフェの注文システム

カフェの店員さんの動きで考えてみましょう。

> 「お客さんのリスト（配列）があるとするね。
> 1. **`map()` の仕事：** 全員の名前の後ろに『様（さま）』をつける。
> （アリ → アリ様、リン → リン様）
> 2. **`filter()` の仕事：** 『アイスコーヒー』を頼んだ人だけを探す。
> （アリ様はホットだから×、リン様はアイスだから○ → リン様だけ残る）
> 
> 
> こうやって、データをきれいに整理するのがプログラミングの基本だよ！」



### 📝 応用編：つなげて使う（メソッドチェーン）

「1000円以上の商品だけを、10%引きにする」のように、組み合わせて使うこともできます。

```javascript
const items = [500, 1500, 2000, 800];

const result = items
  .filter(price => price >= 1000) // 1. まず1000円以上を選んで
  .map(price => price * 0.9);    // 2. その人たちだけ安くする

console.log(result); // [1350, 1800]

```



いかがでしょうか？「全員変身のmap」と「選別（せんべつ）のfilter」。この2つが使えるようになると、長い `for` 文を書かなくて済むので、コードがとてもスッキリします。

## III. reduce()

JavaScriptの配列操作の中で、もっともパワフルで、少しだけ理解にコツがいるのが **`reduce()`** です。

留学生の方には、これを**「雪だるま式（ゆきだるましき）に、一つにまとめる」**、あるいは**「お会計（かいけい）のレジ」**に例えて説明してあげてください。


### 1. `reduce()` とは？

`reduce` には「減らす」「まとめる」という意味があります。配列の中にあるたくさんのデータを、計算したり組み合わせたりして、**最終的に「1つの値」にする**ときに使います。

* **イメージ：** バラバラの野菜を、ミキサーにかけて1杯の「スムージー」にする。
* **特徴：** 合計（ごうけい）を出したり、最大値（さいだいち）を探したりするのに最適です。


### 2. 書き方のイメージ：お会計のステップ

`reduce` は、**「前の結果」を次に引き継ぐ**のが最大の特徴です。

```javascript
const numbers = [100, 200, 300];

// 合計を出す例
const total = numbers.reduce((accumulator, currentValue) => {
  return accumulator + currentValue;
}, 0); // ← 0 は「最初の数字」

console.log(total); // 600

```

#### **留学生への言葉の解説**

* **`accumulator`（アキュムレータ）：** **「これまでの合計」**。レジの画面に表示されている今の金額です。
* **`currentValue`（カレントバリュー）：** **「今の数字」**。今、店員さんが手に持っている商品の金額です。
* **`0`：** **「初期値（しょきち）」**。お会計が始まる前は0円ですよね。


### 3. 処理の流れ（シミュレーション）

配列 `[100, 200, 300]` の場合：

1. **スタート：** 合計は `0`（初期値）。
2. **1回目：** 合計 `0` ＋ 今の `100` ＝ **新しい合計 `100**`
3. **2回目：** 合計 `100` ＋ 今の `200` ＝ **新しい合計 `300**`
4. **3回目：** 合計 `300` ＋ 今の `300` ＝ **最終結果 `600**`


### 4. `map` / `filter` との違いまとめ

留学生に「いつどれを使うの？」と聞かれたら、こう答えてあげてください。

| メソッド | 動きのイメージ | 結果 |
| --- | --- | --- |
| **`map`** | 全員変身！ | 配列（同じ数） |
| **`filter`** | 合格者だけ！ | 配列（減るかも） |
| **`reduce`** | **全部まとめて1つに！** | **1つの値** |


### 5. 留学生へのアドバイス：他にもこんな使い道が！

> 「数字の合計だけじゃなくて、**『一番高い商品はどれ？』** と探したり、**『文字列を全部つなげて一つの文章にする』** 時にも使えるんだ。
> 最初は少し難しいけど、**『バトンを渡していくリレー』** だと思えば大丈夫。前のランナー（accumulator）が持っているバトンに、自分のパワー（currentValue）を足して、次のランナーに渡すんだよ！」


いかがでしょうか？「一つにまとめる」という感覚が掴めれば、データ処理の達人（たつじん）になれます！

## IV. 複雑なデータ処理

これまでの道具を全部使って、本格的な **「ショッピングカートの計算システム」** を作ってみましょう！

留学生の方には、 **「ベルトコンベア（map）で加工し、門番（filter）がチェックし、最後にレジ（reduce）で合算する」** という一連の工場の流れとして説明すると非常に分かりやすくなります。

---

### 🛒 実践：ショッピングカートのデータ処理

以下のルールで計算するプログラムを作ります。

1. **filter：** 在庫（ざいこ）がある商品だけを選ぶ。
2. **map：** 消費税（10%）をプラスした価格にする。
3. **reduce：** すべての合計金額を出す。

#### **元のデータ（商品リスト）**

```javascript
const cart = [
  { name: "iPhoneケース", price: 2000, stock: true },
  { name: "充電ケーブル", price: 1500, stock: false }, // 在庫なし
  { name: "モバイルバッテリー", price: 4000, stock: true },
  { name: "スクリーン保護シート", price: 1000, stock: true }
];

```


### 🛠️ プログラムの実行

```javascript
const totalPrice = cart
  .filter(item => item.stock === true)          // 1. 在庫があるものだけ選ぶ
  .map(item => item.price * 1.1)                // 2. それぞれに消費税10%を足す
  .reduce((total, price) => total + price, 0);  // 3. 全部を合計する

console.log(`合計金額（税込）は ${totalPrice} 円です！`);
// 結果：(2200 + 4400 + 1100) = 7700円

```


### 💡 留学生へのステップ解説

留学生にこのコードを説明するときは、**「データの旅」**を追ってみてください。

| ステップ | 状態 | 残っているデータ |
| --- | --- | --- |
| **スタート** | 最初 | 4つの商品すべて |
| **① filter** | 在庫チェック！ | 充電ケーブルが消えて、残り3つ |
| **② map** | 値札（ねふだ）の書き換え | 2000→2200, 4000→4400, 1000→1100 |
| **③ reduce** | レジでお会計 | **7700** という「1つの数字」に！ |


### 🌟 留学生へのアドバイス：ドット（ . ）でつなぐ魔法

> 「このように、命令をドット `.` でつなげて書くことを **『メソッドチェーン』** と呼ぶよ。
> 1. `filter` でいらないものを捨てる。
> 2. `map` で形を整（ととの）える。
> 3. `reduce` で最後にまとめる。
> 
> 
> この順番で考えると、どんなに複雑なデータもきれいに処理できるよ。まるで魔法のパイプラインみたいだね！」


### 📝 もう一歩進むなら？

「合計が5000円以上のときは送料無料（むりょう）」といった条件を、最後に追加してみるのも良い練習になります。

```javascript
const shippingFee = totalPrice >= 5000 ? 0 : 500;
console.log(`送料込みの最終支払額は ${totalPrice + shippingFee} 円です。`);

```


いかがでしょうか？バラバラの知識が一つにつながると、プログラミングがぐっと楽しくなります。
